## 小沙弥的设定图

- **`monk-sheet-v6-2026-11-22-eyes-closed.webp`：第六版，闭眼，#642 换脸和调色的依据。** 所有者 2026-11-22 用 GPT Image 出的四视图（正、侧、背、背着斗笠的斜背面），在与美术总监的对话里选定：闭眼、短平眉、浅笑；褐橘的袍，袍到膝；念珠是一条松的长串，垂到胸口，后颈只露两三颗；斗笠与肩同宽，两根细带过肩。仓库里这份是对话里贴的那张的副本（2000 像素宽，不是原始大图）。美术总监的意见：可以定稿；里衬领子在后颈可再露一道细边；袍色进殿内暗处若发闷再往橘回一点（进场景后判）。它只定脸、颜色、念珠和斗笠的样子，不改骨架。
- **`monk-props-v6-2026-11-22.webp`：第六版的道具图，念珠和斗笠。** 所有者 2026-11-22 用 GPT Image 出，配上面那张人物图。念珠：约 38 颗同大的圆木珠，一颗大的母珠带一小束穗，平铺、侧看、近看各一。斗笠：浅锥形竹编，顶上一个小结，俯视、侧视、从下往里看各一，里面有帽圈和两根细带。美术总监的意见：形可以照着做；三处以人物图为准，不照这张：(1) 两根带子画短了，够不到肩，长度照人物图上过肩的样子；(2) 下面那个比例剪影上没有画斗笠，斗笠的大小照人物图（与肩同宽）；(3) 珠子的颜色比人物图上的更橘更亮，照人物图的红褐。仓库里这份是对话里贴的副本（1672 像素宽）。
- **`monk-poses-v6-2026-11-23-sitting.webp`、`monk-poses-v6-2026-11-23-gassho-head.webp`、`monk-poses-v6-2026-11-23-hat-worn.webp`：第六版的三张补充图。** 所有者 2026-11-23 用 GPT Image 以第六版四视图（斗笠那张另加道具图）为参考出的，提示词是美术总监写的，为的是用代码照设定图重画时有姿势可依（#642）：盘坐和凳坐各正、侧；头部正、侧近照和合掌正、侧；斗笠戴在头上的正、侧、背。美术总监看过，三张可用，脸没有跑。**它们只管姿势、布怎么垂、东西怎么戴；长相、颜色、比例只认四视图，斗笠和念珠的做法只认道具图。** 各张不要照的：坐姿图的袍色偏褐；合掌那两格的袖子画长了、念珠画到了腰带；戴笠图的笠偏陡、编纹画成了方格。仓库里是对话里贴的图的副本（1536×1024）。
