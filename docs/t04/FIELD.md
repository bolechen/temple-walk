# T04 现场采集清单

核对日期：2026-11-17。本文是「如果要去现场，带什么、问什么、拍什么、记什么」。
**没有现场许可就不做**；进入寺院与获准拍照不等于获得商业图片/录音授权。

---

## 0. 先去之前

### 0.1 许可与边界

- [ ] 向**张掖市甘州区博物馆/大佛寺文物管理所**说明来意：游戏场景研究、非商业发布前的资料采集；问清是否允许拍照、测量、录音。
- [ ] 向**张掖市文化广电和旅游局**/甘肃省文物局（如涉及测绘/扫描）咨询；专业测绘（全站仪/RTK/激光扫描）必须另行取得文物部门许可。
- [ ] 向**寺院常住/客堂**说明：这是宗教活动场所，不是只有博物馆；问清法事/香客/闭关时间，避免打扰。
- [ ] 说明用途：网页游戏《山门之外》的 T04 关卡；是否收费未定；素材是否进游戏、是否商用，要如实说。
- [ ] 问清：哪些殿可进、哪些区域不开放、大佛殿内是否可停留/拍摄、藏经阁是否开放、土塔/地宫是否可接近、能否上塔。
- [ ] **山西会馆、张掖市博物馆、木塔寺是不同管理方**；分别问，不并入 T04。
- [ ] 不使用无人机；不架三脚架堵路；不在殿内使用闪光灯；不拍摄正在礼佛的人正面；不进入标有「游客止步」的区域。
- [ ] 遵守开放时间（OSM 标 08:00–18:00；以当日公告为准）；门票约 20 元（以现场为准）。[S13；摘要]
- [ ] 若管理方拒绝，尊重并停止；不偷拍、不绕开、不冒充记者/学者/官方。

### 0.2 装备

- 相机 + 24–70 mm / 70–200 mm；广角 16–35 mm；大光圈定焦（殿内暗，不用闪光）。
- 手机（记录 GPS、时间、指南针、水平仪）。
- 激光测距仪（室内 40 米够用；**人眼安全**，不对人）；卷尺 5 m；粉笔/标记贴（不损伤表面）。
- 录音机 + 防风毛套 + 立体声话筒；耳机。
- 色卡（X-Rite 或灰卡）；白平衡卡。
- 笔记本/表格；笔；头灯（低亮、红光，不直射壁画/佛像）。
- 水、伞、防滑鞋；冬天防寒，春天防风沙。
- **不携带**：无人机、大型灯架、反光板（殿内）、扩音器、闪光灯、激光扫描仪（除非有许可）。

## 1. 空间与建筑测量

### 1.1 总体

- [ ] 山门中心 GPS、海拔（手机 GPS 即可，标误差）。
- [ ] 山门—大佛殿、—藏经阁、—土塔的**水平距离**（激光/测距仪 + 步测）。
- [ ] 每段台地/台基的高差（激光测距仪从台面到台面，或用水准仪）。
- [ ] 每段台阶：级数、级高、踏面、总宽、有无垂带/栏板。
- [ ] 主要路线的宽度（最窄处）；侧廊最窄处。

### 1.2 大佛殿（重点，至少 90 分钟）

- [ ] 平面：面阔九间的逐间宽度（柱中到柱中）、进深七间的逐间深度、台基宽/深/高。
- [ ] 立面：檐口高、屋脊高、台基高、门高/宽、窗高/宽。
- [ ] 屋顶：重檐/三滴水的上下檐关系、举高、出檐、瓦作、脊饰。
- [ ] 柱：柱径、柱础、收分、侧脚、生起；内柱/檐柱的数量与位置。
- [ ] 斗栱：有无、几铺作、出跳、材等；清代做法还是西夏遗风。
- [ ] 墙：颜色（色卡）、厚度、墙脚返潮高度、风蚀/雨痕/剥落。
- [ ] 门：门洞净宽/净高、门槛高、门钉/门簪/抱鼓石；两侧砖雕尺寸/位置。
- [ ] 佛坛：平面尺寸、高度（1.2 m？）、供桌/香炉/长明灯位置。
- [ ] 卧佛：长度、肩宽、脚长、耳长；头/脚到墙的距离；离地高度。
- [ ] 31 尊：十大弟子/二胁侍/十八罗汉的位置、高度、间距；侧廊最窄处。
- [ ] 壁画：面积、位置、病害、是否可拍（不用闪光）；逐幅题材/年代（需文物部门配合）。
- [ ] 殿内曝光：门外/门内/佛首/佛脚/侧廊的 EV；下午 15:00–18:00 的西晒角度。

### 1.3 藏经阁（至少 30 分钟）

- [ ] 平面：21.3×10.5 m 的实测；台基高、门/窗。
- [ ] 经橱：数量、尺寸、排列；是夹壁内还是展柜；能否看柜门/标签。
- [ ] 展柜：尺寸、玻璃/亚克力、灯光、照度（lux）、紫外线。
- [ ] 经卷：北藏/金经的展陈方式（半开/整卷/复制）；卷数口径。
- [ ] 说明牌：文字、尺寸、位置、语言。

### 1.4 土塔（至少 20 分钟）

- [ ] 基座：23 m 见方、高、材料。
- [ ] 塔身：13 层/节的逐层高度/收分；覆钵/相轮/华盖。
- [ ] 36 风铎：位置、尺寸、材质、音高（若可录）。
- [ ] 地宫/博物馆：入口、开放范围、展品（若允许）。
- [ ] 塔院：环道宽度、与藏经阁/大佛殿的距离。

### 1.5 山门/钟鼓楼（至少 20 分钟）

- [ ] 山门：三间各间宽、进深、门洞、门槛、屋顶。
- [ ] 钟楼/鼓楼：平面、层数、屋顶、钟/鼓尺寸；是否可登。
- [ ] 前院：铺地、树、香炉、石狮/旗杆。

## 2. 照片清单

### 2.1 每栋建筑（至少 6 张）

1. 正面（含台基与门）。
2. 左前 45°。
3. 右前 45°。
4. 侧面（含进深）。
5. 背面（若可绕）。
6. 屋顶/檐下/斗栱/砖雕特写。

### 2.2 每处关键物

- [ ] 山门：门洞、门钉、门簪、抱鼓石、匾、石狮。
- [ ] 大佛殿：重檐、门、砖雕、佛坛、卧佛（头/手/脚/耳）、十大弟子、十八罗汉、壁画四壁/佛身后/二层。
- [ ] 藏经阁：经橱、展柜、金经/北藏、说明牌。
- [ ] 土塔：全景四向、13 层、风铎、塔刹、地宫入口。
- [ ] 钟鼓楼：钟/鼓、楼层、屋檐。
- [ ] 城市界面：广场、博物馆、小学、饭店、住宅（不拍人正脸）。
- [ ] 古树：国槐/刺槐/杨树；树根/树冠/名牌。

### 2.3 光线与天气

- [ ] 同一天至少拍「上午/正午/下午 16:00–17:30」三组，记录时间、天气、太阳方向。
- [ ] 下午西晒：门外/门内/佛首/佛脚各一张，记录曝光。
- [ ] 雨天/雨后（若遇到）拍湿石、土红墙、广场。
- [ ] 风沙/薄霾（若遇到）拍城市背景与土塔。
- [ ] 冬季（若遇到）拍雪后土塔/屋顶/广场。

### 2.4 元数据

每张照片记录：文件名、时间、地点、朝向、镜头/焦距、光圈/快门/ISO、白平衡、天气、许可、备注。
回来按建筑/主题建文件夹，保留原图，不覆盖。

## 3. 声音

见 `SOUND.md` 第 2 节。补充：

- [ ] 每条 60–90 秒，同一天、同设备。
- [ ] 记录声压（手机 App 即可，标误差）或至少「安静/一般/吵」。
- [ ] 不录可辨识的人声；若无法避免，回来说明并删除。

- [ ] 殿内：录 room tone（无人时）3–5 分钟；脚步/衣料/门轴/纸/木柜。
- [ ] 不录诵经/法事，除非明确授权；不录游客谈话。
- [ ] 广场/城市：只录环境，不录报站/可辨人声。

- [ ] 不把寺方/文物部门的内部文件、平面图、安防信息写进公开仓库。

## 7. 礼仪、安全与文保

### 7.1 文保红线

- **不触摸**佛像、壁画、经橱、碑刻、砖雕、风铎；不倚靠栏杆/展柜。
- **不使用闪光灯**；不在殿内使用三脚架/灯架（除非许可）。
- **不拓印/不采样/不刮取**任何表面。
- **不攀爬**佛像/佛坛/土塔/屋顶/栏杆。
- **不进入**佛坛后、经橱后、夹壁、地宫、标有「游客止步」的区域。
- **不移动**香炉/供品/蒲团/说明牌。
- **不投喂**动物；不摘植物。
- 若发现壁画/塑像有病害，记录位置/照片，报告管理方；不自行处理。

### 7.2 礼仪

- 不挡香客礼佛；不拍人脸；不进入法事区域。
- 殿内不喧哗、不饮食、不吸烟、不接电话。
- 尊重宗教场所：不跨过供桌/蒲团；不背对佛像自拍；不做出轻慢动作。
- 若被问起，如实说明是游戏研究；不冒充记者/学者/官方。
- 若管理方/僧人拒绝，尊重并停止。

### 7.3 安全

- 殿内暗、门槛高、地面不平；带头灯（低亮/红光），小心脚下。
- 冬天冷、地面滑；春天风沙；夏天防晒/补水。
- 不单独在闭馆后停留；不进入施工/维修区域。
- 激光测距仪不对人眼；不站在梯子/栏杆上。

## 8. 回来之后

1. 当天备份、算 hash、写备注。
2. 把「能支持的事实」逐条写进 `SOURCES.md`；把「照片里看到的」与「文字资料说的」分开。
3. 更新 `SITE.md` 的尺寸/高程（若有实测）。
4. 更新 `ARCHITECTURE.md` 的形制（若有新发现）。
5. 把新照片/录音的授权状态写进 `asset-register.csv`。
6. 若发现本包的推断有错，直接改，并在 `README.md` 记一条「2026-xx-xx 现场修正」。
7. 把「不能公开」的信息（安防、内部平面、未授权照片）单独存放，不进仓库。
