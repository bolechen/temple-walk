# T04 声音设计调研

核对日期：2026-11-17。T00/T01 的音频全部是 Web Audio 合成，没有录音；T04 默认沿用这条路线。
本文先写「现场有什么声」，再写「哪些能合成、哪些必须录、哪些不用」。T04 的关键不是「加声音」，而是**留静默**。

---

## 1. 六段声场

| 段 | 位置 | 主导声 | 次要声 | 不该有的 |
|---|---|---|---|---|
| Z1 广场/山门外 | 大佛寺广场、民主西街 | 城市低频、远处车流、脚步、风 | 树声、鸟、远处人声（不可辨） | 叫卖/广播/音乐 |
| Z2 山门/前院 | 山门内、钟鼓楼 | 门洞压低后的城市闷响、风过门洞 | 钟/鼓（稀疏）、槐/杨叶、脚步 | 突然静音；门内完全听不见城市 |
| Z3 门口适应区 | 大佛殿门槛 | 门槛内外的声场切换；殿内长混响 | 衣料、呼吸、脚步、远处木构 | 恐怖片式低频/心跳 |
| Z4 巨像近侧 | 佛首/佛手 | **近静默**、殿内 room tone | 细微木构、尘、远处鸟、极轻的风 | 音乐/诵经/人声 |
| Z5 侧廊 | 佛脚—佛首 | 脚步（石/木）、衣料、长混响 | 十八罗汉的「无声」、远处门洞 | 每个塑像配一个音效 |
| Z6 经卷展柜/院外 | 藏经阁、土塔、广场 | 纸、木柜、风铎（36）、城市远声 | 脚步、铜锁、鸟 | 宝库音效/金币声/开箱声 |

### 1.1 声压与距离（提案，需现场测）

- 广场：城市低频约 55–65 dB(A)（普通城市广场，未测）。
- 山门内：50–55；前院：45–50；殿门口：40–45；殿内：30–35；佛首/侧廊：25–30。
- 土塔/院外：35–45（风铎 + 城市）。
- **殿内比殿外低 10–15 dB(A)**；这是 T04 最重要的声学对比。真实数据要现场测。

### 1.2 时间

- 上午：游客少、鸟多、城市低。
- 下午：游客多、西晒、风起；16:00–17:30 是 T04 的基准。
- 傍晚：城市下班车流、风铎、光低。
- 夜间：不开放；若做夜景，只有风、风铎、远处城市。

## 3. 合成方案（默认路线）

T00 的 `audio.js` 有三条总线（音乐、山声、音效）、两套混响（庭院、木构殿内）、`instruments.js` 的琴/箫/泛音/钟/鼓。T04 新增：

| 声 | 合成做法 | 复用 |
|---|---|---|
| 城市低频 | 粉红噪声 + 低通 200–400 Hz + 缓慢 LFO；按距离/门洞衰减 | 新 |
| 车流 | 噪声 + 随机经过的带通扫频；不要每辆都一样 | 新 |
| 广场人流 | 宽带噪声 + 稀疏脚步脉冲；不辨人声 | 新 |
| 门洞 | 低通 + 短混响；内外切换 | 新 |
| 殿内长混响 | 大木构/石殿 impulse；3–5 s；早期反射稀疏 | 新 |
| 脚步 | 复用 `steps.js`；新增石/砖/木/土 | 复用 + 新 |
| 衣料/呼吸 | 细噪声 + 低频；近景；只在静止/走动时 | 新 |
| 风铎（36） | 小铜铃：几个不谐和分音 + 随机轻击；36 个不同相位的稀疏事件 | 新 |
| 钟/鼓 | 复用 T00 `bell()` / 鼓；钟楼/鼓楼 | 复用 |
| 纸/木柜/铜锁 | 纸页摩擦、木门、铜锁轻响 | 新 |
| 鸟 | 复用 `bird()`；院外/土塔，白天 | 复用 |
| 音乐 | 新主题（见 §4）；低音持续/箫/琴；殿内几乎无音乐 | 新 |

**原则**：
- **静默是主声**：殿内大部分时间只有 room tone + 脚步；不要用音乐填满。
- 城市声是「底」，不是「事件」；不要每隔几秒来一辆车。
- 寺内声是「点」，钟、鼓、磬、木鱼要稀疏；不要循环成背景音乐。
- 殿内声是「空间」，长混响、低电平；不要每个塑像配一个音效。
- 土塔风铎是「偶发」，不是「连续铃声」；36 个铃不等於 36 个同时响。
- 不做「宝库/开箱/金币」音效；不做「佛肚心跳」；不做「Boss 低频」。

### 3.1 与 T00/T01 的差异

| T00/T01 | T04 |
|---|---|
| 竹林风、竹击、龙井滴水、檐下滴水、鸟只在山上 | 城市低频、门洞、殿内长混响、风铎、纸/木 |
| 墙内只有钟磬 | 墙内极远的城市底噪（广场/山门） |
| 山顶回望是群山 | 院外回望是土塔/城市 |
| 仪式音乐（钟、茶、香、坐） | 几乎没有仪式；只有看/走/读 |
| 七印/朱印的反馈音 | 长照札记的纸/笔反馈（极轻） |

## 4. 配乐

> 资料库 T04 没有强制配乐；本包建议「先做环境声，再决定音乐」。T04 的殿内应该**没有连续配乐**，只有极少的持续音/箫。

### 4.1 结构提案

- **调式**：可用 G 羽或 D 羽；比 T00 更「空」、更慢；不要五声音阶的甜美。
- **乐器**：低音持续（大鼓/低音弦的极轻持续）、箫的呼吸、琴的泛音；不要编钟/电子。
- **段落**：
  - Z1 广场：只有城市低频 + 一点琴的泛音，几乎不是音乐。
  - Z2 山门：一个低音，像门洞的风。
  - Z3 门口：音乐退到几乎无；只留一个持续音。
  - Z4 佛首：**静默**；最多一个极轻的箫音，像呼吸。
  - Z5 侧廊：脚步/衣料/混响；音乐不进来。
  - Z6 院外：土塔风铎 + 城市；音乐只在最后一句，停在未解决音。
- **与钟的关系**：钟声响起时音乐退后 14 秒（复用 T00 的 `strike()` 规则）；T04 的钟声更少。
- **与风铎的关系**：风铎不是音乐，是环境；不要给它配和弦。

### 4.2 不要做

- 不要用「西域/异域」音阶/手鼓/电子做「西夏风情」；T04 不是异域奇观。
- 不要用可辨识的佛号/诵经采样，除非取得授权。
- 不要让音乐盖过脚步/风铎/静默。
- 不要在佛首/侧廊放「神圣合唱」；那是游客想象，不是现场。

## 6. 验收

- [ ] 广场能听见城市；进山门后城市变闷；进殿后只剩极远底噪。
- [ ] 殿内有 3–5 秒长混响；脚步/衣料可辨；没有音乐填满。
- [ ] 佛首/侧廊有静默段（≥3 秒无新事件）；不是「一直有声音」。
- [ ] 风铎稀疏、偶发；不是连续铃声/旋律。
- [ ] 没有可辨识的游客谈话/诵经/报站人声（除非授权）。
- [ ] 没有「宝库/开箱/金币/心跳/Boss」音效。
- [ ] 切换不爆音、不突然静音；门洞内外过渡平滑。
- [ ] 音乐不盖过脚步、风铎、静默；钟声时音乐退后。
- [ ] 现场录音（若有）与合成层能分开调音量。

**注意**：自动测试只能证明「不削波、按规则切换、频率对」，不能证明「好听/安静」。T04 的音频最终要真人试听，尤其是在殿内站 2–3 分钟。
