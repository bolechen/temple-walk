# T04 美术方向与候选机位

核对日期：2026-11-17。本文不是最终美术定稿，是把「张掖大佛寺这块地长什么样」翻译成可执行的光、色、构图与验收口径。
通用原则仍以 [`../ART-SPEC.md`](../ART-SPEC.md) 为准；本文只写 T04 与 T00/T01 不同的部分。

---

## 1. 一句话方向

**「土色的城，深木的殿，一束从西面门进来的侧光照在 34.5 米的卧佛上。」**
不是江南的白墙，不是武汉的黄墙琉璃，也不是沙漠的孤寺；是河西绿洲城里的一座西夏皇家寺院，干、亮、土红、深褐，金只在佛像与经卷上。

与 T00/T01 的差别：

| 维度 | T00 云径禅寺 | T01 栖岚寺 | T04 长照寺 |
|---|---|---|---|
| 主色 | 白墙、深木、灰瓦、竹绿 | 黄墙、朱柱、琥珀琉璃、青石 | **土红/赭石墙、深褐木、深灰瓦、暗金** |
| 光 | 阴天雨后的柔光 | 秋雾/冬晴 | **秋末低西晒、室内侧向天光、硬光长影** |
| 远景 | 五峰、云海、竹林 | 城市屋顶线 | **土塔、低层城市、绿洲树冠** |
| 近景 | 竹、柳杉、石阶 | 黄墙、石狮、菜薹田 | **厚墙、砖雕、佛坛、经橱、土塔** |
| 情绪 | 出世、静 | 入世中的静 | **在巨像前的身体感/时间感** |
| 季节 | 夏昼 | 秋雾/冬晴 | **秋末晴日 16:00–17:30（提案）** |
| 室内 | 宋式殿内、冷暗 | B02 冷暗内殿 | **Z01 室内侧向天光：暗、暖、干、尘** |

## 2. Z01 室内侧向天光（Interior Side Daylight）

这是 T04 的核心照明预设。名字里的「侧向」有两层：

1. **对建筑**：光从西面门/高窗进来，照在东墙上，是侧光；
2. **对卧佛**：佛身南北向，光从西面来，正好**侧擦佛身**，不是正面平光；佛的脸朝西，得到的是门洞的柔光/反射光，不是直射。

### 2.1 参数（设计提案，不是现场测量）

| 项 | 值 | 说明 |
|---|---|---|
| 时间 | 秋末 16:00–17:30 | 太阳低、西晒正对殿门 |
| 太阳方位 | 245°（WSW） | 张掖秋末下午的近似方位；现场再核 |
| 太阳高度 | 18° | 低角度，长影 |
| 太阳色温 | 3,400 K | 暖，但不橙 |
| 天空/天光 | 5,200 K | 干、灰蓝 |
| 室内反射/补光 | 4,200 K | 土红墙/深木的反弹，不是蓝色补光 |
| 灯火 | 2,200 K | 佛前长明灯/酥油灯，小范围 |
| 门洞 | 3.6 m 宽 × 5.5 m 高 | 白盒提案；真实净宽待测 |
| 光柱进深 | 10–14 m | 从门射入，落在佛身中段/侧廊 |
| 曝光 | 门外 EV 10 / 殿内 EV 6 | 高光滚降；暗部保留 0.15 细节 |
| 雾/尘 | 0.12–0.18 / 尘 0.3 | 只在光柱里可见；不是全屋雾 |
| 对比 | 高光:暗部 ≈ 1:8 | 不是死黑；壁画/梁架可读 |

### 2.2 光的来源与叙事

- **主光**：西面门。下午的太阳低，光穿过门洞，落在佛身/侧廊地面上；光柱里有尘。
- **次光**：门洞/地面的反弹，照亮佛的面部/胸部；不是直射。
- **第三光**：佛前长明灯/酥油灯，暖、小、只在佛首/供桌附近。
- **远光**：二层板壁/高窗的微弱天光，勾出屋顶/梁架；不要做成「天窗洒圣光」。
- **暗部**：佛身后（东）、侧廊尽头、屋顶下；暗，但能看见衣纹/壁画/罗汉的轮廓。

### 2.3 必须避免

- 直射阳光打在佛脸上（会变成「舞台追光」/「Boss 登场」）。
- 全局橙色滤镜/暖色 LUT；T04 的暖只来自太阳/灯火/土墙。
- 金色泛光/bloom 过强；暗金不是亮金。
- 无来源的「god ray」；只有门洞光柱里有尘。
- 死黑：佛身后、侧廊、屋顶下要保留细节；壁画不能黑成一片。
- 现代展陈灯/射灯/Track light；T04 是古建/寺庙，不是美术馆。

### 2.4 冬季变体

- 雪后：门外青白反光，殿内更冷；灯火更暖；土塔/屋顶有雪。
- 光比更大：门外 EV 11 / 殿内 EV 5；用曝光过渡/眼睛适应，不要硬切。
- 只作变体，不作基准；最终由所有者看图定。

**纪律**（照 ART-SPEC）：
- 暖色必须来自可信的光或材料，不做全局橙色滤镜。
- 低饱和不等于灰片；檐下、门洞、通路、壁画要看得清。
- 土红墙不是一整片均匀的红：墙脚返潮、风蚀、雨痕、手摸的位置要有。
- 金色只出现在佛像/经卷/铜器/少量装饰；不要把整座殿做成金色。
- 深灰瓦不是 T00 的灰白瓦；它是更重、更干的灰。
- 壁画颜色要比墙面鲜一点，但不能做成现代高饱和。

## 4. 基准季时

### 4.1 第一版：秋末晴日 16:00–17:30

- 天空：干、灰白/灰蓝，薄云或晴。
- 光：低西晒，硬、暖；门洞光柱；长影。
- 地面：石/砖干、灰；墙脚有干土/风蚀。
- 植物：国槐/刺槐/杨树，叶黄/半落；不是竹。
- 城市：广场、低层屋顶、树冠；远处土塔。
- 为什么：寺门朝西、卧佛面西；低西晒是「室内侧向天光」的天然来源；干空气让光硬、影长；土塔在低光下是暖色剪影。[设计提案]

### 4.2 变体：冬雪

- 雪后土塔/屋顶/广场；门外青白反光；殿内暖灯。
- 只作变体；雪量/日期不可预测，不做「保证有雪」的关卡。
- 与 T01 的冬晴区分：T01 是城市山寺的塔影田；T04 是河西巨殿的雪光/土塔。

### 4.3 不推荐：盛夏正午

- 硬光、热、反差过大；门洞光柱变成一小块，殿内太黑。
- 与 T00 夏昼重复；T04 的「西晒」故事也消失。

**最终由所有者看图定。** 白盒阶段一律中性日光；Z01 与冬雪是两条并列的对照线，不互相覆盖。

## 5. 六个候选机位

坐标是相对山门的本地坐标（+x 东，+z 南，米）；`ground_m` 是本地地坪高，`eye_m` 是眼高（在地坪之上）。
详细 JSON 见 `camera-manifest.json`。六个机位对应资料库的六段：前院、门口适应区、巨像近侧、侧向观察、经卷展柜、院外远景。

### CAM-01 前院（山门内）

- 位置：(8, −2)，地坪 0.4 m，眼高 1.62 m。
- 朝向：yaw 80°（东偏北），pitch +3°，fov 60°。
- 画面：近景是山门内的铺地/门槛；中景是钟楼（右）、鼓楼（左）、第一进院落；远景是大佛殿的深檐与土塔尖。**不要看到整尊卧佛**。
- 光：Z01 的门外/院内光；土红墙、深木、深灰瓦。
- 要验证：轴线是否清楚；钟鼓楼是否压得住；土塔是否露出；是否一眼看出「土色的城」。

### CAM-02 门口适应区（大佛殿门槛）

- 位置：(62.5, −15.8)，地坪 1.2 m，眼高 1.62 m。
- 朝向：yaw 90°（东），pitch +3°，fov 50°。
- 画面：近景是门槛/门框/砖雕；中景是殿内暗部；**只在门框内看到佛的侧身一小块**，不是全长；远景是佛坛/佛身/十大弟子的暗影。
- 光：门外亮、门内暗；曝光过渡 2–3 秒；光柱/尘。
- 要验证：门内是否可读；是否只看到局部；砖雕是否可辨；是否有「眼睛适应」的过渡。

### CAM-03 巨像近侧（佛首/佛手）

- 位置：(68, −27)，地坪 1.2 m，眼高 1.62 m。
- 朝向：yaw 56°（东南），pitch +6°，fov 44°。
- 画面：近景是佛首/佛手/耳；中景是佛身向佛脚延伸；远景是十大弟子/东墙。**不要切掉佛首**。
- 光：西面门的侧光擦过佛脸/手；面部靠反弹光；不是正面追光。
- 要验证：面部/手是否可读；耳/手的尺度是否比人高；是否有「身体在巨像前」的感觉；是否像「Boss 登场」（失败）。

### CAM-04 侧向观察（佛脚端，沿佛身向北看）

- 位置：(72, +7)，地坪 1.2 m，眼高 1.62 m。
- 朝向：yaw 5°（北偏东），pitch +4°，fov 55°。
- 画面：近景是佛脚/佛坛南端；中景是 34.5 米佛身向佛首延伸；远景是佛首/东墙；左侧/右侧是十八罗汉与侧廊。**头/脚都要在画面内，不能被切**。
- 光：西面门的侧光从右（西）擦过佛身；侧廊尽头暗；佛脚/佛首有微弱的轮廓光。
- 要验证：全长是否成立；34.5 米的透视是否被压缩；侧廊是否 ≥2.5 m；头/脚是否被切；十八罗汉是否像「一排」而不是「一堆」。

### CAM-05 经卷展柜（藏经阁内）

- 位置：(166, −19.3)，地坪 1.0 m，眼高 1.62 m。
- 朝向：yaw 90°（东），pitch 0°，fov 44°。
- 画面：近景是经橱/展柜/说明牌；中景是金经复制/北藏卷册/经卷封面；远景是东墙/窗。**不要开柜/不要取经**。
- 光：低照度、暖白 3,000 K；展柜内小灯；无紫外线；金不泛光。
- 要验证：说明牌是否可读；金经是否「暗金」不是「亮金」；是否像「宝库」（失败）；纸/绢的颜色是否准。

### CAM-06 院外远景（广场回望）

- 位置：(−95, +17)，地坪 0.0 m，眼高 1.62 m。
- 朝向：yaw 80°（东偏北），pitch +5°，fov 55°。
- 画面：近景是广场/树/行人（不拍正脸）；中景是山门、钟鼓楼、大佛殿深檐；远景是土塔 33.37 m 在屋顶之上，再远是低层城市/树冠。**土塔不能被屋顶完全挡住**。
- 光：下午的低西晒在背后（相机向西看？不，相机向东看，太阳在背后），山门/屋顶被照亮；土塔暖色。
- 要验证：土塔是否露出；城市是否低层；是否误用群山/沙丘；是否看出「寺在城里」。

### 5.1 机位纪律

- 六个机位都要能站人、能走上去；不能悬空/穿墙。
- 每个机位拍 16:9、4:3、9:16 三种画幅（T00 的 `shots.js` 支持）。
- 每个机位至少拍「基准季时 + 一个备选季时」。
- 机位定稿后写进 `camera-manifest.json`，由 `tools/cameras.mjs` 生成清单。
- 机位坐标是本包提案；白盒后按实际几何修正。

## 6. 构图与「尺度弧」

T04 的构图不是「一张比一张大」，而是**局部—侧身—全长—经卷—远景**的尺度弧：

| 段 | 机位 | 看到什么 | 手段 | 失败的样子 |
|---|---|---|---|---|
| 1 前院 | cam01 | 山门/钟鼓楼/殿檐/土塔尖 | 低机位、轴线、三层景深 | 一眼看到整尊佛；土塔被挡 |
| 2 门口 | cam02 | 门框、砖雕、殿内暗部、佛的侧身一小块 | 门框取景、曝光过渡 | 门内死黑；整尊佛在画面里 |
| 3 巨像近侧 | cam03 | 佛首/佛手/耳、十大弟子 | 近景、侧光、仰角 | 像 Boss 追光；面部过曝/死黑 |
| 4 侧向 | cam04 | 34.5 米全长、佛脚→佛首、十八罗汉 | 长透视、头/脚入画、侧光 | 头/脚被切；透视压扁；侧廊太窄 |
| 5 经卷 | cam05 | 经橱/金经/北藏/说明牌 | 低照度、展柜、暗金 | 像宝库；金泛光；字不可读 |
| 6 院外 | cam06 | 土塔/屋顶/城市 | 回望、低层城市、土塔在屋顶上 | 群山/沙丘替代城市；土塔被挡 |

**核心原则**：**先让玩家觉得「这殿很大」，再让他发现「佛比殿还长」**。门口只给局部；侧廊才给全长；院外才给「寺在城里」的整体。

## 7. 验收口径（看图时问什么）

### 7.1 每张图

- [ ] 主体（佛/殿/塔/经卷）是否在三分线或中心，是否被切？
- [ ] 近景/中景/远景是否至少有三层？
- [ ] 阴影里是否看得清梁柱、门洞、通路、壁画？
- [ ] 土红墙是否有风蚀/雨痕/返潮，而不是一片平涂？
- [ ] 金色是否克制（暗金，不是亮金）？
- [ ] 光是否来自可信来源（西面门/灯火/天光），而不是全局橙？
- [ ] 是否有不属于河西/清代的器物（日式石灯笼、藏式经幡、江南白墙）？
- [ ] 佛像是否像「涅槃」而不是「睡觉/Boss」？
- [ ] 经卷是否像「纸/绢/木轴」而不是「宝箱」？

### 7.2 整组

- [ ] 六张是否像同一座寺、同一季节、同一天？
- [ ] 是否一眼看出「河西绿洲城里的巨殿」，而不是「沙漠孤寺/江南寺院」？
- [ ] 尺度弧是否成立（局部—侧身—全长—经卷—远景）？
- [ ] 土红、深木、暗金、绀青是否形成可记忆的色组？
- [ ] 与 T00/T01 的六张并排，是否明显是另一座寺？

### 7.3 不能做的事

- 不用生成图冒充现场照片；生成图只定氛围。
- 不把 T00 的宋式大殿/白墙直接刷土红当 T04。
- 不把大佛殿做成金色琉璃/故宫式。
- 不把土塔做成楼阁式塔/金色佛塔。
- 不把卧佛做成「睡佛」/「Boss」/「宝箱」。
- 不把城市做成赛博/玻璃幕墙；张掖是低层绿洲城市。
- 不做「满殿红灯笼/祈福带」的网红寺。
- 不做「佛肚探险/取宝」的画面。

## 8. 目标图怎么来

T00/T01 的经验：目标图分两类——**真实照片**（定格局与配色）与**生成参考**（定氛围，不证明构造）。T04 建议：

1. **真实照片**：从 Commons 选 3–6 张（山门/大佛殿/土塔/经藏），只作研究；CC BY-SA，不进游戏。[S16]
2. **目标图**：在白盒截图的基础上做「光色草图」（不改变几何），标注「参考，不是实机」；Z01 的侧光可以先用手绘/灰盒。
3. **实机验收图**：必须来自 T04 的页面，标 commit 与 GPU job。

**注意**：张掖大佛寺的卧佛/壁画照片不能直接做贴图；没有扫描/摄影授权。原创模型/壁画纹理必须从零做，参考照片只定比例/色调。[S00]

## 9. 与 T00 美术线的衔接

T00 的美术分五阶段：便宜的电影感 → 间接光 → 体积光 → 植被 → 材质细节。T04 不必重走一遍；直接继承已完成的部分，只补：
