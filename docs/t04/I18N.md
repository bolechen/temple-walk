核对日期：2026-11-17。T00/T01 的规则照旧：**中文是记录文本**，日/英/韩由中文查表；新增文字四种语言齐全，字体重新裁切。

## 2. 命名政策

### 2.1 寺名

- 资料库定名：**长照寺**；候选：**长觉寺**。[S00]
- 真实原型：**张掖大佛寺**（甘肃张掖甘州区）。[S10]
- 游戏内使用虚构寺名；**不使用真实寺名「张掖大佛寺」作为关卡名**，除非取得寺方/管理方许可。[设计/权利]
- 名字的含义：
  - **长照**：长久的照见/光照；对应西面门的长光、卧佛的长时间、修护的世代。
  - **长觉**：长久的觉悟；更直接地回应佛教，但少一点「光」的意象。
- 若虚构：
  - 匾额、印章、标题都用「长照寺」；不出现「张掖大佛寺」四字。
  - 年表、殿名可以取意，但不能写「张掖大佛寺始建于……」；要写「本关取意张掖大佛寺」。
- 若用真名：
  - 需要寺方/管理方许可；匾额书法不能描现代书家原迹；年表/殿名逐条核。
  - 游戏内注明「场景为原创演绎，非实测复原」。

**翻译陷阱**：

- **卧佛 ≠ sleeping Buddha**。英文用 `reclining Buddha` 或 `Buddha in parinirvana`；不要用 `sleeping Buddha`（会变成「睡觉的佛」）。
- **涅槃 ≠ death**。英文用 `nirvana` / `parinirvana`；不要用 `death of the Buddha` 作为标题（可以作解释）。
- **西夏**：英文用 `Western Xia` 或 `Tangut state`；不要用 `Xixia Dynasty`（音译+朝代名，不准确）。`Tangut` 指党项/西夏语/西夏人；`Western Xia` 指政权。
- **大佛寺**：很多城市都有；英文必须 `Zhangye Giant Buddha Temple`；游戏内 `Changzhao Temple`。
- **装藏**：不要译成 `treasure` / `treasure chamber`；用 `consecration deposit`，必要时加解释「sacred objects placed inside a statue」。
- **经藏**：不要只译 `library`；`sutra canon` / `sutra collection`。`藏经阁` 才是 `Sutra Library`。
- **土塔**：`earthen stupa`，不是 `pagoda`；`弥陀千佛塔` 是 `stupa`，不是 `pagoda`。
- **长照**：`Changzhao`（cháng zhào），不是 `Long Zhao`；不要按字面译 `Long Shine`。
- **河西**：`Hexi Corridor`，不是 `west of the river`。
- **党项**：`Tangut (Dangxiang)`；不要只写 `Dangxiang` 让英文读者不知所云。
- **大佛殿高度**：UI 里不要写「33 米」或「20.2 米」作为定论；写「约 20 米（出版著录），另有 33 米说」或干脆不写数字。
- **《西游记》壁画**：不要写「早于吴承恩」；写「晚明清初，小说成书之后」。
- **「三层楼阁」**：不要译成 `three-storey building` 作为定论；写 `a three-tiered structure recorded in the 1747 stele`，并注现存外观重檐两层。

## 4. 新增界面文字（中文草案）

> 这些是 T04 可能出现的句子；定稿后要补 ja/en/ko。占位符用 `{}`。

- 入寺：`从广场走进山门。`
- 提示：`点地面走过去。`
- 前院：`钟楼和鼓楼，一南一北。`
- 门口：`站一会儿，让眼睛适应。`
- 第一眼：`门里只看见佛的侧身。`
- 巨像近侧：`一只耳朵，比人还高。`
- 侧廊：`沿着佛身走，才看得见全长。`
- 佛脚：`三十四点五米，从这里到佛首。`
- 佛首：`他面向西，眼睛半闭。`
- 经卷：`六百卷金经，六千多卷北藏。`
- 修护：`这一层颜色，是后来补的。`
- 年表：`一千零九十八年，开始。`
- 守护：`有人把经橱砌进墙里，守了五十多年。`
- 院外：`土塔在屋顶上。`
- 结束：`可以在这里站一会儿，也可以回去。`
- 札记：`长照札记`
- 一记未记：`今天只是走了一趟。`
- 记了几处：`你把看见的几件事，记在了纸上。`
- 不做：`不进佛像，不取装藏，不开经柜。`（可作为提示/边界说明）

**不要写**：佛号、经文、许愿语、因果报应式劝诫；不要假装是寺方原话；不要写「早于吴承恩」「佛肚藏宝」「许愿灵验」。

## 5. 字体

T04 新增的字（部分）：

> 长、照、觉、河、西、夏、卧、佛、涅、槃、装、藏、经、土、塔、张、掖、甘、州、嵬、咩、乾、顺、昙、谶、净、红、赭、暗、金、绀、纸、银、字、迦、叶、如、来、寺、弥、陀、千、壁、画、修、护、年、表、侧、廊、坛、铎、铃、柜、卷、轴、碑、记、铜、牌、镜、壶、守、护、像、塑、胎、泥、骨、架、裂、缝、补、塑、层、代、岁、月、日、光、影、尘、静、默

- 中文六套字体都要包含这些字；缺字会让 `pnpm run check` 失败。
- 日文用日文字形（如「仏」「経」「蔵」）；韩文用韩文字体。
- 匾额/石刻不翻译；若用真名，石刻文字用繁体/异体，逐字核。
- 新增后运行：`python3 tools/fonts.py <dir with the TTFs>`。

## 6. 不翻译的东西

- 匾额文字（「大佛殿」等殿名；若用真名，「张掖大佛寺」）。
- 碑记/铜牌/对联原文。
- 博物馆来源行、作者名、版权行。
- 寺名/地名的罗马字（可在括号里给读音）。
- 展柜里的经卷文字（西夏文/汉文/藏文）——不翻译，只做「不可读的经卷」的视觉。
