# T04 空间底图（白盒用）

核对日期：2026-11-17。这份文件只回答「哪里有什么、多远、多高、能不能走」。数字分三类：
**OSM 轮廓**（公开地图数据，米级到十米级误差）、**SRTM 高程**（30 米格网，±5–10 米）、**提案**（我们自己的设计）。
没有现场测绘。白盒可以用，精模与验收不能拿它替代实测。

---

## 1. 坐标、朝向、单位

- 建议的本地坐标：以**山门中心**为原点，**+x 向东，+y 向上，+z 向南**（北 = −z，与 T00/T01 的 `north/uphill is -z` 一致）。1 单位 = 1 米。
- 真实朝向：自山门指向大佛殿的轴线朝向约**东偏北 11.6°**（罗盘方位约 78°）；寺**坐东朝西**，visitor 从西面进入。[S13；推算]
- WGS-84 参考：
  - 山门：约 38.929875, 100.453305（OSM way 1383725391 中心）。[S13]
  - 大佛殿：约 38.929986, 100.454226（OSM way 958220434 中心）。[S13]
  - 资料库点：38.9300, 100.4542；**落在大佛殿轮廓内**，约在大佛殿中心以西 1.2 米、以南 3.1 米。[S00、S13；推算]
  - 寺院范围：约 38.9301, 100.4547（OSM way 458773994；Nominatim 38.9301006, 100.4546879）。[S13、S14]
  - 土塔（OSM 无名 temple）：约 38.93014, 100.45554（OSM way 1383725389）。[S13；推算]
- 投影换算（本地近似）：
  - 1° 纬度 ≈ 110,574 米；
  - 1° 经度 ≈ 111,320 × cos(38.93°) ≈ **86,600 米**。
  - 0.001° 经度 ≈ 86.6 米；0.001° 纬度 ≈ 110.6 米。

**资料库点核验**：资料库给的是 38.93, 100.4542。这个点不是寺院几何中心，也不是山门，而是**大佛殿**：OSM 大佛殿中心相对它只有 (−1.2, +3.1) 米。把它作为 T04 的定位点是合理的；但做白盒时不要把「资料库点」当山门。山门在它以西约 78 米。[S00、S13；推算]

## 4. 入口、边界与「不可进入」

### 4.1 入口

- 主入口：民主西街大佛寺巷，山门朝西；门前是大佛寺广场（OSM 约 137×135 米）。[S13、S30]
- 山门：面阔三间、进深一间；牌楼式/门殿式；中门可走，两侧门可走或封闭（待核）。[S30；摘要]
- 开放时间：OSM 标 `Mo-Su 08:00–18:00`；旅游攻略多写 8:00–18:00、门票约 20 元。**只作 run guide，出发前再核。** [S13；摘要]
- T04 的开场不需要复刻售票/安检；可以做「广场—山门」的一小段，门内即入寺。[设计]

### 4.2 边界

- 西：大佛寺广场、民主西街。
- 南：张掖市博物馆、甘州区民族小学、住宅。
- 北/西北：木塔寺（万寿寺）、张掖饭店、住宅。
- 东/东北：山西会馆（独立景区）、住宅/学校。
- **山西会馆、木塔寺、张掖市博物馆都不并入 T04**；只作城市背景/远景。[S13、S30]

### 4.3 视线通廊

T04 可以设计三条视线（设计提案，不是现场测量）：

1. **广场 → 山门 → 大佛殿屋顶 → 土塔**：从西面广场看，山门压低，大佛殿的深檐在后，土塔在最后/最高处露出一截。
2. **前院 → 大佛殿门**：门内是暗的，佛像的侧身只在门槛内一小块；看不到全长。
3. **大佛殿侧廊 → 佛首/佛尾**：沿南北向走，34.5 米的全长在两端成立；这是全关的核心视线。
4. **院外回望**：从广场/寺外回望，土塔、屋顶、城市低层；不是群山。

**注意**：这些是设计提案；公开资料只支持「坐东朝西、轴线、土塔在后」的关系，没有逐点视线照片。[S03、S13]

## 5. 游线 A–F（对应资料库六段）

资料库 T04 的路线是：**前院 → 门口适应区 → 巨像近侧 → 侧向观察 → 经卷展柜 → 院外远景**。[S00]
下面把它落成可走的六段；距离/高程是提案。

| 节点 | 位置（相对山门 x,z） | 距离/高差 | 玩家做什么 | 要验证什么 |
|---|---|---|---|---|
| A 前院 | (18, −2) → (40, −6) | +40 m / +0.4 m | 从山门进，穿过第一进院落；看钟鼓楼、大佛殿深檐、土塔尖 | 轴线是否清楚；钟鼓楼是否压得住；土塔是否露出 |
| B 门口适应区 | (55, −15.8) → (63.5, −15.8) | +24 m / +1.2 m | 站上门槛，等眼睛适应；看门框、砖雕、殿内暗部；第一眼佛像侧身 | 门内是否可读；曝光过渡是否温和；是否只看到局部 |
| C 巨像近侧 | (68, −27) | +13 m / 0 | 走到佛首/佛手一侧；看耳、手、衣纹、十大弟子；不触摸 | 面部/手是否可读；尺度是否成立；是否挡住通路 |
| D 侧向观察 | (72, +7) → (77, +1.5) → (77, −33) | +40 m / 0 | 沿南侧廊走到佛脚，再走到佛首；在两端看全长；看十八罗汉 | 全长是否在两端成立；侧廊是否 ≥2.5 m；头/脚是否被切 |
| E 经卷展柜 | (160, −19.3) → (166, −19.3) | +90 m / −0.2 m | 穿过艺术厅到藏经阁；看经橱、金经复制、北藏、说明牌；不开柜 | 展柜是否可读；光是否伤纸；是否像「宝库」 |
| F 院外远景 | (0,0) → (−92, +17) | +95 m / −0.9 m | 出山门，到广场回望；看土塔、屋顶、城市；结束 | 土塔是否在屋顶上；城市是否低层；是否误用群山 |

总长约 **300 米**（含侧廊与回程），真人试玩目标 **12–18 分钟**。[S00]

### 5.1 侧廊的走法（设计）

- 门（西）→ 南侧廊（佛脚方向）→ 佛脚 → 东侧（佛身后、十大弟子前）→ 佛首 → 北侧廊 → 门。
- 也可以反向；游戏默认引导顺时针（右绕），但不强制、不扣分。
- 侧廊宽 2.5–3.5 米（推算）：大佛殿宽 48.3 米，卧佛长 34.5 米，两端各余约 6.9 米；进深 24.5 米，佛身宽 7.5 米，前后各余约 8.5 米，扣除佛坛/罗汉/供桌后约 2.5–3.5 米可走。[推算/设计]
- 佛坛是 solid；佛像、十大弟子、十八罗汉都是 solids/posts；玩家不能上坛、不能跨供桌、不能摸。[设计]

## 6. 白盒的「可走性」规则（照 T00/T01 的做法）

T00 的 `site.js` 用 `walk = {solids, decks, ramps}` 矩形 + `posts` 表达可走性；T04 直接照搬。

- **solids**：山门侧墙、钟鼓楼、大佛殿台基/墙体、佛坛、藏经阁、土塔、配殿、围墙。
- **decks**：广场、山门地坪、前院、大佛殿地坪、侧廊、藏经阁地坪、土塔院。
- **ramps**：山门台阶、大佛殿台基台阶（3–5 级）、藏经阁台阶；用 `stairGeo`，不用斜坡。
- **posts**：山门柱、钟鼓楼柱、大佛殿外檐柱/内柱、佛像/弟子/罗汉、供桌、香炉、经橱、土塔（整体 solid）、树。
- **roofs**：山门、钟鼓楼、大佛殿（重檐两层）、藏经阁、土塔 13 层、配殿；土塔的每一层檐都要进 `walk.roofs`，否则第三人称镜头会穿塔。
- **drops**：第一版不做跳下；台基边缘用栏杆/挡墙。
- **shade**：每栋建筑与围墙在铺地上的暗部；大佛殿的深檐要在前院投下大面积阴影。

### 6.1 需要特别注意的宽度

- **大佛殿门**：净宽未给；白盒先按 3.6 米（中门）做，两侧门 1.8 米；门槛高 0.2–0.3 米。[设计]
- **侧廊**：≥2.5 米；佛像/罗汉/供桌之间留 0.5 米安全距离（玩家不能挤进去）。[设计]
- **佛坛**：高 1.2 米；玩家不能上；坛前留 1.5–2 米礼拜带。[S21、S22；设计]
- **经卷展柜**：柜前留 1.5 米；柜高 1.0–1.2 米，玻璃/亚克力；玩家不能开柜。[设计]
- **土塔**：基座 23 米见方；周围留 2.5–3 米环道；不登塔、不进入地宫。[S06；设计]
- **门槛/台基**：真实高差未测；白盒用 0.2–0.3 米门槛、1.2 米台基；现场再核。
