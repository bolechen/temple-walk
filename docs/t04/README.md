## 先给结论

1. **T04 的核心不是「一尊很大的佛像」，而是「身体在巨像前的尺度感」。** 卧佛长 34.5 米、肩宽 7.5 米，大佛殿面阔 48.3 米、进深 24.5 米；人从西面门进去，先看到的是佛的侧身，不是全身。只有沿佛坛侧廊走到佛首或佛尾，34.5 米的全长才成立。这个「先局部、后整体」的空间经验，就是资料库说的「入口决定先看到局部还是整体」。
2. **卧佛是涅槃像，不是「睡觉的佛」，也不是藏宝箱。** 木胎泥塑、中空装藏，腹内分上中下三层、头部另有一间藏室；1966 年清理出明代铜牌、铜镜、铜壶。这些是**修护年代与宗教仪轨的证据**，不是可进入、可拿取的关卡空间。
3. **现存大佛殿不是 1098 年的原构。** 乾隆十年（1745）殿倾，乾隆十二年（1747）「改式重修三层阁楼，仍塑卧佛金身」；2005–2007 年又落架大修。把「西夏皇家寺院」当成现存木构的年代，会把修缮史抹掉。T04 的主题恰恰是「许多世代共同守护一件作品」。
4. **寺史的主流学术起点是 1098 年（西夏永安元年）**，依据是卧佛腹内 1477 年铜牌、1427 年《敕赐宝觉寺碑记》与《重刊甘镇志》的互证（崔云胜 2016）。另有西晋永康元年（300）创建迦叶如来寺的地方志/寺传说；本包把它标为「前身/传说」，不写成定论。
5. **空间骨架已经能从 OSM 搭出来。** 寺院坐东朝西，山门—钟鼓楼—大佛殿—藏经阁（经籍厅）—土塔沿一条约 11° 北偏东的轴线排列；山门到大佛殿约 77 米，到藏经阁约 171 米，到土塔约 197 米（OSM 量算，非测绘）。SRTM 高程 1477–1483 米，场地基本平坦，不能分辨殿内地坪或佛坛。
6. **资料缺口仍然明确：** 没有现场测绘、没有殿内平面/柱网、没有壁画逐幅年代报告、没有造像扫描授权、没有现场录音/摄影的商业授权。白盒可以做，精模与「真实游线」不能假装已经有。
7. **美术方向是「土色、深木、克制的金，一束从西面门进来的侧光」。** 张掖是干旱的河西绿洲城市，不是江南，也不是沙漠；寺在城里，门外是广场与低层街市。T04 的「院外远景」要看见土塔、屋顶和城市，不要用群山替代。
8. **不做的比做的重要：** 不进佛像、不取装藏、不开经柜、不登土塔、不摸壁画、不做求财/求姻缘、不把「西游记壁画早于吴承恩」当定论。所有打卡都是「看、走、站、读、记」。

## 怎么读本包的标记

- **【原文】**：本包写作时实际打开页面并读了正文。
- **【PDF】**：下载 PDF 并用文本层抽取；印刷页以原文标注的页码为准。
- **【API】**：结构化数据（OSM Overpass/Nominatim、Commons API、SRTM 高程）。
- **【摘要】**：只读到搜索引擎摘要或别人转述，没有打开原文。引用前要再核。
- **【照片】**：从公开照片上读到的现状，不是测绘。
- **【推算】**：由 OSM 轮廓、SRTM 高程或公开数字算出来的，可能有 5–10 米或数度的误差。
- **【设计提案】**：我们自己的取舍，不是大佛寺的事实。可以改，改了不算篡改历史。
- **【未核】**：资料互相矛盾或没有一手来源，开发时不得当作定论。
- **【资料库】**：来自 T04 条目或资料库美术规范，是创作提案，不是历史/现场测量。

## 三条纪律

1. **不把参考照片当实机证据。** T04 的六机位与性能数字必须来自 T04 自己的页面与白盒。
2. **不把传说写成史实。** 300 年创建、嵬咩掘得碧玉卧佛、忽必烈出生、宋恭帝出家、元顺帝生于寺中、本觉尼师的具体细节，都要么标「相传/报道」，要么只作氛围。
3. **不把博物馆图当寺藏。** GALLERY 里的涅槃图与经卷是「同一主题的公开馆藏」，不是张掖大佛寺的旧藏；来源行必须原样保留。

## 本轮（2026-11-17）读资料后确认的七件事

1. **寺是坐东朝西的。** 山门在西，大佛殿在东； visitor 从西面进，下午的西晒正对殿门。这不是「坐北朝南」的中国寺院常规，T04 的轴线和光都因此不同。
2. **卧佛头北脚南、面西而卧，佛坛高约 1.2 米。** 34.5 米的长度沿南北向，与入口的东西向垂直；所以进门先看到侧身，不是全长。
3. **现存大佛殿是 1745–1747 年改式重建的三层楼阁，2005–2007 年又落架大修。** 「西夏皇家寺院」是寺史/地位，不是现存木构的年代。
4. **大佛殿的尺寸有 20.2 米与 33 米两套说法，进深有七间与五间两套说法。** 本包以 48.3×24.5×20.2 米、面阔九间/进深七间为出版著录值，其余进矛盾表。
5. **壁画 530 余平方米，不是 330。** 东西壁诸天礼佛、南北壁十八罗汉与山水花鸟/《山海经》、佛身后观音救八难与《西游记》；二层板壁有过去七佛、天龙八部、护法、世俗书画。
6. **《西游记》壁画的学术主流是「晚明清初、小说成书之后」**（蔡铁鹰、于硕等据李卓吾评本插图比对），不是地方宣传说的「早于吴承恩」。T04 不采用「早于小说」的说法。
7. **经藏有 636 函/6361 卷《永乐北藏》与 600 卷金银字《大般若经》。** 1941 年经橱被砌进夹壁、1995 年重见天日；本觉尼师守护经卷至 1975 年。这是「守护」的故事，不是「取宝」的关卡。

这些都在 `SOURCES.md` 与 `RESEARCH.md` 的矛盾表里有记录；引用时按「出版著录」「政府/媒体」「游记/摘要」「推算」分开标注。
