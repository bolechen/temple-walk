## 0. 阅读方式与可信度分级

- **【原文】**：本包写作时实际打开页面、读了正文。引文保留网页原有的乱码/异体字说明。
- **【PDF】**：下载 PDF 并用文本层抽取；印刷页以原文标注的页码为准。
- **【API】**：结构化数据（OSM Overpass/Nominatim、Commons API、SRTM 高程），按字段读，不靠转述。
- **【摘要】**：只读到搜索引擎摘要、新闻转述或百科条目，没有打开原文。**引用前必须再核。**
- **【未用】**：链接打不开或内容不足，明确不采用。
- **【资料库】**：来自 T04 条目/美术规范，是创作提案，不是历史或现场测量。

同一个网页可能被多家转载，**转载数量不等于独立证据数量**。政府/寺方网页也有宣传语、年代混写与编辑痕迹，不能当作碑记原文。

## 4. 再分发与授权边界

- **政府网站/规划 PDF**：可阅读与引用；不要把整份 PDF 或大段文字打包进游戏仓库。引用时注明文号/日期/页码。
- **学术论文/PDF**：可阅读与引用；论文的图/表再分发权未取得。引用要短，注明作者/期刊/页码。
- **维基百科/百度百科**：CC BY-SA 或版权不明；只作线索，不直接引用长段文字。
- **Wikimedia Commons**：CC BY-SA 3.0/4.0；可商用，但必须署名、注明许可、相同方式共享。游戏是闭源商业产品时，是否接受「相同方式共享」要所有者决定。T04 目前**不下载、不进 dist/**，只作研究。
- **Met Open Access**：CC0/公有领域；可用，但要保留来源行，不用馆标，不暗示馆方背书。
- **ColBase**：允许商用，但必须写出典行+加工说明；T04 只列候选，未下载。
- **Cleveland Open Access**：CC0；保留来源行。
- **OSM**：ODbL；地图数据可用于游戏，但要署名 OpenStreetMap contributors；衍生数据可能有相同方式共享义务。
- **SRTM/opentopodata**：公开高程数据；作为设计参考，不直接分发原始数据。
- **寺方/媒体照片**：未取得再分发权；只作研究/配色参考，不进游戏。
