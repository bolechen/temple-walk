## 1. 可以直接复用的 T00/T01 资产

### 1.1 扫描贴图（Poly Haven，CC0）

T00 已有 8 套，T04 至少能直接用 6 套，但要改颜色/粗糙度：

| T00 资产 | 用途（T04） | 备注 |
|---|---|---|
| `TEX-wood` 木纹 | 柱、梁、门、经橱、展柜 | 调深、去红，河西干木 |
| `TEX-stone` 石面 | 台基、台阶、铺地、土塔基座 | 调灰/土黄 |
| `TEX-blocks` 砌块 | 土红墙、围墙、土塔 | 调土红/赭石；不是青砖 |
| `TEX-plaster` 抹灰 | 殿内墙、壁画地仗 | 调土黄；壁画底层 |
| `TEX-bark` 树皮 | 国槐/刺槐/杨树 | 院内外树 |
| `TEX-leaves` 叶 | 槐/杨树冠 | 调干绿/土黄 |
| `TEX-snow` 雪 | 冬季土塔/屋顶/广场 | 只作变体 |
| `TEX-weave` 织物 | 经卷封面、幡、坐垫 | 调绀青/暗红 |

需要新增的扫描/程序材质：
- **土红墙**（赭石/土黄，带风蚀、雨痕、墙脚返潮）——T04 的主墙面。
- **河西干木**（深褐、裂纹、无漆/半漆）——柱、梁、门、经橱。
- **暗金/土金**（佛像金妆、经卷金泥）——不是亮金。
- **草泥/泥塑**（卧佛胎体、壁画地仗）——粗糙、颗粒。
- **绀青纸**（金经/银字）——深蓝黑，配金/银。
- **深灰筒瓦**（大佛殿/山门/藏经阁）——不是 T01 的琥珀琉璃。
- **土塔砖土**（土黄/灰白，层层收分）——不是青砖塔。

### 1.4 模型与馆藏图

- `MODEL-buddha` / `MODEL-pedestal`：T00 的坐佛/座，**不能用作 34.5 米卧佛**；可作配殿/侧厅的坐佛占位。
- 7 件博物馆 CC0 扫描像：可作十八罗汉/弟子/胁侍的**占位**，但 T04 的 31 尊群像需要自己的比例/姿态；占位不能冒充成品。
- 32 件 T00 馆藏画：T04 不直接复用；T04 的 GALLERY 选涅槃图/经卷（见 `GALLERY.md`），与 T00 的宋元禅林墨迹分开。

**卧佛必须是原创模型**：不能扫描张掖大佛寺的卧佛（无授权、文物保护），不能用 T00 的坐佛放大/旋转，不能用 AI 生成图冒充。原创模型要单独做面部/手部/衣纹；身体可低模 + 法线/AO。[S00]

## 3. 只能当参考、不能进游戏的素材

### 3.1 Wikimedia Commons 照片

T04 统计了 15 个文件（S16）：

| 许可 | 数量 | 能用吗 |
|---|---:|---|
| CC BY-SA 3.0 | 14 | 商用可以，但必须署名 + 相同方式共享；闭源商业游戏有风险 |
| CC BY-SA 4.0 | 1 | 同上 |
| Public domain | 0 | — |

主要作者：Livewireshock（2）、Zhangzhugang（5）、guan（5）、Leuband（1）、张骐（1）。
**建议**：全部只作研究与配色/构图参考，不进 `dist/`。若所有者接受 CC BY-SA，再逐张选 3–6 张做「书册里的现场照」，并在鸣谢页列出作者、许可、链接。

### 3.2 博物馆图

- Met Open Access（CC0/PD）：可作 GALLERY 候选；保留来源行，不用馆标。
- ColBase：可作 GALLERY 候选；出典行 + 加工说明；未下载。
- Cleveland Open Access：可作候选；CC0；保留来源行。
- **西夏/黑水城佛教绘画（Hermitage 等）**：权利不清；只作研究线索，不进游戏。
- **中文博物馆藏品网页图**：未见明确商用许可；不用。

### 3.3 现场照片/游记

- 旅游攻略、博客、公众号照片：无许可；只作构图/现状参考，不进游戏。
- 寺方网页/书页：未取得再分发权；只作研究。

## 5. 授权与署名

### 5.1 必须保留的署名

- Poly Haven：CC0，不强制署名，但 T00/T01 已在鸣谢页列；T04 保持。
- 字体：SIL OFL；`shared/fonts/OFL.txt`；保留版权行与保留字体名。
- three.js / meshopt / Basis / lil-gui / stats：MIT/Apache；`THIRD-PARTY-NOTICES.txt`。
- Met：CC0/PD；来源行；不用馆标。
- ColBase：出典行 + 加工说明。
- Cleveland：CC0；来源行。
- OSM：`© OpenStreetMap contributors, ODbL`。
- Commons（若采用）：作者 + 许可 + 链接 + 是否修改。

### 5.2 不能用

- 现代书法家的题字（著作权期内）。
- 寺方网页/书页的整段文字/图片。
- 西夏/黑水城绘画的未授权图。
- 中文博物馆藏品的网页图。
- 旅游博客/游记照片。
- AI 生成的「大佛寺实景」。
- 张掖大佛寺卧佛的 3D 扫描/照片贴图（无授权；文物保护）。
- 「装藏=宝藏」的视觉/玩法。

### 5.3 需要所有者决定

1. 是否接受 CC BY-SA 的「相同方式共享」义务（Commons 现场照）。
2. 是否委托原创卧佛模型/31 尊群像；预算/工期。
3. 是否请摄影师/录音师做一次合规的现场采集。
4. 是否使用 ColBase/Met 的馆藏图（GALLERY）；是否接受来源行/出典行。
5. 是否使用真实寺名「张掖大佛寺」，还是继续虚构「长照寺」。
6. 是否展示本觉尼师/1941/1995 的故事；宗教/伦理敏感度。
7. 是否展示装藏剖面/铜牌释文；宗教敏感度。
8. 基准季时：秋末西晒 vs 冬季雪景。

### 5.4 交付命名（照资料库 V0.2）

每关交付：空间概念图、同白盒四视图、三处特写、材质板、照明预设、资产清单、来源授权表、运行截图。
命名示例：

- `T04_ENV_Forecourt_Z01_v001`
- `T04_LGT_Interior_SideDaylight_v001`
- `T04_CAM_Hall_Door_16x9_v001`
- `T04_SRC_Architecture_001`

每个版本记录：关卡 ID、场景、季节天气、来源图 ID、相机、太阳方位、材质版本、作者、日期、权利状态、变更说明。

## 6. 资产登记表怎么读

`asset-register.csv` 的 `status` 列：

- `reuse`：直接复用 T00/T01，已随项目分发。
- `planned`：T04 新做，尚未存在。
- `candidate`：候选（博物馆图/现场照），许可/内容未定。
- `reference`：只作研究/参考，不进 `dist/`。
- `deferred`：暂缓（如整卷长图）。
- `blocked`：权利不清或没有来源，不用。

`commercial_use` 列只写「yes / conditional / no / unknown」，不写推断。
