## 一、职责与评审标准

我们是**独立评审**：主创和开发会话不能代改我们的结论。我们不改代码，只复拍、量、写条目。

**看什么**

- **树**（干、枝、冠）：根脚、分叉、枝梢、冠形、冬天的枝，五项一张表。
- **小沙弥的身体**：蒙皮撕裂、袖子腋下、手位、念珠、外廓、坐姿。
- **步态**：上、下台阶的腿、骨盆、袍摆、手臂。
- **造像**：站在殿里的佛像和雕像（`app/shared/models/`），与 `docs/JINGSHAN.md` 对照。

**怎么判**

1. **从三个以上方向看**（`AGENTS.md`「改形体的，从几个方向看」）：所有者的机位、正视、侧视、仰视；冬天再看一遍。只看一个角度我吃过亏：第一次复核漏了枫树根脚的一圈暗环，原因是只拍了一个暗面。
2. **放大看原图**。拼图缩小后接缝、唇口、一道细暗线都看不出。交接处要截出原图放大再判。
3. **证据必须是干净提交**：`report.json` 的 `site.commit` 不带 `+dirty`。带了就在 head 上用 T4 补拍一次，不要信开发方的图。
4. **每条要能由别人照着检查**：机位或命令、数、阈值；阈值写依据（查到的原文，或写明「按常理」）。「好看」「自然」不算一条。
5. **先问是谁的毛病**：把每个缺陷分成「重新生成也改不了（蒙皮、绑定）」「与设定图相符、不是毛病」「生成一侧」。`refs/monk-apose-sheet.png` 是所有者认可的设定图，袍摆到膝上、睁眼，都是它画的。
6. **合并后在 main 的提交上复拍一次**再关 issue（关 #91 就是这样做的）。实施方只能标 `fixed_pending_retest`，不能自己关。
7. 通过写「通过，可以合」；没过写「暂不通过」，只列挡住的几项和改法，别把不挡的混进去，不挡的写成「后续一项」。

## 四、工具与看图

- **`node tools/novice-views.cjs`**：身体五姿四面。`--code` 代码身体，`--glb=<文件>` 别的身体，可以并排放多个；`--poses=chair --sides=正` 只看一张；`--near=<k> --focus=<m>` 凑近；`--faces` 背面涂洋红、背景涂绿（洞是绿的）；`--hide=legs,skin`；`--brow` 试举香手位。
- **`node tools/portrait.js [季-时] [bind] [sculpt]`**：五个近景。
- **`node tools/novice-measure-hands.mjs` / `novice-measure-fingers.mjs` / `novice-measure-beads.mjs <glb>`**：手大小、指尖张开、念珠进布深度。
- **`node tools/gait-stairs.mjs --speed=0.714,0.952 [--csv=…]`**：台阶步态数。注意上行 `lift` 是两级（每只脚一个步幅爬两级），别当作抬腿夸张。
- **`node tools/stair-film.cjs [--places=hall,hill,summit] [--label=…] [--out=…]`**：页面里逐帧，默认 400×260 太小，要看袍摆和裤子，把视口改成 ≥ 960×624（复制一份改，别改仓库的）。要等页面构建，上、下各约 10 分钟。
- **`node tools/stair-strip.cjs`**：正、侧、背三个方向，每段 8 帧，改前改后并排。
- **`node tools/edges.mjs`（`pnpm run edges`）**、**`node tools/walk/outline.mjs`**：身体进没进东西、外廓。想看换身体的外廓，临时把文件放到 `app/shared/models/novice.glb` 再跑 `outline()`，**跑完 `git checkout -- app/shared/models/novice.glb` 还原**。
