## 1. 一句话方向

**「城中山寺，雨后塔影」**：黄墙压着街声，青石一路向上，珊瑚朴的冠把塔遮了又露，最高处塔影落在紫秆菜薹上；回头是武昌的屋顶。

与 T00 的差别：

| 维度 | T00 云径禅寺 | T01 宝通寺 |
|---|---|---|
| 主色 | 白墙、深木、灰瓦、竹绿 | **黄墙**、朱柱、**琥珀/黄琉璃瓦**、青石、珊瑚朴的褐绿 |
| 光 | 阴天雨后的柔光 | B01 秋雾的漫射光（第一版对照）；冬晴低角度光（T01 变体）；B02 冷暗内殿 |
| 远景 | 五峰、云海、竹林 | **城市屋顶线**、梧桐/珊瑚朴冠、塔北山脊 |
| 近景 | 竹、柳杉、石阶 | 黄墙、石狮、菜薹田、摩崖石 |
| 情绪 | 出世、静 | 入世中的静；城市始终在场 |
| 季节 | 夏昼（J01） | 冬晴／秋末雨后（提案） |

### 1.5.5 与现场照片的冲突（必须写明）

资料库的 B01 是**生成视觉参考**，写的是「暗朱木构、深绿与少量秋叶、雾天漫射」。现场照片显示的是：

- 山门与主要殿宇：**饱和土黄墙 + 琥珀/黄琉璃瓦 + 朱红门**；
- 洪山宝塔：**赭红/砖红塔身 + 石檐铁栏 + 青铜塔刹**；
- 寺后洪山：深绿阔叶林，城市贴着寺墙。

所以 T01 的用法是：**取 B01 的雾、光、层次和「近屋脊/远塔分开」，不取它的暗朱木殿与灰绿色调**；颜色以 §2 的现场校正值为准。若所有者要按 B01 的生成画面做，那是一条「原创演绎」方向，必须标成生成参考，不写成宝通寺现状。[S58]

- 山门就贴着武珞路：照片下缘是金属栏杆、公交候车亭、地铁口下行楼梯、共享单车和车流；门内是放生池的暗。
- 山门是**三间、多层琥珀琉璃屋顶**的门殿：中央门屋较高，两侧低；**黄墙 + 蓝底金字的「宝通禅寺」匾 + 朱红拱门 + 红底金字的「庄严国土」**；檐下斗拱/梁枋彩绘偏青绿/靛蓝；门前一对石狮、白色铁栏与绿篱。
- 寺后的洪山是一整片深绿阔叶林；**塔从街对面就几乎整座可见**，在画面右上，红褐色塔身、七层密檐、很高的塔刹。
- 右侧有一栋米黄色多层住宅（贴瓷砖、空调外机），说明「城市」不是远景，是紧贴寺墙的体量；还有一块红色导览牌。
- 天空是薄云/灰白，光线不硬；照片是夏天，树很密。

这张照片直接支持 T01 的「城市—山门—山林—塔」四层构图，也修正了两个假设：**屋面是琥珀琉璃（不是灰瓦）**，**塔在街上就能看见（不是只露塔尖）**。

### 2.1b 从 2024 年塔的近照读到的

- 塔身是**赭红/砖红**的砖石，不是灰色；石檐逐层出挑，檐角微微上翘，檐口有深色水痕。
- 七层，每层有窗，窗框是白色/浅色；下层能看到窗外的铁栏。
- 塔顶是**文笔峰式青铜刹**，细长，带相轮/宝珠，颜色偏铜绿/深褐。
- 上层檐口长着灌木/杂草，是真实的老塔状态；T01 可以保留少量，不要做得太干净。
- 塔前的黄色服务建筑是**红瓦 + 黄墙 + 红窗框**，与寺内主殿的琥珀琉璃不同；不要把它当成大殿。
- 天空是雨天白，塔在灰白天空前是暖红剪影——这是 T01 塔院机位的好光。

### 2.2 从 2026 年摩崖照片读到的

- 寿泉：一块约 3–4 m 高的**麻点状石灰岩巨石**，赭红「寿泉」二字竖刻；左边是石栏杆，右边是**鹅卵石/碎石铺地**，石缝长苔，背后是竹林。
- 栖霞岩：一整面**天然石灰岩崖壁**，红字竖刻在岩面上；树从岩缝里长出来，岩面有苔、地衣、水痕；不是平整的碑面。
- 东岩：刻痕很浅，红漆已褪成粉白，字迹难辨；岩面粗糙、开裂、长苔。
- 狮子峰：一组天然巨石，最大一块上有红字；旁边有**现代仿石挡墙**（绿色/粉色混凝土仿石）、一个小香炉/供台、红绸带、靠在石边的扫帚、铺地落叶。
- **结论**：摩崖不是「碑林」，是「山林里的几块石头」；大部分字已风化，只有少数涂红可辨。T01 不要把摩崖做成整齐的石碑墙。

## 3. 基准季时（与资料库对齐后）

资料库给 T01 的外部预设是 **B01 秋雾外院**，室内是 **B02 冷暗内殿**，另有 **B03 冬季内殿**的文字预设；它同时要求「白盒先用中性日光看清空间，再比较秋雾；冬季雪景独立备选，不当作现场气候记录」。[S58]
所以顺序是：

1. **白盒阶段**：中性日光，不做季节，不调色。
2. **第一版美术对照**：B01 秋雾外院——与资料库共用同一张基准，先对雾、光、层次。
3. **T01 独有变体**：冬晴·塔影在田——菜薹、塔影、疏枝；作为冬季外部变体，**不与 B01 合并**。
4. **室内**：B02 冷暗内殿（大雄宝殿/玉佛殿）；B03 冬季内殿作为冬季变体。

### 3.1 第一版对照：B01 秋雾外院

- 季节/天气：秋季，雾天漫射；不是大雨，也不是晴空。
- 光：天空漫射为主，太阳很弱；近处能看清梁柱、门洞、台阶，远处塔是一层灰绿的剪影。
- 植物：深绿为主，少量秋叶；银杏开始黄，珊瑚朴还绿。
- 颜色：**按现场校正**——黄墙、琥珀瓦、赭红塔；不照 B01 的「暗朱木殿、灰绿」原样刷。B01 只借雾、光、层次与构图。
- 构图：近景门框/树干，中景院落/黄墙，远景塔；**近屋脊与远塔分开**，不无意相切。
- 为什么先做它：与资料库共用一张基准，评审能直接对照；雾天也最容易暴露「空气透视、层次、塔的剪影」这些问题。
- 风险：B01 的生成画面与现场照片的墙/瓦颜色不一致；必须写明「参考其光雾，不参考其色彩」。

### 3.2 T01 独有变体：冬晴·塔影在田

- 时间：晴日 9:00–10:30 或 14:30–16:00，太阳低，影子长。
- 天光：冷白，阴影偏蓝；太阳暖但不高。
- 地面：青石干冷；菜薹田的土略湿。
- 植物：银杏落尽，珊瑚朴疏枝，黑松深绿，菜薹紫秆黄花。
- 城市：武珞路的楼在薄雾里，声音清楚。
- 为什么保留它：塔影、菜薹、疏枝、城市灰，是这块地独有的；B01 的秋雾看不到这些。它对应资料库的 B03 冬季预设（B03 是室内文字预设；T01 的冬晴外景是同一季节的外部变体）。
- 风险：冬季画面容易灰；要靠黄墙、菜薹紫、塔的赭红把颜色提起来。

### 3.3 室内：B02 冷暗内殿 / B03 冬季内殿

- B02：主体居中、暗哑金色、冷灰地面、两点灯火与细烟；用于大雄宝殿、玉佛殿。**不要死黑**，门洞、柱列、通路要可辨。
- B03：门外雪地青白反光，柔和托起佛面，油灯为唯一暖光；只作冬季室内变体，且没有对应上传图确认。
- 两套都不证明造像工艺；佛像仍是占位/剪影时，不要用光把细节「补」出来。

### 3.4 不推荐：夏昼

- 与 T00 基准重复；武汉夏天热岛、湿闷，画面容易糊。
- 若要用，做成「梅雨午后」的闷绿，而不是 T00 的清爽夏昼。

**最终由所有者看图定。** 白盒阶段一律中性日光；B01 与冬晴是两条并列的对照线，不互相覆盖。

## 4. 六个候选机位

坐标是相对山门的本地坐标（+x 东，+y 北，米），高程按 `SITE.md` 的提案台地；机位高度是**眼高**，不是相机绝对高。
详细 JSON 见 `camera-manifest.json`。

### CAM-01 街边山门（城市 → 寺）

- 位置：山门外南侧约 25 m，(0, −25)，眼高 1.65 m。
- 朝向：向北，微微仰 3°。
- 画面：下三分之一是路面/斑马线/地铁口，中景是三间门殿、黄墙、蓝底金匾、朱红拱门与石狮，门洞后是放生池的暗；**塔在门殿右上方露出大半或整座**（2024 年照片），但不要与门殿屋脊相切。
- 光：B01 秋雾的漫射光，或冬晴的侧光；门外城市灰，门内暖。
- 要验证：城市声是否还在；山门是否压得住街面；塔是否露出且不与屋脊相切。

### CAM-02 放生池/圣僧桥（入院）

- 位置：山门内约 30 m，(0, 30)，眼高 1.6 m。
- 朝向：向北偏东 4°，平视。
- 画面：近景是石桥栏杆与水面，中景是钟楼/鼓楼与弥勒殿，远景是银杏；塔应被门殿/树冠遮住，最多露一角。
- 光：B01 秋雾的天光在池面；黄墙的暗部要有细节。
- 要验证：池水、龟、桥、钟鼓楼的层次；塔是否真的「消失」。

### CAM-03 大雄宝殿前（七重台地的第三重）

- 位置：弥勒殿后、大雄宝殿前约 25 m，(9, 112)，眼高 1.6 m。
- 朝向：向北，仰 5°。
- 画面：近景是宽石阶、石栏（莲蕾望柱）与阶中石雕，中景是重檐立面、竖匾「大雄寶殿」与黑底金字横匾，两侧是银杏。
- 光：前廊阴影深，匾要可读；石阶湿/干要有区别；雨丝/雨后的湿石是加分项。
- 要验证：重檐比例（下檐+上檐）；面阔五间是否读得出来；石栏与石雕的尺度；殿内是否可进。

### CAM-04 玉佛殿/后院转折（第四重）

- 位置：大雄宝殿后约 20 m，(12, 160)，眼高 1.6 m。
- 朝向：向北偏东，平视。
- 画面：近景是后院廊庑/斋堂的一角，中景是玉佛殿两层，远景是万佛殿的重檐与塔。
- 光：后院比前殿暗，要有檐下补光；黄墙与朱柱的对比。
- 要验证：两层玉佛殿/藏经楼是否读得出；后院是否太暗；塔是否被万佛殿挡住。

### CAM-05 法界宫/罗汉堂前（第五、六重）

- 位置：万佛殿后、罗汉堂前约 20 m，(30, 272)，眼高 1.6 m。
- 朝向：向北偏东 15–20°（对准五亭顶与塔）。
- 画面：近景是罗汉堂的五亭顶（黄琉璃）与石阶，中景是塔身，远景是塔北山脊。
- 光：黄琉璃在冷天光里要有节制地亮；石阶的阴影。
- 要验证：五亭顶是否一眼认出；罗汉堂的旋转是否自然；塔是否完整出现。

### CAM-06 塔院/塔影田回望城市（第七重）

- 位置：塔东南侧、菜薹田边，(95, 300)，眼高 1.6 m。
- 朝向：向南偏西，回望武昌；或先仰塔、再回望。
- 画面：近景是塔基/铁栏/菜薹田，中景是层层屋顶（万佛殿、罗汉堂、玉佛殿、大雄宝殿），远景是武珞路的楼群与灰天。
- 光：逆光或侧逆光；城市在薄雾里。
- 要验证：回望是否「看见城市」；塔影是否落在田里；屋顶线是否有层次；塔与近屋脊是否相切。

### 4.1 机位纪律

- 六个机位都要能站人、能走上去；不能是悬空/穿墙。
- 每个机位拍 16:9、4:3、9:16 三种画幅（T00 的 `shots.js` 支持）。
- 每个机位至少拍「基准季时 + 一个备选季时」。
- 机位定稿后写进 `camera-manifest.json`，由 `tools/cameras.mjs` 生成清单。

## 5. 「塔的三次露出」的构图

| 次 | 机位 | 构图手段 | 失败的样子 |
|---|---|---|---|
| 1 | CAM-01 | **街对面已能看见整座塔**（2024 年照片证实），在门殿右上方，隔着车流与树；塔是「目的地」的预告 | 塔被门殿完全挡住；或塔与门殿屋脊相切 |
| 2 | CAM-02/03/04 | 进山门后，门殿、弥勒殿、银杏、后院把塔遮住；只在抬头/转角时露一角 | 塔一直悬在画面里，没有「消失」 |
| 3 | CAM-05/06 | 上到第五、六、七重，塔重新完整出现，且比街上近得多；背景是山脊 | 塔与近屋脊相切；塔顶被裁掉；没有「近了」的感觉 |

**注意**：这与 `T01-BAOTONG.md` 原来的「先局部露出、再遮住、最后完整出现」不完全一样。街上的照片显示第一次就能看见整座塔；更准确的节奏是「远看整座—进门消失—高处重逢」。这是设计提案，不是史料。

## 6. 验收口径（看图时问什么）

### 6.1 每张图

- [ ] 主体（塔/殿/门）是否在三分线或中心，是否被切？
- [ ] 近景/中景/远景是否至少有三层？
- [ ] 阴影里是否看得清梁柱、门洞、通路？
- [ ] 黄墙是否有雨痕/返潮/剥落，而不是一片平涂？
- [ ] 湿面与干面是否有可解释的区别？
- [ ] 远塔与近屋脊是否无意相切？
- [ ] 城市背景是否压住了高度（一线 ≤40 m、二线 ≤60 m）？
- [ ] 是否有不属于武汉/清末的器物（日式石灯笼、枯山水、藏式经幡）？

### 6.2 整组

- [ ] 六张是否像同一座寺、同一季节、同一天？
- [ ] 是否一眼看出「城市里的山寺」，而不是「深山古寺」？
- [ ] 塔的出现是否有节奏（局部—消失—完整）？
- [ ] 黄墙、琥珀瓦、青石、菜薹紫是否形成可记忆的色组？
- [ ] 与 T00 的六张并排，是否明显是两座不同的寺？

### 6.3 不能做的事

- 不用生成图冒充现场照片；生成图只定氛围。
- 不把 T00 的宋式大殿/白墙直接刷黄当 T01。
- 不把洪山宝塔做成西安大雁塔/杭州六和塔。
- 不把法界宫五亭顶改成普通歇山。
- 不把城市做成赛博/现代玻璃幕墙；武珞路是 1990s–2010s 的普通城市。
- 不做「满山红灯笼/祈福带」的网红寺。

## 7. 目标图怎么来

T00 的经验：目标图分两类——**真实照片**（定格局与配色）与**生成参考**（定氛围，不证明构造）。
T01 建议：

1. **真实照片**：从 Commons 选 6–10 张（CAM-01/02/05/06 的近似视角），只作研究。
2. **目标图**：在白盒截图的基础上做「光色草图」（不改变几何），或在现场照片上做调色参考；标注「参考，不是实机」。
3. **实机验收图**：必须来自 T01 的页面，标 commit 与 GPU job。
