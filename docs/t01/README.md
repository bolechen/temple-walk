## 先给结论

1. **T01 最值得保留的不是「又一座山寺」，而是「城市里的山寺」。** 山门直接开在武珞路上，门外是亚贸、梦时代、地铁 2 号线宝通寺站；门内七重台地一路爬高，塔在最高处，冬天塔影落在菜薹田里。城市声、院内声、林下声、塔下声可以连成一条由闹到静、再由静回望城市的声线。
2. **空间骨架已经能从公开数据搭出来。** OSM 有导览图与逐栋建筑轮廓，SRTM 有高程，寺方专题有七重台地的文字。把它们拼起来，足以做第一版白盒：从山门到塔约 320 米，爬升约 48 米（SRTM 推算，不是测绘）。
3. **形制与 T00 不同，不能直接套宋式生成器。** 宝通寺现存殿宇多为清同治—光绪重建，大雄宝殿是庑殿顶、面阔五间；法界宫是 1920 年代仿日的密宗坛城，五亭结顶；洪山宝塔是元代砖石仿木楼阁式，1871–1874 年改石檐铁栏。T00 的 `buildHall` 是宋式木构词汇，T01 至少需要一套「清末武汉寺院 + 一座元塔 + 一座近代密宗殿」的补充词汇。
4. **资料缺口仍然明确：** 没有现场踏勘、没有测绘、没有摄影/录音的商业使用授权；塔的逐层尺寸、各殿开间进深、摩崖逐字录文、现状游线都没有一手测量。白盒可以做，精模与真实游线不能假装已经有。

## 怎么读本包的标记

- **【已读原文】**：本包写作时实际打开了页面并读了正文。网页乱码处会注明。
- **【摘要】**：只读到搜索引擎摘要或别人转述，没有打开原文。引用前要再核。
- **【推算】**：由 OSM 轮廓、SRTM 高程或公开数字算出来的，可能有 5–10 米或数度的误差。
- **【设计提案】**：我们自己的取舍，不是宝通寺的事实。可以改，改了不算篡改历史。
- **【未核】**：资料互相矛盾或没有一手来源，开发时不得当作定论。

## 本轮（2026-11-17）读照片后修正的五件事

1. **屋面不是灰瓦**：山门与主要殿宇是琥珀/黄琉璃瓦；塔身与塔檐是赭红/砖红（2024 年近照）。T00 的灰瓦不能直接沿用。
2. **街上就能看见整座塔**：2024 年街景照片里，塔在门殿右上方几乎整座可见。所以「塔的三次露出」应改为「远看整座—进门消失—高处重逢」，不是「先只露塔尖」。
3. **罗汉堂＝法界宫＝海岛罗汉宫**：现场铜牌写「原为法界宫……一九九七年改为海岛罗汉宫。五百罗汉」；寺方专题写 1998 年重建为罗汉堂。三个名字指同一处，年份差一年。
4. **大雄宝殿可能是重檐**：雨照显示前廊之上有下檐、上檐之下是高立面与竖匾「大雄寶殿」，不是简单单檐；阶前有石栏、莲蕾望柱与阶中石雕。
5. **摩崖是山林里的几块石头**：寿泉是一块麻点巨石、栖霞岩是天然崖壁、东岩字迹已风化；旁边有现代仿石挡墙、红绸带、扫帚。不要做成整齐的碑墙。

这些都在 `SOURCES.md` 的矛盾表里有记录；引用时按「照片」而不是「测绘」标注。

1. **不把参考照片当实机证据。** D04/D05/D06 必须来自 T01 自己的页面与白盒。
2. **不把传说写成史实。** 慈忍断足、无念建桥、岳飞手植松、夏斗寅千僧斋，都要么标「相传」，要么只作氛围，不写进可考的碑记。
