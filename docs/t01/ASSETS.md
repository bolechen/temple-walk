# T01 素材与授权计划

核对日期：2026-11-17。这份文件回答：哪些可以直接用 T00 的，哪些必须新做，哪些只能当参考，哪些权利不清不能用。
逐件登记在 `asset-register.csv`（草案，不是最终交付表）。

## 1. 可以直接复用的 T00 资产

### 1.1 扫描贴图（Poly Haven，CC0）

T00 已有 8 套，T01 至少能直接用 6 套：

| T00 资产 | 用途（T01） |
|---|---|
| `TEX-wood` 木纹 | 柱、梁、门、栏杆、藏经楼 |
| `TEX-stone` 石面 | 台基、台阶、铺地、塔基 |
| `TEX-blocks` 砌块 | 黄墙、挡墙、围墙、塔身砖石 |
| `TEX-plaster` 抹灰 | 黄墙的灰泥面、殿内墙 |
| `TEX-bark` 树皮 | 珊瑚朴、麻栎、银杏、黑松 |
| `TEX-leaves` 叶 | 树冠、菜薹叶（需调色） |
| `TEX-snow` 雪 | 冬季台地、屋顶 |
| `TEX-weave` 织物 | 蒲团、幡、帘 |

需要新增的扫描面（仍是 Poly Haven CC0，`tools/textures.py` 打包）：
- **青砖**（塔身、围墙）——T00 的 `blocks` 偏混凝土，T01 需要更细的青砖。
- **黄墙**（寺墙的土黄/赭黄）——可以用 `plaster` 调色，但真实黄墙有雨痕与剥落，建议新扫一套。
- **琥珀/黄琉璃瓦**（山门与主要殿宇的屋面，现场远望照片确认；法界宫五亭顶再亮一档）——T00 只有灰瓦；这是 T01 的**主屋面材质**，需要扫描或高质量程序材质，不能沿用灰瓦。
- **塔身/塔檐**（赭红/砖红砖石 + 石檐，2024 年近照确认）——与殿宇的琉璃瓦区分；不是灰色。
- **铁**（塔栏、钟、香炉）——可以用程序材质，未必要扫描。
- **菜薹**（紫秆、黄花、叶）——程序化或手绘贴图；不需要扫描。

### 1.2 字体（SIL OFL）

T00 的六套中文字 + 日/英/韩共 16 个文件都能复用：
- 「Yunjing Brush」标题、印章页
- 「Yunjing Kai」标签、对白、匾额（繁体）
- 「Yunjing Xing」手写、诗、便笺
- 「Yunjing Bang」重笔匾额
- 「Yunjing Serif」「Yunjing Seal」
- 日/英/韩各自的面

**T01 新增文字后必须重跑 `python3 tools/fonts.py <dir>`**，否则 `pnpm run check` 会因缺字失败。
T01 的新字包括：宝、洪、塔、薹、淳、珙、翊、黎、松、罗汉、法界、华严、珊瑚朴、麻栎、女贞、榔榆、柞木、菜薹、钟声、塔影、禅耕、东岩、寿泉、云扃、栖霞、翠屏、狮子峰、巉岩、爽垲 等。

## 3. 只能当参考、不能进游戏的素材

### 3.1 Wikimedia Commons 照片

本包统计了 275 个文件（S32）：

| 许可 | 数量 | 能用吗 |
|---|---:|---|
| CC BY-SA 3.0 | 243 | 商用可以，但必须署名 + 相同方式共享；闭源商业游戏有风险 |
| CC BY-SA 4.0 | 29 | 同上 |
| Public domain | 3 | 可以用；仍要逐张核 PD 理由 |

主要作者：
- **Vmenkov**：2012 年宝通寺与洪山宝塔约 150 张（CC BY-SA 3.0）。
- **Zhangzhugang**：2012 年宝通寺与塔 30 余张（CC BY-SA 3.0）。
- **Windmemories**：2024 年宝通寺、摩崖、塔（CC BY-SA 4.0）。
- **Auongkinghe**：2026-06-10 的导览图、东山赋、东岩、寿泉、栖霞岩、狮子峰、珊瑚朴、菜苔传说（CC BY-SA 4.0）。
- **Saigyouji-Noriko**：2025 年远望（CC BY-SA 4.0）。
- **Zheng Zhou**：菜地（CC BY-SA 4.0）。

**建议**：全部只作**研究与配色/构图参考**，不进 `dist/`。若所有者接受 CC BY-SA，再逐张选 6–10 张做「书册里的旧照/现场照」，并在鸣谢页列出作者、许可、链接。

### 3.2 旧照片

- 1928 年 Collin de Plancy 明信片集（PD）。
- 1934 年粤汉铁路洪山宝塔照片（PD）。
- 黎元洪国葬牌楼（PD）。
- 1913–1915 年 Clapp 底片（PD 理由未核）。

用法：书册/说明牌里的「同一地点，不同时代」；不做贴图。

### 3.3 导览图

2026-06-10 拍摄的寺内导览图（S32）是**展板照片**，展板设计本身可能有版权；只用来核对建筑相对位置，不抠图、不进游戏。

## 5. 授权与署名

### 5.1 必须保留的署名

- Poly Haven：CC0，不强制署名，但 T00 已在鸣谢页列；T01 保持。
- 字体：SIL OFL；`shared/fonts/OFL.txt`；保留版权行与保留字体名。
- three.js / meshopt / Basis / lil-gui / stats：MIT/Apache；`THIRD-PARTY-NOTICES.txt`。
- ColBase：每件图下保留馆方来源行；修改过的（resize/crop）加一行说明。
- Met/Cleveland：CC0，保留来源行。
- OSM：若用其数据做地形/布局，鸣谢「© OpenStreetMap contributors, ODbL」。
- Commons（若采用）：作者 + 许可 + 链接 + 是否修改。

### 5.2 不能用

- 赵朴初、昌明、傅洪胜的书法原迹（著作权期内）。
- 寺方网页的整段文字/图片（未取得再分发权）。
- 武汉出版社书页的整段/整图。
- 摩崖的网页转录当碑文（错字）。
- 任何「宝通寺独家」的仪式/茶谱/秘方（无来源）。
- AI 生成的「宝通寺实景」冒充现场照片。

### 5.3 需要所有者决定

1. 是否接受 CC BY-SA 的「相同方式共享」义务，用 Commons 照片进游戏。
2. T01 用虚构寺名「栖岚寺」，还是取得授权用「宝通禅寺」真名。
3. 是否请摄影师/录音师做一次合规的现场采集（预算、许可、时间）。
4. 是否买 Poly Haven 之外的商用扫描材质（目前不需要）。
5. 玉佛/卧佛、密宗图像是否要委托制作，还是先用占位。

### 5.4 交付命名（照资料库 V0.2，S58）

每关交付：空间概念图、同白盒四视图、三处特写、材质板、照明预设、资产清单、来源授权表、运行截图。
命名示例：

- `T01_ENV_Courtyard_B01_v001`
- `T01_LGT_Interior_B02_v001`
- `T01_CAM_Interior_Front_16x9_v001`
- `T01_SRC_Architecture_001`

每个版本记录：关卡 ID、场景、季节天气、来源图 ID、相机、太阳方位、材质版本、作者、日期、权利状态、变更说明。

## 6. 资产登记表怎么读

`asset-register.csv` 的 `status` 列：

- `reuse`：直接复用 T00，已随项目分发。
- `planned`：T01 新做，尚未存在。
- `reference`：只作研究/参考，不进 `dist/`。
- `candidate`：候选，许可/内容未定。
- `blocked`：权利不清或没有来源，不用。

`commercial_use` 列只写「yes / conditional / no / unknown」，不写推断。
