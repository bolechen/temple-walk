# T01 打卡点设计

核对日期：2026-11-17。本文从**关卡设计**角度列 T01 可以做的打卡点，并把「真实访客在宝通寺做什么」与「这座寺真正独特的东西」分开。
不是所有能打卡的都要做；第一版建议只做七记，其余可选或不做。

---

## 0. 先定三条原则

1. **打卡不是集卡。** 不做「集齐七处才算上山」，不做进度条、不做「恭喜获得」。每一记只是纸上多一道墨，走完可以一记都没有。
2. **不做求财、求姻缘、算命。** 财神殿、玉佛殿「求正缘」是游客攻略里的民间说法，不是寺方表述；游戏不承诺任何现世结果。数罗汉只做「找到一尊与你此刻相称的尊者」，不做吉凶签诗。
3. **不碰文物、不喂动物、不登塔（第一版）。** 不敲 1240 年的万斤钟，不拓摩崖，不摘菜薹，不喂猫，不爬塔。所有打卡都是「看、听、站、走、记」。

---

## 1. 两种打卡

| 类型 | 做什么 | 例子 | 适合 T01 吗 |
|---|---|---|---|
| 观察型 | 站住、看、听、比较，然后在纸上记一笔 | 看水、认石、寻字、听钟、看影 | **主**：与「巡查便笺」的设定一致，安静 |
| 行为型 | 做一件与地点相称的事 | 领香、绕塔三圈、数罗汉、留影 | **辅**：少量，要有出处，不夸张 |
| 仪式型 | 敲钟、上香、诵经、供灯 | T00 的钟、茶、香、坐 | **少**：T00 已做；T01 第一版不扩仪式 |

T01 的定位是「先验证观察与路线」，所以**观察型为主，行为型点缀**。

## 3. 第一版推荐：山行记·七记

### 3.1 是什么

一张折起来的**山行记**（不是 T00 的朱印帐）：七个小格，每格一个淡淡的墨痕；玩家在对应地点做一件相称的事，格子里落一道笔触和一句短话。
- 打开：B（与 T00 的 book 同一个键位，但内容不同）。
- 不做百分比、不做「还差几处」；没记的格子就空着。
- 结尾按已记的格子说一两句话；一记都没有，也有一句「今天只是走了一趟」。

七记：**入、水、石、字、图、罗汉、塔**。
可选：钟、亭、影、相、猫、城。

### 3.2 七记的触发与反馈

| 记 | 触发 | 反馈 | 失败/跳过 |
|---|---|---|---|
| 入 | 山门内香案前按 E | 三支香出现在手里；纸上落「入」；提示一次「香可以拿到大殿前」 | 不领也能进；格子空着 |
| 水 | 圣僧桥中间站住 3 秒且视线朝下 | 水面起一圈涟漪，一只龟/锦鲤游过；落「水」 | 走动就重置；不强制 |
| 石 | 在大殿阶前先看旧石、再看补石（各 1 秒），按 E | 一句「这一级的石色浅些，边角也齐整」；落「石」 | 只看一块不触发；提示「再走近看看」 |
| 字 | 找到 3 处摩崖，各按 E 读一张小牌 | 第三处读完落「字」；牌上有景名、一句白话、出处 | 找 1–2 处也可以不落记；不显示「还差几处」 |
| 图 | 站在后院/万佛殿走廊，把便笺上的屋脊+塔轮廓与实景对上（视角容差内停 2 秒） | 一声轻磬；落「图」；便笺上的草图淡去 | 对不上就多试几次；不显示箭头 |
| 罗汉 | 进罗汉堂，选左/右起数，走到第 N 尊 | 该尊罗汉的名号/神态出现在纸上；落「罗汉」 | N 由玩家私下选（见 3.4），不存年龄 |
| 塔 | 顺时针绕塔三圈 | 每圈纸上多一道浅痕；三圈后一声塔铃；落「塔」 | 逆时针不计；提示「顺时针」；不催时间 |

### 3.3 为什么是这七记

- **入**：把「门里门外」变成第一个动作；香是真实的入寺礼，且能自然引导到大殿。
- **水**：教玩家「站住」，这是 T01 与 T00 最大的不同；桥是现成的舞台。
- **石**：把「认一处修补」变成可玩的比较，不是看说明牌。
- **字**：摩崖是这块地最独特的文化层；找字比读碑自然。
- **图**：把「塔的三次露出」变成玩家自己完成的一次构图；便笺是原创道具，不冒充古图。
- **罗汉**：真实访客最常做的打卡；但去掉算命，只留「找一尊」。
- **塔**：绕塔是真实习俗，也是全关的高潮；三圈不快，正好把呼吸放慢。

### 3.4 数罗汉怎么做（隐私与尊重）

真实习俗：男左女右，从任意一尊起，按虚岁数到最后一尊，记编号换签诗（约 20 元）。[S45、S46]
游戏里**不建议**让玩家输入年龄/生日，也不存任何个人数据。两个可选方案：

- **A 私下数字**：玩家在 1–500 里选一个数（转盘/输入，不显示、不存），从左手或右手第一尊起走到第 N 尊。最接近「数」的动作，但没有年龄。
- **B 今日步数**：用玩家从山门到罗汉堂的步数（取模 500）作为 N。更「这一刻」，也不用输入；但和年龄习俗不同。

推荐 **A**，并在小牌上写一句「数到哪一尊，只看你此刻想停在哪一尊」，不解释吉凶。
结果只显示：尊名（若有）、姿态/表情的一句话、以及玩家自己记的一句。**不做签诗、不做运势、不做「灵验」。**

### 3.5 绕塔怎么做

- 以塔心为圆心，记录玩家绕行的角度累计；**顺时针**（右绕）才计数。
- 三圈可以一次走完，也可以分几次；不要求连续。
- 每圈在纸上多一道浅痕，不弹窗；三圈后一声很轻的塔铃（可复用/新增合成）。
- 不做「必须走满 108 圈」「必须念咒」「必须捐钱」；不把绕塔变成体力任务。
- 第一版**不登塔**；塔下的三圈就是全部。以后若开放登塔，可在三圈后给一个「上塔」选项，但不改七记。

### 3.6 寻塔（旧草图）怎么做

- 便笺上有一张**原创**的线稿：一道屋脊 + 塔的上半截，比例与实景大致对应。
- 玩家在后院/万佛殿走廊找到让线稿与实景重合的视点；系统用相机朝向 + 位置容差判断（不要求像素对齐）。
- 对上后：草图淡去，纸上落「图」；不显示「正确/错误」，只一声轻磬。
- 这是「设计」，不是史料；线稿是虚构的巡查便笺，不冒充古图。

### 3.7 猫山支线：九间房与七间房

这是 T01 最特别的一条支线，也是所有者做第二关的私人理由之一：宝通寺在武汉以「猫猫寺」闻名，后山有猫舍、猫别墅，寺猫由义工照看。

#### 两处猫舍

| 名字 | 位置 | 样子 | 来源与可信度 |
|---|---|---|---|
| **九间房**（「九间房猫别墅」） | 后山、洪山宝塔旁 | 较豪华的猫舍；山顶水泥砌、灰瓦斜顶，粉笔写「欢迎来到猫别墅」，主要住老猫 | 今日头条游记称「九间房猫别墅」；澎湃写山顶猫别墅住老猫 [S54、S55] |
| **七间房** | 摩崖石刻另一侧、上山路一处 | 一排朴素猫舍/混凝土小屋；「猫舍」石头标记；旁边有捐赠箱，一元也是心意 | 湖北日报称「猫的别墅」提供七间房屋；十六番写「看到写着猫舍的石头」 [S53、S57] |

**七间还是九间，公开资料不一致。** 湖北日报写七间，今日头条写九间房，澎湃只写「猫别墅」；可能是不同时期扩建、两处不同猫舍，或口耳相传的差异。所有者的现场经验是两处都有（九间房、七间房）。开发时：
- 不在游戏里写死「七间」或「九间」为官方数字；可以用「九间房」「七间房」作为**地名**，让玩家自己数。
- 若要做「数房间」的观察，只作为可选的小趣味，不做成就，也不纠正玩家数出来的数字。
- 现场核对：两处的准确位置、房间数、是否可接近、是否允许拍摄。

#### 为什么适合做打卡点

- **有空间**：不是一只随机出现的猫，而是一条「塔后上山—找猫舍—看见老猫」的路线，能把玩家从塔院再往上带一段。
- **有情感**：寺猫是真实生活的一部分，不是布景；义工的猫粮、猫窝、捐赠箱、粉笔字，都是可以看的东西。
- **有边界**：猫舍是猫的家，不是游乐设施；玩家只能在外面看，不能进入、不能抱、不能喂。
- **有节奏**：放在「绕塔」之后，作为全关的**安静尾声**；也可以作为结尾的另一个选择（塔院回望 / 猫山看猫）。

#### 怎么做

- **位置**：塔院之后，沿后山小路上行；先到九间房（近塔），再到七间房（近摩崖/上山路）。具体坐标待现场 GPS；白盒先放在塔北/塔后山坡，接摩崖小径。
- **动线**：可选支线，3–5 分钟；不做主线必经；不挡「绕塔」与结尾。
- **触发**：
  - 走到「猫舍」石头/猫别墅门口，站住 2–3 秒；若有一只猫在门口/窗内，它抬头或继续睡；纸上落「九」或「七」。
  - 不要求「看到猫」才落记：猫在睡觉、躲起来、当天不在，都可以落记——记的是「来过猫舍」，不是「收集到猫」。
  - 不做「找到 N 只猫」的计数；不做猫猫地图任务。
- **反馈**：一声很轻的猫呼噜/铃铛（合成，稀疏）；一句「它在睡觉，不要吵它」或「它看了你一眼」；不弹成就。
- **不进猫舍、不伸手、不投喂、不抱、不追**。玩家靠近到门口即停；猫舍内部是禁区。
- **不做领养/捐款玩法**：捐赠箱只作为世界物件，点它只显示一句「一元也是心意」，不发起支付、不做功德值。
- **不拍照闪光**：留影模式在猫舍附近默认关闭闪光/快门声，或提示「不要用闪光灯」。
- **时间**：猫上午多在后山，下午多在殿前晒太阳；游戏里不需要精确模拟，但可以让猫在上午更常出现在猫舍、下午更常出现在墙头。
- **随机缺席**：猫可以不在。缺席不是失败；纸上的记仍然成立，句子变成「今天猫舍很安静」。
- **声音**：极稀疏的呼噜/轻叫，不循环；不要做成猫咖 BGM。

#### 2025 年领养风波（要避开的方向）

2025 年 7 月，网上出现「宝通寺开放领养寺内流浪猫」的帖子；寺方知客能韬法师随后回应：**官方并未对外发布领养信息，也不主张把已与禅寺结缘的猫送出去**。媒体对数量的说法从 50 多只、80–110 只到一两百只不等；义工说剩下的多是老弱病残、有皮肤病或口炎。[S56]
**设计含义**：
- 不做「领养一只猫」的玩法，不把猫做成可带走的宠物。
- 不把猫舍做成「猫很多、很热闹」的网红猫咖；它是一个**安静的疗养院/猫山**。
- 不做「猫的数量」成就；数量本身在现实中就没有统一统计。
- 可以保留「义工每天上山送猫粮」的痕迹（猫粮袋、水碗、猫窝），但不出现具体人物姓名。

#### 结尾的另一种可能

T01 现在的结尾提案是「塔院回望城市」。猫山提供了另一种收束：
- **A 塔院回望**：城市在下面，塔在身后；收在「人从哪里来」。
- **B 猫山看猫**：从塔后再往上，猫舍很安静，一只老猫在睡；收在「这里还有别的生命」。
- **C 两者都有**：先回望，再往上走到猫舍；结尾按玩家最后停下的地方选一句。
建议先做 A；猫山作为可选尾声，等所有者看白盒后定。

## 5. 不做清单（及原因）

- **财神殿求财、玉佛殿求姻缘**：游客攻略的民间说法，不是寺方表述；游戏不承诺现世结果。玉佛殿只做「看卧佛」。
- **敲万斤钟**：1240 年的宋代铁钟是文物；没有资料说游客可敲。[S17、S52]
- **拓摩崖**：拓片是专业行为，涉及文物表面；只做「看字」。
- **登塔**：第一版不做；资料说可登，但今天政策/安全未核。
- **喂猫/抱猫/追猫/进猫舍**：寺方与义工都提醒不要投喂、不要强抱；猫舍是猫的家，只做门外远观。[S47、S55]
- **领养/捐款玩法/猫数量收集**：2025 年领养风波后，寺方明确不主张把猫送出去；不做领养、不做功德值、不数猫。[S56]
- **闪光灯/快门声惊吓猫**：猫舍附近默认关闭闪光与快门声，或提示不要用。[S55]
- **摘菜薹/进田**：田是寺产；只做田边看。
- **数罗汉换签诗/算命**：不做吉凶；只做「找一尊」。
- **素斋/禅茶体验**：目前只有内容农场来源，未核实；不做。[S51]
- **「小故宫」叫法**：这是社交媒体的标签；游戏里不出现，避免把寺院变成网红布景。
- **财神殿/药师殿求健康**：宝通寺是否有药师殿未核；不写。

## 6. 技术实现

### 6.1 触发

| 类型 | 做法 | 复用 |
|---|---|---|
| 站住看 | 位置圆 + 视线夹角 + 持续 2–3 秒 | `walker` 位置、相机朝向；`__probe` |
| 按 E 读 | 近距 + 朝向 + `pickFloor` 命中 | T00 的交互/卡牌 |
| 绕塔 | 以塔心为圆心的角度累计；方向符号 | 新 `circumambulate` |
| 数罗汉 | 沿罗汉像的顺序点/走；N 私下选 | 新 `countArhats` |
| 留影 | 复用 T00 `capture()` | T00 照片模式 |
| 听钟 | 站住 + 随机钟声窗口 | T00 钟声 + 新触发 |

### 6.2 纸与反馈

- 山行记的纸、笔触、墨痕复用 `paper.js` / `ui.css` 的纸本风格；**不要**用 T00 的朱印（红印是 T00 的语法）。
- 每记落笔：一声极轻的笔触/纸声（合成），不弹「成就」。
- 七记的格子可以是一个竖排的纸条，也可以是一张折页；最终看界面评审。
- 结尾：按已记的格子生成一两句；不做评分。

### 6.3 季节与时辰

- 看影：只在冬季晴日 14:00–16:00 可触发；其他时候田还在，但不落记。提示「塔影要等晴天的下午」。
- 看银杏：秋末（10–11 月）才落「叶」；其他季节只做树。
- 听钟/绕塔/数罗汉/寻字/看水/认石/寻塔：全年可做，不依赖天气。
- 不做「必须某个时辰才能进」的门槛，除看影外。

### 6.4 性能与内容量

- 五百罗汉：第一版用 30–50 尊占位 + 实例化；数罗汉只需要「顺序」和「编号」，不需要 500 个精模。
- 摩崖：5 块石头 + 3 张可读小牌；不做整面碑墙。
- 猫：1–2 只低模/剪影，随机出现在墙头/后山；不做猫群。
- 留影：复用 T00 的 `capture()`；T01 的相框/印章另做。
- 纸：一张折页，不做复杂动画。

### 6.5 隐私与无障碍

- 不询问年龄/生日/性别；数罗汉的 N 由玩家私下选或按步数。
- 不做计时、不做连点、不做必须跳/跑的动作；绕塔可以慢慢走。
- 所有文字四语；纸上的字用可读字号；颜色之外还有形状/位置区分。
- 可以跳过任何一记；结尾不惩罚。
