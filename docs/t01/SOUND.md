# T01 声音设计调研

核对日期：2026-11-17。T00 的音频全部是 Web Audio 合成，没有录音；T01 默认沿用这条路线。
本文先写「现场有什么声」，再写「哪些能合成、哪些必须录、哪些不用」。

---

## 1. 五段声场

| 段 | 位置 | 主导声 | 次要声 | 不该有的 |
|---|---|---|---|---|
| Z1 街边 | 武珞路、山门外 | 车流低频、公交/电动车、地铁口人流、商场空调 | 脚步声、共享单车、远处喇叭 | 可辨识的游客谈话、警笛滥用 |
| Z2 山门 | 门洞、放生池 | 城市声被门洞压低后的闷响、水声、龟拨水 | 鸽子、风过门洞 | 突然的静音；门内不该完全听不见城市 |
| Z3 前院 | 弥勒殿、钟鼓楼、大雄宝殿前 | 钟/鼓、木鱼、磬、诵经（若有授权）、银杏叶 | 游客低声、香炉、脚步 | 商业广播、流行音乐 |
| Z4 林下 | 玉佛殿后、万佛殿、罗汉堂、环山小路 | 风过珊瑚朴/麻栎、鸟、落叶、台阶脚步 | 远处城市闷响、塔角风铃 | 密集的虫鸣（除非夏夜）、野生动物叫声 |
| Z5 塔下 | 塔院、塔影田 | 风、塔角风铃、菜薹叶、城市远声 | 钟声（从寺内传来）、鸟 | 山顶大风（塔不在主峰）、宗教音乐循环 |
| Z6 猫山 | 九间房/七间房 | 风、树叶、极稀疏的猫呼噜/轻叫 | 猫粮袋、水碗、脚步 | 猫咖式连续喵叫、投喂声、儿童追逐声 |

### 1.1 声压与距离

- 街边：城市低频约 55–65 dB(A)（普通主干道，未测）；进山门后应降到 45–50，再进前院 40–45，林下 35–40，塔下 30–35。【提案，需现场测】
- 钟声：T00 的钟约 45 秒衰减；T01 的钟楼在 Z3，塔下听到的是「远处的钟」，要加低通与混响。
- 城市声不能完全消失：塔下回头仍应听见极远的车流，像一层底噪。

### 1.2 时间

- 早晨：鸟多、车少、钟声清楚。
- 上午：游客多、城市声上升。
- 午后：人少、风起、树声。
- 傍晚：鼓声、城市下班车流、光线低。
- 夜间：不开放；若做夜景，只有风、铃、远处城市。

## 3. 合成方案（默认路线）

T00 的 `audio.js` 有三条总线（音乐、山声、音效）、两套混响（庭院、木构殿内）、`instruments.js` 的琴/箫/泛音/钟/鼓。T01 新增：

| 声 | 合成做法 | 复用 |
|---|---|---|
| 城市低频 | 粉红噪声 + 低通 200–400 Hz + 缓慢 LFO；按距离/门洞衰减 | 新 |
| 车流 | 噪声 + 随机经过的带通扫频；不要每辆都一样 | 新 |
| 公交/地铁 | 低频隆隆 + 金属摩擦；不做报站人声 | 新 |
| 地铁口人流 | 宽带噪声 + 稀疏脚步脉冲 | 新 |
| 放生池水 | 水波噪声 + 偶发气泡/龟拨水 | 新 |
| 钟/鼓 | 复用 T00 `bell()` / 鼓 | 复用 |
| 木鱼/磬 | 短促木质/金属脉冲 + 混响 | 复用/新 |
| 风过阔叶 | 噪声 + 带通随时间移动 + 叶簇颗粒 | T00 `trees` 声可改 |
| 鸟 | 复用 `bird()`，只放在 Z4/Z5，白天 | 复用 |
| 塔角风铃 | 小金属铃：几个不谐和分音 + 随机轻击 | 新 |
| 菜薹叶 | 高频细碎噪声，只在 Z5，风大时 | 新 |
| 脚步 | 复用 `steps.js`；新增青石、黄墙院、菜地三种 | 复用 + 新 |
| 门轴/木鱼 | 摩擦噪声 + 谐振 | 新 |

**原则**：

- 城市声是「底」，不是「事件」；不要每隔几秒来一辆车。
- 寺内声是「点」，钟、鼓、磬、木鱼要稀疏；不要循环成背景音乐。
- 林下声是「层」，风、叶、鸟；不要盖过脚步。
- 塔下声是「空」，风、铃、远城市；留白最多。

### 3.1 与 T00 的差异

| T00 | T01 |
|---|---|
| 竹林风、竹击、龙井滴水、檐下滴水、鸟只在山上 | 城市低频、车流、地铁、放生池水、塔铃、菜薹叶 |
| 墙内只有钟磬 | 墙内仍有极远的城市底噪 |
| 山顶回望是群山 | 塔下回望是城市屋顶 |

## 4. 配乐

> 资料库 T01 页也建议「首轮可无配乐」，先采五段环境声，再决定城市声如何变化。[S58] 这与下面的提案一致；配乐可以晚于白盒。

### 4.1 结构提案

T00 是「G 羽、七音主题、七印逐音出现」。T01 第一版不做七印，建议：

- **调式**：仍可用 G 羽，但主题更短（5 音），更「城市」：加入一个不解决的二度/四度，像街声里的不安。
- **乐器**：琴、箫保留；加入木鱼/磬的「点」、极轻的低频持续音（城市底）。
- **段落**：
  - Z1 街边：只有低频与一点点琴的泛音，几乎不是音乐。
  - Z2 山门：琴的一个音，像门轴。
  - Z3 前院：完整的短主题第一次出现（钟声之后）。
  - Z4 林下：主题拆成碎片，箫的呼吸。
  - Z5 塔下：主题只剩骨架，最后一个音不回家（像 T00 的结尾「停在 D，不回家」）。
- **与钟的关系**：钟声响起时音乐退后 14 秒（复用 T00 的 `strike()` 规则）。

### 4.2 不要做

- 不要用「城市噪音 + 电子鼓」做现代感；T01 不是赛博武汉。
- 不要用可辨识的佛号/诵经采样，除非取得授权。
- 不要让音乐盖过城市声/钟声/脚步；T00 的经验是音乐在场景之下。

## 6. 验收

- [ ] 街边能听见城市，进山门后城市变闷，进前院后只剩底噪。
- [ ] 钟声在塔下能听见，但比钟楼前远、暗。
- [ ] 五段声场切换不爆音、不突然静音。
- [ ] 音乐不盖过钟、脚步、城市底噪。
- [ ] 塔下有留白，不是一直有声音。
- [ ] 没有可辨识的游客谈话/报站人声（除非取得授权）。
- [ ] 现场录音（若有）与合成层能分开调音量。

**注意**：自动测试只能证明「不削波、按规则切换、频率对」，不能证明「好听」。T01 的音频最终要真人试听。
