# T01 语言与命名

核对日期：2026-11-17。T00 的规则照旧：**中文是记录文本**，日/英/韩由中文查表；新增文字四种语言齐全，字体重新裁切。
本文只写 T01 新增的术语、命名与翻译陷阱。

---

## 1. 语言范围

- 汉语（简）：记录文本；所有界面、对白、说明先写中文。
- 日语、英语、韩语：由 `app/locales/{ja,en,ko}.js` 按中文查表；T01 的关卡文字放 `app/levels/t01/locales/`。
- 测试与工具固定 `zh-CN`；`lang` 场景与 `mobile-audit --lang=ja|en|ko` 看另外三种。
- 每个分析事件带 `lang`（`withLang`）。

## 2. 命名政策

### 2.1 寺名

- 现状：T00 用虚构寺名「云径禅寺」；T01 暂名「栖岚寺」。
- **未定**：T01 是否继续虚构，还是取得授权用真名「宝通禅寺」。
- 若虚构：
  - 匾额、印章、标题都用「栖岚寺」；不出现「宝通禅寺」四字。
  - 年表、殿名可以取意，但不能写「宝通禅寺始建于……」，要写「本关取意武汉宝通寺」。
- 若用真名：
  - 需要寺方许可；匾额书法不能描赵朴初原迹；年表与殿名要逐条核。
  - 游戏内要注明「场景为原创演绎，非实测复原」。

### 2.2 地名

| 中文 | 处理 | 备注 |
|---|---|---|
| 洪山 | 若用真名，保留；若虚构，可改「岚山」「栖山」 | 洪山是真实地名 |
| 武珞路 | 若用真名，保留；虚构版可改「山门外的长街」 | 不建整条街 |
| 宝通寺地铁站 | 虚构版不出现真实站名 | 只做地铁口体块 |
| 东岩、寿泉、栖霞岩、翠屏、狮子峰 | 石刻景名，若用真名保留；虚构版可换名 | 石刻文字不翻译 |
| 塔影田、钟声地 | 可保留为设计概念 | 不是正式地名 |
| 洪山菜薹 | 若用真名，保留；虚构版可叫「塔下菜」 | 不要写成「油菜」 |

| 藏经楼 | 蔵経楼 | Sutra Library | 장경루 | 在玉佛殿上层 |

| 绕塔 | 繞塔 | circumambulate the pagoda | 탑돌이 | 顺时针三圈 |
| 数罗汉 | 羅漢を数える | counting the arhats | 나한 세기 | 不做吉凶签 |

**翻译陷阱**：

- 「天王殿」与「弥勒殿」是同一殿；不要在同一段里混用两个名字。
- 「法界宫」「罗汉堂」「海岛罗汉宫」是同一建筑（或同一址）的三个名字；不要当成三栋。现场铜牌用「海岛罗汉宫」，寺方专题用「罗汉堂」。
- 「洪山宝塔」与「灵济塔」是同一塔；正文选一个，括号注另一个。
- 「塔影田」不是「塔影钟声」；后者是四字短语/品牌，不是田名。
- 「菜薹」不是「油菜」；英文用 caitai + 解释。
- 「摩崖」不是「石碑」；英文用 cliff inscriptions。

## 4. 新增界面文字（中文草案）

> 这些是 T01 可能出现的句子；定稿后要补 ja/en/ko。占位符用 `{}`。

- 入山：`从街边走进山门。`
- 提示：`点地面走过去。`
- 便笺：`巡查便笺：看见什么，记一句就好。`
- 便笺第一条：`这一级台阶的石色浅些，边角也齐整。`
- 便笺第二条：`排水沟从这里转向坡下。`
- 便笺第三条：`树旁能看见塔。`
- 看塔：`塔在树上面。`
- 回望：`刚才走过的院子，在下面第二层屋顶后。`
- 结束：`可以在这里坐一会儿，也可以继续走。`
- 跳过：`不记也可以。`
- 塔下：`塔影落在田里。`
- 冬季：`菜薹是紫的，花是黄的。`
- 声音提示（可选）：`门外的车声还在。`
- 山行记：`山行记`
- 领香：`领三支香。`
- 看水：`站一会儿，水里有动静。`
- 认石：`这一级石色浅些，边角齐整。`
- 寻字：`石上有字。`
- 寻塔：`便笺上的屋脊，和这里的塔对上了。`
- 数罗汉：`从这一尊起，数到你停下的地方。`
- 绕塔：`顺时针，绕塔三圈。`
- 看影：`晴天的下午，塔影会落到田里。`
- 留影：`黄墙和塔，可以留一张。`
- 遇猫：`墙头有只猫。`
- 回望：`下面是武昌的屋顶。`
- 结尾（一记未记）：`今天只是走了一趟。`
- 结尾（记了几处）：`你把看见的几件事，记在了纸上。`

**不要写**：佛号、经文、许愿语、因果报应式劝诫；不要假装是寺方原话。

## 5. 字体

T01 新增的字（部分）：

> 栖、岚、洪、宝、塔、灵、济、薹、淳、珙、翊、黎、元、松、柏、泉、岩、寿、霞、翠、狮、峰、巉、爽、垲、扃、云、根、飞、雪、半、霄、清、啸、堆、罗、汉、法、界、华、严、禅、耕、钟、影、紫、菘、便、笺、巡、查、修、补、排、水、台、地、屋、脊、檐、栏、铁、琉、璃

- 中文六套字体都要包含这些字；缺字会让 `pnpm run check` 失败。
- 日文用日文字形（如「宝」的日文写法）；韩文用韩文字体。
- 匾额/石刻不翻译；若用真名，石刻文字用繁体/异体，逐字核。
- 新增后运行：`python3 tools/fonts.py <dir with the TTFs>`。

## 6. 不翻译的东西

- 匾额文字（宝通禅寺/栖岚寺、万德庄严等）。
- 摩崖石刻的景名（东岩、寿泉……）。
- 碑文、诗、楹联原文。
- 博物馆来源行、作者名、版权行。
- 寺名/地名的罗马字（可在括号里给读音）。
