# T01 来源账本

核对日期：2026-11-17。编号沿用 `../T01-BAOTONG.md` 的 S01–S15（S06、S12 原为空号，保留不补），本包新增 S16–S43。
每条都写：**读了哪里、能支持什么、不能支持什么**。不是「有这个链接」就算来源。

## 0. 阅读方式与可信度分级

- **【原文】**：本包写作时实际打开页面、读了正文（必要时用浏览器绕开反爬）。引文保留网页原有的乱码/异体字说明。
- **【PDF】**：下载 PDF 并用文本层抽取；印刷页以原文标注的页码为准。
- **【API】**：结构化数据（OSM Overpass、Commons API、SRTM 高程），按字段读，不靠转述。
- **【摘要】**：只读到搜索引擎摘要、新闻转述或百科条目，没有打开原文。**引用前必须再核。**
- **【未用】**：链接打不开或内容不足，明确不采用。

同一个网页可能被多家转载，**转载数量不等于独立证据数量**。寺方网页自身也有乱码、年代混写与编辑痕迹，不能当作碑记原文。

## 5. 再分发与授权边界

- **政府网站/规划 PDF**：可阅读与引用；不要把整份 PDF 或大段文字打包进游戏仓库。引用时注明文号/日期/页码。
- **武汉出版社网页**：可阅读；书页的再分发权未取得。引用要短，注明书名与章节。
- **寺方网页**：可阅读；文字与图片的再分发权未取得。可用作研究，不直接搬运。
- **Commons**：CC BY-SA 3.0/4.0 可以商用，但必须署名、注明许可、相同方式共享；PD 的可自由使用（仍需核对每张的 PD 理由）。**游戏是闭源商业产品时，CC BY-SA 的「相同方式共享」是否可接受，要所有者决定。**
- **OSM**：ODbL；地图数据可以用于游戏，但要署名 OpenStreetMap contributors；衍生数据可能有相同方式共享义务。
- **SRTM/opentopodata**：公开高程数据；作为设计参考，不直接分发原始数据。
- **百度百科/维基百科**：CC BY-SA 或版权不明；只作线索，不直接引用长段文字。

## 6. 下一次核对的顺序

1. 现场许可与边界（寺院、洪山公园、部队用地）。
2. 各殿的面阔/进深/台基/屋顶，逐栋三向照片。
3. 塔的逐层尺寸与现状（能否登）。
4. 摩崖八景的位置、朝向、可读性、拓片。
5. 塔影田的范围与冬季作物。
6. 五段声场的录音（同日、同设备、60–90 秒）。
7. 旧照片/档案的版权（1928/1934/1913–15）。
