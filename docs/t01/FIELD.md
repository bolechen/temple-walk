# T01 现场采集清单

核对日期：2026-11-17。本文是「如果要去现场，带什么、问什么、拍什么、记什么」。
**没有现场许可就不做**；进入寺院与获准拍照不等于获得商业图片授权。

### 0.2 装备

- 相机 + 24–70 mm / 70–200 mm；广角 16–35 mm；偏振镜。
- 手机（记录 GPS、时间、指南针、水平仪）。
- 激光测距仪（室内 40 m 够用）；卷尺 5 m；粉笔/标记贴（不损伤表面）。
- 录音机 + 防风毛套 + 立体声话筒；耳机。
- 色卡（X-Rite 或灰卡）；白平衡卡。
- 笔记本/表格；笔。
- 水、伞、防滑鞋；夏天防蚊，冬天防滑。
- **不携带**：无人机、大型灯架、反光板（殿内）、扩音器。

## 1. 空间与建筑测量

### 1.1 总体

- [ ] 山门中心 GPS、海拔（手机 GPS 即可，标误差）。
- [ ] 山门到弥勒殿、弥勒殿到大雄宝殿、玉佛殿、万佛殿、罗汉堂、塔的**水平距离**（激光/测距仪 + 步测）。
- [ ] 每段台地的高差（激光测距仪从台面到台面，或用水准仪）。
- [ ] 每段台阶：级数、级高、踏面、总宽、有无垂带/栏板。
- [ ] 主要路线的宽度（最窄处）。

### 1.2 逐栋（每栋 15 分钟）

- [ ] 平面：面阔（柱中到柱中，逐间）、进深（逐间）、台基宽/深/高。
- [ ] 立面：檐口高、屋脊高、台基高、门高/宽、窗高/宽。
- [ ] 屋顶：形式（庑殿/歇山/硬山/攒尖）、举高、出檐、瓦作、脊饰。
- [ ] 柱：直径、柱础、收分、侧脚、生起（目测 + 照片）。
- [ ] 斗拱：有无、几铺作、出跳、材等（目测 + 特写）。
- [ ] 墙：颜色（色卡）、厚度、墙脚返潮高度、雨痕、剥落。
- [ ] 门窗：样式、格心、门钉、门簪、门槛。
- [ ] 匾额：文字、尺寸、挂法、底色、字色、落款、印章。
- [ ] 石碑/石刻：位置、尺寸、文字、风化。
- [ ] 现状用途、是否可进、是否拍照允许。

### 1.3 塔（单独 1 小时）

- [ ] 塔基：直径/周长、台基高、石阶、栏杆。
- [ ] 每层：层高、檐口出挑、石檐厚度、铁栏高度/疏密、窗的位置/大小。
- [ ] 收分：每层对角/对边尺寸。
- [ ] 塔刹：文笔峰造型、高度、铜色、与塔顶的连接。
- [ ] 塔记：6 方元代塔记的位置、尺寸、可读性（不拓）。
- [ ] 塔内：能否进、石级、塔心室、光线（若允许）。
- [ ] 塔院：平台尺寸、环道宽度、与菜薹田的高差。

### 1.4 法界宫/罗汉堂（单独 30 分钟）

- [ ] 五亭顶：五个方亭的位置、尺寸、间距、高度、黄琉璃瓦、与大屋顶的连接。
- [ ] 平面：19×16 m 的实测、旋转角。
- [ ] 外顶镂空雕龙、内顶彩绘藻井（若可进）。
- [ ] 现状罗汉数量、布局（若允许）。

## 2. 照片清单

### 2.1 每栋建筑（至少 6 张）

1. 正面（含台基与匾额）。
2. 左前 45°。
3. 右前 45°。
4. 侧面（含进深）。
5. 背面（若可绕）。
6. 屋顶/檐下/斗拱特写。

### 2.2 每处关键物

- [ ] 山门：门洞、门钉、门簪、抱鼓石、石狮、匾、门联。
- [ ] 放生池：水面、桥、栏杆、龟。
- [ ] 钟楼/鼓楼：钟/鼓、楼层、屋檐。
- [ ] 弥勒殿：石狮（正面/侧面/底座）、长联、弥勒、韦驮、四大天王。
- [ ] 大雄宝殿：庑殿顶、前廊栏杆、万斤钟、匾、楹联、供桌。
- [ ] 玉佛殿：卧佛、藏经楼、栏杆。
- [ ] 万佛殿：毗卢佛、万佛壁、藻井、台基。
- [ ] 罗汉堂：五亭顶（四角/俯视）、琉璃瓦、藻井、罗汉。
- [ ] 塔：全景（四向）、每层檐、铁栏、塔刹、塔记、塔院。
- [ ] 摩崖：东岩、寿泉、栖霞岩、翠屏、狮子峰、云扃、《东山赋》。
- [ ] 古树：珊瑚朴、银杏、黑松、麻栎、女贞；树根/树冠/名牌。
- [ ] 菜薹田：全景、塔影、植株特写、田垄。
- [ ] 城市界面：山门外街景、地铁口、公交站、亚贸/梦时代、医院方向（不拍人）。

### 2.3 光线与天气

- [ ] 同一天至少拍「上午/正午/下午」三组，记录时间、天气、太阳方向。
- [ ] 雨天/雨后（若遇到）拍湿石、黄墙、菜地。
- [ ] 雾天/薄霾（若遇到）拍城市背景与塔。
- [ ] 冬季（12–2 月）拍菜薹与疏枝；秋季（10–11 月）拍银杏。

### 2.4 元数据

每张照片记录：文件名、时间、地点、朝向、镜头/焦距、光圈/快门/ISO、白平衡、天气、许可、备注。
回来按建筑/主题建文件夹，保留原图，不覆盖。

## 7. 礼仪与安全

- 不挡香客礼佛；不拍人脸；不进入标有「游客止步」的区域。
- 殿内不喧哗、不饮食、不倚靠佛像/供桌。
- 雨后石阶滑；塔院/山坡注意脚下；不攀爬栏杆/屋顶。
- 夏天防暑、防蚊；冬天防滑、防寒。
- 若被问起，如实说明是游戏研究；不冒充记者/学者/官方。
- 若管理方拒绝，尊重并停止；不偷拍、不绕开。
