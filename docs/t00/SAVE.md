# 存档

游戏把访客的进度存在浏览器的 localStorage 里。浏览器按来源（origin）隔离存储，所以正式站 `temple.rushiwowen.co`、内测 `temple-walk-canary.bole-chen.workers.dev`、另一台设备，彼此读不到。「带走存档」（#338）把整份存档写进一个链接，带到另一处。

## 有哪些键

全部是 `yunjing.*.v1`，`src/carry.js` 的 `KEYS` 逐个列出，并各有一个严格的校验：

| 链接里的名字 | 存储键 | 内容 | 校验 |
|---|---|---|---|
| `journey` | `yunjing.journey.v1` | 朱印帐：哪几枚印、何时得的，钟敲了几下，藏经楼抽到的句子，何时集满、开时节、看过结尾、盖过七印圆满印 | `v` 为 1；印只认本版知道的七处（不认识的忽略），时间为正数；钟 0–3 下的整数；句子是字符串；时节是四季之一 |
| `place` | `yunjing.place.v1` | 上回停在哪：坐标、朝向、地名、时间，楼上时是哪一层楼 | 坐标为有限数且绝对值 < 5000；地名不超过 12 个字；楼层名为小写字母 |
| `settings` | `yunjing.settings.v1` | 歇脚菜单里的设置：画质、环顾快慢、视野、反转、锁定鼠标、自动镜头、三分线、虚化、四个音量，以及 `rev` | 每个字段必须是 `settings.js` 的 `sanitize` 原样保留的值（超范围、类型不对都拒绝）；`rev` 为小整数 |
| `lang` | `yunjing.lang.v1` | 选的语言 | `zh` `ja` `en` `ko` 之一 |
| `visit` | `yunjing.visit.v1` | 这一趟走了多少米、多少秒 | 非负有限数 |
| `prologue` | `yunjing.prologue.v1` | 序章标题已经在山门前升起过 | 只能是 `"1"` |
| `incense` | `yunjing.incense.v1` | 各殿香插下的时间，回来时按墙上的钟接着烧 | 殿只认大雄宝殿、药师殿、观音殿（不认识的忽略），时间为正数 |

不带：`yunjing.debug.v1`（调试面板的开关，存在 sessionStorage）、`yunjing.lang.from` 与 `yunjing.relang.v1`（换语言时一次性的交接，sessionStorage）、`yunjing.ending.v1`（旧版的标记，读过即迁进朱印帐并删除）。

## 链接格式

`https://<目标站>/#save=<数据>`

- `<数据>` 是 `{ v, game: "yunjing", keys: { … } }` 的 JSON，用 `deflate-raw` 压缩（浏览器的 `CompressionStream`）后，再写成 base64url。
- 数据放在 `#` 后面：浏览器不会把它发给服务器，也不会进访问日志。
- 典型长度：两枚印加上全部设置，约 530 个字符（单测会打印），放得进一条聊天消息或一个二维码。
- 打开链接后，页面先把 `#save=…` 从地址里去掉（`history.replaceState`），再问要不要写入；刷新、收藏、截图都不会把它带下去。

## 导入

1. 页面的第一个脚本（`lang.js`）发现 `#save=`，先解码、整份校验，然后在标题之上打开一张纸（`#carryIn`）。纸上写明有几枚印、上回走到哪里，并说明会覆盖这个浏览器里现在的进度。
2. 点「接着走」：先清空这个浏览器里所有被带的键，再写入存档里有的键，两份进度不会混在一起；然后重开页面，标题照常提供「接着走」。
3. 点「不用了」：什么都不写。

## 拒绝

整份拒绝，一个键也不写：
- 任何一个字段校验不过；
- 链接被截断、乱码，或解压不出来；
- 既没有朱印帐、也没有地点（没有可接着走的）；
- `v` 大于本版的 `SAVE_VERSION`：更新的版本做的存档，旧页面不读，并说明「请先刷新到最新版本」。

存档里多出来的、本版不认识的键会被忽略。

## 版本规则

- `SAVE_VERSION` 现为 1。
- 某个键的形状改成旧页面读不了时，把它加 1；同时让 `check` 能读所有旧的版本号。
- 只是新增一个键时不必加：旧页面会忽略它。

## 方向

只有人点了才会搬，没有任何自动回写：内测版的进度不会自己回到正式版，要回去也只能再用一次「带走存档」，并且要确认。

正式版上可以选「本站」或「带去内测版」，内测版上可以选「本站」或「带回正式版」；PR 预览与本机只有「本站」（`carry-page.js` 的 `destinations`，按 `src/deploy.js` 的 `DEPLOY`）。

## 统计

只记两个事件，都不带存档的内容：
- `save.export { to }`：复制或分享了链接，`to` 为 `here`、`canary` 或 `production`；
- `save.import { result }`：结果是 `ok`、`declined`、`damaged`、`newer` 或 `empty`。

见 `ANALYTICS.md`。
