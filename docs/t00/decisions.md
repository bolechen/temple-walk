## 这一轮改了什么，为什么

| 改动 | 原因 | 评审条目 |
|---|---|---|
| 「夏 · 昼」定为基准预设 J01：阴天雨后，几乎没有直射光，天比白墙暗，薄雾 | 交接包要求先统一到 J01，不混用秋暮雪景 | ART-02 |
| 铺地积水从六七成降到少量洼处，其余是哑光湿石；只有常潮的缝有苔 | 「不要把全部地面做成镜面」「不要所有石缝一样长苔」 | ART-01 ART-13 |
| 木色去红、压暗，雨水冲刷处发灰 | 参考图是风化深木 | ART-03 |
| 白墙只在墙脚和压顶下有污痕 | 磨损要有原因 | ART-05 |
| 山门各间改木板壁，次间是关着的版门（门钉、中缝） | 山门应是三门；参考图山门全木 | ART-04 STR-04 |
| 半山亭从坡上挪到平台南侧，坐在伸出坡外的石台上 | 原来山坡穿过亭身，柱础落在坡土上 | STR-01 |
| 每级踏步出挑，挑檐下一条暗线 | 阴天没有影子，从下往上看石阶读不出踏步 | STR-06 ART-08 |
| 照壁顶改成两坡瓦顶加窄脊；匾缩小 | 原来像一块石板压在瓦上 | STR-07 ART-11 |
| 香炉两侧的石灯改成一对不点灯的经幢 | 成对点亮的石灯读作日式 | STR-03 |
| 大殿上下檐间距收紧，去掉其间的格子窗 | 重檐读成了两层楼 | STR-05 |
| 匾额改繁体、楷体（霞鹜文楷），金色调暗 | 寺院匾额用繁体；原来的金太新 | STR-08 ART-11 |
| 柳杉加密压暗，墙外山坡上加一圈柳杉；竹下加矮竹和蕨 | 建筑背后要有深色树林；山坡不能只是一张落叶贴图 | ART-10 ART-06 |
| 竹竿压暗、竹节环变淡；山门前的两棵柳杉外移；铺地上不再长竹 | 竹子像玩具；树挡了山门；竹从铺地里长出来 | ART-07 STR-16 STR-14 |
| 檐下椽子提亮（地面反光），檐下遮蔽减弱 | 暗部要读得出梁柱 | ART-09 STR-02（部分） |

## 关于生成参考图

`T00.png` 和 `T00-sheet.png` 是 2026-11-14 实际打开看过的。只用它们定明度结构、材料关系和气氛：
深木、白墙、灰瓦三者的明暗次序；地面是暗的湿石而不是镜子；植被是深而饱和度低的绿；天是亮灰而不是白。
没有照搬的东西：三间山门、山门两侧直接接院墙、门内正对上山石阶、远处山腰的殿宇位置。
