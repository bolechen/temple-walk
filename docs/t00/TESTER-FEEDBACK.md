# 测试者反馈：把看到的画面原样带回来

在内测版（canary）或 PR 预览上遇到镜头问题（眼睛钻进墙里、钻到地下、他悬空等）时：

1. 在地址后加 `?debug=1`（预览上面板自己打开），打开调试面板。
2. 在出问题的那一刻点「位置」里的「复制反馈地址」（等于控制台的 `__debugURL()`），把地址贴给我们。
3. 地址里 `cam=` 是他站的位置和朝向，`eye=x,y,z,dist` 是眼睛当时的世界坐标和跟随臂长度。打开这个地址，眼睛就停在当时的位置，直到你第一次走动或拖动视角，之后才交还给跟随的弹簧臂。

正式站不认 `eye=`。不带 `eye=` 的地址行为和以前完全一样。（#623）
