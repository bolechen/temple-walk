### 中

1. **第一次来、访客那边是夜里，第一眼几乎全黑。**（已定、已改）所有者 2026-11-17：「第一次进来默认白天吧，序章可以这样」。现在序章（第一次集满朱印帐之前）时辰固定为昼，季节仍是访客自己的；集满一次之后才随访客的钟。`hour` 场景开头断言首访为昼。后续章节怎么办见文末「章节与时辰」。
2. **歇脚菜单十五行平铺，没有分组。** 画质、环顾快慢、视野、上下反转、锁定鼠标、自动镜头、时节、时辰、文字、四个音量，再加一排按钮。访客要找「声音太大」得扫完整页。建议分三段，每段一个小标题和一笔墨线：「看」（画质、视野、自动镜头、时节时辰）、「手」（环顾快慢、上下反转、锁定鼠标）、「声」（音量和三条分音量，分音量默认收起）；「文字」挪到最后或标题页。判定：手机 390×844 不滚动能看到「声」的标题；`mobile-audit` 无报。**单独一个 PR**，等 #180 合入后从 main 起（#185）。
3. **触屏第一句提示一次说三件事**（圆盘行走、拖动环顾、双指远近并换成自己的眼睛），长、且后半句要读两遍。建议拆成按需出现的三句：入山说「推左下的圆盘行走」；第一次拖动画面后说「双指开合，远近」；第一次拉到最近时说「再拉，换成自己的眼睛」。判定：`__hud().said` 顺序如上，每句不超过一行（390 宽）。**已做**（`hints.js` 的 `dragged`、`nearest`）。
4. **按 B 打开朱印帐有等待、没有回应。** 朱印帐每次现画（`drawGoshuin` + `toBlob`），慢的手机上按下去要一两秒什么都不发生，容易连按。建议按下即先开纸面（显示上一次画好的图或一张空纸），画好再换上；或在左上小印上给一个按下的态。判定：`book` 场景里从按键到 `#book[open]` 不超过两帧。**已做**：`keys` 场景断言按 B 的同一帧纸面已开。
5. **朱印帐上的「这一趟走了 0 步，在山上 1 分钟」。** 0 步时说这句有点像嘲讽，分钟又向上取到 1。建议走过 20 步以后再说，分钟不足一分钟说「不到一分钟」。**已做**：走不到 20 步不说，不到一分钟说「不到一分钟」。

## 章节与时辰（给后续章节的建议，待所有者定）

从游戏的节奏看，时辰是叙事的一部分，不只是画面设置：

- **每一章有自己的「首访时辰」**，写在关卡数据里（如 `app/levels/<level>/` 的一项 `firstHour`），像电影每场戏定好光。序章是昼（雨后阴天，J01，教人怎么走，看得清最要紧）；后面的章节可以按故事选，例如一座以晚钟、燃灯为核心的寺，首访就在暮；而不是一律跟着访客的钟。
- **随时辰是走完一章之后给的。** 和时节一样，集满一章的朱印帐后，这一章才随访客的钟、才可选时节时辰。第二次走同一章，看到的是自己此刻的山。这让「再来一次」有新东西看，也和朱印帐的奖励逻辑一致。
- **章节之间可以按顺序推时间**：序章昼，下一章暮，再下一章夜或晨，一趟连起来就是「一日」或「一年」，把地图上的一城一寺串成一段旅程（`VISION-AND-RESEARCH.md`「一城一寺」）。
- **夜不作首访。** 夜的画面靠灯，第一次来看不清路，引导也读不清；夜留给走过一遍的人，作为回访时的惊喜。
- 实现上只需把 `prologueDay` 的「昼」换成从当前关卡读出的首访时辰，`filledBefore` 改成按关卡分开记（每章一个朱印帐键）。
