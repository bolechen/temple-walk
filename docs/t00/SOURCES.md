# T00 效果来源登记

所有者 2026-11-15 定的规矩：**游戏里的每一个效果都要有来源记录。** 新加或改动一个效果（画面、声音、玩法、镜头、界面），
同一个提交里在这里补一行。没有出处的也要写，标成「按常理」或「自拟」，不许空着，也不许把推断写成出处。

「核对」一栏的说法：
- **已核原文**：读过一手文本（古籍原文、博物馆原始著录、参考项目自己发布的文件）。
- **转引**：只读到别人的引用或百科转述，没有见到原书。
- **照片**：从公开照片上读出来的。
- **参考项目**：取自 CLAUDE.md 列的参考项目，拆解见各自的 `docs/*-TEARDOWN.md`。
- **所有者指定**：所有者给的图、选的方向或定的数。
- **按常理**：没有出处，按一般经验或物理常识做。
- **自拟**：我们自己写的字句或设计，不冒充出处。

更细的研究在别处，这里只登记、指过去：真寺的格局与匾额见 `docs/JINGSHAN.md`，美术规范见 `docs/ART-SPEC.md`，
配乐见 `docs/t00/MUSIC.md`，素材许可见 `docs/t00/asset-register.csv`，宋式做法的判断见 `docs/t00/decisions.md`。
