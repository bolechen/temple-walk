## 四、不能动的

这一轮是给现在的身体换形和颜色，不是从零重做。下面这些是别处在用的，动了要先说：

- 骨骼的名字和层级（`root`、`hips`、`spine`、`chest`、`neck`、`head`、左右 `Shoulder/UpperArm/LowerArm/Hand/UpperLeg/LowerLeg/Foot`、`robeFront/Back/Left/Right`、`sashTail`、`hat`），绑定姿势（A 字，38°），他朝 +z。
- 四块蒙皮件（皮肤、袍、裤、鞋，`createMonk().parts`）和 `monk.dress()`；念珠和斗笠是挂在骨头上的刚体。
- `update(dt, speed, pose, t, surfaceAt, grounding)` 的各个姿势：走、`sit`、`chair`、`hop`、`bind`，以及 `rites.js` 写进 `act` 的合掌、举碗、拉绳。手到嘴、到眉、到绳的偏移是按现在的比例定的，头变小以后要跟着重定。
- 他的宽度 `BODY`（0.38 米，`geo.js`）和外廓 `tools/walk/outline.json`。体量变了要重量；烘焙的地面可能跟着变（#469 走过一遍）。
- 现有的测试：`tests/unit/monk.test.mjs`、`novice.test.mjs`、`rites.test.mjs`，`pnpm run edges`。
- 出图工具：`node tools/novice-views.cjs --code`（五个姿势四面，几秒钟）、`node tools/portrait.js summer-day bind`（A 字正、侧、背）。
- `novice.glb`、`novice.js`、`novice-tripo.glb` 和它们的工具留着不删；Tripo 那条线所有者已叫停，不在这一轮里。

## 五、怎么算做完

「一比一」的口径，所有者 2026-11-23 定了，原话是「**尽可能还原设定图**」（经总主创转）。下面是美术总监对这句话的读法，不是所有者的话：轮廓、比例、颜色、脸要和设定图一致，这四样有下面的数管着；质感（软陶那种哑光、柔和的明暗、布的细绒）也往设定图上靠，能做到几分做几分，不拿「游戏自己的材质」当不做的理由。做不到逐像素一样的地方（设定图是影棚平光，游戏里是有方向的天光）写明差在哪，由所有者看图定够不够。

1. **轮廓。** `tools/portrait.js … bind` 出的正、侧、背三张，缩到和 `refs/monk-v6-ortho/` 同一比例、脚底对齐后叠上去，人形的重合度（交 ÷ 并）正面和背面 ≥ 0.92、侧面 ≥ 0.90。斗笠背在背上那一格不算在内。这三个数是我估的，第一版出来量过以后可以重定，重定要写明原因。
2. **比例。** 第二节表里的每一行，做出来的在 ±1.5% 全高以内（约 1.8 厘米）。
3. **颜色。** 首院正面全身（`?shot=1&q=medium&show=cam06&view=third`，眼睛用 `__look` 放到他面前 2.4 米，夏昼）：袍的中位数和正式版现在的闭眼身体相差不超过 3 个 L\*，不比它更红更艳；额头同。袍 ÷ 额头的亮度比重新量一个数，写进 `skills/art-gate` 判法 25。
4. **脸。** 正面近景一张，对 `monk-poses-v6-2026-11-23-gassho-head.webp` 的上面两格：闭眼的弧、短平眉、小鼻、浅笑、淡腮红、耳朵低（耳顶约齐眼）。**这一条所有者点头再往下做。**
5. **姿势。** 走、上下台阶、合掌、盘坐、凳坐、背笠各一组图，没有穿插、没有撕裂、袍摆不进台阶；盘坐和凳坐对 `…-sitting.webp`，合掌对 `…-gassho-head.webp`。
6. **访客看到的。** 竹径石阶第三人称背影（`?shot=1&q=high&show=cam02&view=third`）和首院跟随各一张，新旧并排。这是访客九成时间看到的画面，美术终审按这两张判。
7. **不变慢。** 首院 T4 上的帧耗不高于改之前（`tools/gpu-render.sh`，改前改后各量一次，写进 `docs/HANDOFF.md`）；他的三角形数写明。
8. **测试。** `pnpm run verify`、`pnpm run edges:grid` 0 处超出、`walk-diff` 命名地点都到得了。
9. **出处。** 看得见的改动登记进 `docs/t00/SOURCES.md`。
