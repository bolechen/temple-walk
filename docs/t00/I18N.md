# 日文、英文界面（2026-11-16）

用户的话：「demo 上线的实时数据来看，日本用户不少，分析增加日本界面的可行性」→「开 pr 落地」→「一起加英文版」→「日本用户越来越多，尽快完成 mvp 上线」。

## 怎么选语言

`src/i18n.js`。顺序：地址里的 `?lang=zh|ja|en`（并记下）→ 上次在菜单里选的（`yunjing.lang.v1`）→ 浏览器语言里第一个是中、日、英的 → 浏览器三种都不说的给英文 → 中文。歇脚菜单里有「文字」一行，标题右上角给另外两种语言；切换后整页重开。

## 怎么译

- 中文仍是原文。代码里写的都是中文，`t("中文")` 按访客语言到 `src/i18n-ja.js`、`src/i18n-en.js` 里找，**以中文本身为键**，找不到就显示中文，不会空着。`{n}` 这样的空在三种语言里都填。
- `index.html` 由 `app/lang.js` 在标题画出来之前整页换掉（文本节点和 aria-label、alt、title、meta）。
- `tests/unit/i18n.test.mjs` 从源码里收集页面会显示的每一句（`t()` 的字面量、`index.html`、七印、得句、照片诗句、殿内小画、殿名），要求日、英两张表都有、空位和标记一致、表里没有页面已不用的句子。加一句中文就得在两张表里各加一句，否则单测不过。

## 有意没有译的

| 什么 | 为什么 |
|---|---|
| 匾额（`plaque.js`） | 刻在寺里的字。日本访客当汉字读，其他访客当书法看 |
| 印、朱印帐那一页、标题「山门之外」四字 | 是书法。日文版改成日本字形（聞鐘、雲径禅寺、奉拝），英文版保留原字，就像外国人在日本寺院拿到的御朱印。印下的地名和页脚是访客的语言 |
| 馆藏说明（`works.js`） | 博物馆著录的原文。卡片上多一行「解説は今のところ中国語のみ」／"The museum notes are in Chinese for now"。14 件来自东博、九博（ColBase），馆方有日文著录，**能否转载要先查条款** |
| 内测反馈群 | 群在微信、说中文：日文、英文页面不显示 |
| 调试面板、`?tour` 测量 | 只给开发者 |

## 字体

日文：Klee One（霞鹜文楷就是从它改的）、Noto Serif JP（正文 400、印 900）、Yuji Boku（标题、朱印帐）、Yuji Syuku（照片诗句、纸签、小画题字）。英文：EB Garamond（正文）及其斜体（手写的地方）。都是 SIL OFL，从 google/fonts 取，`python3 tools/fonts.py --lang ja|en <目录>` 裁到各自表里的字。每种语言的字体排在中文字体前面，缺的字（没译的、书法）落回中文字体。浏览器只下载用到的字体：中文访客一个字节也不多下。`pnpm run check` 分别检查三张字表。

英文排版：字距收紧（中文的 .3–.6em 拉开的字距对拉丁字母不成立），留影、歇脚两张签条和纸签改横排。

## 还没做（按重要程度）

1. **两张表都是开发方写的初稿，没有母语者审过。** 语气按中文原文的规矩（写具体的人、器物、动作，不替玩家下结论）。得句十四句的日文用書き下し，英文是自拟的译法。上线前最好各找一位母语者通读 `i18n-ja.js`、`i18n-en.js`。
2. 馆藏说明的日文、英文（`tools/gallery.py` 出第二份；先查 ColBase 的转载条款）。
3. Umami 事件还没带语言，看不出日文访客走到哪一步。
4. `brush-ja`、`xing-ja` 按整张日文表裁，各约 380 KB；可以只裁到标题、诗句用的字。
5. 菜单里的中文标签是「文字」不是「语言」：中文字体里没有「语」「言」，要重裁中文字体才能改。
6. 没有在真手机上看过日文、英文页面；`node tools/mobile-audit.cjs --lang=ja` 的结果见 PR。
