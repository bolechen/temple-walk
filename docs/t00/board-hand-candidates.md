# 匾字的取舍：集字可行性与开放字体候选（#192 第二步）

标准不是「匀不匀」（所有者 2026-11-19 更正：他指的是字上的黑块，已由 #216 修好），而是 T00 的卖点：匾上的字与殿里挂的宋人真迹同出一手。以下只做对照，不改线上的匾。

|---|---|---|---|

| 萬年正續 | 山门下檐 | 同上 | 4 |

## 二、(a) 集字可行性：张即之

查了我们已登记的两件、大都会、Commons。结果：**没有一块匾能用张即之一人的字做齐。**

| 来源 | 许可 | 张即之的字 | 匾上用字里有的 | 说明 |
|---|---|---|---|---|
| 大都会 2000.325《乐游园歌》残卷（已在凌霄阁画框，`met-zhangjizhi-leyouyuan`） | CC0（Open Access，已核 API：`isPublicDomain: true`） | 大字行楷，八字：幕 排 銀 牓 拂 水 低 徊 | **无** | 原图 4000×3002（画心 32.4×76.8 厘米）；是他大字的样子，但八字与匾无一重合 |
| ColBase TB-1209《楷书大方广佛华严经册》（已在藏经楼画框，`zhangjizhi-huayanjing`） | ColBase 可自由使用，须注出处 | 小楷，每字约 1.5 厘米；我们登记的这一开 | 法、眼（读这一开所见，未做全册逐字索引） | 小楷放大做榜书，笔画比例与他的大字不是一路，不宜直接用 |
| 大都会其他张即之 | — | 检索 `Zhang Jizhi`（v1.1 接口）只有 2000.325 一件 | — | — |
| 上海博物馆《待漏院記》（Commons） | Commons 记为公有领域 | 楷书大字 | 见 #192 评论：萬、寺 | **Wikimedia 接口回 429，没有绕**；未取到图，未核字 |
| 台北故宫《李衎墓誌銘》等 | 许可未核 | 楷书 | 未查 | 不列为可用 |
| 东福寺「禪院額字」（寺藏） | 寺产，Commons 图 570×256 | 额字 | — | 图太小 |

拼偏旁（集字的老办法）：

- 徑 = 彳 + 巠。华严经册这一开有「經」（巠）、「得」「行」（彳），可拼；**拼的要标明是拼的**，而且是小楷的字根。
- 雙、歸、堂、藏、禪、雲、寺、茶、喫、去、年、正、萬、續：这一开与《乐游园歌》八字里都找不到可拆的部件。
- 所以按匾列：五块一块都做不齐；「正法眼藏」最近（法、眼有，正、藏无）。

要继续只剩两条路：(1) 在浏览器里查 ColBase 全册 TB-1209 逐页建字索引，并等 Commons 限流放开取《待漏院記》；(2) 用无准师范的字（所有者已知「釋迦寶殿」四字出自原迹，「歸」「堂」「雲」「禪」见 #192 评论），但那是另一个人的手，不能与张即之混在一块匾上。

## 三、(b) 开放字体候选

| 候选 | 许可 | 保留字体名 | 匾上 17 字缺 | 与张即之大字的对照（见 `zhang-strip.jpg`） |
|---|---|---|---|---|
| **Yuji Boku**（= Yuji Syuku = Yuji Mai 的汉字，字形逐点核过相同，差别只在假名） | SIL OFL 1.1 | 无 | 无（《乐游园歌》的「牓」无） | 最近：起笔切口方、收笔带飞白、横画重而竖画顿，笔画是尖的；比张即之温和、字形偏方正 |
| Kaisei Tokumin Bold | OFL 1.1 | 无 | 无 | 是明朝体，笔画有明确的粗细对比和圆头；不是楷书 |
| Potta One | OFL 1.1 | 无 | 无 | 重笔，但是圆头的流行体，不庄重 |
| 全字庫正楷體 | 政府资料开放授权 v1.0 与 OFL 1.1 双许可，任选其一（字体文件版权行与 Debian 包版权文件均如此写） | 无 | 无 | 干净的教科书楷体，笔画偏细；要到榜书的粗只能再加粗，起收笔的顿挫没有 |
| 霞鹜文楷 TC 粗体（现在线上，#207） | OFL 1.1 | 有，已改名 Yunjing Bang | 无 | 印刷体，起收笔圆润 |
| 衡山毛筆フォント（青柳衡山） | **未列**：只查到 2009 年的新闻稿说「商用、非商用皆可」，没找到再分发、嵌入网页的条款原文 | — | — | 核不清，不列 |
| Ma Shan Zheng（马善政） | OFL 1.1 | 无 | 缺 萬 續 雙 徑 歸 喫 雲 禪（8 字，只有简体） | 不能用于旧字形匾；现用于标题 |

没有一款开源字体是照张即之或无准做的（JINGSHAN.md 早已记下）。

## 四、(c) 总对照图

- `compare-raw.jpg`：五块匾 × 5 款字体（不补墨），画在真匾的配色上；每行标字体名、许可、同匾各字笔画宽的差。
