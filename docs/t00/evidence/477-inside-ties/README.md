# #477 第二处：同一位置的并列面让烘焙随远处的树改变

#533 合并后，T05 主创把远处的银杏换成别的再烘一次，大雄宝殿月台脚下仍差 6 格。本 PR 追到根，并把 `bake.mjs` 里所有取「第一个交点」的地方过了一遍，发现同一类问题有两处，都修了。

## 一、机制：谁先返回，取决于整个场景

three-mesh-bvh 返回同一距离的面时，顺序由 BVH 的分裂决定，而分裂跟着场景里**每一个**三角形走。两个实体贴在一起时，它们的面落在同一个位置（月台的石座与踏步在踏步头；柱子的脚与柱础的顶；墙脚与台面），哪个先返回，换一棵远处的树就可能变。烘焙里有两处靠「先返回的是谁」下结论：

1. `inside()`（判断一点是否在实体里）：四条水平射线各取第一个交点，是背面才算在里面。石座的背面和踏步的正面在踏步头重合，取到正面就判成「在外面」，石座里的假地面（`aboveUp && inside` 本该把它去掉）就留下，邻格边界差 5 cm。这是月台脚下那 6 格。
2. 向下的那条射线（每格的地面）：`above - y >= CLEAR` 判一个面上方有没有一人高的空气。墙立在台面上时，墙脚（朝下）与台面（朝上）同高；朝下的先返回，台面上方没有空气，不是地面；朝上的先返回，台面上方是墙里的 5 m，成了「地面」。（`inside()` 只在上一个面朝上时才被问到，墙里嵌着梁，上一个面是梁底朝下，就问不到了。）这一处在本 PR 之前没被发现：T05 的 `[9.26, 3]` 与 `[3]` 在一万多个格子上取决于顺序，其中 155 格的最终开关也不同（见第四节）。

## 二、修法

1. `inside()`：取到第一个交点后，再看它前后 1 mm 内的**所有**面。有背面就算离开了实体；只有同距的面全是正面，才算从空地进入。
2. 向下的射线：同距时固定顺序（朝下的在前，再按材质编号）：`hitOrder(S)`。同一平面上，朝下的面在，台面上方就没有空气，不是地面。`BAKE.version` 29。

### 其余取「第一个」的地方（逐个）

| 位置 | 做什么 | 并列时会不会改结论 |
|---|---|---|
| `inside()` 的 `raycastFirst` | 见上 | 会，已改 |
| `inside()` 的 `tie` 射线 | 在第一个面前 1 mm 起、2 mm 内取全部面，只问有没有背面 | 不取「第一个」，与顺序无关 |
| 每格向下的 `raycast` 与排序 | 见上 | 会，已改（固定顺序） |
| `shapecast`（边界，`bake.mjs` 的第 4 步） | 访问一格周围的三角形，顺序随 BVH | 开关由 `min`/`max` 取（`wlo`、`whi`、`llo`、`lhi`、`sill`、`wpost`），与顺序无关；只有 `what`/`lwhat`（给关上的格子起什么名字）取第一个或最后一个，只改格子的名字（`walk-diff` 里「部分」的归属），不改开关；两关的开关位在测试里与顺序无关 |
| `tools/walk/*.mjs` 其余文件 | 没有 `raycast`、`raycastFirst`、`shapecast` | — |

## 三、1 mm 的容差

- 本来要重合的面是用同一组数画出来的，只差 float32 的舍入：离原点 100 m 处一个单位是 8 微米（不到 0.01 mm）。1 mm 是它的一百多倍。
- 生成器里我找到的最小的有意偏移是 4 mm（月台边上的压条，`building.js`）；1 mm 在它之下，所以不会把有意分开的两个面并成一个。
- 格子是 50 mm，1 mm 是它的五十分之一，不会让容差本身改变一格的开关。
- 高度判断里已有的同高容差是 2 mm（`Math.abs(above - y) < 0.002`），同一数量级。

## 五、单测（`tests/unit/walk-bake-inside.test.mjs`）

1. 台阶与石座并列面：24 个种子的远景，`inside()` 在石座里恒为真（旧规则 12/24 不一致）。
2. 空地、月台上方、台阶之外为假，台阶内为真。
3. **正面对正面重合**：两块一样的实体叠在一起（每个面有两份，都朝外），点在它们外面，判「不在里面」，12 个种子。
4. **没有重合时与改前一样**：20 个种子、每个 30 块互不贴合的方块、1200 个点，与「四个方向的第一个面是背面」的旧写法逐点比，一点不差；点既有在里面的也有在外面的。
5. 同一高度的面：把 BVH 返回的顺序随机打乱 40 次，`hitOrder` 排出来的顺序恒为一种，且在石座的顶（y = 1）上墙脚（朝下）在前、石座（朝上）在后。旧写法（只按距离）这一项不过。
6. 真实的 T00 场景：围着首院窗口烘焙两次，一次全部场景，一次把树皮材质的网格全藏起来，一格不差（旧规则 9 格不同）。
