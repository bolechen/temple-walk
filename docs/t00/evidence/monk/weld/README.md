## 怎么修的（`tools/novice.mjs` 第 4a、4b 步）

1. **同一点同一份权重**（4b，`tools/novice-weld.mjs`）：距离小于 1e-5 米的顶点副本归为一组，取同一份权重。
   - 第一步的比较页用的是「整组取平均」。实测平均会弄坏三条原有检查（任何平滑次数都一样）：
     - 下摆里侧缝在裤子上，平均以后一半是裙摆骨骼、一半是大腿，下摆挂在裙摆骨骼上的比例从 0.9 以上降到 0.86–0.90；
     - 脚踝处鞋拿到一半小腿权重，降到 0.87–0.93；
     - 走路时裤子从袍子里露出 21–23 厘米。
   - 所以两个部件交界的点**只取一个部件的权重**：鞋优先于袍，袍优先于皮肤，皮肤优先于裤。同一部件里的接缝照样平均。
   - 平滑也只在同一部件里做，袍子的权重在袍子里扩散，到边上为止。
2. **手臂按在臂上的位置取权重**（4a，新加）：只做第 1 步时，合掌的斜俯图上袖口拉出一大片浅色三角（见下表「只焊合 8」）。
   - 查下来不是接缝。雕刻身体的手臂比代码身体张得开（手腕处高约 10 厘米），袖子又缝在前臂上；代码身体的袖子是从上臂垂下的宽袖。
   - 所以「最近的代码身体顶点」在前臂上会取到上臂或手的权重：一圈前臂皮肤全挂在上臂上，紧挨着的全挂在手上，合掌一屈肘，3 厘米的边被拉到 25 厘米。
   - 改成：手臂上的皮肤和袖子按离肩关节多远、对照骨骼自己的上臂（0.20 米）和前臂（0.15 米）取权重，过肘、过腕各在几厘米里渐变。
   - 只在离「肩关节到雕刻身体手心」这条线 7 厘米以内（10 厘米外完全不管），且沿线 8 厘米以外（14 厘米起完全按臂）。
   - 第一次没有限定「沿线向外」，这条线往肩后延长到了脖子，领子被掀起来；加了方向以后好了。

- **「只焊合 1」不能用**：原有检查「裤子不比绑定姿势多露」没过，走路时露出 65 mm。2 档以上原有十条全过。
- **加了手臂一步以后，袍边的条数反而比只焊合多**：袖子现在跟着前臂弯，肘外侧的布被拉长；以前是手从不动的袖口里抽出来。
  - 这张表只量袍子，前臂那片三角是**皮肤**，表里看不到。
  - 合掌时皮肤拉长 3 倍以上的边：改前 175 条（最长 8.2 cm，因为是裂开的）、只焊合 8 是 298 条（最长 25.7 cm）、焊合+手臂 8 是 87 条（最长 7.2 cm）。
  - 看图（`compare-pray.jpg`）：只焊合时袖口有浅色楔形，加手臂一步后没有。
- **4、6、8 三档看图都没有碎片**，8 档每个姿势的条数和最大拉长都最低。截图里看不出袖口、手指因平滑变软。10 档以上没试。

## 结果（看图）

- 站立、合掌、走路：正、侧、背、斜俯都**没有可见的碎片和裂缝**（`views-after.jpg` 前三行、`compare-stand/pray/walk.jpg`）。改前在袖口、手腕、下摆有白色碎片。
- 坐凳、盘坐：**仍然撕裂**（`compare-seated.jpg`）。改前是碎片，改后连成被拉长的布片，膝盖和腿上露出灰白的裤子和破面。
  原因是袍子下面没有腿，见 `docs/t00/monk-body-options.md`「A 为什么解决不了坐姿」。要分层的模型（B 路）。
