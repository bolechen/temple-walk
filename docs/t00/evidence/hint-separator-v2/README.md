# 提示行折行：「·」不挂行尾，也不丢（#747，8967965 之后的修法）

「怎么走」那句，触屏、DPR 2、`q=low`、四种语言（中、日、英、韩）。`collage-v2.jpg`：左列 390 宽，右列 320 宽。折行的行，「·」收起、改成真的断行；没折行的行，「·」在两段中间。
这一版是改了「收起的点换成真的断行」之后重拍的；上一版 `t00/hint-separator` 里的 320 宽韩文，点收起后两段又并回一行、中间没有点（美术初审发现的），那一张和它的 README 说法作废。
守卫：e2e `hint-break`：四种语言、两句话（怎么走、合书后）、各两种形状（触屏、键盘），260–360 宽每 4 px 扫一遍，每一对相邻两段，在同一行就必须有点，在两行就必须点收起、断行是真的；再把行藏起来（拍照）、回来，状态与藏起之前一样。
