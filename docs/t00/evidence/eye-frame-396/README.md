## 门口近景：去掉暗盒前面那一面，院子里看到的画面是否改变
本地同一份构建、同一台机器，只切换 `building.js` 里那一行（去不去掉暗盒的前面），第一人称，固定时间，960×540，大殿、禅堂在门前 4 m 和 2 m 各拍一次。

| 文件前缀 | 构建 |
|---|---|
| door-closed-* | 保留前面那一面（修改前） |
| door-open-* | 去掉前面那一面（本 PR） |
| door-open2-* | 去掉前面那一面，同一份构建再拍一次 |

结果：`closed` 和 `open2` 四个视角逐像素完全相同（最大差 0）。`open` 和 `open2` 是同一份构建拍了两次，大殿 4 m 却在 (407, 229) 处有 6 个像素不同，是一个 3×4 px 的小点。所以这个小点是两次运行之间本来就有的差异，与本 PR 无关。
