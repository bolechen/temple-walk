# 结尾后停在远景（#147）证据

画法：`node tools/far-views.cjs <outdir>`。夏昼，`q=low`（软件渲染），`?fast=1`（结尾快放），第一次来的人在山顶静坐，结尾演完后一页依次改成三种画幅，镜头保持在远景上。

- `far-16x9.jpg`（1280×720）、`far-4x3.jpg`（1024×768）、`far-phone.jpg`（390×844）：结尾演完后、玩家操作前。画面上只有底部一行「B 翻开朱印帐」；朱印帐没有自动弹出。
- `far-phone-book.jpg`：按 B 翻开朱印帐，凌霄阁在纸后。
- 改前：main 上结尾一演完就弹出朱印帐，盖住画面；没有拍对照图（改前的画面就是 `far-phone-book.jpg` 那样的纸页）。
- 手机上提示行写作「翻开朱印帐」，点这一行打开（`far-phone.jpg` 是电脑口径下的键位写法；触屏的写法由 `hints.coarse` 决定，没有单独拍）。
- 没拍：四种语言。
