# #192 匾字恢复为 Yuji Boku：三个版本并排

所有者 2026-11-19 更正：当初指出「喫茶去」有问题，说的是字上的黑块（匾被斗拱挡住，已由 #216 修好），不是字的轻重不匀；#207 换成霞鹜文楷 TC 粗体是不必要的，而且是印刷体，不够庄重。本 PR 把匾字恢复为 Yuji Boku 及其画法。

- **`boards-three-builds.jpg`**：三列，从左到右
  1. #207 之前（`bc7a68f` 的上一个提交）
  2. 现在线上（`d0da596`，#207 起的霞鹜文楷 TC 粗体加按字补墨）
  3. 恢复后（本 PR 的 head）
  - 六行：大殿「正法眼藏」、山门两块、照壁「雙徑歸堂」、茶寮「喫茶去」（两个机位）、功德箱（#207 之后才有，第一列空）。
  - 软件渲染（SwiftShader，1280×720，`?shot=1&q=medium&view=first`，夏昼），不是 T4。每个版本只开一次页面，眼睛用 `__pose` / `__look` 站到各处；工具是 `tools/plaque-views.cjs`，拼图是 `tools/plaque-sheet.py`，功德箱用 `node tools/shots.js shot-main-box`。
  - 机位：大殿 `__look(at 0,3.2,2.0 → to 0,6.9,-4.6)`；山门 `cam=0,53.5,0,0.45`；照壁 `__look(0,1.8,64.5 → 0,2.5,55.4)`；茶寮 `cam=-9,16.5,-1.18,0.55` 与 `-7.0,14,-1.571,0.28`。
  - 第三列与第一列的字形逐点相同（`bang.woff2` 里「正法眼藏」四字的轮廓哈希一致）；两列大殿匾的位置不同，是 #216 把匾挂到了斗拱昂嘴之外。
