# #518 并排对比：0.6.0 / main / D0.5 / D0.8，以及墨池边下层清前清后

用的是本地构建，SwiftShader，1280×720；竖屏是 390×845。每张图都在 `__eyeSpace` 变成 ready 之后再等 90 帧才拍（0.6.0 没有这一步，它走的是写成的平面）。

各版本：
- 0.6.0 = 标签 v0.6.0；
- main = 6699c5d；
- D0.5 = 本分支 c2a9a2a 至 67783c4（不清下层）；
- D0.5+clear = 同上，加上清墨池边 1.4 m 内的下层（即 3bdf197 写进代码的规则，当时是在临时工作树里试的）；
- D0.8 = 只把 `EYE_EDGE` 改成 0.8，没有提交；
- head = 3bdf197（已清下层）；
- mainfp = main 6699c5d，第一人称。

## 叶子怎么量（`leafmetric2.mjs`）
- 按记录下的镜头在 Node 里种出同一片竹林。从 0.6.0 到现在 GROVE 和 bamboo.js 都没变，所以 0.6.0 也用这片林子。
- 叶片按贴图自己的透明度判：在浏览器里画出叶片贴图取 alpha，每 4×4 像素取平均，0.5 以上算不透明。
- 只算比他更近的叶子：沿视线的水平距离小于镜头到他的臂长。
- 在画面 64×36 个点上统计：
  - 近处叶子占画面的比例；
  - 其中不在四角的部分（四角定义为 |x| > 0.6 且 |y| > 0.6）；
  - 落在他的框放宽 5% 之内的比例；
  - 再沿视线看，到他的头、腰、脚，到池中，到碑，第一下打到的是什么。
