## 垂带

- 单测 `tests/unit/cheek-feet.test.mjs` 沿场上每段三级以上台阶（16 段）的每块垂带往下找：横向取 3 点，纵向每 5 cm 一点，找它下面第一块朝上的、不属于台阶本身的面。
- **main 上失败两处**：
  - 进山第二段（rise 4.5 m）西侧垂带脚，比土高 5.3 cm；
  - 上山顶那段 82 级台阶最下面两米：山坡在那里为台阶让开了，底下是空的。两侧有墙，站着的地方看不到。
- **禅堂、药师殿两处在 main 上就不悬空**：墩和象眼埋在铺地下 10 cm，垂带头埋在铺地下 2 cm。普查图里那块「三角楔」，`picks.txt` 里逐像素的命中都是 `steps`：对面那块垂带朝踏步的内侧立面（禅堂 z≈12.4、药师殿 z=−48.5 的面），以及垂带顶落在檐影里的部分，不是空气。`yaoshi-near-slot.jpg` 是贴近拍的同一处。主创同意不改这块（真台阶也有这个面）。
- **改法**：按评审的「方头落地、墩做到地」，垂带不削短。
  - 垂带下端切成方头，落地一掌长（12 cm）；方头连同墩、象眼一起做进地下 0.4 m（`CHEEK_STONE.base`）。
  - 象眼的两道退线在地下止于象眼尽头。
  - 山顶那段台阶脚下垫一块观音殿台地同样的石头，2.6 m 长。
- **改前改后**：
  - 禅堂：`pairs/chan-*`，含普查地址 `chan-cam`。
  - 药师殿：`pairs/yaoshi-*`，含 `yaoshi-cam`。
  - 最少级数（3 级）就是禅堂、药师殿；最多级数（82 级）是 `pairs/summit-*`。
  - 地面以上只有方头那一掌在贴近图里看得出（`chan-side-low` 约 200 像素），其余几乎没有变化。
