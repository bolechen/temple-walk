# #564 秋暮首院：殿前薄雾找回来，禅堂白槛墙不再比天亮

`collage.jpg`：左 #546 合入前的 main（`e6b3a74`），右本 PR；上 court，下 art3（取画面中间 960×540 一块放大）；秋暮，T4，高档，1920×1080，界面已隐藏。单张原图在证据库（`court-*`、`art3-*`），见 `MANIFEST.json`。

两处原因都不在光晕里：

1. **薄雾：** `props.js` 的光柱（光站在雾里的几束淡光）只在太阳高度 y < 0.3 时画。#546 的太阳 y = 0.309，刚好过线，光柱全灭，殿前的雾也没了。阈值改成 0.35（`SHAFT_SUN_Y`）：别的 15 种季时的太阳不是低于 0.2 就是高于 0.5，只有这一种落在 0.2–0.5 之间，所以别处一个像素不变。
2. **白槛墙：** 禅堂前的白槛墙受斜阳，屏上亮度 216–220，比天（211–214）还亮。日光倍数从 1.25 降到 0.8，墙 206，天 214。
