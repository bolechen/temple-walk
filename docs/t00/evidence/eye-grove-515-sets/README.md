# 竹林镜头的三组对照：修前、直退、直退加抬高（#515，PR #518）

本地构建，SwiftShader，自动画质（`before-pool-high-16x9` 是 q=high）。每张图都在 `__eyeSpace` ready 之后再走 90 帧才拍。数据见 `views.log`：眼睛位置、臂长、`monkBox`，以及它在画面高度里的上下沿（`inFrame`），还有画面正中最先打到的东西。

| 组 | 代码 | 说明 |
|---|---|---|
| before-* | main 8cd4d2a | 修前：报告点、竹林起点、半山亭三处，眼睛都站在竹林里（`GROVE.grows` 为真） |
| straight-* | 2cf2c6e | 只收臂：眼睛在竹林外，报告点臂 1.25 m，竹林起点臂 1.75 m，他出画（报告点 16:9 框从 -5% 到 135%，竹林起点框下沿 108%） |
| risen-* | d65afa6 | 收臂并抬高：眼睛在竹林外，抬高到他身边 0.6 m 方框四边都在画面里、各留 5%（报告点竖屏抬约 1.9 m）。半山亭没有被竹林挡住臂，和直退一样 |

要请审图二判的一点：抬高后，报告点的画面是从高处往下看他，洗砚池碑、亭子和竹林都出了画，画面里主要是石板、草地和池沿。
