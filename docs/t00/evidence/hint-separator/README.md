# 提示行折行时，分隔号「·」不再挂在第一行末尾

触屏（`hasTouch`/`isMobile`），DPR 2，`q=low`，四种语言，拍的是进来后说的那句「怎么走」（`walk`）。`collage.jpg`：左边一列 390 宽（中、日、英、韩），右边一列 320 宽（同序）。折行的（390 宽下的日文，320 宽下的日文和英文）在断开处没有「·」；没折行的（其余），「·」仍在两段中间。
修在 `app/src/hints.js` 的 `phrases()`/`unhang()`：「·」单独成一个 `.dot`，两段不在同一行时把它收起；窗口大小变了再算一次。e2e `hint-break` 在四种语言、390 宽下读每个「·」的位置，不许它在下一段的上一行。改之前这个场景在日文下红。
