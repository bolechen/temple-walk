关掉的是三处，全是贴边：
1. 殿门两侧、门线以外的门槛立面前（x ±0.7…1.75，z ≈ −74.7），宽一两格。门洞本身前面一格没少，门站位走得到。
2. 前檐柱（x ±2.4, z −75.1）柱础外圈一圈，以及四周每根檐柱外 8 格左右。原因是外廓按新身体放宽了鞋。
3. 前踏跺两侧垂带石的头上（x ±2.5，z −73.5…−73.0），即垂带和台明齐平的那一小块石面，约 0.3 × 0.4 m。它原来算地面，鞋一宽就封了。那上面本来就不是该站人的地方。
