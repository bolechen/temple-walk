# 朱印帐分享图：二维码三种放法（#319，供所有者选）

`node tools/goshuin-pages.cjs <dir> --styles=seal,colophon,inscribed --kinds=full`：七印圆满的一页，四种语言（中、日、英、韩）。

- `seal`：码当一枚印，深朱色，模块略圆，外一道印框，放在页脚的七印同一条线上靠右（七印缩小一点让位）。
- `colophon`：码用墨色，放在页面最下方居中，像书页最后的落款，旁边写「扫码入山」和主站地址（七印上移）。
- `inscribed`：同样的印式的码，放在日期下方的空白里，「扫码入山」在它下面。
- `photo-card-qr.jpg`：留影卡片的样子（印式的码在卡片脚右侧、印的左边，默认开）。
- `sheet.jpg`：三种放法 × 四种语言的拼图（一行一种放法，一列一种语言）。

三种放法都由 e2e `goshuin` 在页面里生成后裁出码、用 jsQR 解过（四种语言各一次）。
