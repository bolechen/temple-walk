# #288 的共用改动落到 T05 上：改前改后

软件渲染（SwiftShader，`?level=t05&q=low`，夏天白昼，第一人称，960×540；不是 T4）。改前是 main `7bb3c3e` 的构建，改后是 #475 的分支。拼图 `collage-t05.jpg`（左改前右改后）；单张在证据库。地址都是 `?shot=1&q=low&view=first&level=t05&cam=<下表>`。

#475 改了共用的 `building.js`，T05 因此受两处影响：

1. **压面石在后阶处断开**（#475 第 6 条）：T05 的外山门（`stepsBack`）和无量殿（`stepsBack: 4.0`）的后阶，台沿石原先伸出 7 cm 压在最上一级，现在在踏步处断开。walk-diff：无量殿 −0.06 m²（x 1.8..2.1，z 59.8..60.0）、外山门 −0.06 m²（x −2.1..2.1，z 203.8..204.0），都在后阶头，都不到 1 m²。
2. **山门通道有了天花**（#475 第 1 条，我先前没有查到 T05 也带）：`building.js` 对「前后都是 `pass` 且 `timber`」的建筑加平綦天花和梁格。T05 的外山门（z 205–211，高 4.9 m）和内山门（z 117–123，高 5.4 m）都满足，所以两座山门的门洞顶原先那块一整块平黑，现在有了天花。天花不进地面烘焙（`userData.bake = false`），所以 T05 的 walk-diff 没有它的影响；眼睛仍收它。没有量 T05 的天花亮度，用的是 T00 同一个材质（`passage`，提亮后）。
