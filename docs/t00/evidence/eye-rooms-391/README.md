# 殿内与出殿门的跟拍眼睛（#391）

所有者在内测版 27c9458 上反馈「很多地方走的时候都有穿模」，这组截图是修复后的核对。

- 截图来源：PR #391 的预览。三个殿内部的截图用提交 574b14e 的预览（https://72952a60-temple-walk-preview.bole-chen.workers.dev）；户外和切语言之后的截图用提交 4f0b9cb 的预览（https://a8992ba6-temple-walk-preview.bole-chen.workers.dev）。两者的应用代码与头提交 9757cb9 相同，9757cb9 只改了一条测试。
- 渲染条件：软件渲染（SwiftShader），低档，1280×720，夏季白天，第三人称。脚本是 `tools/out/eye-shots.cjs`（没有提交，`tools/out/` 被 git 忽略）。
- 每张图的数据在 `halls.jsonl`（殿内）和 `outdoors.jsonl`（户外、切语言）里：他所在的位置、眼睛的位置、眼睛空间的状态和三角形数、`shutNow`，以及 `inPicture`。`shutNow` 由页面自己的 BVH 判断：眼睛此刻所在的球是否碰到画出来的东西。`inPicture` 只表示他投影在画面范围内，不判断有没有被挡住。
