## 看得出什么、看不出什么

- 软件渲染的深度缓冲比手机深得多，这些重合面在这里大多本来就不闪，所以图能证明的是**画面没有变样**，证明不了**在 16 位手机上不闪了**；“不闪”由 `tests/unit/flush-faces.test.mjs`（几何上不再共面）担保，没有在真手机上测。
- 御碑亭的白灰带是个例外：改前在软件渲染下就能看到木色和灰色混着，改后稳定是白灰。这是两个面争同一个像素时赢的那个换成了固定的一个（白灰）；美术初审请看这条带是不是该是白灰。
- 眼睛挪 1 mm 的两帧相减，改前改后的像素差数量差不多（视差边缘占了大头），所以没有用它当判据。
