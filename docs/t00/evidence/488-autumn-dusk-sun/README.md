# #488 秋暮首院落在斜阳里（第三版）

现行方案：北偏西 65°、仰角 18°、日光 ×2.25（即 `TIME.dusk.sunI` 的 2.25 倍），天空光晕留一个小而紧的（`glow 0.1`、`bloom 0.2`、`disk 0.25`），都在 T00 的 `moodFor` 里。

`collage-v3.jpg`：`court`、`art3`、`art4`、`teatable`（秋暮，T4，高档）。`court-1920x1080.jpg`、`art3-1920x1080.jpg`、`art4-1920x1080.jpg` 是 1920×1080、`?shot=1` 的单张原图（JPEG 90 档，T4 渲染的 PNG 太大）。

量法按审图二（#488 评论），`tools/sun-lit.cjs`，art4 只量左三分之二。现行方案：

| 机位 | 受光 | 亮度比 | 三线明暗交替 | 过曝（任一通道 ≥250） |
|---|---|---|---|---|
| court | 49.9% | 1.73 | 3 / 5 / 6 | 0.2% |
| art3 | 42.6% | 1.65 | 3 / 2 / 4 | 0.3% |
| art4 左 2/3 | 11.8% | 1.39 | 4 / 7 / 3 | 0.0% |

阈值：受光 25–60%（art4 ≥ 8%）、比 1.4–2.0（art4 ≥ 1.3）、三线至少两条 ≥ 2 次、过曝 ≤ 2%。

补扫（北偏西 25°–65°，每 5° 一档，仰角 13°/15.5°/18°，光晕同上）：court、art3、art4 三项同时过的只有北偏西 65°、仰角 18° 这一档；60° 以内 court 受光不到 25%（60°/18° 为 13.6%），70° 以上 art3 低于 25%。65°/20° 也过（court 48.5%、art3 31.8%、art4 11.4%/1.37）；65°/22° court 60.4%，略超。**注意**：前几轮扫描通过一个调试钩子乘日光，钩子乘在 `moodFor` 已有的倍数之上，所以那些轮次里的「日光 ×k」实际是 ×1.3k 或 ×1.5k；这一轮的数字都是从最终代码直接出的图量的。

方案 A（北偏西 16°）和 B（北偏东 35°）弃用：A 的 art4 受光 7.6%、比 1.26，B 的 court 受光 6.1%。
