# #592 rewind02 试验：烘焙的环境光探针（A）与按太阳算的天空（B）

分支 `feat/render-probe-sky-592`。两项都是**默认关**的试验：`?trial=probe`（A）、`?trial=sky`（B，页面里也可 `__skyTrial(on)` 开关）；
可以合着开 `?trial=probe,sky`。不开时页面的着色器里没有这两项的任何一行，`mood.js` 也不走那一句。

**画面由美术总监判，这里只给事实和数。**

## 试验 A：探针

做法：`tools/bake-probes.mjs` 在首院（含山门前的前院，2.5 m 一格，21×6×45 个点）和大雄宝殿内（1.5 m 一格，17×6×11 个点）
放一组点，每点向 `buildDrawn` 画出来的网格打 192 条射线，记下一阶球谐（天空看得见多少：四个系数；墙面反回来的光：平均一项的 RGB）。
两张三维图（RGBA 半精度），页面每个像素取两次（硬件三线性），文件 `app/shared/probes/t00.bin` 共 106 KB，提交在 git 里
（试验用，不进构建；采用时再接 `pnpm build`）。一次反弹的估计：院里是天空光的反弹（单位是天空的亮度，随时辰），殿里是灯的反弹（绝对值）；
**不含太阳的直射反弹**。树的枝叶按 55% 的缝隙让射线穿过。表面反照率按材质名查表（`ALBEDO`），是读图的估计。
运行时：半球光和天空环境图的漫反射乘探针给的天空份额（**下限 0.42**，不压到更黑），再加墙面反光；探针范围外一格半淡出。
挂在 `procMat` 的 `aomap_fragment` 处和铺地着色器里。

### 帧耗（T4，同一个作业里开关交替，`__cost` 毫秒；cam06 夏昼，每项三次）

| 一：四次取样（`80b82b0` 之前的版本，`273b065`） | 10.92 / 10.38 / 10.42，中位 10.42 | 10.66 / 11.02 / 11.29，中位 11.02 | **+0.60**（均值 +0.42） | 5.02 / 4.72 / 4.94 | 4.79 / 4.77 / 4.62 | −0.17 |

验收是高档增加不超过 0.3 ms：**两次取样的版本正好压在线上（+0.3，在抖动之内，三次的散布约 ±0.4）**，不是明确的「过」。
低档不变（差在抖动里，且低档也开着探针）。只量了 cam06 一个机位；殿内没有单独量帧耗（同一套着色器，殿内的材质更少）。

- cam06：大殿正面和檐下明显更暗、更有进深，院子地面几乎不变；平均亮度 87.0 → 83.5（差 3.6/255）。
- cam03：照壁和两侧的殿略暗（90.1 → 83.8，差 6.3/255）。
- cam05（48.1 → 43.0，差 5.1/255）：山门洞里的梁、格栅、门扇更暗（有下限 0.42 之后仍比不开时暗得多，**这一张最可能被判过暗**）。

  灯的一次反弹本来就只有直射光的十分之一上下，这是真实的量级，不是没生效（`__probes()` 报着殿的格子，开关亮度有差）。

## 试验 B：按太阳高度算的天空

做法：`app/src/atmosphere.js`。单次散射加臭氧和一个粗的二次散射项（Rayleigh + Mie，Nishita 1993 的做法、Hillaire 2020 天空视图表的形状，缩减版），
对每个时辰的太阳高度算一张 48×32 的天空颜色表（约 20 ms，每次换时辰算一次，**没有烘成十六个文件**：算一次比取一个文件还快，省了 400 KB）。
从表里取天顶、地平、雾、天光、太阳穿过空气后的颜色，**只取色相和形状，亮度仍用时辰表手写的数**（曝光是按手写表调的，J01 不许动）；
有云时往手写表退（`over`）；雾和天光只取 40–60% 的色相（地面和霾会还光，晴空裸地的模型没有）；夜晚不动（月亮不是太阳，夜的蓝是眼睛的事）。
天空着色器里在 `uSkyOn` 时读这张表；天空、雾、天光、太阳色因此同源。

- **J01（夏·昼）和四个夜晚逐像素不变**（对照图差 0.0，单测 `atmosphere.test.mjs` 也守着）。
- 其余十二个时辰变了，差最大的是**秋·暮**（平均差 10.8/255）：物理算出来的天空在太阳 10° 时还是蓝的，手写的是整片暖紫粉；
  春昼的天更蓝、石面和花偏冷。**物理的天比手调的更干净、更蓝、更冷**；单次散射没有手写表想要的那层霾和暖。
- 帧耗（T4，作业二，cam06 夏昼，开关交替）：高档 不开 10.55 / 开 10.61（中位，+0.06）；低档 4.82 → 4.96（+0.14，在抖动里）。夏昼是 J01，天空表不参与，**所以这个耗是「着色器多了一次取样」的耗，不是十六个时辰的**；夏昼之外没有单独量。

## 建议（给美术总监和所有者）

- **A**：值得继续，但要调：首院正面的檐下进深是好的；山门洞太暗，要么抬高下限、要么山门洞内另放更密的探针；加上太阳的反弹后暖色的反光才会出现
  （现在只有天空光的反弹，所以 J01 阴天上几乎看不出「光从哪面墙反上来」）。成本在 0.3 ms 的线上，没有余量。
- **B**：不建议整体采用。它让十二个时辰在物理上自洽，但比手调的更冷更干净，和「安静写实、光从某处来」的暖调不合；
  可取的是**让雾色、天光和太阳色跟着同一个太阳**这一条，可以只把这三项接上、天空本身仍用手写表。
