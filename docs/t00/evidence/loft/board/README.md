# 凌霄阁三层竖匾：缩小（A）与原大挂到门上墙面（B）的对比（#101，#122 评审）

同一提交、同一渲染法（本机 SwiftShader，高档，1280×720），回廊 1.6 米。B 用一个没有提交的临时开关画出。

- **A（#122 现在的做法）**：位置、斜度不变（门外回廊上方，前倾 0.3 弧度），缩到底边离楼面 2.03 米，匾高 2.35 → 1.72 米。
- **B（原大）**：匾高 2.35 米不变，往上挂已经挂不上去：原来的位置上，匾顶已经顶到檐下（离檐底 8 厘米）。
  三层出檐 2.2 和 2.8 两种方案，在离墙同样远的地方檐底一样高，加深出檐也腾不出地方。能做的只有贴回墙面、挂在门的正上方（离墙 0.22 米，前倾 0.06），
  这时底边离楼面 1.88 米，比第一人称镜头（1.3 米）高 0.58 米，但盖住了门上部约 1.1 米的格子门。
