# #555 暮时不点灯的殿，门洞是暗下来的屋子

`collage.jpg`：秋暮，T4，高档，1920×1080，界面已隐藏；左 main，右本 PR；六行：禅堂、茶寮、藏经楼、凌霄阁、大殿、观音殿。大殿、观音殿（中间一间点灯）前后相同；其余四座（中间一间不点灯）门里的浅板变成暗的屋子。单张原图在证据库，见 `MANIFEST.json`。

原因：门洞着色器按灯的强度（`uLamp`）渐变地套「暗门」系数，而晴秋暮的灯强度只有 0.23，系数只套到四成，门里仍是白天烘焙的房间。改成灯强度 > 0.08 就全量，白天（灯 0）不变。

量法（屏上亮度，T4 高档 1920×1080，同一机位）：

| 殿 | 门洞墙 / 暗窗 改前→改后 | 门洞墙 / 门外背光白墙 改前→改后 |
|---|---|---|
| 禅堂 | 1.42 → 0.84 | 0.66 → 0.39 |
| 茶寮 | 1.11 → 0.87 | 0.63 → 0.49 |

禅堂门洞墙亮度 49.5 → 29.3，暗窗 35，白墙 75.5；茶寮 41.3 → 32.2，暗窗 37，白墙 65.5。门里房间的下限从 0.12 降到 0.05（`uDusk`），茶寮因此从 0.50 到 0.49，差别很小：茶寮门洞里剩下的亮度主要是门框的木色和雾，不是房间。药师殿、大会堂：从能走到的最近机位（`yaoshi` 视角附近、`dahui` 视角附近）看，门在画面里只露一角，改前改后门洞都是暗的，量不出比值。注意：我量的是同一机位里的小块区域，审图二在 #459 里的 72/30/85 是另一把尺，两者的绝对值不同，比值方向相同。
