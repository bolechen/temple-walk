# #212 檐下斗拱：改前、改后

改前是 main `49ec3cc` 的代码（另加了测试用的 `__probe(points)`，不改画面）；改后是 PR #229。亮度一律是**线性光下的亮度 Y**（Rec.709，把截图的 sRGB 值解码后算），验收第 1 条按它算（主创 2026-11-18 定，见 #212 的评论）。

取样：用 `__pick` 在画面上每 12 px 问一次是什么，「拱眼壁」= 画面上部的 `plaster`（取高度的 5%–95% 分位一段），「斗拱」= 同一行、同一高度带里的木（`woodX/woodZ/woodV`）；每点取 3×3 像素。四殿的机位：眼在台前 1.9 米上方 2.2 米，看前檐柱头上的斗拱带（大殿 `0,-1.0 → 0,-6.3`，山门 `0,47.5 → 0,43.0`，藏经楼 `0,-40.6 → 0,-44.8`，观音殿 `0,-70.9 → 0,-75.1`），第三人称，夏昼，`?shot=1`。
