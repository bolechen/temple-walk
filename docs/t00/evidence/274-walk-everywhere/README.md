## 主创看到的那一处（大殿东侧台面，右边院墙上方那片边缘很碎的白绿面）

站位 `?cam=16.1,-4.91,-0.297,0.033&view=first`（`spots/owner-spot.png`、`spots/owner-spot-autumn.png`）。在本机用 `__pick` 打了画面右上角 16×13 个点：院墙上方那一片是 **`backdrop.js` 画的竹屏**（`part: backdrop`、`ShaderMaterial`，x 24–27.5，z −26.7～−35.6，高 7.8–9.8 米），就是 `backdrop.js` 第 69 行 `band(...)` 沿东西院墙外面立的那几条。它离东院墙（x = 22）只有 2–5 米，碎边是画片上竹梢的透明边。站在院子地面上时院墙挡住了大半，站上台基就整片露出来。

**修不修**：本 PR 不修。它不是天空也不是场景外面，是远景画片放得太近。我的建议是开一个 `景观` 的 issue：要么把东西两侧的画片往外挪（x ≥ 30），中间补几排真的竹子（`bamboo.js` 的近竹林现在只种在前院两侧和山路边上），要么让画片的上沿在 1.3 米的视线高度看不出边。同一个 issue 管第 1、3、13、21 处。
