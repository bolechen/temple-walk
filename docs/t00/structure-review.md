## 依据和方法

- **代码**：`building.js` 的 `buildHall` 和斗拱、屋面、椽、脊；`site.js` 的 `put`/`putStack` 和每座建筑的参数；
  `framing.js` 的室内梁架；`interior.js` 的房间尺寸。
- **量**：在 Node 里建出整座寺，逐座读出开间、进深、柱高、出檐、举高、补间朵数、上下层柱位（脚本没有提交，结果见下表）。
- **看**：软件渲染截图，见 `docs/t00/evidence/structure/`（提交 452f14e，`?shot=1`，夏日白天）：
  - `main-hall-front.jpg`（`?show=hall`）：大殿心间与次间一样只有一朵补间，柱头一线平直，没有生起；
  - `gate-upper-storey.jpg`（`?show=fiveroofs`）：山门上层直接坐在下檐瓦面上，只有一圈栏杆，没有平坐铺作。
  - `main-hall-eave.jpg`（`?cam=12.8,-1.2,-0.7,0.5&view=first`）：大殿下檐底下只有一层檐椽，没有飞子，椽距偏疏；檐下已不是平黑板（可复核 R2-ART-03）。
  这一机位没有拍到屋角，所以 S-07（角梁）的依据是代码，没有截图。

  材广约合宋尺 6.8 寸，落在第四、第五等之间。

## 结论

**对的地方。** 斗拱本身的比例基本合《营造法式》，问题主要不在构件尺寸。

**主要问题。** 都在「建筑之间」和「层与层之间」：
- 各级建筑用同一套斗拱；
- 心间少一朵补间，开间宽窄倒置；
- 楼阁上下层柱子不对位，又没有平坐；
- 屋面普遍比宋式陡。

**次要问题。** 没有角梁、飞子、侧脚、生起，椽子偏疏偏细。

ART-SPEC 里「斗拱、梁架、屋面与柱网通过结构检查」这一条**仍不能勾**。

## 问题

严重程度：**major** 是一眼可见或违背明文制度；**minor** 是细部或要走近才看得到。
「依据」一栏写明是原文明文，还是从原文推断，还是按常理。

### S-01 楼阁上下层柱子不对位（major）

**现状。** `putStack` 把上层直接立在下层屋面上，上层柱网是另给的一组数，和下层哪根柱子都对不上：

| 建筑 | 下层柱线（x / z） | 上层柱线 | 说明 |
|---|---|---|---|
| 山门 | x ±9.6、±6.0、±2.2；z ±3 | x ±7.0、±2.2；z ±1.8 | 上层四角柱和前后檐柱都落在下层六米大梁的半跨上，下面没有柱 |
| 藏经楼 | x ±9.4、±5.4、±1.9；z ±4.2、0 | x ±6.4、±2.2；z ±2.6 | 无一对位 |
| 凌霄阁 | 一层 x/z 每 3 米一线（±7.5…） | 二层 ±5.4、±1.8；三层 ±3.4、±1.2 | 三层之间无一对位 |
| 大雄宝殿 | 下层 z ±8.6、±4.3、0 | 上层 z ±5.0 | x 对上了；进深方向殿身柱与上檐柱差 0.7 米 |
| 御碑亭 | ±2.0 | ±1.2 | 上檐柱悬在下层屋面上 |

**依据（原文推断）。** 卷四平坐：「若叉柱造，即每角用櫨枓一枚，其柱根叉於櫨枓之上」「凡平坐先自地立柱謂之永定柱」。
上层柱要么叉在平坐铺作的栌斗上，要么由永定柱从地面起。平坐铺作又坐在下层柱头之上。
所以上层柱位应当落在下层某一圈柱的上方，或者用副阶多退一圈。条文没有一句写「上下必须对齐」，这一条是从做法推出来的。

**建议。** 上层柱线取下层内圈柱线：
- 山门上层 z 取下层前后柱之间加一排内柱，或把上层进深做成与下层相同；
- 藏经楼、凌霄阁的上层柱线取下层次间柱线；
- 大雄宝殿上檐 z 改成 ±4.3。

改动会动到 `walk`、`edges` 和殿内房间的柱位，要一起跑 `pnpm run edges` 和 `interior.test.mjs`。

### S-02 楼阁没有平坐（major）

**现状。** 有平坐的应当是三处：山门上层、藏经楼上层、凌霄阁二三层。现在这几层都是一块 0.32 米厚的木板压在下层瓦面上（`platBase = foot - 0.4`），外加一圈栏杆。下面没有平坐铺作，也没有雁翅版。

**依据（原文明文）。**
- 卷四：「造平坐之製，其鋪作減上屋一跳或兩跳。其鋪作宜用重栱及逐跳計心造作」「四周安雁翅版，廣加材一倍」。
- `JINGSHAN.md` 记的实物凌霄阁是「三层带平座」。

**建议。** 在 `putStack` 的上层底下加平坐：
- 一圈普拍方，上面坐减一跳的铺作，再加雁翅版；
- 栏杆立在雁翅版内；
- 腰檐收在平坐之下。

这样也正好接上 S-01 的柱位。

### S-03 各级建筑同一材等、同一套斗拱（major）

**现状。** `buildHall` 里斗拱的尺寸写死，七开间重檐大殿、五开间山门、三米见方的钟鼓楼和三层阁用的是同一套。

**依据（原文明文）。** 卷四：「材有八等，度屋之大小因而用之」：
- 第二等「殿身五間至七間則用之」，材广 8.25 寸，约 0.256 米；
- 第六等「亭榭或小廳堂皆用之」，材广 6 寸，约 0.19 米；
- 第七等「小殿及亭榭等用之」，材广 5.25 寸，约 0.16 米。

现在的材广约 0.21 米，大殿偏小约两成，钟鼓楼、凌霄阁上层偏大一到三成。大殿檐下的斗拱因此显得细碎，小楼上的又显得臃肿。

**建议。** 给 `buildHall` 加一个 `cai`（材广，米）参数，斗拱、阑额、柱径、椽径都按分值乘它。站点表里按间数取：
- 大殿 0.256；
- 观音殿、山门 0.232；
- 配殿 0.205；
- 钟鼓楼、亭 0.186。

### S-04 心间只用一朵补间铺作（major）

**现状。** `between()` 只在开间大于 4.6 米时放两朵补间，结果全场所有建筑的心间都只有一朵：大殿心间正好 4.6 米，山门心间 4.4 米。山门上层更是两侧次间（4.8 米）放两朵、心间（4.4 米）放一朵，完全倒过来。

**依据（原文明文）。** 卷四：「當心間須用補間鋪作兩朵，次間及梢間各用一朵。其鋪作分布令遠近皆勻。」

**建议。** 改成按开间的位置定朵数：心间两朵，其余一朵。开间宽窄配合 S-05 调整。

### S-05 开间宽窄倒置（major）

**现状。** 宋式心间最宽，向两端渐窄或相等。现在多处梢间比次间宽，甚至比心间宽：

| 建筑 | 开间（自西向东，米） |
|---|---|
| 大雄宝殿 | 4.2 / 4.0 / 3.9 / **4.6** / 3.9 / 4.0 / 4.2（梢间宽于次间） |
| 释迦宝殿（上檐） | 4.0 / 3.9 / **4.6** / 3.9 / 4.0 |
| 藏经楼下层 | **4.0** / 3.5 / 3.8 / 3.5 / **4.0**（梢间宽于心间） |
| 观音殿 | **3.8** / 3.4 / 3.6 / 3.4 / **3.8**（梢间宽于心间） |
| 山门上层 | **4.8** / 4.4 / **4.8**（次间宽于心间） |

**依据（原文明文）。** 卷四：
- 「如隻心間用雙補間者，假如心間用一丈五尺，則次間用一丈之類」；
- 「或間廣不勻，即每補間鋪作一朵不得過一尺」：补间铺作之间的距离，相差不得超过一尺（约 0.31 米）。

心间两朵、次间一朵时，心间约为次间的一倍半。

**建议。** 以大殿为例，总宽 28.8 米不变，可取心间 5.4 米，次间、梢间、副阶间 4.2、3.9、3.6 米。这时朵距约 1.8、2.1、1.95、1.8 米，相差不超过一尺；上檐柱线随之落在 ±10.8 米。其余四座同理。

### S-06 屋面普遍比宋式陡（major）

**量法。** 举高取脊槫背到前檐橑檐方心处屋面的高差，跨度取前后橑檐方心的距离。

| 建筑 | 现在的举高比 | 法式 | 原文 |
|---|---|---|---|
| 山门上层 | **0.58** | 0.33 | 卷五「如殿閣樓臺……分為三分……舉起一分」 |
| 藏经楼上层 | **0.52** | 0.33 | 同上（楼阁） |
| 禅堂、茶寮 | **0.41** | 0.27 | 「㼧瓦廳堂，即四分中舉起一分……每一尺加八分」 |
| 凌霄阁顶层 | **0.40** | 0.33 | 楼阁 |
| 药师殿、大慧院 | 0.39 | 0.27 至 0.33 | 厅堂或殿 |
| 大殿上檐 | 0.39 | 0.33 | 殿阁 |
| 观音殿 | 0.38 | 0.33 | 殿阁 |

最陡的山门上层几乎是宋式的两倍，看上去更像明清，而且是南方的明清。

另外，屋面曲线是一条幂曲线（`profile`），一直弯到檐口变成水平。宋式是逐架折出的折线，橑檐方以外的檐椽顺着最下一架的坡度伸出去，只有飞子略平（据举折、檐两条推断）。

**建议。**
- 按「举高 ＝ 前后橑檐方距 ×（1/3 或 0.27）」反算每座的 `rise`，写成 `site.js` 里的一个函数，不再逐座手填；
- `profile` 改成按架数的折线，再在橑檐方外接一段直檐。

### S-07 没有角梁（major）

**现状。** 每个屋角只有一扇从柱头散出去的翼角椽，角上没有大角梁、子角梁，戗脊下面空着。四角的风铎直接挂在瓦面底下。

**依据。**
- 卷五阳马（原文明文）：「大角樑其廣二十八分至加材一倍」「子角樑隨飛檐頭外至小連檐下，斜至柱心」。翼角椽是「並隨角樑分布」的，先有角梁才有翼角椽。
- 风铎挂在子角梁头下，是常见实物做法，这里按常理，没有查到条文。

**建议。** 每角加一根大角梁，自转角铺作上斜出到檐角，梁头卷杀。上面压子角梁，梁头略翘，风铎挂在子角梁头。翼角椽改为依角梁排。

### S-08 没有飞子（minor）

**现状。** 檐下只有一层檐椽。
**依据（原文明文）。** 卷五：「檐外別加飛檐，每檐一尺，出飛子六寸。」
**建议。** 在檐椽之上、出檐的外三分之一加一排方形飞子，檐口线随之再挑出一点。

### S-09 没有侧脚、生起，檐口平面没有生出（minor）

**现状。** 所有柱子垂直、同高，阑额和普拍方是一条直线；檐角的起翘全靠屋面曲面上的 `lift`。

**依据（原文明文）。** 卷五：
- 「至角，則隨間數生起角柱……七間生高六寸，五間生高四寸，三間生高二寸」；
- 「每屋正面，隨柱之長，每一尺即側腳一分」；
- 檐：「其檐自次角柱補間鋪作心椽頭皆生出向外漸至角樑。若一間生四寸，三間生五寸，五間生七寸」。

**建议。** 柱高按距心间的间数线性抬高，七间大殿角柱约高 0.19 米；阑额、普拍方、橑檐方随之成一条缓曲线。檐口的平面在角部外生。这一条是宋式「檐角舒缓」的来源，比单靠曲面起翘更像。

### S-10 椽子偏疏、偏细，布椽不对间心（minor）

**现状。** 椽距 0.34 米，椽截面 0.085×0.10 米，从 `-X` 起排，不管间心。

**依据（原文明文）。** 卷五：
- 「殿閣廣九寸五分至九寸……廳堂廣八寸五分至八寸」（约 0.28 至 0.29 米、0.25 至 0.26 米）；
- 「殿閣……徑九分至十分。若廳堂，椽徑七分至八分」（按本场材分约 0.13、0.10 米）；
- 「凡佈椽，令一間當間心。若有補間鋪作者，令一間當耍頭心」。

**建议。** 椽距按殿阁 0.29、厅堂 0.26 米取，从心间中线（或补间耍头心）向两边排，椽径按材分。

### S-11 柱高大于间广（minor）

**现状。** 柱高与心间之比：
- 藏经楼下层 5.0 / 3.8＝1.32；
- 凌霄阁一层 1.30；
- 钟鼓楼 4.4 / 3.4＝1.29；
- 观音殿 1.17；
- 禅堂、茶寮 1.13；
- 大殿 1.04。

**依据（部分推断）。** 卷五：「若副階廊舍，下檐柱雖長，不越間之廣。」条文只说副阶、廊舍，把它推到殿身是推断。不过宋代实物的檐柱大多不高于心间。

**建议。** 藏经楼下层柱降到约 4.0 米，钟鼓楼降到约 3.6 米，或者加宽开间。其余可以不动。

### S-12 柱础只有圆形覆盆，没有方石（minor）

**现状。** 檐柱下是一个旋出的圆鼓，直径约柱径 1.5 倍，高 0.25 米；殿内柱础也是圆的。
**依据（原文明文）。** 卷三：「造柱礎之制：其方倍柱之徑……若造覆盆，每方一尺，覆盆高一寸。」
**建议。** 先放一块边长为两倍柱径的方石，再在上面浅浅起一圈覆盆，高约为方石边长的十分之一。这一条与旧评审 R2-STR-04 是同一件事，还开着。

### S-13 彻上明造缺托脚和襻间（minor）

**现状。** 禅堂、茶寮、大慧院的室内有驼峰、蜀柱、平梁、叉手，但中、下平槫底下没有托脚，蜀柱上也没有襻间。

**依据（原文明文）。** 卷五：
- 「凡中下平槫縫，並於樑首向裹斜安托腳」；
- 「凡屋如徹上明造，即於蜀柱之上安枓……枓上安隨間襻間」。

**建议。** 在 `openRoof` 里每道下平槫下加一根斜撑，从下面一道梁的梁头斜上去托住槫；蜀柱顶加一斗，斗上加一道襻间方顺着槫走。

### S-14 殿内房间比外观大得多（major，已知）

**现状。** 房间进深是外观的：
- 禅堂、茶寮、大慧院：2.0 倍；
- 药师殿：开间 1.44 倍、进深 2.42 倍；
- 藏经楼：进深 1.38 倍；
- 观音殿：反而窄了，开间 0.87 倍。

室内柱网是把外观柱线按比例拉开的，所以柱距也跟着变形。

**依据。** 内外一致性，不是法式条文。`HANDOFF.md` 已记为已知问题。

**建议。** 改法有两种：
- 外观加深（禅堂、茶寮、药师殿、大慧院现在只有两排柱，进深 4.8 米，作殿堂偏浅），让外观追上房间；
- 房间减小。

前者同时改善 S-06 的比例。

### S-15 殿阁类室内柱头只有栌斗，梁直接压在栌斗上（minor）

**现状。** 大殿、观音殿、凌霄阁的室内柱头上只有栌斗，月梁直接搁在栌斗上，平棋方没有铺作承托。`KNOWN-ISSUES.md` 第 71 行写「斗拱只有栌斗，没有出跳」，指的就是室内。

**依据（原文推断）。** 卷四「凡鋪作並外跳出昂，裹跳及平坐隻用卷頭」，说明铺作有里跳。殿阁内的梁和平棋方由里跳承托。条文没有直接写室内柱头必须用铺作，这一条是推断。

**建议。** 殿阁类房间的柱头上加一跳或两跳卷头，托住月梁头和平棋方。厅堂类（彻上明造）维持现状。

### S-16 屋顶等级没有拉开（建议，非错误）

**现状。** 除攒尖亭外，所有殿屋都是九脊（歇山），配殿、禅堂、茶寮也是。

**依据。** 卷五阳马：「凡堂廳若廈兩頭造……今亦用此製為殿閣者……亦曰九脊殿」，厦两头本来就可以用在堂厅上，所以这不算错。

**建议。** 禅堂、茶寮、药师殿、大慧院改为两厦（悬山），歇山留给大殿、观音殿、藏经楼和山门，这样主次更分明（按常理，属于设计取舍，可不改）。

### S-17 凌霄阁鸱尾偏小（minor）

**现状。** 约 1.6 米，合宋尺五尺二寸。
**依据（原文明文）。** 卷十三：「樓閣：三層簷者與殿五間同」，即「高七尺至七尺五寸」。
**建议。** 把鸱尾尺寸从 `rise` 推算改成按建筑等级查表。

## 建议的顺序

1. **S-04、S-05 补间和开间。** 只改参数和 `between()`，代价最小，一眼可见。
2. **S-06 举高。** 一个函数加参数，影响整座寺的天际线。
3. **S-01、S-02 楼阁的柱位和平坐。** 山门是验收机位 CAM-04、CAM-05 的主体，凌霄阁是终章。
4. **S-07 角梁，S-03 材等。**
5. **其余 minor。**

每一步都要先写会失败的单元测试，例如：
- 「每座建筑心间补间两朵」；
- 「上层每根柱下面都有下层的柱或平坐柱」；
- 「举高比在法式值的 ±10% 内」。

再跑 `pnpm run edges`、`shots.js` 看图，并测一次三角面数，因为角梁、飞子、平坐都会增加几何。
