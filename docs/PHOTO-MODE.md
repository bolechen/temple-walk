# 风景留影

以展示寺院和风景为主，参考欧卡拍照时将场景让出来的布局原则；不复制其图标或素材。

默认16:9横幅、广角、人物隐藏。常驻快门、设置、收起三个操作；画幅、远近与人物选项收入折叠面板，触控目标至少44px。设置状态通过aria-expanded表达，Tab正常移动焦点，Esc先关闭设置，再退出拍照。每次进入时收起面板。

画面始终清晰：没有点选对焦、光圈或景深模糊。后处理移除整个景深pass和专用深度纹理，不是仅把滑块设为零。远处山雾仍是场景环境的一部分。宽/方/竖构图、可选人物/合掌、相纸导出与分享保留。

验证：`node tests/e2e/run.cjs photo-ui` 检查桌面与触屏的默认界面、面板范围、人物切换与Esc；`node tests/e2e/run.cjs photo` 检查三种画幅和实际导出。Pages CI包含photo-ui，完整导出另按改动验证。测试结果以对应提交的工作流和交付证据为准，不在文档中预写成功。
