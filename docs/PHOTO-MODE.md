# 风景留影

以展示寺院和风景为主，参考欧卡拍照时将场景让出来的布局原则；不复制其图标或素材。

默认16:9横幅、广角、人物隐藏。常驻快门、设置、收起三个操作；画幅、远近与人物选项收入折叠面板，触控目标至少44px。设置状态通过aria-expanded表达，Tab正常移动焦点，Esc先关闭设置，再退出拍照。每次进入时收起面板。

画面始终清晰：没有点选对焦、光圈或景深模糊。后处理移除整个景深pass和专用深度纹理，不是仅把滑块设为零。远处山雾仍是场景环境的一部分。宽/方/竖构图、可选人物/合掌、相纸导出与分享保留。

验证：`node tests/e2e/run.cjs photo-ui` 检查桌面与触屏的默认界面、面板范围、人物切换与Esc；`node tests/e2e/run.cjs photo` 检查三种画幅和实际导出。photo-ui 不随每次推送运行：它在 `--smoke`、每周的完整运行和手动触发的 e2e 里；改了拍照就在本地或手动触发跑它，完整导出另按改动验证。测试结果以对应提交的工作流和交付证据为准，不在文档中预写成功。

## 2026-11-15 改动（所有者要求）

「点拍照后，默认是用户当前游戏看到的画面，高精度，相机里只允许放大缩小，不再允许转动视角，鼠标左键默认就是拍照。」

- 进入留影时画面一动不动：同一只眼、同一个方向与距离，默认画幅是「全幅」（整个画面，不画取景框）；人物是否入画跟当时的视角一致（身后视角在画里，自己的眼睛则不在，此时「入画」不可选）。上面写的「默认16:9横幅、广角、人物隐藏」不再是默认，横/方/竖三种画幅仍在设置里。
- 相机不转：拖动不改变方向。只有远近——滚轮或双指，以及设置里的「原景 / 拉近 / 特写」三档；范围 0.7×–6×。
- 鼠标左键点画面即拍（拖动不算）；触屏仍按快门键，避免误触。
- 导出按画质档重新绘制：低档长边 1600，中档 2160，高档 2880 像素。


## 2026-11-16 改动（所有者要求）

「拍照的时候加上音效，加上取景器效果，拍照预览时画面应该是冻结的。」

- **定格**：按下快门的一瞬，当前画面复制成一张静止图盖住视图，渲染循环和仪式的时钟一起停下；高清成片用按下那一刻的时间重绘，所以成片就是所见（以前用的是重绘时的时间，飘叶和雪的位置会对不上）。收起照片后接着走，不会跳。
- **快门**：两片墨色快门帘约 0.2 秒合上又打开；同时一声木壳叶片快门的轻响（两下，相隔约 30 毫秒）。照片出来时一声盖印的闷响和纸的轻响。手机上轻震一下。都走「音效」，配乐短暂让一让。
- **取景器**：画幅外铺一层半透明的纸，就是成片装裱的那张纸，所见即所得；框内只有四角细线。全幅时不铺纸，只在离边缘一点的地方画四角，进没进拍照模式一眼看得出。设置里「取景」一栏有「三分线」，默认开（所有者 2026-11-17 要求），关了会记住。取景时四周轻微压暗，只在屏幕上，成片不带。
- 验证：`photo-ui` 检查全幅时只有四角、三分线开关与记忆、拍下后帧数不再增加、静止图盖住画面、快门声和盖印声各响一次、收起后恢复。

## 2026-11-19 改动（所有者要求，#275 / PHOTO-02）

「我觉得虚化了不好看，或者考虑加个相机开关？默认不虚。」

- 举起相机，画面和举起前一模一样，任何档位：`__probe().post.dof` 举起后仍为 false。上面「画面始终清晰」一条因此恢复成默认。
- 留影设置的「取景」一栏多一行「虚化」（四种语言），默认关，圈红为开，存进 `yunjing.settings.v1` 的 `blur`；缺失或损坏按关。只在画得出景深的档位（现在只有高档，有深度缓冲）显示这一行，别的档位没有。打开后样子就是此前高档举相机时的浅景深，快门拍出的大图与取景一致（开着虚，关着不虚）。
- `?shot` 的景深不动：它是工具和证据截图用的，仍对焦；两者在 `yard.js` 里是分开的两个条件。
- 验证：`finish` 场景三档举相机前后 `post.dof`，高档开关打开后为 true。
