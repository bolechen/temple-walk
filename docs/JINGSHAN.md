# 径山寺：查到了什么，留下了什么

这座数字寺院取意于杭州余杭的径山万寿禅寺，但不是它的复制品。寺名「云径禅寺」是虚构的。
本文记录调研得到的事实、我认定的灵魂元素，以及每一项在场景里是怎么落下来的。

## 资料来源和可信度

- **卫星影像**（2026-11-12 取自 Esri World Imagery，坐标约北纬 30.3819°、东经 119.7600°，每像素约 0.5 米）。
  这是格局的主要依据。影像没有放进仓库，需要时按坐标重新取。
- **维基百科「径山寺」条目**（2026-11-12 读的全文）。历史沿革、复建后的主轴和两侧建筑、现存文物、
  宋代的格局、茶宴的由来，都以它为准。
- **搜索引擎返回的摘要**：杭州市文旅局、几家本地媒体和游记。用来补充游览次序和古道上的地名；
  只有单一来源的标了出来。
- **实地照片**（维基共享资源上的十八张，2026-11-12 取）：山门正面两张、大雄宝殿和它的院子、从钟楼平台
  看全寺、凌霄阁、御碑亭、龙王殿、龙井、明代铁香炉、永乐大钟、茶宴模型，以及 1920 年代的两张旧照。
  建筑的层数、颜色、栏杆、匾额的挂法、门前的树，都是对着这些照片改的。照片没有放进仓库。
- 没有读到的：百度百科（拒绝访问）、官方导览图、建筑图纸。
  所以各殿的大小是按卫星图上量到的屋顶尺寸定的，**开间数是对着照片数的近似值，不是图纸数据**。

## 真实的径山寺是什么样

**位置和山势**
- 在径山之上，四周五峰环抱，寺在群峰之间的台地上。满山竹海，寺北紧挨着成片的茶园梯田。
- 从山下的古道走上来约五公里，沿途有亭。到寺前的最后几处是东坡洗砚池、金线竹、孝宗御碑亭。
- 卫星图上，寺前（东南角）有一条之字形的步道穿过竹林爬上来。

**格局**（卫星图）
- 坐西北朝东南，主轴沿山势由低到高，从山门到最高处约 190 米。
- 轴线上依次是：山门 → 一个大院 → 全寺最大的殿（屋顶约 39 米见方）→ 小院 → 一座殿（约 27 米）→
  再高一级的殿（约 27 米）→ 最高处的一组大建筑（约 35 米）。
- 两侧有长条形的配殿和一组四合院，白色山墙很醒目。

**建筑**（文字资料和照片）
- 入口先是「双径归堂」照壁，然后是五凤山门：两层的重阁，下层白墙、深色木构，明间是门；上层收小，
  檐下挂竖匾，下层挂金底黑字的横匾「万年正续」。两端各接一座带宝顶的小楼，五个屋顶连成一线。
  门前立着两棵很高的柳杉。山门左右是钟楼和鼓楼，钟是明永乐年间的。
- 复建后的主轴是五凤山门、大雄宝殿、藏经楼、观音殿、凌霄阁（维基百科）。大雄宝殿是重檐歇山顶，
  立在带白石栏杆的台基上，匾额金底黑字。凌霄阁是三层带平座栏杆的高阁，立在最高处，回望殿宇重重。
- 两侧有禅堂、药师殿、大慧院；龙王殿供奉灵泽龙王。龙井是一个石砌的拱形井龛，水在暗处。
  传说法钦开山时，龙神让出了地盘，只留下这口井。
- 明万历的铁香炉是塔式的：三足的炉身带两个耳，上面叠着两重小亭顶。
- 御碑亭是重檐的方亭。
- 宋代的格局是山门、普光明殿、观音殿、法堂、方丈在中轴，千僧阁在西，百尺楼在东兼作钟楼。
  这个平面被日本禅寺当作蓝本，称为「径山寺制度」。
- 近年按宋代式样复建，依据《五山十刹图》并参考日本建长寺。墙是白的，木构是深红褐色，灰瓦。
- 寺里的旧物：宋孝宗御碑、西方三圣铁佛、历代祖师名衔碑、明永乐大钟、明万历铁香炉。
  钟楼在 1990 年失火，大钟和祖师碑都受了损。山门上曾挂过明代的「天下径山」匾。

**它是什么地方**
- 南宋时位列「五山十刹」之首。宋孝宗题额「径山兴圣万寿禅寺」。
- 禅茶的祖庭：径山茶宴传到日本，是日本茶道的源头之一。

## 灵魂元素，以及它们在场景里的样子

场景里上山的方向是 -z，对应真实的西北；寺院正面朝 +z，对应东南。晨光从东边来，也就是正面偏右。

取舍的标准是：去掉它，这里就不再像径山；留下它，不需要把每一座殿都搬来。

| 灵魂 | 真实的径山 | 场景里 |
|---|---|---|
| 从竹林里走上来 | 五公里的古道，沿途有亭；寺前是之字形步道；最后几处是洗砚池、御碑亭 | 古道的最后一段：从望江亭出发，三段折线石阶，途经洗砚池和半山亭，到寺前的御碑亭。竹子是真 3D 的 |
| 两条路在这里会合 | 「双径归堂」照壁 | 石阶尽头正对一面照壁，题「双径归堂」，绕过它才见山门 |
| 重阁山门 | 五凤山门：两层，两端各带一座宝顶小楼，门前两棵柳杉 | 同样的五个屋顶；上层竖匾，下层金匾「万年正续」；门前两棵柳杉 |
| 钟声 | 山门左右的钟楼鼓楼，永乐大钟 | 山门两端的小楼里，东钟西鼓，点一下能敲响 |
| 层层升高 | 山门之后四进，一进比一进高 | 同样是四进：大院里的大雄宝殿、藏经楼、观音殿、山顶的凌霄阁，各在一级台地上 |
| 最大的殿在第一进 | 大雄宝殿，重檐歇山，屋顶约 39 米，白石栏杆，金匾；殿内有西方三圣铁佛 | 七开间的重檐大殿，屋顶约 34 米宽，白石栏杆，金匾。进殿是三尊像：主尊在后，两尊深色的铁佛在前 |
| 禅和茶面对面 | 禅堂；茶宴用矮桌和茶盏 | 大院东侧是禅堂，西侧是茶寮「吃茶去」，檐下摆着矮桌、铁壶、黑釉盏和蒲团 |
| 白墙深木 | 宋式，白墙，深红褐色的木构，灰瓦 | 白粉墙，深褐偏红的木构，灰瓦，不施彩画 |
| 龙井 | 石砌的拱形井龛 | 第二级台地的石壁上开一个毛石拱龛，暗处有水 |
| 茶园 | 寺北的梯田 | 登顶的石阶两侧是一垄垄茶树 |
| 登顶回望 | 凌霄阁，三层带平座 | 山顶的三层楼阁，每层有栏杆。站在阁前回头，观音殿、藏经楼的屋顶和柳杉的尖顶一层层隐进雾里 |
| 御碑 | 重檐的御碑亭，在寺前 | 山门外西侧的重檐碑亭，里面立着碑 |
| 铁香炉 | 明万历，塔式，两重亭顶 | 大院正中的铁香炉是同样的形制 |
| 柳杉 | 门前和院里的大树 | 山门前一对，各进院子里各有几棵 |
| 山里的声音 | — | 竹林的风、檐下的滴水、起风时的檐铃，都是合成的 |
| 五峰环抱 | 径山五峰 | 远景的山做成五座峰，北面最高 |

## 有意没有做的

- **除禅堂、茶寮、药师殿、大慧院之外的其他配殿和僧寮**。真实的寺里两侧是连成片的房子，这里每进院子只留一两座。
- **石狮和石经幢**。照片里山门前有，但用代码做雕像很难不走样，宁可没有。
- **红灯笼和祈福的红绸**。真实的寺里很多，和这里要的素净不合。
- **铁佛、祖师碑**。殿内目前是固定机位的一张图，放不下它们；等殿内改成真 3D 再说。
- **寺西的大水池和成片的客舍**。那是现代的配套，不是寺的一部分。
- **卡通菩萨雕像**。真实的步道边有，但和这里要的安静不合。

## 还欠着的

- 古道有五公里和七座亭子，这里是它的最后一百米：三段台阶、三座亭、一口池。再长就不是走十分钟的事了。
- 茶寮里没有茶席，井里没有水声，竹林没有风声。
- 殿内仍是固定机位，不能走动；三尊像用的是同一个佛像模型，铁佛只是缩小并换成铁色。
- 建筑的开间数没有图纸可对。
