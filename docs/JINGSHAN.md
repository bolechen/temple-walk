# 径山寺：查到了什么，留下了什么

这座数字寺院取意于杭州余杭的径山万寿禅寺，但不是它的复制品。寺名「云径禅寺」是虚构的。
本文记录调研得到的事实、我认定的灵魂元素，以及每一项在场景里是怎么落下来的。

## 资料来源和可信度

- **卫星影像**（2026-11-12 取自 Esri World Imagery，坐标约北纬 30.3819°、东经 119.7600°，每像素约 0.5 米）。
  这是格局的主要依据。影像没有放进仓库，需要时按坐标重新取。
- **搜索引擎返回的摘要**：百科、杭州市文旅局、几家本地媒体和游记。名称和次序互相印证的我才采用；
  只有单一来源的标了出来。
- 没有读到原文的：维基百科和百度百科的条目（接口限流）、任何官方导览图、任何建筑图纸。
  所以**开间数、尺寸、层数都没有可靠数据**，场景里的尺寸是我按卫星图上的屋顶大小估的。

## 真实的径山寺是什么样

**位置和山势**
- 在径山之上，四周五峰环抱，寺在群峰之间的台地上。满山竹海，寺北紧挨着成片的茶园梯田。
- 从山下的古道走上来约五公里，沿途有亭。到寺前的最后几处是东坡洗砚池、金线竹、孝宗御碑亭。
- 卫星图上，寺前（东南角）有一条之字形的步道穿过竹林爬上来。

**格局**（卫星图）
- 坐西北朝东南，主轴沿山势由低到高，从山门到最高处约 190 米。
- 轴线上依次是：山门 → 一个大院 → 全寺最大的殿（屋顶约 39 米见方）→ 小院 → 一座殿（约 27 米）→
  再高一级的殿（约 27 米）→ 最高处的一组大建筑（约 35 米）。
- 两侧有长条形的配殿和一组四合院，白色山墙很醒目。

**建筑**（文字资料）
- 入口先是「双径归堂」照壁，然后是五凤山门：全木结构的重阁，底层兼作天王殿，上层供五百罗汉。
  山门左右是钟楼和鼓楼，钟楼里是明永乐年间的大钟。
- 轴线上是大雄宝殿、潮音堂（也有资料写作藏经楼）、观音殿，最高处是凌霄阁，登阁回望殿宇重重。
- 两侧有禅堂、药师殿、大慧院；有一口唐代的龙井，旁边是龙王殿。
- 近年按宋代式样复建，依据《五山十刹图》并参考日本建长寺。白墙，木构不上彩。
  有人批评鸱尾等细部并不准确（单一来源，知乎）。
- 寺里的旧物：宋孝宗御碑、三尊宋代铁佛、元代的历代祖师名衔碑、明代钟楼。

**它是什么地方**
- 南宋时位列「五山十刹」之首。宋孝宗题额「径山兴圣万寿禅寺」。
- 禅茶的祖庭：径山茶宴传到日本，是日本茶道的源头之一。

## 灵魂元素，以及它们在场景里的样子

取舍的标准是：去掉它，这里就不再像径山；留下它，不需要把每一座殿都搬来。

| 灵魂 | 真实的径山 | 场景里 |
|---|---|---|
| 从竹林里走上来 | 古道和寺前的之字形步道 | 起点在竹林深处的石阶脚下，三十多级台阶上到寺前。竹子是真 3D 的 |
| 两条路在这里会合 | 「双径归堂」照壁 | 石阶尽头正对一面照壁，题「双径归堂」，绕过它才见山门 |
| 重阁山门 | 五凤山门，两层 | 两层的山门，从底层明间穿过 |
| 钟声 | 钟楼和永乐大钟 | 山门内东侧的钟亭，点一下能敲响；西侧是鼓 |
| 层层升高 | 四级台地 | 三级：大院、藏经楼的台地、山顶。少一级，但每上一级都要爬台阶 |
| 最大的殿在第一进 | 大雄宝殿，约 39 米见方 | 重檐的大雄宝殿，全寺最大的屋顶，可以进殿礼佛 |
| 禅和茶面对面 | 禅堂；茶宴 | 大院东侧是禅堂，西侧是茶寮，匾额「吃茶去」 |
| 素木白墙 | 宋式，不施彩 | 所有木构是不上漆的深褐色，墙是白粉墙 |
| 龙井 | 唐代古井 | 第二级台地东侧的井亭 |
| 茶园 | 寺北的梯田 | 登顶的石阶两侧是一垄垄茶树 |
| 登顶回望 | 凌霄阁 | 山顶的两层楼阁，站在阁前回头，藏经楼、井亭、院墙和远山都在脚下的雾里 |
| 御碑 | 孝宗御碑亭，在寺前 | 山门外西侧的碑亭 |
| 五峰环抱 | 径山五峰 | 远景的山做成五座峰，北面最高 |

## 有意没有做的

- **观音殿、药师殿、大慧院**。它们让真实的寺院完整，但对一个走十分钟的场景来说只是重复。
- **朝向**。真实的寺朝东南，场景里朝正南。这不影响体验，却能让代码简单。
- **铁佛、祖师碑**。殿内目前是固定机位的一张图，放不下它们；等殿内改成真 3D 再说。
- **寺西的大水池和成片的客舍**。那是现代的配套，不是寺的一部分。
- **卡通菩萨雕像**。真实的步道边有，但和这里要的安静不合。

## 还欠着的

- 第二进殿和第三进殿之间那一级台地。现在从藏经楼直接上山顶，少了一次「以为到了，其实还有」的感觉。
- 古道上的亭子。现在的上山路只有三十多级台阶，太短。
- 茶寮里没有茶席，井里没有水声，竹林没有风声。
