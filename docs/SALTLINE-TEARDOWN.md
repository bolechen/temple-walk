# Saltline 源码对照

Saltline 是 Felix Rieseberg 用 Fable 5.2 一次指令、8 小时生成的码头射击游戏
（[帖子](https://x.com/felixrieseberg/status/2119925633564463609)，[页面](https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp)）。
它是我们画面目标的参照物。本文记录读它源码得到的事实，以及我们和它的差距。

读的是 2026-11-11 拿到的页面源码（3.6 MB 单文件，压缩过）。变量名被压缩了，但着色器里的注释、
字符串和配置表都在，下面的结论都来自这些。没有运行过它，也没有看过视频。

## 它是怎么搭的

| 层 | 做法 |
|---|---|
| 引擎 | three.js r180，WebGL2，打包内联。没有外部模型、贴图或音频文件 |
| 场地 | 可活动范围 80 × 60 米，分四个区：gate、yard、shed、quay。一条 12 个机位的巡游路线 |
| 模块 | render、materials、fx、level、backdrop、ground、audio、weapon、enemies、hud，各自有 `create()` |
| 启动 | 分阶段加载并显示进度文案。非关键模块失败时换成空实现，不让整页崩掉 |
| 静态几何 | 关卡搭完后按材质合并成少数几个网格（`level-merged`） |
| 背景 | 独立的 backdrop 模块：吊机、货轮、城市天际线，都在可活动范围之外 |
| 贴图 | **启动时烘焙**：用渲染到纹理的方式生成可平铺的反照率、法线、粗糙度贴图，带多级渐远和各向异性过滤。贴图尺寸随画质档位变化（512 到 2048） |
| 细节 | 在烘焙贴图之上，着色器再叠一层世界坐标下的程序噪声，近看不糊 |
| 文字 | 用 canvas 画出标签、编号和喷漆字，再做旧，合成一张图集 |
| 地面 | 单独的 ground 模块：一张唯一的大尺度遮罩（积水、潮湿、油渍、磨损）加平铺细节；积水处用平面反射 |
| 天空 | 一个着色器画云层和太阳，并采成环境光 |
| 阴影 | 改写了 three.js 的阴影着色器块，做成带半影的软阴影（先找遮挡物，再按距离放大半影） |
| 后期 | 环境光遮蔽、半分辨率体积光（按档位 10 到 40 步）、泛光、镜头光晕、自动曝光、色调映射、调色、暗角、颗粒、运动模糊（高档位） |
| 兜底 | 高级渲染管线启动时自检，失败就退回普通前向渲染；软阴影被驱动拒绝就退回默认阴影 |
| 音频 | 全部合成：启动时算出各个声音的缓冲，带空间定位和混响，音乐随战况变化 |
| 天气 | 雨丝、落地水花、偶发雷声，湿度是一个可调参数 |

### 画质分档

| 档位 | 渲染比例 | 像素预算 | 抗锯齿 | 阴影图 | 贴图 | 体积光步数 | 遮蔽 | 平面反射 |
|---|---|---|---|---|---|---|---|---|
| low | 0.7 | 100 万 | 无 | 2048 | 512 | 12 | 关 | 关 |
| medium | 0.85 | 150 万 | 2 倍 | 2048 | 1024 | 16 | 开 | 半分辨率 |
| high | 1 | 230 万 | 4 倍 | 4096 | 1024 | 24 | 开 | 半分辨率 |
| ultra | 1 | 370 万 | 4 倍 | 4096 | 2048 | 40 | 开 | 全分辨率 |

**手机一律走 low**，也就是没有遮蔽、没有平面反射。集成显卡走 medium，独立显卡走 high。

### 开发方式

这是最值得学的部分，也是它能在无人看管的情况下迭代 8 小时的原因：

- **每个模块都有 `showcase()`**：用网址参数把场景切到只展示这一个模块的固定机位，比如只看吊机、只看天空、
  只看武器。这样每改一处都能截一张图自查。
- **确定性的测试参数**：固定时间步长、逐帧步进、指定机位、指定画质、冻结特效。同一个网址每次渲染出同一帧。
- **到处是带模块名的日志和兜底**，出错能定位到模块，而不是白屏。

## 我们和它的差距

| 项目 | Saltline | 我们（2026-11-12） | 差距 |
|---|---|---|---|
| 场地 | 80 × 60 米，四个区 | 34 × 34 米，一进院子 | 大 |
| 模块化 | 十个模块，各有展示机位 | 两个大文件 | 大 |
| 画质分档 | 四档，手机走最低档 | 三档加按帧时间自动降级（本次补上） | 已补 |
| 贴图 | 启动时烘焙，带多级渐远 | 全部在片元着色器里逐像素算噪声 | 大：又慢又容易闪 |
| 软阴影 | 带半影 | 普通阴影加手写的遮蔽 | 中 |
| 环境光遮蔽 | 屏幕空间 | 手写的解析式遮蔽（只有檐下和地面） | 中 |
| 体积光和雾 | 半分辨率光线步进 | 距离雾加几片雾气贴片 | 中：这是寺院气氛的关键 |
| 平面反射 | 有 | 有 | 持平 |
| 后期 | 自动曝光、镜头效果、调色 | 泛光、调色、暗角、颗粒 | 小到中 |
| 背景 | 独立模块，大型剪影物体 | 墙外几层竹林平面 | 大：我们最弱的地方 |
| 文字 | canvas 生成并做旧 | 没有，匾额留空 | 中：可以直接学 |
| 音频 | 全合成，带空间定位 | 没有 | 大 |
| 天气 | 雨、水花、雷 | 静态的雨后 | 中 |
| 兜底 | 管线自检和多级退路 | 只有殿内加载失败的提示 | 中 |
| 测试 | 确定性参数，逐模块截图 | 一条走通全程的测试 | 中 |

## 它没有、而我们需要的

- **有机形体**。码头全是方盒子和金属。寺院有斗拱、瓦垄、竹林、古树，源码里没有可借鉴的做法。
- **近距离的雕像**。它没有需要端详的东西；我们有佛像，靠现成的模型解决。
- **安静**。它的画面靠冲突感撑着（雷、火、枪）。我们要的是没有事件发生时也耐看。

## 从中得出的做法

1. **先搭架子再铺内容**。拆成模块，每个模块一个展示机位，测试用确定性参数。没有这个，扩建会越来越难改。
2. **贴图改成启动时烘焙**。木、石、瓦、粉墙各烘一套可平铺贴图，着色器里只留近处的细节噪声。
   这同时解决手机性能和远处闪烁。
3. **把背景当成独立模块来做**：远山、山上的塔影、竹海，都放在可活动范围之外。
4. **体积雾和光束**排在软阴影前面，因为雾是这个场景的主角。
5. **匾额和楹联用 canvas 写字**，字体从 Google Fonts 取。
6. **声音全部合成**：钟、木鱼、檐铃、雨滴、竹林的风。
