# T02 声音设计调研

核对日期：2026-11-17。T00 的音频全部是 Web Audio 合成，没有录音；T02 默认沿用这条路线。
资料库的 sound 字段是：「外部林声进入岩下后改变，木板脚步与局部滴水形成近景；滴水位置为设计。」本文把它拆成可执行的声场与合成方案。

---

## 1. 五段声场

| 段 | 位置 | 主导声 | 次要声 | 不该有的 |
|---|---|---|---|---|
| Z1 湖面/码头 | 船上、码头、林间窄路 | 湖水轻拍、风、船的低频 | 鸟、虫、远处船 | 城市交通、广播、可辨人声 |
| Z2 岩口 | 石阶、券洞、洞口 | 风声被岩壁收窄、脚步回声、滴水初现 | 林声在背后、湖水在远处 | 突然的静音；洞外声完全消失 |
| Z3 木楼下部 | 平台下、状元柱周围 | 木构吱呀、脚步在石/木上的切换、滴水 | 洞顶渗水、远处湖声 | 持续的低频轰鸣、夸张的洞穴回声 |
| Z4 侧向栈道 | 南侧栈道、两阁之间 | 木板脚步、栏杆轻响、风过檐口 | 两阁檐下的暗响、滴水 | 密集的游客声、商业音乐 |
| Z5 上层小殿 | 小殿内、回望洞口 | 近处的静、自己的呼吸/衣料、极远的滴水 | 洞口外的湖风、鸟 | 诵经（未授权）、钟鼓（无来源） |

### 1.1 声压与距离

- 湖面/码头：约 50–60 dB(A)（风、水、船；未测）。【提案】
- 林间窄路：约 40–50 dB(A)；进洞后降到 30–40。
- 木楼下部：约 30–35；滴水是「点」，不是「底」。
- 上层小殿：约 25–30；留白最多。
- 洞内混响比室外长 3–5 倍（【提案】，未测）；但不要做成教堂/溶洞的夸张回声。

### 1.2 时间

- 上午：鸟多、船少、滴水清楚。
- 中午：船多、人声多；洞内仍安静。
- 下午：洞口逆光、风起、湖水声上升。
- 傍晚：景区关闭；不做夜景。

## 2. 现场录音清单（若做）

> 前提：取得景区/寺方许可；不录可辨识的游客谈话；不使用无人机；不在洞内敲打文物。

每个点 60–90 秒，同一天、同一设备、写明天气/时段/朝向/事件：

1. 湖面船上（距洞口 100–200 m），朝洞口。
2. 甘露寺码头，朝石阶。
3. 林间窄路中段，朝洞口。
4. 岩口/券洞内，朝洞腹。
5. 木楼下部，朝状元柱，录「石脚步 → 木脚步」的切换。
6. 侧向栈道，朝两阁。
7. 上层小殿内，朝洞口；再录一条朝内。
8. 单独录：滴水（不同位置、不同水滴）、木板脚步、木构吱呀、栏杆轻响、湖水、船、风过杉针、鸟（不辨种）。
9. 参考：洞外的雨声与洞内的滴水，各一条。

**每条记录**：文件名、时间、地点、朝向、设备、天气、许可、SHA-256。

## 3. 合成方案（默认路线）

T00 的 `audio.js` 有三条总线（音乐、山声、音效）、两套混响（庭院、木构殿内）、`instruments.js` 的琴/箫/泛音/钟/鼓。T02 新增：

| 声 | 合成做法 | 复用 |
|---|---|---|
| 洞穴混响 | 卷积/算法混响，3–5 s，低频保留、高频衰减；按「洞内/洞口」两档 | 新 |
| 滴水 | 单个水滴（正弦衰减 + 轻微音高下滑）+ 水面回声；每 4–12 s 一次，位置化 | 新 |
| 湖水 | 低频噪声 + 缓慢起伏 + 偶发拍岸 | 新 |
| 船 | 低频引擎 + 水声；只在 Z1，随距离衰减 | 新 |
| 林声 | 风过杉针（高频细碎）+ 阔叶（中频）+ 鸟/虫 | T00 `trees` 声可改 |
| 木脚步 | 木板空腔（短促低频 + 吱呀）+ 石脚步（干/湿） | `steps.js` 扩展 |
| 木构吱呀 | 极稀疏的摩擦/谐振；不循环 | 新 |
| 栏杆轻响 | 短促木质点击 | 新 |
| 雨 | 洞外雨（宽带噪声）+ 洞内滴水（点） | 新 |
| 钟/磬 | 复用 T00 `bell()`；资料没有说甘露寺有可敲的大钟，不要滥用 | 复用/克制 |

**原则**：

- 洞外是「层」，洞内是「点」；不要把洞内做成持续的环境铺底。
- 滴水是 T02 的「近景声」，要有位置感；不要做成全局循环。
- 木脚步与石脚步的切换，是玩家理解「平台/岩面」的关键；每一次切换都要清楚。
- 不做「溶洞景区」的彩色回声/水滴音乐。

### 3.1 与 T00 的差异

| T00 | T02 |
|---|---|
| 竹林风、竹击、龙井滴水、檐下滴水 | 湖水、船、杉林、洞顶滴水 |
| 庭院/木构两套混响 | 洞穴混响（更长、更暗）+ 洞口过渡 |
| 钟声是主要仪式声 | 滴水是主要近景声；钟声克制 |
| 山顶回望是群山 | 洞口回望是湖面 |

## 4. 配乐

> 资料库没有给 T02 的配乐要求；T00 的经验是「音乐在场景之下」。T02 第一版建议「先做环境声，再决定是否要音乐」。

### 4.1 结构提案

- **调式**：仍可用 G 羽，但更空、更少音；主题 3–5 个音，像滴水/回声。
- **乐器**：琴、箫保留；加入极轻的木鱼/磬「点」、低频持续音（湖/岩的底）。
- **段落**：
  - Z1 湖面：只有水、风、船；几乎没有音乐。
  - Z2 岩口：一个琴音，像洞口的回声。
  - Z3 木楼下部：主题的碎片，低音区。
  - Z4 栈道：箫的呼吸，音少。
  - Z5 上层小殿：主题只剩骨架，最后一个音不解决。
- **与滴水的关系**：滴水不是节拍器；音乐不要跟着水滴走。

### 4.2 不要做

- 不要用「空灵女声/佛号/诵经」采样，除非取得授权。
- 不要用大鼓/低音炮做「震撼」；T02 是安静。
- 不要让音乐盖过滴水、脚步、湖水。

## 6. 验收

- [ ] 从湖面到洞口，风声被岩壁收窄、混响变长；不是突然静音。
- [ ] 滴水在洞内有位置感；不是全局循环。
- [ ] 石脚步 → 木脚步的切换清楚。
- [ ] 洞内没有城市交通/广播/可辨人声。
- [ ] 音乐不盖过滴水、脚步、湖水。
- [ ] 上层小殿有留白，不是一直有声音。
- [ ] 没有未授权的诵经/佛号采样。

**注意**：自动测试只能证明「不削波、按规则切换、频率对」，不能证明「好听」。T02 的音频最终要真人试听。
