# T02 来源账本

核对日期：2026-11-17。每条都写：**读了哪里、能支持什么、不能支持什么**。不是「有这个链接」就算来源。
资料库条目 `T02` 的两个来源（S01、S02）是本包的骨架；其余来源用于补坐标、高程、洞穴尺度、到达方式与馆藏图像。

## 0. 阅读方式与可信度分级

- **【原文】**：本包写作时实际打开页面、读了正文。
- **【PDF】**：下载 PDF 并用文本层抽取；印刷页以原文标注的页码为准。
- **【API】**：结构化数据（OSM Overpass、Nominatim、opentopodata、Commons/CMA API），按字段读，不靠转述。
- **【摘要】**：只读到搜索引擎摘要、新闻转述或百科条目，没有打开原文。**引用前必须再核。**
- **【照片】**：从公开照片上看到的现象，只作研究，不作测量。
- **【未用】**：链接打不开或内容不足，明确不采用。

同一个网页可能被多家转载，**转载数量不等于独立证据数量**。甘露寺的很多数字（洞高、柱高、台阶数）在旅游文里互相抄，找不到一手来源时一律标【摘要】或【未核】。

## 9. 再分发与授权边界

- **政府网站/规划 PDF**：可阅读与引用；不要把整份 PDF 或大段文字打包进游戏仓库。引用时注明文号/日期/页码。
- **鸟取环境大学纪要 PDF**：可阅读与引用；再分发权未取得。引用要短，注明作者、刊名、页码。
- **新闻/百科**：可阅读；不直接搬运长段文字与图片。
- **OSM**：ODbL；地图数据可用于游戏，但要署名 OpenStreetMap contributors；衍生数据可能有相同方式共享义务。
- **SRTM/opentopodata**：公开高程数据；作为设计参考，不直接分发原始数据。
- **Wikimedia Commons**：CC BY-SA 3.0/4.0、CC BY 3.0 可以商用，但必须署名、注明许可、相同方式共享；是否接受「相同方式共享」由所有者决定。**本包不下载、不进 `dist/`。**
- **克利夫兰艺术博物馆 Open Access**：CC0，可商用；保留来源行。
- **1959 年测绘图/1960 年模型**：版权未清；只作研究，不描图。
