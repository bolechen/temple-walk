# T02 现场采集清单

核对日期：2026-11-17。本文是「如果要去现场，带什么、问什么、拍什么、记什么」。
**没有现场许可就不做**；进入景区与购票不等于获得商业图片/录音授权。

---

## 0. 先去之前

### 0.1 许可与边界

- [ ] 向**大金湖景区/泰宁世界地质公园管理方**说明来意：游戏场景研究、非商业发布前的资料采集；问清是否允许拍照、测量、录音。
- [ ] 向**甘露寺管理所**（1996 年由金湖管委会与泰宁县宗教局成立）说明来意；问清哪些殿可进、哪些区域不开放、能否拍佛像、能否进洞内平台下。
- [ ] 向**泰宁县宗教局/福建省文物局**确认：寺院现状的保护级别、是否允许专业测绘/三维扫描。
- [ ] 说明用途：网页游戏《山门之外》的 T02 关卡；是否收费未定；素材是否进游戏、是否商用，要如实说。
- [ ] **不进入未开放区域**（栈道维修段、岩壁裂隙、洞顶下方）；不翻越栏杆。
- [ ] **不使用无人机**；不架三脚架堵路；不在殿内使用闪光灯；不拍摄正在礼佛的人正面。
- [ ] 遵守景区开放时间与游船班次；不单独行动；雨季注意山洪/落石。
- [ ] 若需要专业测绘（全站仪/RTK/激光扫描），必须另行取得文物与景区许可；本文默认**不做专业测绘**。

### 0.2 装备

- 相机 + 16–35 mm 广角（洞穴）、24–70 mm、70–200 mm；偏振镜。
- 手机（记录 GPS、时间、指南针、水平仪、测光）。
- 激光测距仪（洞穴 40 m 够用）；卷尺 5 m；粉笔/标记贴（不损伤表面）。
- 录音机 + 防风毛套 + 立体声话筒；耳机；可录 5.1 的话筒更好。
- 色卡/灰卡；白平衡卡；照度计（或手机测光 App）。
- 头灯（红光模式，不干扰他人）、防滑鞋、轻便雨衣、手套。
- **不携带**：无人机、大型灯架、反光板（殿内）、扩音器、香烛。

## 1. 空间与建筑测量

### 1.1 总体

- [ ] 洞口中心 GPS、海拔（手机 GPS 即可，标误差）。
- [ ] 洞口高、宽；洞腹最宽、最高、最深；洞底起伏（至少 5 个点）。
- [ ] 从码头到洞口的高差与水平距离；石阶级数、每级高/踏面/净宽。
- [ ] 主平台的平面尺寸、板厚、梁距、短柱位置、状元柱位置。
- [ ] 栈道的宽度、长度、转弯、栏杆高度/间距、支撑方式。
- [ ] 洞内外的照度（洞口、平台下、殿内、栈道），记录时间与天气。

### 1.2 逐座（每座 20 分钟）

- [ ] 平面：面阔（柱中到柱中，逐间）、进深（逐间）、台基宽/深/高。
- [ ] 立面：檐口高、屋脊高、台基高、门高/宽、窗高/宽。
- [ ] 屋顶：形式（歇山/悬山）、举高、出檐、翼角、脊饰。
- [ ] 柱：直径、柱础、收分、侧脚、生起（目测 + 照片）。
- [ ] 插拱：位置、出跳、组物、与柱头/大引的接触。
- [ ] 穿斗：穿枋层数、出头、替木、地柎。
- [ ] 墙：白灰/岩面/木板的比例、厚度、剥落。
- [ ] 匾额/题记：文字、尺寸、挂法、底色、字色、残损。
- [ ] 现状用途、是否可进、是否拍照允许。

### 1.3 状元柱与平台（单独 40 分钟）

- [ ] 柱：直径、周长、高度、材质、柱础、裂纹、修补。
- [ ] 柱头：组物形式、出跳、与大引的接触、是否有垫木/木楔。
- [ ] 大引：断面、跨度、与横材的连接。
- [ ] 短柱：数量、位置、直径、落在岩面的方式。
- [ ] 横材：层数、走向、与岩壁的连接。
- [ ] 平台底：可见的梁/板/栈木；哪些是原构、哪些是重建（若可辨）。

### 1.4 岩壁与节点（单独 40 分钟）

- [ ] 后檐抵岩：岩面凿平范围、砖砌/白灰、佛坛与岩的接触。
- [ ] 两翼半依岩：短柱/栈木与岩面的接触、木楔、垫石。
- [ ] 洞顶：滴水位置、流量、渗水带、钟乳石。
- [ ] 岩体：层理、裂隙、风化、苔、水痕、落石风险点。
- [ ] 左右钟鼓石：轮廓、与洞口的关系。

## 2. 照片清单

### 2.1 总体（至少 10 张）

1. 湖上远望（船/码头），朝洞口。
2. 码头到石阶的路径。
3. 林间窄路中段，朝洞口。
4. 洞口正面（含左右钟鼓石）。
5. 券洞/入口。
6. 洞腹全景（从洞口向内）。
7. 平台底/状元柱（从下向上）。
8. 侧向栈道（从栈道看两阁）。
9. 上层小殿回望洞口。
10. 洞顶/滴水。

### 2.2 每座建筑（至少 6 张）

1. 正面（含台基与檐口）。
2. 左前 45°。
3. 右前 45°。
4. 侧面（含进深）。
5. 背面/抵岩处（若可绕）。
6. 屋顶/檐下/插拱特写。

### 2.3 每处关键物

- [ ] 状元柱：柱身、柱头、柱脚、与大引的接触。
- [ ] 短柱/横材：每一类接触。
- [ ] 插拱：正面、侧面、里转。
- [ ] 穿斗：穿枋出头、替木、地柎。
- [ ] 草灰泥屋面：表面、厚度、雨渍、脊饰。
- [ ] 残彩：黑地白线、牡丹/莲花、叠晕。
- [ ] 题记：可辨的字、位置、残损（不拓）。
- [ ] 岩壁：层理、湿痕、苔、凿痕、裂隙。
- [ ] 滴水：水滴、落点、水痕。

### 2.4 光线与天气

- [ ] 同一天至少拍「上午/正午/下午」三组，记录时间、天气、太阳方向。
- [ ] 雨天/雨后（若遇到）拍湿岩、湿石阶、滴水。
- [ ] 雾天/薄霾（若遇到）拍湖面与洞口。
- [ ] 记录洞内外的照度差。

### 2.5 元数据

每张照片记录：文件名、时间、地点、朝向、镜头/焦距、光圈/快门/ISO、白平衡、天气、许可、备注。
回来按建筑/主题建文件夹，保留原图，不覆盖。

## 5. 安全

### 5.1 落石

- 洞穴是丹霞砂岩，有层理、裂隙、渗水；洞顶与洞口上方是落石风险区。
- 不在洞顶正下方久留；戴头盔（若允许）；听景区警示；雨后不进入裂隙区。
- 不敲打岩壁、不撬石块、不攀爬岩体。

### 5.2 窄道与湿滑

- 石阶与栈道雨后湿滑；穿防滑鞋；扶栏杆；不奔跑。
- 栈道窄（约 1.1 m），不并排、不推挤；三脚架不堵路。
- 栏杆间距 ≤0.12 m；不把小孩抱上栏杆。

### 5.3 防火

- 甘露寺 1961 年因取暖火焚毁；木构 + 草灰泥屋面，防火是第一安全项。
- 洞内**不点香烛、不吸烟、不用明火**；不使用大功率灯（发热）。
- 不在木构旁充电/换电池；电池随身，不放在木板上。
- 发现火情/焦味，立即离开并报警。

### 5.4 其他

- 不进入未开放区域；不翻越栏杆；不单独行动。
- 雨季注意山洪、雷击；船上穿救生衣。
- 尊重礼佛者；不拍人脸；不喧哗。
- 若被问起，如实说明是游戏研究；不冒充记者/学者/官方。
- 若管理方拒绝，尊重并停止；不偷拍、不绕开。

## 6. 数据管理

- [ ] 原图/原音不动；工作副本另存。
- [ ] 每个文件算 SHA-256；目录结构：
  ```
  t02-field-YYYY-MM-DD/
    photo/<zone>/...
    audio/<zone>/...
    notes/
    register.csv
  ```
- [ ] `register.csv` 列：文件、类型、时间、地点、作者、许可、用途、SHA-256、备注。
- [ ] 不把现场照片直接放进仓库；先筛，再按授权决定。
- [ ] 长录像/长录音放仓库外，记地址与 SHA-256。
- [ ] 下载的 PDF/图片按「不可信数据」处理：单独目录、不执行、不安装。
