## 0. 结论

- **四幅，全部来自克利夫兰艺术博物馆 Open Access，CC0**：华严三圣 1 幅、西方三圣 1 幅、白衣观音 2 幅。
- **墙面只有四处**：主殿（蜃阁/原创小殿）、上殿、观音阁、南安阁侧壁。洞内空间小、光线暗，四幅已是上限；宁少勿多。
- **不冒充本寺旧藏。** 甘露寺真实殿内供的是（重建的）塑像，不是这些画；卡片写「同题材的公开馆藏图像，非本寺旧藏」。
- **只用可商用的图。** 克利夫兰 CC0；中文博物馆的网页图、日本寺院的官方照片、Commons 的 CC BY-SA 实景照都不进游戏（Commons 只作研究，见 `ASSETS.md`）。
- **与 T00/T01 不重复。** T00 的 32 件是宋元禅林墨迹与禅画；T01 的 17 件是唐—明—清汉传佛像与东密图像。T02 的 4 件是「华严/西方三圣/白衣观音」，两关都没有用过。

4. 图不能直接当贴图；要按墙面比例缩放、加画框、做旧（可选），但「做旧」不能改变图像内容。

## 2. T02 选件的五条原则

1. **殿的用途先于画的名气。** 主殿挂华严三圣，上殿挂西方三圣，观音阁挂白衣观音；不为「名作」硬找墙。
2. **不冒充本寺旧藏。** 每件卡片写「同题材的公开馆藏图像，非本寺旧藏」。
3. **只用可商用的图。** 克利夫兰 CC0；其他来源不进游戏。
4. **一幅一义。** 每幅只承担一个叙事功能；同一主题不挂三幅互相打架的。
5. **汉传与藏传分开。** T02 是汉传岩寺；藏传罗汉/五佛冠只作参考，不挂墙。

## 4. 逐件著录

### 4.1 主殿 `cave-main`

**墙面**：原创小殿/蜃阁的后壁或侧壁；不要挂在佛坛正后方（正面留给像设）。洞内暗，画框要有极轻的边光，但不能像画廊射灯。

#### W-CV-01 释迦三尊：文殊与普贤

- **著录**：Shakyamuni Triad: Buddha Attended by Manjushri and Samantabhadra (Bodhisattva with Lion)，佚名，中国福建福州，元，14 世纪晚期，立轴，绢本设色，画心 107 × 46.5 cm，整幅 192 × 62.5 cm，克利夫兰艺术博物馆，**2009.342.1**，**CC0**。
- **图像**：`https://openaccess-cdn.clevelandart.org/2009.342.1/2009.342.1_web.jpg`（馆方 web 图；另有 `_print`/`_full.tif`）。
- **为什么**：甘露寺蜃阁供华严三圣（释迦、文殊、普贤）；这件正是释迦+文殊+普贤，且出自**福建福州**，地域上与甘露寺最近。元代的福建佛画，比泛泛的「华严经变」更贴。（馆方标题称「Bodhisattva with Lion」，可能指普贤的坐骑；按「释迦三尊」的构图理解，具体尊格以馆方条目为准。）
- **卡片**：写「华严三圣是《华严经》的像设：释迦居中，文殊表智、普贤表行。甘露寺蜃阁在宋构中供华严三圣。」并注明「此画为克利夫兰艺术博物馆藏，非本寺旧藏」。
- **不说**：不说这是甘露寺的旧藏；不说它与蜃阁塑像同作者、同年代；不把「福州」说成「泰宁」。

### 4.2 上殿 `upper`

**墙面**：上殿侧壁；不要挂在正面佛坛后。上殿是最高、最后一进，画要小、要暗。

#### W-UP-01 阿弥陀与二胁侍

- **著录**：Buddha Amitābha with Two Attending Bodhisattvas，佚名，中国，南宋，13 世纪，立轴，绢本设色，画心 134 × 79.7 cm，整幅 223 × 95.7 cm，克利夫兰艺术博物馆，**1974.35**，**CC0**。
- **图像**：`https://openaccess-cdn.clevelandart.org/1974.35/1974.35_web.jpg`。
- **为什么**：上殿在宋构中供西方三圣（阿弥陀、观音、大势至）；这件正是阿弥陀与二胁侍，南宋，年代与甘露寺宋构（1146–1227）相接。
- **卡片**：写「西方三圣是阿弥陀佛与观音、大势至二胁侍；上殿在宋构中供西方三圣。此画为克利夫兰艺术博物馆藏，非本寺旧藏」。
- **不说**：不说二胁侍一定是观音/大势至（馆方标题只写「二胁侍」）；不说这是上殿的原像。

### 4.3 观音阁 `guanyin`

**墙面**：观音阁侧壁；观音阁是上下两层、三重檐，画挂在**上层**侧壁，不挂在下层通道。

#### W-GY-01 白衣观音

- **著录**：White-Robed Guanyin，佚名，中国，南宋，13 世纪晚期，立轴，纸本水墨，画心 104.5 × 42.2 cm，整幅 195.4 × 56.6 cm，克利夫兰艺术博物馆，**1972.160**，**CC0**。
- **图像**：`https://openaccess-cdn.clevelandart.org/1972.160/1972.160_web.jpg`。
- **为什么**：甘露寺观音阁供观音；白衣观音是宋代以后最常见的观音形象之一，纸本水墨、色调安静，适合洞内暗壁。
- **卡片**：写「白衣观音是观音的一种形象，白衣表清净；宋代以后常见于江南与福建。此画为克利夫兰艺术博物馆藏，非本寺旧藏」。
- **不说**：不说这是「送子观音」（白衣观音不等于送子观音）；不说这是甘露寺的旧藏。

### 4.4 南安阁 `nanan`

**墙面**：南安阁侧壁；南安阁在宋构中供观音/南安（名称待考），所以用第二幅观音是合理的，但要与观音阁的那幅区分时代与材质。

#### W-NA-01 白衣观音（金/纸）

- **著录**：White-Robed Guanyin，佚名，中国，元，13 世纪晚期–14 世纪早期，立轴，绢本水墨描金，画心 80.7 × 25.7 cm，整幅 166 × 39.4 cm，克利夫兰艺术博物馆，**1978.47.2**，**CC0**。
- **图像**：`https://openaccess-cdn.clevelandart.org/1978.47.2/1978.47.2_web.jpg`。
- **为什么**：与 1972.160 同一题材、不同时代/材质（南宋纸本水墨 vs 元绢本水墨描金），并置能让玩家看到「同一尊观音，隔了一个朝代，画法已经不同」。南安阁与观音阁对称，正好成对。
- **卡片**：写「同一题材，南宋与元的两幅；并置不是为了比高下，是让人看见时间。此画为克利夫兰艺术博物馆藏，非本寺旧藏」。
- **不说**：不说两幅是同一寺的旧藏；不说 1978.47.2 比 1972.160「更真」。

## 8. 技术落地

### 8.1 文件与数据

```
app/levels/t02/gallery/<slug>.webp          # 1280 px 长边，WebP q80（本包未下载）
app/levels/t02/works.js                     # 由 tools/gallery.py 写出，不手改
app/levels/t02/locales/{ja,en,ko}.js        # 每件的 title/note/link 三语
```

`HANG` 草案（殿 id 以将来 `site.js` 为准）：

```js
export const HANG = {
  "cave-main": ["cma-shakyamuni-triad-2009-342-1"],
  upper:       ["cma-amitabha-triad-1974-35"],
  guanyin:     ["cma-white-robed-guanyin-1972-160"],
  nanan:       ["cma-white-robed-guanyin-1978-47-2"],
};
```

### 8.2 `tools/gallery.py` 要改一行

现在工具把输出写死为 `app/levels/t00/`，`HANG` 也只有 T00 的殿。T02 要加一个层级参数：

```
python3 tools/gallery.py <dir> --level t02
```

`HANG` 按 `LEVEL_HANG = { "t00": {...}, "t01": {...}, "t02": {...} }` 分表；`CROP` 可以共用一张，slug 不冲突即可。工具的其他逻辑（1280、WebP、`processed`、`works.js` 写出）不动。

### 8.3 卡片与鸣谢

- 卡片照 T00：图、中文说明、馆方来源行；T02 的四件都是 CC0，不需要「加工说明」，但如果缩图/转 WebP，仍建议写「缩小并转为 WebP」。
- T02 的鸣谢页（`credits.js`）新增一节：克利夫兰艺术博物馆 4 件（4 个条目），逐件链条目页；不出现馆标，不写「馆方认可」。
- **中文说明由我们写**，不转抄馆方英文；馆方来源行不译。

### 8.4 测试

- `tests/unit/i18n.test.mjs`：每件 `title`、`note`、`link` 三语齐全，缺一失败。
- `tests/unit/credits.test.mjs`：鸣谢页列出每一件。
- 新增 `tests/unit/gallery-t02.test.mjs`：`HANG` 的每个 slug 在 `WORKS` 里有记录；每个殿 id 在 `site.halls` 里存在；无 T00/T01 重复 slug。
- e2e：等 T02 有页面后，加一个 `t02-gallery` 场景，站在每面墙前按 E 开卡，检查图、来源行。

### 8.5 资产登记

`asset-register.csv` 已加 `WORK-` 行（状态 `candidate`），逐件写馆方条目地址、许可、商用、署名义务、核对日期。取图后再把 `file` 从 `(planned)` 改成实际路径，状态改 `shipped` 只在该件真正进构建之后。

## 10. 这份文件不做什么

- 本文件记著录与候选；**没有下载任何图**，也没有 `works.js`、三语卡片与页面接入。
