# T02 岩隐寺 · 调研包（待评审）

核对日期：2026-11-17。范围：取意福建泰宁甘露寺（甘露岩）的原创关卡 T02，章节「岩腹藏楼」，寺名暂用资料库名「岩隐寺」，候选「栖露岩寺」。
本包只做**资料调研与开工准备**：不改 `app/`、不下载图片；作为 T02 的调研包提交评审。

## 这份包和资料库的关系

- 资料库条目 `T02` 是本包的出发点：主题「先看见巨大的岩腹，再看懂小小的木楼」，路线「林间窄路 → 岩口 → 木楼下部 → 侧向栈道 → 上层小殿」，范围「一个主岩穴＋一组原创木楼＋一间室内」，时长 10–15 分钟。本包不推翻这些设定，只把它们逐条落到可核的来源、空间和验收上。
- 资料库的两个来源（福建日报/福建省文物局《泰宁甘露寺的前世今生》；鸟取环境大学纪要《甘露寺と福建省の古刹》）都已读；前者读到正文，后者下载 PDF 并抽取了文字层。
- 资料库里「一柱插地」「1961 年火灾」「不能整体称为宋代原构」三条，本包逐一核过，并把「一柱插地」的**实际受力范围**写清楚（见 `RESEARCH.md` §6、`ARCHITECTURE.md` §4）。

## 先给结论

1. **T02 的核心不是「又一座悬空寺」，而是「岩腹与木楼的尺度差」。** 甘露岩的洞口净高约 37 米、宽约 32 米、深约 27 米（洞身数据见 `SOURCES.md` S08，属【摘要】），而木构殿阁只有几米见方。玩家先被岩腹压住，再在楼下抬头看懂柱、梁、栈道怎样把一个小楼挂在岩壁上。
2. **「一柱插地」是历史描述，不是结构结论。** 康熙《泰宁县志》的原话是「一柱插地，不假片瓦」；但 2014 年鸟取环境大学的现场记录明确说：状元柱只承托基台的一根大引，柱头只在前侧有组物，基台整体看起来是由横材支承的。把它简化成「一根柱子撑起整座寺」会误导玩家，也会把宋构的地方做法讲错。
3. **现在看到的甘露寺不是宋代原构。** 1959 年张步骞等测绘的五座南宋木构（蜃阁、上殿、观音阁、南安阁、库房）在 1961 年 2 月 4 日（一说 2 月 3 日清晨）的一场火灾中全毁；1964 年 9 月按原式重建，1979 年重修，1982 年开放。T02 的建筑是**原创架空木楼**，取宋构的构造逻辑与地方做法，不冒充复原，也不把现状重建说成宋代遗构。
4. **「重源来过甘露寺」是寺传，不是定论。** 方志与旅游牌写 1180 年日本僧人重源为重建东大寺大佛殿来此考察；鸟取环境大学的报告指出：寺方拿不出文书，现重建建筑的大佛样要素也很稀薄，关口的分析更认为甘露庵三殿「与日本大佛样并不直接相连」。T02 只能把它作为「一种流传的说法」，不能写成史实，更不能做成「日本和尚偷师」的玩法。
5. **空间底图只能做到「提案级」。** OSM 在甘露岩寺只有一个 POI 节点（26.8722728, 117.0721788，WGS-84）和三条步道，没有任何建筑轮廓；SRTM 30 米格网只能给出山体与湖岸的粗剖面，分辨不了洞穴内部。白盒可以搭，精模与验收不能拿它替代实测。
6. **资料缺口明确：** 没有公开的逐间尺寸（只有间数、架椽数）、没有剖面标高、没有柱网米制数据、没有火灾前完整照片的开放授权、没有寺方或景区许可、没有现场声压与混响测量。本包把这些写成「待补」，不假装已有。

## 怎么读本包的标记

- **【已读原文】**：本包写作时实际打开了页面并读了正文。
- **【PDF】**：下载 PDF 并用文本层抽取；印刷页以原文标注的页码为准。
- **【摘要】**：只读到搜索引擎摘要、新闻转述或百科条目，没有打开原文。引用前要再核。
- **【API】**：结构化数据（OSM Overpass、Nominatim、opentopodata、Commons/CMA API），按字段读，不靠转述。
- **【照片】**：从 Commons 或其他公开照片上看到的现象，只作研究，不作测量。
- **【推算】**：由 OSM 节点、SRTM 高程或公开数字算出来的，可能有 5–10 米或数度的误差。
- **【设计提案】**：我们自己的取舍，不是甘露寺的事实。可以改，改了不算篡改历史。
- **【未核】**：资料互相矛盾或没有一手来源，开发时不得当作定论。

## 三条纪律

1. **不把参考照片当实机证据。** D04/D05/D06 必须来自 T02 自己的页面与白盒。
2. **不把传说写成史实。** 重源来访、状元还愿、抱柱求子、叶祖洽重修，都要么标「相传」「寺传」，要么只作氛围。
3. **不把「一柱插地」做成「一根柱子承重」的奇观。** 它是历史描述与地方做法，结构上更接近「前台由一根落地柱与横材共同托起，后部与两翼依岩架栈」。游戏要让玩家看懂这一点，而不是强化误解。
