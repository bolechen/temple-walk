# T02 语言与命名

核对日期：2026-11-17。T00 的规则照旧：**中文是记录文本**，日/英/韩由中文查表；新增文字四种语言齐全，字体重新裁切。

## 1. 语言范围

- 汉语（简）：记录文本；所有界面、对白、说明先写中文。
- 日语、英语、韩语：由 `app/locales/{ja,en,ko}.js` 按中文查表；T02 的关卡文字放 `app/levels/t02/locales/`。
- 测试与工具固定 `zh-CN`；`lang` 场景与 `mobile-audit --lang=ja|en|ko` 看另外三种。

## 2. 命名政策

### 2.1 寺名：两个候选，未定

| 候选 | 含义 | 优点 | 风险 |
|---|---|---|---|
| **岩隐寺** | 「藏在岩里的寺」 | 直接对应「岩腹藏楼」；两个字都常用，字体覆盖容易 | 「岩隐」偏直白；需做重名/商标检索（未做） |
| **栖露岩寺** | 「栖于露的岩寺」；「露」呼应甘露，「栖」呼应栖霞 | 有诗意；保留「岩寺」形态；与真实「甘露岩寺」有距离 | 四字较长；匾额/标题排版更难；「栖露」可能被读成地名 |

**不定的原因**：资料库把「岩隐寺」作为暂名、「栖露岩寺」作为候选；所有者尚未定。本包不替所有者选。

### 2.2 命名规则

- 若用虚构名：匾额、印章、标题都用虚构名；不出现「甘露寺」「甘露岩寺」四字。
- 年表、构造说明、来源行可以写「取意泰宁甘露寺」；但不能写「本寺始建于 1146 年」而不加「取意」。
- 真实地名（泰宁、大金湖、一线天）在游戏内**不出现**；用「湖」「岩口」「林间窄路」等通名。
- 洞名「甘露岩」不直接使用；可叫「露岩」「岩腹」。

### 2.3 地名对照（设计用）

| 真实 | 游戏内（提案） | 备注 |
|---|---|---|
| 泰宁 | 不出现 | 只作来源说明 |
| 大金湖 | 湖 / 山下湖 | 不写真实湖名 |
| 甘露岩 | 露岩 / 岩腹 | 不写「甘露」 |
| 一线天 | 不出现 | 可选支线不做 |
| 状元桥 | 不出现 | 不做 |
| 甘露寺码头 | 湖岸 / 码头 | 通名 |

## 4. 翻译陷阱

1. **「一柱插地」不是「one-pillar temple」。** 英文不要写「the temple is supported by a single pillar」；写「a single pillar is planted in the ground at the front platform」，并在说明里补「与横材、岩壁共同支承」。
2. **「不假片瓦」不是「no roof」。** 是「没有铺瓦」，不是「没有屋顶」；屋面是草灰泥。
3. **「悬空寺」是绰号。** 不要与山西浑源悬空寺（Hanging Temple）混；英文用「rock temple」为主，绰号加引号。
4. **「蜃阁」不是「Mirage Pavilion」。** 「蜃」是海市蜃楼，但殿名是专名；英文用 Shen Pavilion，首次出现加一句解释。
5. **「状元」不是「champion」。** 是科举殿试第一名；英文用 zhuangyuan + 解释。
6. **「甘露」不是唯一的寺名。** 中国有多座甘露寺（镇江、泰宁等）；英文必须写「Ganlu Temple, Taining」。
7. **「丹霞」是专名。** 英文用 Danxia，不要只写 red sandstone；地质说明可以补「red clastic rock」。
8. **「大佛样」是日本术语。** 英文用 Daibutsuyō；不要写「the Ganlu style」或「the origin of Daibutsuyō」。
9. **「插拱」不是「dougong」。** dougong 是官式斗栱；插拱是福建地方做法，英文用 inserted bracket arm。
10. **「穿斗」不是「through-beam」。** 英文用 chuandou frame（或 column-and-tie frame），首次出现加解释。
11. **「岩寺」不是「cave temple」。** cave temple 容易联想到印度/敦煌的石窟；这里用 rock temple / rock-shelter temple。
12. **「副阶」不是「secondary stairs」。** 是殿身四周的檐廊；英文用 surrounding veranda。
13. **「平座」不是「flat seat」。** 是楼阁外部的木构平台/栏杆；英文用 balcony deck。
14. **「开山僧」不是「mountain-opening monk」。** 是开山立寺的僧人；英文用 founding monk。
15. **「上殿」不是「大雄宝殿」。** 宋构上殿供西方三圣；今天的大雄宝殿供释迦。两个名字不能互换。
16. **「观音阁」与「千手观音殿」不是同一座。** 宋构只有观音阁；千手观音殿是后代加建。

## 5. 新增界面文字（中文草案）

> 这些是 T02 可能出现的句子；定稿后要补 ja/en/ko。占位符用 `{}`。

- 入岩：`从湖边走上来，洞口在树后面。`
- 提示：`点地面走过去。`
- 岩口：`洞口比想象的大。`
- 楼下：`抬头看，柱和梁在这里交接。`
- 数支点：`一根柱、几根短柱、几道横材，还有岩壁。`
- 栈道：`木板下面就是岩面。`
- 上层：`从这里回望，洞口是一块亮。`
- 岩行记：`岩行记`
- 听水：`站一会儿，水滴在石头上。`
- 认柱：`这根柱只托住一根大梁。`
- 看缝：`木头和岩石之间，塞着木楔。`
- 记一笔：`把这一处画下来。`
- 回望：`洞外是湖。`
- 结束（一记未记）：`今天只是走了一趟。`
- 结束（记了几处）：`你把看见的几处，记在了纸上。`
- 不记：`不记也可以。`

**不要写**：佛号、经文、许愿语、因果报应式劝诫；不要假装是寺方原话；不要写「一柱撑起整座寺」。

## 6. 字体

T02 新增的字（部分）：

> 岩、隐、栖、露、甘、丹、霞、穴、腹、栈、柱、插、拱、穿、斗、杉、草、灰、泥、蜃、阁、南、安、观、音、弥、陀、题、记、壁、画、状、元、还、愿、重、源、佛、样、悬、空、滴、苔、湿、雾、湖、船、码、头、阶、凿、楔、缝、残、彩

- 中文六套字体都要包含这些字；缺字会让 `pnpm run check` 失败。
- 日文用日文字形（如「観」「仏」）；韩文用韩文字体。
- 匾额/题记不翻译；若用虚构寺名，由项目自写，不描今人书法。
- 新增后运行：`python3 tools/fonts.py <dir with the TTFs>`。

---

## 7. 不翻译的东西

- 匾额文字（虚构寺名、殿名）。
- 题记原文（只做可辨认的几个字）。
- 馆藏来源行、作者名、版权行。
- 寺名/地名的罗马字（可在括号里给读音）。
