# T02 美术方向与候选机位

核对日期：2026-11-17。本文不是最终美术定稿，是把「甘露岩这块地长什么样」翻译成可执行的光、色、构图与验收口径。
通用原则仍以 [`../ART-SPEC.md`](../ART-SPEC.md) 为准；T02 只写与 T00/T01 不同的部分。

---

## 1. 一句话方向

**「岩腹藏楼，洞口一束光」**：先看见一个巨大的红岩洞穴，再在洞里看见一组小木楼；木楼不是站在地上，而是被岩壁含住、被一根落地柱与横材托起；唯一强光来自洞口，洞内暗而可读。

与 T00/T01 的差别：

| 维度 | T00 云径禅寺 | T01 宝通寺 | T02 甘露寺 |
|---|---|---|---|
| 主色 | 白墙、深木、灰瓦、竹绿 | 黄墙、琥珀瓦、赭红塔 | **丹霞红岩、老杉木灰黄、草灰泥灰褐** |
| 光 | 阴天雨后的柔光 | 秋雾/冬晴的城市光 | **洞口一束 + 洞内反弹光** |
| 远景 | 五峰、云海、竹林 | 城市屋顶线 | **湖面、崖壁、林** |
| 近景 | 竹、柳杉、石阶 | 黄墙、石狮、菜薹田 | **岩壁、柱脚、栈道、滴水** |
| 空间 | 开阔 | 垂直台地 | **内收的洞穴** |
| 情绪 | 出世、静 | 入世中的静 | **被岩腹压住的静；小与大的对照** |
| 季 | 夏昼（J01） | 冬晴/秋末 | **初夏雨后上午（提案）** |

- 因此下面的 G01 是**推演**：从条目 `T02` 的 `art` 字段（「借用统一写实、低饱和原则；岩色、构造与具体材料另行调查，不套用江南庭院」）与 S01/S02 的现场描述，反推一套「岩下柔光」的可执行条件。标【推算/设计提案】。
- 若所有者能提供 G01 原文，以原文为准；本节的色值与光比可以改。

### 1.5.1 推演的 G01 条件

| 项 | 条件 | 理由 |
|---|---|---|
| 时间 | 上午 8:00–10:00 | 洞口朝东，上午光进洞；下午洞口逆光太硬 |
| 天气 | 梅雨初歇、薄云 | 光柔、岩面湿、滴水清楚；符合泰宁 3–6 月雨季 |
| 主光 | 洞口天光，色温 4800–5200 K | 不是直射太阳；洞内没有硬阴影 |
| 补光 | 岩壁反弹的暖红 | 丹霞岩的二次反射；不是全局橙色滤镜 |
| 光比 | 洞口 : 洞内 ≈ 8:1 – 12:1 | 洞口不过曝，洞内梁柱仍可读 |
| 雾 | 只在洞口外一层薄雾 | 洞内不塞雾；雾用来拉开湖面与崖壁 |
| 湿 | 岩面湿、石阶湿；木构不滴水 | 洞顶滴水落在石上，不落在木上 |
| 色 | 低饱和，但红岩要有温度 | 「低饱和不等于灰片」 |

### 1.5.2 与 T01 B01 的区别

T01 的 B01 是「秋雾外院、暗朱木构、深绿与少量秋叶」；T02 的 G01 是「初夏雨后、红岩、灰黄木构、苔绿、洞口一束」。两者都低饱和，但 T02 **更暗、更内收、更湿**；不要把 T01 的雾天外院直接搬进洞里。

### 1.6 对照 `docs/ART-SPEC.md` 的八条

| 原则 | T02 怎么落 |
|---|---|
| 摄影感与可读性 | 洞内暗但梁柱、柱脚、通路可读；洞口不过曝；不用死黑遮错 |
| 材料分工 | 红岩、老杉木、草灰泥、白灰、苔、湖水各有粗糙度；湿面只在岩面与石阶，不全局加湿 |
| 光有来源 | 唯一主光是洞口天光；洞内是岩壁反弹；小殿一盏灯；不做无来源的全局橙 |
| 磨损有原因 | 岩面湿痕沿渗水线，苔在低处/背光处，木构裂纹在柱脚/梁头，石阶磨亮在中间 |
| 构图有层次 | 近景岩壁/柱，中景平台/木楼，远景洞口/湖；六个机位都按三层构图 |
| 地域准确优先 | 南宋福建穿斗 + 插拱 + 草灰泥；不套江南官式、不混日式石灯笼/枯山水 |
| 生成图是参考 | G01 是推演；白盒与现场照片优先；生成图不证明年代/材料/承重 |
| 基准画面与游戏内容分开 | 玩家、香炉、草图都可以在画面里；不为了「干净」删掉生活 |

**相机例外**：ART-SPEC 建议全画幅 35–50 mm；T02 的洞内用 52°（约 38 mm）是有意的广角，为了装下岩腹的尺度；洞外仍用 44°（约 45 mm）。眼高保持 1.6 m。

| 暗金 | `#9C8050` | 像设、供具；克制 |

**纪律**：

- 红岩不是一整片均匀的红：层理、湿痕、苔、水痕、凿痕要有。
- 木构不是红木：老杉木是灰黄，新杉木是浅黄；重建与老构要能区分。
- 洞内不是死黑：梁柱、通路、题记要可读；靠反弹光与 AO，不靠全局提亮。
- 洞口不是纯白：保留岩壁的轮廓与层次，不要过曝成一片。
- 不要用 T00 的白墙灰瓦、T01 的黄墙琉璃；T02 是红岩 + 灰黄木 + 草灰泥。

## 3. 基准季时

### 3.1 白盒阶段

中性日光，不做季节，不调色；洞内用均匀环境光 + 一盏方向光，先看清空间与接触关系。

### 3.2 第一版美术对照：G01 岩下柔光（推演）

- 初夏，梅雨初歇，上午 8:00–10:00。
- 洞口柔光，洞内反弹光；岩面湿、石阶湿；木构干。
- 湖面薄雾，崖壁清楚。
- 这是 T02 的**基准**，与 T00 的夏昼、T01 的秋雾/冬晴都不同。

### 3.3 变体

- **秋晴午后**：洞口逆光，岩壁暖，湖面蓝；适合「回望」机位。
- **冬雨**：岩面深、木构冷、苔少；适合「记录/重建」的冷静版本。
- **夜**：不做；景区不开放，光源不可信。

**最终由所有者看图定。** 白盒阶段一律中性日光。

## 4. 构图原则

1. **先岩后楼**：每个外部机位都要先读出洞穴的尺度，再读到木楼；木楼不能占满画面。
2. **洞口是框**：从洞内往外看，洞口是天然的画框；从洞外往里看，洞口是暗框，木楼在暗里。
3. **小与大**：木构的檐口、栏杆、柱径要与岩壁的层理、洞顶的高度同框；没有尺度参照就没有「岩腹藏楼」。
4. **接触点**：柱脚/短柱/横材/岩壁的接触要看得见；不要用雾或暗把接触藏掉。
5. **一束光**：洞内只有一个主光方向（洞口）；不要在洞内加第二个「神光」。
6. **不做奇观**：不把「一柱」做成发光的图腾；不做「悬浮」特效；建筑要落地、落岩。

## 5. 六个候选机位

坐标是相对岩口的本地坐标（+x 东/出洞，+z 南，米）；高程按 `SITE.md` 的提案；机位高度是**眼高**，不是绝对海拔。详细 JSON 见 `camera-manifest.json`。

### CAM-01 湖上远望（湖 → 岩）

- 位置：(+150, -60)，地面 275 m，眼高 1.65 m（船/码头）。
- 朝向：西南（yaw 248°），仰 8°。
- 画面：下三分之一是湖面与船影；中景是崖壁与「左钟右鼓」；洞口是一个暗的倒三角；木楼只在洞口里露出一点檐口与柱。
- 光：G01 的上午薄雾；湖面反光柔，崖壁暖。
- 要验证：洞穴的尺度是否压得住；木楼是否「小」；洞口是否可读。

### CAM-02 林间窄路（路 → 岩口）

- 位置：(+34, -10)，地面 284 m，眼高 1.60 m。
- 朝向：西南（yaw 254°），仰 10°。
- 画面：近景是湿石阶与杉木/阔叶；中景是岩壁夹峙；远景是洞口亮部。
- 光：林下散射光；洞口比林下亮 2–3 档。
- 要验证：窄路是否「仅容单骑」；洞口是否先藏后开；石阶是否可走。

### CAM-03 岩口（洞口 → 洞腹）

- 位置：(+12, 0)，地面 300 m，眼高 1.60 m。
- 朝向：正西（yaw 270°），平视。
- 画面：洞口框住洞腹；平台底、状元柱、短柱、横材在暗里；蜃阁的檐口从平台后露出；洞顶高不见顶。
- 光：洞口逆光；洞内靠反弹光；不要打平。
- 要验证：洞腹是否「外大内小」；平台是否悬空；柱/梁是否可读。

### CAM-04 木楼下部（柱 → 梁 → 岩）

- 位置：(+4, 0)，地面 300 m，眼高 1.60 m。
- 朝向：正西（yaw 270°），仰 28°。
- 画面：状元柱在前景；柱头组物、大引、短柱、横材、岩壁的接触依次向上；平台底在头顶。
- 光：洞口侧光扫过柱身；柱头有一点高光；岩壁暗部有细节。
- 要验证：玩家能否数出至少 4 类支点；是否看出「柱只承一根大引」；有没有「一根柱撑全部」的错觉。

### CAM-05 侧向栈道（栈道 → 两阁）

- 位置：(-2, +9)，地面 306.5 m，眼高 1.60 m。
- 朝向：西北（yaw 336°），仰 5°。
- 画面：近景是木栈道与栏杆；中景是南安阁的三重檐与观音阁的平座；远景是洞顶。
- 光：栈道在洞口侧光边缘；两阁的檐下暗，腰檐有一点反光。
- 要验证：栈道宽度是否够；栏杆是否挡视线；两阁的高低差是否读得出。

### CAM-06 上层小殿回望（殿 → 洞口 → 湖）

- 位置：(-6, 0)，地面 309 m，眼高 1.60 m。
- 朝向：正东（yaw 90°），俯 3°。
- 画面：前景是小殿的梁架/佛坛一角；中景是洞口亮部；远景是湖面与对岸；木构的剪影在亮部前。
- 光：洞口是唯一强光；室内暗；像设只做剪影。
- 要验证：洞口是否成为「明亮的远景」（资料库 moments）；木构剪影是否清楚；湖面是否可读。

### 5.1 机位纪律

- 六个机位都要能站人、能走上去；不能悬空/穿岩。
- 每个机位拍 16:9、4:3、9:16 三种画幅（T00 的 `shots.js` 支持）。
- 每个机位至少拍「G01 基准 + 一个备选季时」。
- 机位定稿后写进 `camera-manifest.json`，由 `tools/cameras.mjs` 生成清单。

## 6. 验收口径（看图时问什么）

### 6.1 每张图

- [ ] 主体（岩腹/木楼/柱）是否在三分线或中心，是否被切？
- [ ] 近景/中景/远景是否至少有三层？
- [ ] 阴影里是否看得清梁柱、柱脚、通路？
- [ ] 红岩是否有层理、湿痕、苔，而不是一片平涂？
- [ ] 木构是否老杉木的灰黄，而不是红木/新木？
- [ ] 洞口是否过曝成一片白？洞内是否死黑？
- [ ] 柱、短柱、横材、岩壁的接触是否看得见？
- [ ] 有没有「一根柱撑全部」的视觉暗示？
- [ ] 是否有不属于福建宋构的器物（日式石灯笼、枯山水、藏式经幡、琉璃瓦）？

### 6.2 整组

- [ ] 六张是否像同一座寺、同一季节、同一天？
- [ ] 是否一眼看出「岩腹里的寺」，而不是「山中的寺」或「城里的寺」？
- [ ] 木楼是否明显小于岩腹，但又不是玩具？
- [ ] 洞口的亮部是否有节奏（远—近—内—回望）？
- [ ] 与 T00/T01 的六张并排，是否明显是三座不同的寺？

### 6.3 不能做的事

- 不用生成图冒充现场照片；生成图只定氛围。
- 不把 T00 的宋式官式大殿直接搬进洞里。
- 不把 T01 的黄墙/琉璃瓦刷成红岩。
- 不把「一柱插地」做成发光的图腾或悬浮特效。
- 不把洞穴做成「钟乳石景区」的彩色打光。
- 不做「满洞红灯笼/祈福带」的网红寺。
- 不把 1964 年后的重建说成宋代原构。

## 7. 目标图怎么来

T00 的经验：目标图分两类——**真实照片**（定格局与配色）与**生成参考**（定氛围，不证明构造）。
T02 建议：

1. **真实照片**：Commons 的 5 张（S13），只作研究；注意 CC BY-SA/CC BY。
2. **目标图**：在白盒截图的基础上做「光色草图」（不改变几何），标注「参考，不是实机」。
3. **实机验收图**：必须来自 T02 的页面，标 commit 与 GPU job。
