# 宣发做法调研（#152，2026-11-18）

按主创转达的所有者新规则：先看业界同类独立游戏实际有效的做法，再动手；依据写在这里，PR 里引用。**来源多是行业博客与经验帖，不是对照实验，数字只作参考；没查到的地方明说「自拟」。**

## 一、查到了什么

**Steam 商店页**（[Phiture](https://phiture.com/asostack/game-steam-page-optimization/)、[Steam Page Analyzer 胶囊图指南](https://www.steampageanalyzer.com/blog/steam-capsule-design-guide)、[games.gg](https://games.gg/news/steam-capsule-art-guide/)、[Game Developer](https://gamedeveloper.com/business/so-you-want-to-have-a-kick-ass-steam-page)，均为二手汇总）：

- 访客在第一屏（胶囊图、预告片缩略图、前几张截图、短描述、标签）就决定去留；前三张截图权重最大，建议 8–10 张。
- 胶囊图要在极小尺寸（约 120×45）下还能读，字尽量 0–3 个，且与截图、头图视觉统一。
- 预告片 4–5 秒内就要出现游戏画面，开头不放标志、标题卡或淡入；一条、一分钟以内。
- 截图必须是真实游戏画面，不能是概念图或预渲染图（二手说法，**以 Steamworks 文档为准**，发布时由所有者核对）。
- 短描述头十个字内说清类型和钩子。

**X**（[80.lv 对 Indie Game Joe 的访谈](https://80.lv/articles/the-secrets-to-viral-success-in-game-marketing-according-to-indie-game-joe)、[howtomarketagame.com](https://howtomarketagame.com/?p=1731)、[Tiny Glade 案例](https://opgamemarketing.substack.com/p/tiny-glade-an-indie-game-by-2-devs)）：

- 有效的是短的实机片段或 GIF，加一句直白的话；第一帧就要让人看懂「这是什么」。多数人静音看，屏幕上要有字。
- 对心愿单的转化并不高：有开发者说一条 891 赞的帖只带来约 25 个心愿单，也有分析说每千次浏览约 7 个。X 更适合做曝光，转化靠 Reddit、TikTok 等。
- 持续、小而稳定地发，好过偶尔一次精心制作（建议每周 3–5 条，对我们不现实，见下）。
- 「治愈」「cozy」这类泛标签在部分社区反而招嫌，有具体身份的描述更好。

**小红书**（[36氪](https://eu.36kr.com/zh/p/3905036594628224)、[界面·游戏风向标](https://cj.sina.com.cn/articles/view/1750070171/684ff39b02001gsy2)、[澎湃](https://m.thepaper.cn/detail/33782907)）：

- 平台在拉独立游戏入驻，靠「种草」逻辑；有独立制作人说自己在小红书、小黑盒、B站三处宣发后，玩家大部分来自小红书。
- 图文为主，真实体验分享比广告腔有效；宜提前持续产出，而不是临上线集中投放。
- **封面、标题、笔记结构的具体做法没有查到可靠来源**。本包里这部分（封面用项目字体的大字、标题 ≤20 字、6–9 张图）是**自拟**，由所有者发布后看数据再改。

## 二、对本包的改动

1. **视频开头不放标题卡**：分镜第一段本来就是游戏里的开场飞越（实机画面，第一帧即山寺全貌），序章标题放在第二段。保持。
2. **静音也成立**：字幕 4 句、用项目字体；音乐和钟声是加分，不是依赖。保持。
3. **加一条 10–15 秒的短版与 GIF**（新增）：X 上短片段比 45 秒更适合，由同一批帧用 ffmpeg 截出，不多花 GPU。
4. **Steam 草稿**：5 张截图只用真实画面，前三张按「山门前序章、首院、凌霄阁回望」排；短描述头部先说「网页里行走的山寺」类型与钩子；胶囊图尽量用实机图裁出，字只放游戏名。16:9 视频可兼作预告片候选（≤60 秒，已满足）。
5. **文案不用泛「治愈」标签**：小红书标签保留「治愈系游戏」一个，其余用具体的（山寺、中式建筑、竹径、网页游戏）；X 文案以具体画面开头。
6. **预期写明**：X 的心愿单转化低，这包的主要用处是让所有者有一套可发的实机素材；是否值得持续做，发出第一条后看数据再定（已在 issue 关闭条件里）。

## 三、向主创的两处意见

- issue 要求「X 一条带视频的帖子和一组图」，调研支持，只是建议帖子里的视频用 10–15 秒短版放最前，长版放跟帖；见上第 3 条。
- 「每周 3–5 条」的节奏不属于这个起步包（只备料不发布），我不排期，留给所有者。
