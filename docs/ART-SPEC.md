## 定调：克制的写实，有来处的光

原文：「深木与灰瓦承载时间，石面记录天气。让建筑、光线与行走共同讲述空间。」

这和三位评审给我们定的「水墨、雾、一盏灯」是同一个方向，两者不冲突：评审给的是明暗结构（白墙是纸、屋顶是一块深色、
一处暖光），资料库给的是材料和光的纪律。以资料库为准，评审的明暗规划作为实现手段。

## 八条共通原则，和我们的现状

| 原则 | 要求 | 现状 |
|---|---|---|
| 摄影感与可读性 | 低饱和不等于灰片；阴影里仍看得清梁柱、门洞、通路 | 胶片曲线后白墙约 77%，檐下偏暗，斗拱在暮色里是剪影。**檐下还需要一点补光** |
| 材料分工 | 木、瓦、石、漆、金属各有粗糙度和颜色变化；**不要把全部地面做成镜面** | 木、石、灰泥、树皮用了扫描贴图。大院地面积水是按噪声分布的，不是整片镜面，但夏昼偏湿，可再收 |
| 光有来源 | 先定主光、门窗反射、局部灯火；光束要有可解释的散射条件 | 太阳、天光、灯火各有来源；还没有光束 |
| 磨损有原因 | 雨水路径、脚步、手触、接缝决定变化；不要所有柱脚一样、所有石缝一样长苔 | 墙有檐下雨痕和墙脚返潮。**石缝的苔现在是均匀的**，评审也指出过，要改成只有三成的缝有 |
| 构图有层次 | 近景门框或树干，中景院落，远景主殿或山林；塔楼剪影不要和近屋脊相切 | 第三视角已改成低机位偏一侧；拍照模式还没有构图预设 |
| 地域准确优先 | 中国关卡核对唐宋构造和器物 | 已按宋式评审改了斗拱、槛墙直棂窗、七朱八白、重檐比例 |
| 生成图是参考 | 生成图只定氛围，不能证明年代和构造 | 我们的格局来自卫星图和实拍照片，见 `JINGSHAN.md` |
| 基准画面与游戏内容分开 | 无人无字是部分概念图的拍摄预设，不禁止叙事人物 | 小沙弥、朱印帐、画框剧情都属于游戏内容 |

## 场景预设

- **J01 径山 · 阴天雨后**：柔和天空光、灰绿远山、深木白墙、湿石局部反射。这是 T00 的基准画面，对应我们的「夏 · 昼」。
- **J02 径山 · 秋季**：和 J01 分版本，只有植物转色，建筑不变。对应「秋」。
- 冬季只在对话文字里出现过，没有参考图。我们的冬景是自己发挥的。
- 原文要求：季节只改变对应的植物、地表和气候，不改变建筑几何。我们符合。

## 相机

原文提案：人眼高度 1.55–1.70 米，全画幅等效 35–50 mm 起步，16:9 横幅，9:16 竖幅另设相机而不是裁切。
我们的主角是小沙弥，第一视角眼高 1.3 米，是有意的；第三视角镜头约 44°（横）和 58°（竖），在 35 mm 附近。
竖幅和横幅现在共用一套相机参数，只换了视角大小。
