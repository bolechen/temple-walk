# T03 美术方向与候选机位

核对日期：2026-11-17。本文不是最终美术定稿，是把「沙溪这块地长什么样」翻译成可执行的光、色、构图与验收口径。
通用原则仍以 [`../../ART-SPEC.md`](../../ART-SPEC.md) 为准；T03 只写与 T00/T01 不同的部分。

---

## 1. 一句话方向

**「红砂石的广场，寺门与戏台对望；秋天午后的柔光里，公共生活自己发生。」**

不是「古镇 + 红灯笼 + 民俗表演」，而是**一个仍然被使用的公共空间**：寺院的门槛、戏台的木地板、铺面的门板、背篓、扫帚、孩子的脚步声。

与 T01 的差别：

| 维度 | T01 宝通寺 | T03 兴教寺 |
|---|---|---|
| 主色 | 黄墙、琥珀瓦、赭红塔 | **红砂石**、土黄/白墙、深木、小青瓦、褪色织物 |
| 空间 | 七重台地、垂直 | **一个广场**、水平 |
| 光 | 秋雾/冬晴/冷暗内殿 | **S01 秋季柔光**（午后偏晚） |
| 远景 | 城市屋顶线 | 鳌峰山、农田、巷道、戏台飞檐 |
| 近景 | 石狮、银杏、菜薹 | 红砂石、门板、背篓、槐树 |
| 情绪 | 入世中的静 | **日常中的公共**；不悲不喜 |
| 人物 | 游客/僧人/猫 | 摊主、店主、居民、学徒、游客 |

**纪律**（照 ART-SPEC）：

- 暖色必须来自可信的光或材料，不做全局橙色滤镜。
- 低饱和不等于灰片；门洞、檐下、天井要看得清木构与通路。
- 红砂石不是一整片均匀的红：湿/干、旧/新、磨亮/粗糙、修补/原石要有区别。
- 土黄墙与白墙要分开：寺门/寨门偏土黄，民居/照壁偏白；不要把整座镇刷成一种黄。
- 小青瓦不是纯黑：有灰、有苔、有雨痕。
- 褪色织物只做点缀，不做「民族风」大面积拼贴。

## 3. 基准季时：S01 秋季柔光

### 3.1 定义

- **季节**：秋季（10–11 月），槐叶开始黄，晒秋的玉米/辣椒在檐下。
- **时间**：午后偏晚，约 **16:00–17:30**；太阳低，方向偏西/西南。
- **光**：天空漫射为主，太阳柔和不硬；低对比、暖中性；阴影长但不死黑；空气有薄霾。
- **不是**：金色时刻的橙红滤镜；不是阴雨；不是正午顶光。
- **构图**：寺门/戏台在东西两端；红砂石从前景延伸到中景；槐树冠在顶部；远山/农田在巷口。
- **为什么**：S01 秋季柔光能同时照亮红砂石、土黄墙和木构，不把画面压成灰；低角度光把寺门与戏台的影子拉长，广场的「空」与「被使用」都能看见。[atlas 条目；设计提案]

### 3.2 备选

| 预设 | 条件 | 用途 | 风险 |
|---|---|---|---|
| **S01 秋季柔光** | 秋、午后偏晚、柔光 | **基准**；六机位 | 容易变成「金色古镇」；要靠红砂石/土黄/深木压住 |
| **S02 冬季晴冷** | 冬、上午、低角度冷光 | 周五集市/春节备选 | 色彩灰；需要织物/香火提色 |
| **S03 雨后** | 秋/夏、雨后、湿石 | 红砂石湿态、木台发暗 | 与 T00 的雨后重复；只做变体 |
| **S04 节庆余韵** | 二月八前后、晨/午后 | 太子会余韵 | 需要社区同意；不做游行 |

**最终由所有者看图定。** 白盒阶段一律中性日光；S01 与备选是两条并列的对照线，不互相覆盖。

## 4. 六个候选机位

坐标是相对**四方街几何中心**的本地坐标（+x 东，+z 南，米）；高程按 SRTM（±5–10 m）；机位高度是**眼高**，不是相机绝对高。
详细 JSON 见 `camera-manifest.json`。yaw 0 = 北（−z），顺时针为正（东 = 90°，南 = 180°，西 = 270°）；pitch 正 = 仰。

### CAM-01 东巷（先声后形）

- 位置：东寨门以东的巷内，**(+72, −5.5)**，地面约 2099 m，眼高 1.65 m。
- 朝向：向西，yaw **270°**，pitch **+2°**。
- 画面：近景是巷道的石墙/门洞；中景是东寨门、红砂石路面；远景是戏台的飞檐/屋脊从门后露出；寺院屋顶在更远处。
- 光：S01 的柔光从西侧来，巷内偏暗，门洞外亮。
- 要验证：是否「先听到、再看到」；东寨门是否压得住入口；戏台飞檐是否露出而不与门脊相切。

### CAM-02 广场南端（寺门与戏台同框）

- 位置：四方街南端，**(0, +29)**，地面约 2105 m，眼高 1.65 m。
- 朝向：向北，yaw **0°**，pitch **+2°**。
- 画面：西侧寺门、东侧戏台、两棵槐树、红砂石广场、北巷；两侧铺面/马店在边缘。
- 光：S01 的低角度光从西侧来，寺门半明半暗，戏台正面受光。
- 要验证：寺门与戏台是否同时入画；两棵树是否挡住主体；广场是否「一眼读完」。

### CAM-03 寺门内（一帧）

- 位置：门楼内侧，**(−16, −9)**，地面约 2106 m，眼高 1.60 m。
- 朝向：向东偏南，yaw **118°**，pitch **+2°**。
- 画面：门洞的框（近景）；框中是红砂石广场与戏台（中景）；戏台的三层檐/魁星阁在上方。
- 光：门内暗、门外亮；门洞边缘有一圈亮边；不要过曝。
- 要验证：门洞是否真的框住戏台；框得正的站位在哪里；戏台是否被门框切断。

### CAM-04 戏台侧边（三层关系）

- 位置：戏台东南侧，**(+20, +14)**，地面约 2105 m，眼高 1.65 m。
- 朝向：向西偏北，yaw **305°**，pitch **+6°**。
- 画面：近景是戏台一层铺面/背面室外楼梯；中景是二层台口/三层魁星阁；远景是对面的寺门与广场。
- 光：S01 的光从西侧来，戏台侧面半明半暗；木构的深色要可读。
- 要验证：三层关系是否读得出；14 个飞角是否成立；楼梯是否像「后来加的」而不是原构。

### CAM-05 寺院一进（天井）

- 位置：第一进天井，**(−22, −11)**，地面约 2107 m，眼高 1.60 m。
- 朝向：向西，yaw **270°**，pitch **+3°**。
- 画面：近景是红砂石天井/排水沟；中景是观音楼的两层重檐悬山；两侧厢房的土坯墙/木窗；天井上方的天空。
- 光：天井比广场暗；檐下要有细节；不要死黑。
- 要验证：观音楼是否读得出「重檐悬山」；天井是否太窄/太暗；门外的广场声是否还能听见。

### CAM-06 广场回望（换场）

- 位置：广场中心偏北，**(0, 0)**，地面约 2105 m，眼高 1.65 m。
- 朝向：向东偏南，yaw **110°**，pitch **+2°**。
- 画面：戏台在晚光里，广场的红砂石有长影；收摊的箱子/扫帚/灯；巷口有人在走；不拍正脸。
- 光：S01 的最后一刻；戏台正面暖，广场阴影冷。
- 要验证：返回时广场是否「换了一场生活」；收摊/灯/人是否自然；没有「表演」感。

### 4.1 机位纪律

- 六个机位都要能站人、能走上去；不能是悬空/穿墙。
- 每个机位拍 16:9、4:3、9:16 三种画幅（T00 的 `shots.js` 支持）。
- 每个机位至少拍「S01 秋季柔光 + 一个备选」。
- 机位定稿后写进 `camera-manifest.json`，由 `tools/cameras.mjs` 生成清单。
- **不拍可辨识人脸**；群众只做剪影/背影/远景。

## 5. 「寺前有戏」的构图

| 次 | 机位 | 构图手段 | 失败的样子 |
|---|---|---|---|
| 1 先声 | CAM-01 | 巷子窄、门洞亮，戏台飞檐只露一角；声音先到 | 一上来就是广场全景；戏台与门脊相切 |
| 2 一帧 | CAM-03 | 门洞做框，戏台在框中；红砂石从门内延伸到台前 | 门洞太大/太小；戏台被切；框得正的位置不明显 |
| 3 三层 | CAM-04 | 侧面看下铺/中台/上阁；楼梯在背面 | 戏台做成空舞台；三层压成两层 |
| 4 换场 | CAM-06 | 同一地点、不同时间；收摊/灯/人 | 用一段表演代替生活；人群摆拍 |

**注意**：这是设计，不是现场证据。现有资料只支持「寺与戏台相对」，没有逐点视线照片。

## 6. 验收口径（看图时问什么）

### 6.1 每张图

- [ ] 主体（寺门/戏台/观音楼）是否在三分线或中心，是否被切？
- [ ] 近景/中景/远景是否至少有三层？
- [ ] 阴影里是否看得清木构、门洞、通路？
- [ ] 红砂石是否有湿/干、旧/新、磨亮/粗糙的区别？
- [ ] 土黄墙与白墙是否分开？小青瓦是否有灰/苔/雨痕？
- [ ] 寺门与戏台是否无意相切？戏台的飞檐是否被裁？
- [ ] 是否有不属于沙溪/明代的器物（日式石灯笼、藏式经幡、红灯笼阵）？
- [ ] 群众是否只做剪影/背影/远景？有没有可辨识人脸？
- [ ] 有没有「表演感」/「民俗村」感？

### 6.2 整组

- [ ] 六张是否像同一个广场、同一季节、同一天？
- [ ] 是否一眼看出「寺院与市场共用广场」，而不是「 generic 西南古镇」？
- [ ] 寺门—戏台的对望是否成立？
- [ ] 红砂石、土黄/白墙、深木、小青瓦、褪色织物是否形成可记忆的色组？
- [ ] 与 T00/T01 的六张并排，是否明显是另一座寺/另一个地方？

### 6.3 不能做的事

- 不用生成图冒充现场照片；生成图只定氛围。
- 不把 T00 的宋式大殿/白墙直接套到 T03。
- 不把 T01 的黄墙琉璃瓦搬来。
- 不把戏台做成空舞台/表演秀场。
- 不做「红灯笼 + 油纸伞 + 民族服装旅拍」的古镇布景。
- 不做「小丽江」「艳遇之都」「风花雪月」的文案/视觉。
- 不把阿吒力做成「巫术/密咒/黑 magic」。
- 不把太子会做成「求子/转运」。
- 不复制兴教寺壁画；游戏里的壁画是原创。

## 7. 目标图怎么来

T00/T01 的经验：目标图分两类——**真实照片**（定格局与配色）与**生成参考**（定氛围，不证明构造）。
T03 建议：

1. **真实照片**：从 Commons/公开报道选 6–10 张（CAM-01/02/03/04/05/06 的近似视角），只作研究；不下载、不进 `dist/`。
2. **目标图**：在白盒截图的基础上做「光色草图」（不改变几何），或在现场照片上做调色参考；标注「参考，不是实机」。
3. **实机验收图**：必须来自 T03 的页面，标 commit 与 GPU job。

## 8. 与 T00/T01 美术线的衔接

T00 的美术分五阶段（`../t00/art-goal.md`）：便宜的电影感 → 间接光 → 体积光 → 植被 → 材质细节。
T03 不必重走一遍；直接继承已完成的部分，只补：

- 红砂石铺地的磨损/湿态/修补（新材质）。
- 土坯墙的收分/草筋/返潮（新材质）。
- 小青瓦的弧面/搭接/苔（新材质）。
- 戏台三层木构/飞角/木雕（新几何）。
- 广场公共生活的小物件（摊位/背篓/扫帚/灯）（新）。
- 窄巷—广场—门洞—天井的声场（新）。
