# T03 语言与命名

核对日期：2026-11-17。T00/T01 的规则照旧：**中文是记录文本**，日/英/韩由中文查表；新增文字四种语言齐全，字体重新裁切。
本文只写 T03 新增的术语、命名与翻译陷阱。

---

## 1. 语言范围

- 汉语（简）：记录文本；所有界面、对白、说明先写中文。
- 日语、英语、韩语：由 `app/locales/{ja,en,ko}.js` 按中文查表；T03 的关卡文字放 `app/levels/t03/locales/`。
- 测试与工具固定 `zh-CN`；`lang` 场景与 `mobile-audit --lang=ja|en|ko` 看另外三种。
- 每个分析事件带 `lang`（`withLang`）。

## 2. 命名政策

### 2.1 寺名

- 现状：T00 用虚构寺名「云径禅寺」；T01 暂名「栖岚寺」；T03 资料库暂名「**照尘寺**」，备选「**溪照寺**」。
- **未定**：T03 是否继续虚构，还是取得授权用真名「兴教寺」。
- 若虚构：
  - 匾额、印章、标题都用「照尘寺」；不出现「兴教寺」三字。
  - 年表、殿名可以取意，但不能写「兴教寺始建于……」，要写「本关取意云南剑川沙溪兴教寺」。
- 若用真名：
  - 需要寺方/文物管理方许可；匾额书法不能描当代书法家原迹；年表与殿名要逐条核。
  - 游戏内要注明「场景为原创演绎，非实测复原」。

### 2.2 地名

| 中文 | 处理 | 备注 |
|---|---|---|
| 沙溪 | 若用真名，保留；虚构版可改「溪沙」「沙溪口」 | 沙溪是真实地名 |
| 寺登街 | 若用真名，保留；虚构版可改「寺前街」 | 「登」是白语「地方」，不是「爬」 |
| 四方街 | 可保留为设计概念；虚构版可改「四方场」 | 不是「四条街」 |
| 剑川 | 若用真名，保留；虚构版不出现 | 剑川是真实县名 |
| 鳌峰山、黑潓江、玉津桥、东寨门 | 若用真名保留；虚构版可换名 | 真实地名 |
| 兴教寺 | 若用真名，需授权；虚构版不出现 | 与西安兴教寺同名，必须限定「云南剑川沙溪」 |

**翻译陷阱**：

- **兴教寺**：全国有多座兴教寺，最著名的是西安兴教寺（玄奘塔院）。T03 的兴教寺必须写「云南剑川沙溪兴教寺」（Xingjiao Temple, Shaxi, Yunnan），否则读者会以为是西安那座。**不要在同一段里混用两座寺。**
- **阿吒力/白密/滇密**：地方资料说「阿吒力密宗」「白密」；侯冲等学者认为「滇密/白密」概念不能成立，阿吒力教是明代佛教三分后的「教」/瑜伽教。英文不要写死「Bai Tantrism」；用「Azhali (a local Bai Buddhist tradition; the label 'Bai esoteric Buddhism' is used locally but debated in scholarship)」。
- **寺登街**：不是「Temple Climbing Street」；「登」是白语「地方」。英文用 Sideng Street，首次出现加一句「Bai for 'the place of the temple'」。
- **四方街**：不是「Four Square Street」；它是广场，不是四条街。用 Sifang Square 或 Square of the Four Directions。
- **戏台**：不是 generic「stage」；这座是「shop + opera stage + Kuixing pavilion」三合一。英文首次出现写「three-storey opera stage (shops below, stage in the middle, Kuixing Pavilion above)」。
- **太子会**：不是「Prince Festival」的皇家叙事；太子是释迦为太子时的身份。英文加一句「the Buddha as a prince」。
- **白族**：Bai，不是 White。韩文 바이족。
- **本主**：benzhu，不是 ancestor；解释为 local patron deity。
- **土官**：native official / hereditary local official，不是「local civil servant」。
- **马店**：horse inn / caravanserai，不是 hotel。
- **马锅头**：caravan leader，不是 cook（虽然字面有「锅」）。
- **红砂石**：red sandstone，不是 red sand。
- **魁星阁**：Kuixing Pavilion；Kuixing 是文运之神，不是「Star Pavilion」。
- **照尘寺**：虚构名；不要音译后写成「Zhaochen Temple, a real temple」。首次出现写「Zhaochen Temple (fictional)」。
- **兴教寺 vs 照尘寺**：如果游戏用虚构名，匾额、标题、年表都不能出现「兴教寺」；只在「取意」说明里出现。

- 结束：`广场还在用，不必看完。`

## 5. 字体

T03 新增的字（部分）：

> 照、尘、溪、寺、登、街、四、方、戏、台、魁、星、阁、阿、吒、力、白、族、密、茶、马、古、道、帮、店、锅、头、本、主、土、官、太、子、会、游、门、洞、经、乐、霸、王、鞭、剧、乡、坊、壁、合、天、井、红、砂、石、鳌、峰、黑、潓、江、玉、津、桥、寨、欧、阳、院、剑、川、沙、兴、教、槐、背、篓、摊、扫、帚、卷、帘、租、旅、居、遗、产

- 中文六套字体都要包含这些字；缺字会让 `pnpm run check` 失败。
- 日文用日文字形（如「宝」的日文写法）；韩文用韩文字体。
- 匾额/石刻不翻译；若用真名，石刻文字用繁体/异体，逐字核。
- 新增后运行：`python3 tools/fonts.py <dir with the TTFs>`。

## 6. 不翻译的东西

- 匾额文字（照尘寺/兴教寺等）。
- 壁画题记原文（若出现；本包建议游戏里用原创题记，不照抄）。
- 碑文、诗、楹联原文。
- 博物馆来源行、作者名、版权行。
- 寺名/地名的罗马字（可在括号里给读音）。
- 白语词（本主、古宗、寺登）第一次出现可保留白语/汉字，加解释。
