## 3. 只能当参考、不能进游戏的素材

### 3.1 Wikimedia Commons 照片

- 沙溪/兴教寺/四方街/古戏台有 Commons 照片；本包**没有下载任何图片**，也没有逐张核许可。[S33]
- 常见许可为 CC BY-SA 3.0/4.0：商用可以，但必须署名 + 相同方式共享；闭源商业游戏有风险。
- **建议**：全部只作研究与配色/构图参考，不进 `dist/`。若所有者接受 CC BY-SA，再逐张选 6–10 张做「书册里的旧照/现场照」，并在鸣谢页列出作者、许可、链接。

### 3.2 旅游攻略/自媒体照片

- 马蜂窝、携程、去哪儿、今日头条、微信公众号的现场照片：版权不清，**不进游戏**。
- 只能用来核对空间关系/现状，不能当贴图。

### 3.3 壁画照片/拓片

- 兴教寺壁画是国保文物；没有开放授权的高清图/拓片。
- **不进游戏**；游戏里的壁画是原创。

### 3.4 真实戏曲/洞经录音

- 表演者权利、社区同意、录音许可都不清楚。
- **不进游戏**；音乐全部合成/原创。

## 4. 馆藏开放素材（T03 画廊候选）

T00/T01 已证明 ColBase / Met Open Access / Cleveland Open Access 三条管线可用。T03 选 6 件**新的** CC0/PD 明代佛画（不与 T00/T01 重复）：

| 来源 | 件数 | 主题 |
|---|---:|---|
| 大都会艺术博物馆 Open Access | 2 | 观音（九莲观音、白衣观音） |
| 克利夫兰艺术博物馆 Open Access | 4 | 十地菩萨、天龙八部、阿弥陀三尊、广目天王 |

**原则**：

- 只用明确 PD/CC0 的图；保留馆方来源行；不使用馆标；不写成馆方背书。
- 不冒充寺藏；卡片写「同一时期、同一题材的公开馆藏图像，与兴教寺壁画无直接关系」。
- 不做西藏密教本尊；T03 是白族阿吒力/汉传佛教语境，不是藏密道场。
- 不用日本密教曼荼罗来「补」阿吒力；T01 已经用过两界曼荼罗，T03 不再重复。

## 5. 授权与署名

### 5.1 必须保留的署名

- Poly Haven：CC0，不强制署名，但 T00 已在鸣谢页列；T03 保持。
- 字体：SIL OFL；`shared/fonts/OFL.txt`；保留版权行与保留字体名。
- three.js / meshopt / Basis / lil-gui / stats：MIT/Apache；`THIRD-PARTY-NOTICES.txt`。
- Met/Cleveland：PD/CC0，保留来源行。
- OSM：若用其数据做地形/布局，鸣谢「© OpenStreetMap contributors, ODbL」。
- Commons（若采用）：作者 + 许可 + 链接 + 是否修改。

### 5.2 不能用

- 兴教寺壁画的照片/扫描/拓片。
- 真实洞经/白剧/霸王鞭的录音/录像。
- 可辨识的村民/游客面部。
- 当代书法家的匾联原迹。
- 旅游攻略/自媒体的现场照片。
- AI 生成的「兴教寺实景」冒充现场照片。
- 「小丽江」「艳遇之都」式的宣传语。

### 5.3 需要所有者决定

1. 是否接受 CC BY-SA 的「相同方式共享」义务，用 Commons 照片进游戏。
2. T03 用虚构寺名「照尘寺」，还是取得授权用真名「兴教寺」。
3. 是否做一次合规的现场采集（预算、许可、社区同意、时间）。
4. 是否委托白族画师/设计师做原创壁画，还是先用程序化/剪影。
5. 是否使用真实戏曲的**短句**（需表演者/社区授权），还是完全原创。
6. 是否把「周五集市」做成可选支线（镇外，超出本关范围）。

### 5.4 交付命名（照资料库）

每关交付：空间概念图、同白盒四视图、三处特写、材质板、照明预设、资产清单、来源授权表、运行截图。
命名示例：

- `T03_ENV_Square_S01_v001`
- `T03_LGT_Courtyard_S01_v001`
- `T03_CAM_GateStage_16x9_v001`
- `T03_SRC_Architecture_001`

每个版本记录：关卡 ID、场景、季节天气、来源图 ID、相机、太阳方位、材质版本、作者、日期、权利状态、变更说明。

## 6. 资产登记表怎么读

`asset-register.csv` 的 `status` 列：

- `reuse`：直接复用 T00/T01，已随项目分发。
- `planned`：T03 新做，尚未存在。
- `reference`：只作研究/参考，不进 `dist/`。
- `candidate`：候选，许可/内容未定。
- `blocked`：权利不清或没有来源，不用。

`commercial_use` 列只写「yes / conditional / no / unknown」，不写推断。
