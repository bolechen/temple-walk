## 2. 史实、传说与设计的分层

写进游戏时，每条都要能回答「这是史实、地方志记载、题记、还是民间相传」。

### 2.1 建寺：高兴与十家土官

- 地方资料：兴教寺始建于明永乐十三年（1415），由鹤庆知府高兴发动剑川十家土官兴建；据《故世守鹤庆知府高候行状墓碑》。[S14，摘要]
- **判断**：建寺年代与兴建者在地方政府页面与地方志转述中一致；但「十家土官」的具体名单、出资、分工没有一手材料。
- **可用方式**：一块简短的说明牌；不做「十家土官」的人物群像。

### 2.2 壁画：杨庆与张保

- 题记：「大明永乐十五年岁次丁酉（1417）夏六月 信士杨庆敬绘」「沙退乡甸头村画匠张保」。[S17，摘要]
- **判断**：题记是壁画最重要的原始信息；但本包只读到二手转录，没有原壁/原石录文。
- **可用方式**：游戏里的原创壁画可以有一行**虚构的**题记（不要照抄「杨庆/张保」），或者完全不做题记；若要写真实题记，必须回原壁核对。

### 2.3 石狮油灯

- 地方口述：兴教寺西面有一只破损的石狮，身上有圆孔；旧时孔里放红色木杠，上置防风雨油灯，由寺登村民轮流值守，日落点灯、次日熄灯；茶马古道热闹时，四方街夜夜通明。[S12]
- **判断**：游记/口述，不是碑记；石狮的现状与孔的位置未核。
- **可用方式**：广场夜景的一盏灯、一块说明牌；不做「点灯任务」，不做功德值。

### 2.4 杨升庵咏海棠

- 地方资料：《新纂云南通志》把兴教寺记为「杨升庵、李中溪咏海棠诗处」；杨升庵写有咏海棠诗。[S14，摘要]
- **判断**：地方志转述；诗题/全文/年份未核。
- **可用方式**：一块小牌、一株海棠；不要凭记忆写诗句。

### 2.5 2004 年槐树折断

- 2004 年 6 月，四方街南面大槐树齐根折断，后在原位置补种一棵。[S13，摘要]
- **判断**：媒体报道/百科；可作「树不是原树」的说明。
- **可用方式**：南树略小、树干有支护；不做「古树崇拜」。

### 2.6 旅游与社区张力

- 2024 年游客 311.68 万人次；寺登村单院租金最高 22 万元/年；旅游从业 5080 人（占常住人口 21.2%）。[S05]
- 寺登街两侧被旅拍、咖啡、伴手礼占据；古镇外围开发；加建/加层与保护红线冲突；本地居民外迁。[S34、S37，摘要]
- **判断**：官方数据 + 媒体报道；具体租金/外迁比例没有统一统计。
- **可用方式**：广场上的「新村民」与「老居民」并置；不做「无辜古镇」的怀旧，也不做「商业化批判」的说教。

## 3. 题记与文字

### 3.1 壁画题记（二手转录）

> 大明永乐十五年岁次丁酉（1417）夏六月 信士杨庆敬绘
>
> 沙退乡甸头村画匠张保

- 出处：[S17，摘要]。**没有原壁录文/照片**；引用时注明「据二手转录」。
- 「沙退乡」是明代对沙溪的称呼；「甸头村」今属沙溪镇。[S17，摘要]
- 「信士杨庆」是功德主，「画匠张保」是画工；不要把两人混为一人。

### 3.2 匾额/楹联

- 兴教寺现有匾额/楹联的文字、作者、年代，本包没有拿到清晰照片或录文。**不要凭想象写匾**。
- 戏台台口两根木柱有楹联（内容未核）。[S18，摘要]
- **版权提醒**：当代书法家的匾联在著作权期内，不能照描；若用真名，必须取得授权或用无著作权的古匾。

### 3.3 诗

- 杨升庵咏海棠诗：未取得全文。**不要凭记忆写**。
- 可以用「海棠」作为季节/庭院意象，但不附会具体诗句。

## 4. 节庆：二月八太子会

### 4.1 是什么

- 农历二月初八，剑川白族传统节庆，白语称「史旺标」；受佛教密宗文化影响，纪念释迦牟尼为太子时「游四门」、见生老病死而出家。[S03]
- 明清至今，剑川古城（金华镇）与沙溪寺登街、长乐等地都有活动。[S03]

### 4.2 沙溪的流程

| 时间 | 活动 |
|---|---|
| 二月初六 | 迎太子入城/入村；布扎油漆的「太子行像」请到行宫或本主庙；当年新婚男子抬轿 |
| 二月初七 | 诵经做佛事；百姓备斋礼果品；入夜孩童持小蜡烛随小太子像游走（童子游四门） |
| 二月初八 | 太子游四门；钟鼓齐鸣、焚香诵经；狮队、龙队、舞队引领；沙溪的太子骑马（不是八抬大轿）；家家门前竖香、放鞭炮；常聚万人 |

出处：[S03，原文]。

### 4.3 沙溪的特殊处

- 沙溪要把「太子像」「释迦像」迎至**鳌峰山顶**，面对西面坝子的庄稼，祈五谷丰登。[S03]
- 1989 年开始恢复，成为「二月八民俗节」。[S03]

### 4.4 设计边界

- **第一版不做完整游行**：人太多、授权复杂、容易变成「民俗表演」。
- 可以做**节庆余韵**：香灰、纸扎碎片、孩子的小蜡烛、被踩过的鞭炮屑、本主庙门口的红纸。
- **不做**：把太子会做成「抽签/求子/转运」玩法；不做「太子尿洗眼」等民俗细节的猎奇呈现。

## 5. 戏曲与音乐

### 5.1 洞经古乐

- 洞经音乐是云南地方传统音乐，常与文昌/关帝/佛教仪式相关；寺登街戏台历史上有洞经演出。[S12、S13]
- 2026 年春节，剑川县在古戏台安排洞经古乐驻场（古琴、琵琶、二胡、笛子、唢呐）。[S08，摘要]
- **设计边界**：不要用真实洞经录音；用原创的、五声音阶的短句，取「丝竹+打击」的音色，不冒充某一首洞经。

### 5.2 白族霸王鞭

- 霸王鞭是白族传统舞蹈，舞者手持霸王鞭（一种带铜钱的短棍），边舞边击。[S13，摘要]
- 历史集市/节庆时在戏台/广场表演。[S12]
- **设计边界**：不做舞蹈小游戏；不做「动作捕捉表演」；最多在远处听到鞭声/脚步，看到人群围拢。

### 5.3 白剧、乡戏、滇戏

- 2026 年春节的「古镇乡戏展演」由石龙乡戏队演出；另有马坪关滇戏。[S08，摘要]
- 白剧是白族戏曲剧种；本包没有拿到沙溪本地白剧的演出记录。**不要把「白剧」当成每天都在戏台上演**。
- **设计边界**：第一版只做「排练/乡戏」的声音暗示，不做完整唱段。

## 6. 术语

| 词 | 意思 | 用法/陷阱 |
|---|---|---|
| 寺登街 | 「寺」=兴教寺，「登」=白语「地方」，「街」当地读「该」，即「兴教寺那里的集市」 | 不是「爬寺的街」 |
| 四方街 | 寺登街中心的方形广场 | 不是「四条街」 |
| 古戏台/魁阁带戏台 | 下铺、中台、上魁星阁的三层建筑 | 不要只说「戏台」而丢掉铺子/魁星阁 |
| 魁星阁 | 供奉魁星（主管文运）的楼阁 | 不是「星空楼」 |
| 阿吒力 | 白族地区对密教僧人的称呼；地方传统 | 学术争议；不要写成「白密=定论」 |
| 白密/滇密 | 对云南/白族密教的地方性称呼 | 侯冲等学者质疑其成立；用「地方传统称……」 |
| 本主 | 白族村社的地方保护神 | 不是「祖先」 |
| 土官 | 明清在少数民族地区任命的世袭地方官 | 不是「本地公务员」 |
| 马帮 | 茶马古道的驮马商队 | 不是「马术队」 |
| 马店 | 供马帮住宿、存货、拴马的车马店 | 不是「酒店」 |
| 马锅头 | 马帮首领 | 不是「厨师」 |
| 前铺后马店 | 临街铺面、后面马店的布局 | 不要简化成「商铺」 |
| 三坊一照壁 | 白族民居：三面房屋 + 一面照壁围合天井 | 不要与「四合五天井」混用 |
| 四合五天井 | 四面房屋 + 五个天井的白族民居 | 沙溪坡地多为小尺度/一颗印 |
| 一颗印 | 方形/近方形的小型合院 | 沙溪坡地常见 |
| 红砂石 | 当地丹霞地貌的红砂岩 | 不是「红沙」 |
| 鳌峰山 | 寺登街西侧/南侧的山 | 太子会迎像上山 |
| 黑潓江 | 沙溪附近的河流 | 玉津桥跨黑潓江 |
| 玉津桥 | 东寨门外的单孔石拱桥 | 年代有异说 |
| 东寨门 | 寺登街现存唯一寨门 | 现存为重建 |
| 欧阳大院 | 寺登街著名马店/民居 | 三坊一照壁，含马房、小戏台 |
| 太子会 | 农历二月初八的白族节庆 | 不是「王子节」的皇家叙事 |
| 太子游四门 | 太子（释迦）出游四门、见生老病死 | 与壁画《太子游苑图》呼应 |
| 洞经 | 云南地方传统音乐 | 不要用真实录音 |
| 霸王鞭 | 白族传统舞蹈/道具 | 不做舞蹈小游戏 |

## 7. 可用 / 不可用清单

### 可用（有出处，可写）

- 1415 始建、1417 壁画、张保/杨庆题记（注明二手转录）。
- 一进三院、门楼/观音楼/中殿/大殿的尺寸（S01）。
- 戏台三层、下铺中台上阁、14 飞角、12.2 米（S01/S02）。
- 四方街 1904 年红砂石铺地、赵泾（S12/S13）。
- 两棵槐树、南树 2004 年补种（S13）。
- 东寨门/南寨门/北寨门的方向与用途（S12）。
- 三天一集、前铺后马店、马帮投宿（S12）。
- 二月八太子会的流程（S03）。
- 2024 年旅游数据、租金、从业人数（S05）。
- 沙溪复兴工程的「修旧如旧、最小干预、最大保留」（S22/S34）。

### 需标「相传/口述/未核」

- 石狮油灯的故事。
- 杨升庵/李元阳咏海棠。
- 「女性化释迦」的壁画描述。
- 「唯一幸存」「唯一阿吒力寺院」的绝对说法。
- 张保的生平、十家土官的名单。
- 玉津桥/东寨门的具体年代。

### 不可用（没有来源或权利不清）

- 兴教寺壁画的照片/扫描/拓片（没有开放授权；文物保护）。
- 真实洞经/白剧/霸王鞭的录音/录像（表演者权利、社区同意）。
- 可辨识的村民/游客面部。
- 当代书法家的匾联原迹。
- 「小丽江」「艳遇之都」「风花雪月」式的宣传语。
- 把阿吒力写成「巫术」「黑 magic」「原始宗教」。
- 把太子会写成「求子/转运」玩法。
- 把四方街写成「每天都热闹的集市」。
