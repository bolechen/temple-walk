# T03 声音设计调研

核对日期：2026-11-17。T00/T01 的音频全部是 Web Audio 合成，没有录音；T03 默认沿用这条路线。
本文先写「现场有什么声」，再写「哪些能合成、哪些必须录、哪些不用」。

---

## 1. 五段声场

| 段 | 位置 | 主导声 | 次要声 | 不该有的 |
|---|---|---|---|---|
| Z1 东巷 | 东寨门—巷子 | 窄巷脚步、远处鼓点/木地板、手推车 | 说话声（不可辨内容）、鸟、门轴 | 完整戏曲唱段、循环 BGM、导游喇叭 |
| Z2 广场 | 四方街 | 红砂石脚步、扫帚、货箱、风 | 鸟、远处音乐、孩子跑过、相机快门（稀疏） | 集市叫卖循环、流行歌、广播 |
| Z3 戏台侧边 | 戏台一层/背面楼梯 | 木地板共鸣、楼梯脚步、搬动、卷帘门 | 二层展厅的低声、台口的风、铜铃 | 每天一场的完整演出、掌声循环 |
| Z4 寺院一进 | 门洞—天井—观音楼 | 天井回声、鸟、香火、木门 | 远处广场声（低通）、钟/磬（稀疏） | 诵经采样（无授权）、功德箱硬币声 |
| Z5 回广场 | 四方街（傍晚） | 收摊、灯亮、人声变稀、远处车流 | 戏台木地板最后几声、虫/鸟 | 突然静音、煽情音乐 |

### 1.1 声压与距离

- 东巷：约 45–55 dB(A)（未测）；广场 50–60；戏台侧边 55–65（木地板/搬动）；寺院一进 35–45；傍晚广场 40–50。【提案，需现场测】
- 门洞是天然低通：广场声进门洞后变闷，但**不能完全消失**；寺院里仍应听见极远的广场底噪。
- 戏台木地板是「箱体共鸣」：脚步不是干净的「咚」，而是带低频的「嗡」；搬桌子/拖箱子有摩擦与共振。

### 1.2 时间

- 清晨：扫帚、鸟、第一扇门打开、少量脚步。
- 上午：店铺开门、货箱、游客渐多、远处排练。
- 午后：人最多、快门声、孩子、风。
- 傍晚：收摊、卷帘门、灯亮、人声变稀、戏台最后几声。
- 夜间：不开放；若做夜景，只有风、远处狗/虫、极远的车。

## 2. 现场录音清单（若做）

> 前提：取得寺院、戏台管理方、村委会/社区同意；不录可辨识的谈话；不录完整演出；不使用无人机；不进入商铺/民居内部。

每个点 60–90 秒，同一天、同一设备、写明天气/时段/朝向/事件：

1. 东巷（东寨门内 10 m），朝广场。
2. 东寨门门洞内，朝巷子/朝广场各一条。
3. 四方街南端，朝寺门/朝戏台各一条。
4. 戏台一层铺面前，朝台口。
5. 戏台背面室外楼梯下，朝二层。
6. 寺门门洞内，朝天井/朝广场各一条。
7. 第一进天井，朝观音楼。
8. 广场北端/南端，朝巷道。
9. 单独录：木地板脚步（若允许上台）、楼梯脚步、木门/卷帘门、扫帚、货箱、鸟、风、雨/檐滴。
10. **排练**：只在表演者/组织者同意下录 20–30 秒，不作完整曲目；记录同意的范围（研究/游戏/宣传）。
11. **不录**：可辨识人脸对应的说话、宗教仪式、游客争吵、儿童正脸。

**每条记录**：文件名、时间、地点、朝向、设备、天气、许可、SHA-256。

## 3. 合成方案（默认路线）

T00 的 `audio.js` 有三条总线（音乐、山声、音效）、两套混响（庭院、木构殿内）、`instruments.js` 的琴/箫/泛音/钟/鼓。T03 新增：

| 声 | 合成做法 | 复用 |
|---|---|---|
| 窄巷混响 | 短延迟 + 低通 + 少量早期反射 | 新 |
| 红砂石脚步 | 复用 `steps.js` 的石板；加一点沙粒/磨光 | 复用 + 调 |
| 木地板脚步 | 低频共鸣（30–80 Hz）+ 木头撞击 + 短混响 | 新 |
| 戏台箱体 | 把木地板做成共振峰，搬动/脚步共用 | 新 |
| 扫帚 | 高频噪声 + 节奏性摩擦 | 新 |
| 货箱/木箱 | 低频撞击 + 摩擦 | 新 |
| 卷帘门 | 金属摩擦 + 抖动 + 末端撞击 | 新 |
| 门轴 | 摩擦噪声 + 谐振 | 新 |
| 鸟 | 复用 `bird()`；只在巷口/天井/广场 | 复用 |
| 风过槐树 | 噪声 + 带通 + 叶簇颗粒 | 复用 `trees` |
| 雨/檐滴 | 复用 T00 | 复用 |
| 钟/磬 | 复用 T00；寺院一进稀疏 | 复用 |
| 排练短句 | 原创三弦/笛/小鼓/木鱼/铜铃，5–8 秒，可中断 | 新 |
| 远处人声 | 带通噪声 + 无意义音节（不可辨） | 新 |
| 收摊 | 箱子/布/金属架/脚步的组合 | 新 |

**原则**：

- 巷声是「窄」：混响短、低频少、远处声音有方向。
- 广场声是「开」：混响更长、风/鸟/脚步分层。
- 戏台声是「箱」：木地板有共振，搬动有位置。
- 寺院声是「闷」：门洞低通，天井回声，钟磬稀疏。
- 傍晚是「稀」：不是静音，是「少了一层人声」。

### 3.1 与 T00/T01 的差异

| T00/T01 | T03 |
|---|---|
| 竹林风、城市低频、钟声、菜薹叶 | 窄巷、红砂石、木台、门洞、收摊 |
| 墙内只有钟磬 | 墙内仍听见极远的广场 |
| 山顶回望是城市/群山 | 回到广场，声音变稀 |

## 4. 配乐

> 资料库/T01 的经验：首轮可无配乐，先做环境声；T03 也建议先把五段声场做对，再加音乐。

### 4.1 结构提案

- **调式**：可用 D 羽或 G 羽，但主题更短（4–5 音），更「地方」：加入一个不解决的二度/四度，像巷道里的回音。
- **乐器**：三弦（拨弦）、笛/箫、小鼓、木鱼、铜铃；不用大编制。
- **段落**：
  - Z1 东巷：只有远处鼓点/木地板与一点点三弦泛音。
  - Z2 广场：主题第一次出现，稀疏；不盖过环境。
  - Z3 戏台：主题拆成碎片，像排练停停续续。
  - Z4 寺院：主题只剩骨架，木鱼/磬的点。
  - Z5 回广场：主题最后一次，停在不上不下的音；不解决。
- **与声音的关系**：音乐在环境声之下；戏台排练/门洞/收摊优先。

### 4.2 不要做

- 不要用真实洞经/白剧/霸王鞭录音，除非取得表演者/社区授权。
- 不要用「民族打击乐 + 电子鼓」做现代感；T03 不是「国潮古镇」。
- 不要让音乐盖过木地板/脚步/门洞。
- 不要用可辨识的佛号/诵经采样。

## 5. 与 T00 音频代码的对应

| T00/T01 | T03 用法 |
|---|---|
| `audio.js` 三条总线 | 直接可用；巷/广场/戏台/寺院放「山声」，木地板/门/物体放「音效」 |
| 两套混响 | 庭院混响用于广场；木构混响用于戏台/寺院；巷子用短混响 |
| `score.js` 的 zone/短语 | 新增 Z1–Z5 五个 zone；主题数据另写 |
| `instruments.js` | 复用琴/箫/钟/磬；新增三弦、小鼓、木鱼、铜铃 |
| `tools/music.mjs` | 可离线渲染 T03 的十五分钟走访 |
| `__listen` / `__music` | 测试钩子沿用 |

## 6. 验收

- [ ] 东巷能听见远处鼓点/木地板，但听不出完整曲子。
- [ ] 进广场后声音变开，红砂石脚步/扫帚/鸟分层。
- [ ] 戏台侧边木地板有箱体共鸣；搬动/脚步有位置。
- [ ] 进门洞后广场声变闷，但没消失；天井有回声。
- [ ] 回到广场时人声变稀，不是突然静音。
- [ ] 音乐不盖过木地板/脚步/门洞/收摊。
- [ ] 没有可辨识的谈话/唱段/诵经（除非取得授权）。
- [ ] 现场录音（若有）与合成层能分开调音量。

**注意**：自动测试只能证明「不削波、按规则切换、频率对」，不能证明「好听」。T03 的音频最终要真人试听。
