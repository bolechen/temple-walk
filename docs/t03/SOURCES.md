# T03 来源账本

核对日期：2026-11-17。本包新编 S01–S45；每一条都写「读了哪里、能支持什么、不能支持什么」。不是「有这个链接」就算来源。

## 0. 阅读方式与可信度分级

- **【原文】**：写作时实际打开页面、读了正文（县政府页面用 `curl` 带浏览器 UA；部分站点用 WebFetch）。
- **【API】**：结构化数据（OSM Nominatim/Overpass、opentopodata SRTM、博物馆 API），按字段读。
- **【摘要】**：只读到搜索引擎摘要、新闻转述或百科条目，没有打开原文。**引用前必须再核。**
- **【未用】**：链接打不开、正文为空或内容不足，明确不采用为独立证据。
- **【照片】**：只从公开照片的描述/搜索结果读到现场信息，没有下载图片。

同一个网页可能被多家转载，**转载数量不等于独立证据数量**。县政府页面自身也有数字不一致（6240/5000 m²、46/42 柱），不能当作测绘。

## 7. 再分发与授权边界

- **政府网站/规划/文旅页面**：可阅读与引用；不要把整份页面或大段文字打包进游戏仓库。引用时注明文号/日期/链接。
- **中国华夏文化遗产基金会页面**：可阅读；再分发权未取得；引用要短。
- **维基百科/百科**：CC BY-SA 或版权不明；只作线索，不直接引用长段文字。
- **OSM**：ODbL；地图数据可以用于游戏，但要署名 OpenStreetMap contributors；衍生数据可能有相同方式共享义务。
- **SRTM/opentopodata**：公开高程数据；作为设计参考，不直接分发原始数据。
- **博物馆馆藏（Met/Cleveland）**：Public Domain/CC0；保留来源行；不使用馆标；不写成馆方背书。
- **Commons 照片**：CC BY-SA 有署名 + 相同方式共享义务；闭源商业游戏是否接受，要所有者决定。本包**没有下载任何图片**。
- **真实壁画/戏曲录音**：没有开放授权；不进游戏。
