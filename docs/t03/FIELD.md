# T03 现场采集清单

核对日期：2026-11-17。本文是「如果要去现场，带什么、问什么、拍什么、记什么」。
**没有现场许可与社区同意就不做**；进入寺院/戏台/民居与获准拍照不等于获得商业图片/录音授权。

---

## 0. 先去之前

### 0.1 许可与边界

- [ ] 向**剑川县文化和旅游局**说明来意：游戏场景研究、非商业发布前的资料采集；问清是否需要介绍信/备案。
- [ ] 向**沙溪镇文化站/寺登村村委会**说明来意；问清社区同意流程、哪些区域可拍、哪些不可。
- [ ] 向**兴教寺**（宗教场所/文物管理方）说明：是否允许进入第一进、是否允许拍照、是否允许录音；壁画是否可看。
- [ ] 向**古戏台/茶马古道展厅**管理方说明：二层展厅是否开放、是否允许拍摄、三层是否可上。
- [ ] 说明用途：网页游戏《山门之外》的 T03 关卡；是否收费未定；素材是否进游戏、是否商用，要如实说。
- [ ] 问清：法会/节庆/施工/维修的封闭时间；哪些殿/院落/民居不开放。
- [ ] **不进入私人院落、商铺后场、民居、僧寮、办公区**；不拍门内/院内。
- [ ] 不使用无人机；不架三脚架堵路；不在殿内用闪光灯；不拍摄正在礼佛的人正面。
- [ ] 若需要专业测绘（全站仪/RTK/激光扫描），必须另行取得文物与规划部门许可；本文默认**不做专业测绘**。

### 0.2 社区同意（前置条件）

- [ ] 向村委会/社区说明：我们要记录的是**公共空间与公共生活**，不是「奇风异俗」。
- [ ] 说明照片/录音的用途、范围、期限；是否商用；是否署名；是否可以撤回。
- [ ] 对摊主、店主、表演者、居民分别取得**口头/书面同意**；记录同意范围。
- [ ] 不拍摄可辨识人脸；不拍儿童正脸；不拍私人院落。
- [ ] 若有人拒绝，尊重并停止；不偷拍、不绕开、不后期使用。
- [ ] 给社区一个反馈渠道（项目页面/联系人），允许他们之后要求删除。
- [ ] 不把「社区同意」当成「全社区同意」；只使用具体同意的人/场景。

### 0.3 装备

- [ ] 相机 + 24–70 mm / 70–200 mm；广角 16–35 mm；偏振镜。
- [ ] 手机（记录 GPS、时间、指南针、水平仪）。
- [ ] 激光测距仪（室内 40 m 够用）；卷尺 5 m；粉笔/标记贴（不损伤表面）。
- [ ] 录音机 + 防风毛套 + 立体声话筒；耳机。
- [ ] 色卡（X-Rite 或灰卡）；白平衡卡。
- [ ] 笔记本/表格；笔。
- [ ] 水、伞、防滑鞋；高原防晒；雨季防雨。
- [ ] **不携带**：无人机、大型灯架、反光板（殿内）、扩音器。

## 1. 空间与建筑测量

### 1.1 总体

- [ ] 四方街四角 GPS、边界、铺地范围、排水坡向。
- [ ] 东巷/南巷/北巷的净宽、长度、坡度。
- [ ] 东寨门/南寨门的门洞净宽/净高、墙厚。
- [ ] 寺门中心到戏台中心的方位；「门洞框住戏台」的站位。
- [ ] 广场到寺门/戏台/四周铺面的高差。
- [ ] 两棵槐树的胸径、冠幅、树池尺寸。

### 1.2 逐栋（每栋 15 分钟）

- [ ] 平面：面阔（柱中到柱中，逐间）、进深（逐间）、台基宽/深/高。
- [ ] 立面：檐口高、屋脊高、台基高、门高/宽、窗高/宽。
- [ ] 屋顶：形式（歇山/悬山/硬山/攒尖）、举高、出檐、瓦作、脊饰。
- [ ] 柱：直径、柱础、收分、侧脚、生起（目测 + 照片）。
- [ ] 斗拱：有无、几铺作、出跳、材等（目测 + 特写）。
- [ ] 墙：土坯/白墙/土黄墙的颜色（色卡）、厚度、墙脚返潮高度、雨痕、剥落。
- [ ] 门窗：样式、格心、门钉、门簪、门槛。
- [ ] 匾额/楹联：文字、尺寸、挂法、底色、字色、落款、印章。
- [ ] 石碑/石刻：位置、尺寸、文字、风化。
- [ ] 现状用途、是否可进、是否拍照允许。

### 1.3 戏台（单独 1 小时）

- [ ] 一层平面：商铺进深、门面宽、柜台位置。
- [ ] 二层舞台：台口宽/高/进深、台面高、四根主柱位置、台口楹联。
- [ ] 三层魁星阁：平面、窗/栏杆、像设（若可看）。
- [ ] 三层各层高、总高 12.2 m 的核。
- [ ] 三重檐的出挑、14 个飞角的位置/做法。
- [ ] 背面室外楼梯的位置、宽度、材料、与原构的关系。
- [ ] 台面木板的尺寸/磨损/响声。
- [ ] 现状开放范围：一层/二层/三层分别能不能上。

### 1.4 寺院一进（单独 1 小时）

- [ ] 门楼：中门净宽/净高、门槛高、台基高、两层关系。
- [ ] 天井：进深/面宽、地面铺法、排水沟。
- [ ] 南北厢房：开间/进深/门窗/现状用途。
- [ ] 观音楼：台基、两层关系、斗拱/栏杆/窗、像设（若可看）。
- [ ] 第一进与第二进的分隔：门/墙/廊/绳；是否可进入中殿。
- [ ] 门内外的声光对比（记录时间/天气）。

### 1.5 壁画（若获准，单独 1 小时）

- [ ] 逐幅位置（哪面墙/内壁/外壁/门楣）、尺寸、题材、榜题。
- [ ] 题记全文（拍照/抄录；不触摸、不拓印、不闪光）。
- [ ] 保存状况：褪色/剥落/裂缝/修补/烟熏。
- [ ] 光线：自然光/灯光/是否反光。
- [ ] **不做**：触摸、拓印、闪光、近距离灯照、取样。

## 2. 照片清单

### 2.1 每栋建筑（至少 6 张）

1. 正面（含台基与匾额）。
2. 左前 45°。
3. 右前 45°。
4. 侧面（含进深）。
5. 背面（若可绕）。
6. 屋顶/檐下/斗拱特写。

### 2.2 每处关键物

- [ ] 东寨门：门洞、石基、土坯墙、木门。
- [ ] 东巷：巷道、铺地、两侧铺面、排水沟。
- [ ] 四方街：四角、铺地、马蹄印/磨光、树池、排水沟。
- [ ] 两棵槐树：树干、树冠、树池、南树补种痕迹。
- [ ] 寺门：门洞、门槛、门簪、石狮、匾额。
- [ ] 第一进：天井、厢房、观音楼、排水沟。
- [ ] 戏台：全景（四向）、一层铺面、二层台口、三层魁星阁、14 飞角、背面楼梯、台口楹联。
- [ ] 壁画：逐幅（若获准；不闪光）。
- [ ] 四周民居/马店：门楼、照壁、木雕窗、柜台、马店门洞。
- [ ] 公共生活：扫地、摆货、送货、开门、收摊（**先征得同意；不拍正脸**）。
- [ ] 材质：红砂石、土坯、小青瓦、白墙、深木、褪色织物。

### 2.3 光线与天气

- [ ] 同一天至少拍「上午/正午/下午/傍晚」四组，记录时间、天气、太阳方向。
- [ ] 雨后（若遇到）拍湿石、木台、墙脚。
- [ ] 雾天/薄霾（若遇到）拍远山/巷道。
- [ ] 秋季（10–11 月）拍槐叶、晒秋；冬季（12–2 月）拍晴冷/集市热气；春季（3 月）拍太子会（若获准）。

### 2.4 元数据

每张照片记录：文件名、时间、地点、朝向、镜头/焦距、光圈/快门/ISO、白平衡、天气、许可、备注。
回来按建筑/主题建文件夹，保留原图，不覆盖。

## 3. 声音

见 `SOUND.md` 第 2 节。补充：

- [ ] 每条 60–90 秒，同一天、同设备。
- [ ] 记录声压（手机 App 即可，标误差）或至少「安静/一般/吵」。
- [ ] 不录可辨识的人声；若无法避免，回来说明并删除。
- [ ] 木地板/楼梯/门/卷帘门/扫帚/货箱要单独录。
- [ ] 排练/乡戏：先取得表演者/组织者同意；只录 20–30 秒；不录完整曲目。
- [ ] 寺院：钟/磬/木鱼要问清是否允许录；不录诵经（除非授权）。
- [ ] 雨/檐滴：等雨，录 2–3 分钟。

## 4. 公共生活观察（不打扰）

- [ ] 记录「谁在用广场」：店主、摊主、居民、游客、学生、送货员、清洁工。
- [ ] 记录「什么时候」：清晨/上午/午后/傍晚；周五/非周五；节庆/平日。
- [ ] 记录「怎么用」：穿行、停留、聊天、扫地、摆货、拍照、吃饭。
- [ ] **不记录**：姓名、年龄、收入、租金、家庭情况、身份证/车牌。
- [ ] 只用**行为描述**，不做人物画像；不拍正脸。
- [ ] 观察距离 ≥ 2 m；不挡路、不进店、不跟拍。

## 5. 数据管理

- [ ] 原图/原音不动；工作副本另存。
- [ ] 每个文件算 SHA-256；目录结构：
  ```
  t03-field-YYYY-MM-DD/
    photo/<building|square|life>/...
    audio/<zone>/...
    notes/
    consent/
    register.csv
  ```
- [ ] `register.csv` 列：文件、类型、时间、地点、作者、许可、用途、同意范围、SHA-256、备注。
- [ ] 同意书/口头同意记录放 `consent/`；不公开个人信息。
- [ ] 不把现场照片/录音直接放进仓库；先筛，再按授权决定。
- [ ] 长录像放仓库外，记地址与 SHA-256。
- [ ] 上传云端前确认：不含可辨识人脸/私人院落/未同意素材。

---

## 6. 礼仪与安全

- 不挡香客礼佛；不拍人脸；不进入标有「游客止步」的区域。
- 殿内不喧哗、不饮食、不倚靠佛像/供桌；不闪光。
- 戏台/楼梯/木地板注意脚下；不攀爬栏杆/屋顶/魁星阁。
- 高原（约 2100 m）防晒、补水；雨季防滑；冬季防寒。
- 若被问起，如实说明是游戏研究；不冒充记者/学者/官方。
- 若管理方/社区拒绝，尊重并停止；不偷拍、不绕开。
- 不为了「画面」要求居民/摊主/表演者重复动作或摆姿势。

---

## 7. 回来之后

1. 当天备份、算 hash、写备注。
2. 把「能支持的事实」逐条写进 `SOURCES.md`；把「照片里看到的」与「文字资料说的」分开。
3. 更新 `SITE.md` 的尺寸/高程（若有实测）。
4. 更新 `ARCHITECTURE.md` 的形制（若有新发现）。
5. 把新照片/录音的授权状态写进 `asset-register.csv`。
6. 把社区同意的范围/期限写进 `consent/` 与 `FIELD.md` 的记录。
7. 若发现本包的推断有错，直接改，并在 `README.md` 记一条「2026-xx-xx 现场修正」。
