# T05 来源账本

核对日期：2026-11-17。编号 S01–S43。每条都写：**读了哪里、能支持什么、不能支持什么**。不是「有这个链接」就算来源。

## 0. 阅读方式与可信度分级

- **【原文】**：本包写作时实际打开页面、读了正文。
- **【PDF】**：下载 PDF 并用文本层抽取；印刷页以原文标注的页码为准。
- **【API】**：结构化数据（OSM Overpass、Nominatim、SRTM），按字段读。
- **【摘要】**：只读到搜索引擎摘要、新闻转述或百科条目，没有打开原文。**引用前必须再核。**
- **【未用】**：链接打不开或内容不足，明确不采用。

同一个网页可能被多家转载，**转载数量不等于独立证据数量**。百科类来源彼此转抄，不能当一手材料。

## 9. 再分发与授权边界

- **政府网页/规划 PDF**：可阅读与引用；不要把整份网页/PDF 打包进游戏仓库。引用时注明文号/日期/页码。
- **论文/调查报告**：可阅读；图、表的再分发权未取得。引用要短，注明作者、刊名、年份、页码。
- **百科/新闻**：只作线索；不直接引用长段文字。
- **Commons 照片**：许可逐张不同；CC BY-SA 有署名与相同方式共享义务；PD 也要逐张核 PD 理由。**本包不使用任何 Commons 照片进游戏。**
- **OSM**：ODbL；地图数据可以用于游戏，但要署名 OpenStreetMap contributors；衍生数据可能有相同方式共享义务。
- **SRTM/opentopodata**：公开高程数据；作为设计参考，不直接分发原始数据。
- **馆藏四件**：Cleveland CC0；Met Open Access（公有领域/CC0）；保留来源行，不使用馆标，不暗示馆方背书。
- **奉国寺的现场照片、彩画、壁画、三维扫描、测绘图**：权利不清或未授权；**不进游戏**。
