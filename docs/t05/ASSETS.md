- **辽代木**（深褐/灰褐，纹理直）——柱、梁、斗拱；不要 T00 的暖红木。
- **彩画地仗**（朱红/矿物绿/白/黄丹）——可以是程序材质 + 手绘纹样，不一定要扫描。
- **壁画地仗**（灰泥/土壁）——墙面；不要用照片。
- **石阶/压阑石**——台基/月台边缘。

## 3. 只能当参考、不能进游戏的素材

### 3.1 奉国寺现场照片（Commons 等）

- Commons 的奉国寺照片是**研究/配色/构图参考**，不进 `dist/`。
- 许可逐张不同；CC BY-SA 有署名 + 相同方式共享义务；PD 也要逐张核 PD 理由。
- 不能把照片当贴图、当测绘、当「实机证据」。

### 3.2 彩画/壁画照片

- 彩画/壁画的照片、拓片、复制品，权利不清；**不进游戏**。
- T05 的彩画/壁画是原创，只参考公开描述（题材、颜色、构图），不描任何一铺。

### 3.3 测绘图/三维扫描

- 梁思成、杜仙洲、天津大学、中国文化遗产研究院的测绘图/扫描成果，未取得再分发权；**不进游戏**。
- 不能用「公开论文里的图」当纹理或模型基础；只读数字与结论。

### 3.4 匾额/书法

- 乾隆、刘钟麟的原迹在公有领域，但**照片/拓片**可能有拍摄者/馆方权利；不描。
- 游戏用虚构寺名「奉明寺」与自写字形；保留形制，不保留原字。

### 3.5 导览图/展板

- 景区导览图、展板设计可能有版权；只用来核对相对位置，不抠图、不进游戏。

## 4. 馆藏开放素材（T05 画廊候选）

T00/T01 已证明 ColBase / Met Open Access / Cleveland Open Access 三条管线可用。T05 的主题是辽代佛教殿堂，建议只用**11 世纪中国／辽代**造像（Met 一件馆方只写 China，学界通常定辽代），且明确「非奉国寺旧藏」：

| 编号 | 馆藏 | 年代/材质 | 用途 | 许可 |
|---|---|---|---|---|
| WORK-CMA-1976.14 | 观音菩萨 | 辽，900s，鎏金铜，高 43.8 cm | 胁侍/菩萨的冠式、璎珞、站姿参考 | CC0 |
| WORK-CMA-1974.90 | 文殊骑狮 | 辽，900s，铜，高 17 cm | 菩萨与坐骑的组合参考 | CC0 |
| WORK-CMA-1980.24 | 披鞍象 | 辽，约 1000s，鎏金铜，高 18.5 cm、长 24 cm | 普贤坐骑/一组菩萨的配对参考 | CC0 |
| WORK-MET-2006.284 | 毗卢遮那佛（Dari） | 辽，11 世纪，鎏金铜，高 21.9 cm | 辽代佛的宝冠、面相、衣纹参考 | Met Open Access（公有领域/CC0） |

**原则**：

- 只作「辽代同一时期的造像工艺」参考；不冒充奉国寺旧藏；不冒充七佛。
- 每件保留馆方来源行、 accession number、许可；Met 不使用馆标，不暗示背书。
- 不找「七佛」组像的开放图；现存开放馆藏里没有可靠的辽代七佛组像，T05 的七佛是原创。
- 不做西藏/日本/高丽的密教本尊来替代辽代汉传佛像。

## 5. 授权与署名

### 5.1 必须保留的署名

- Poly Haven：CC0，不强制署名，但 T00 已在鸣谢页列；T05 保持。
- 字体：SIL OFL；`shared/fonts/OFL.txt`；保留版权行与保留字体名。
- three.js / meshopt / Basis / lil-gui / stats：MIT/Apache；`THIRD-PARTY-NOTICES.txt`。
- ColBase：每件图下保留馆方来源行；修改过的（resize/crop）加一行说明。
- Met/Cleveland：CC0，保留来源行；Met 不用馆标。
- OSM：若用其数据做地形/布局，鸣谢「© OpenStreetMap contributors, ODbL」。
- Commons（若采用）：作者 + 许可 + 链接 + 是否修改。

### 5.2 不能用

- 奉国寺的现场照片、彩画/壁画照片、导览图、展板。
- 梁思成/杜仙洲/天津大学/中国文化遗产研究院的测绘图、扫描、报告图。
- 乾隆、刘钟麟原迹的描摹。
- 任何未授权的奉国寺三维扫描/摄影测量。
- AI 生成的「奉国寺实景」冒充现场照片。
- 「七佛药师」图像/名号替代「过去七佛」。
- 七佛「七种人格/七种能力/七个愿望」的旅游文案。

### 5.3 需要所有者决定

1. 是否做一次合规的现场采集（许可、预算、时间）；不做的话，白盒的台基/月台/踏道只能是复原。
2. 七佛/胁侍/天王是委托雕塑师，还是程序生成 + 手工修？预算与工期。
3. 是否请一位佛教美术/辽代建筑顾问核对尊格、手印、排列、彩画纹样。
4. ~~寺名用「寂明寺」还是「奉明寺」~~ 已定「奉明寺」（2026-11-20），英文 Fengming Temple（`DECISIONS.md`）。
5. 是否在游戏里呈现 1948 年炮弹/右手修补；呈现到什么程度。
6. 是否接受 CC BY-SA 的 Commons 照片进游戏（本包建议：不进）。
7. 是否做「辽代造像」小展（四件馆藏）；如果做，放在无量殿还是观察页。

### 5.4 交付命名（照资料库 V0.2）

每关交付：空间概念图、同白盒四视图、三处特写、材质板、照明预设、资产清单、来源授权表、运行截图。
命名示例：

- `T05_ENV_Courtyard_F01_v001`
- `T05_LGT_Interior_F01_v001`
- `T05_CAM_Door_Center_16x9_v001`
- `T05_SRC_Architecture_001`

每个版本记录：关卡 ID、场景、季节天气、来源图 ID、相机、太阳方位、材质版本、作者、日期、权利状态、变更说明。

## 6. 资产登记表怎么读

`asset-register.csv` 的 `status` 列：

- `reuse`：直接复用 T00/T01，已随项目分发。
- `planned`：T05 新做，尚未存在。
- `reference`：只作研究/参考，不进 `dist/`。
- `candidate`：候选，许可/内容未定。
- `blocked`：权利不清或没有来源，不用。

`commercial_use` 列只写「yes / conditional / no / unknown」，不写推断。

## 7. 为什么 T05 的素材策略比 T01 更严

T01 可以用「同一主题的公开馆藏图像」挂在殿内，因为宝通寺的殿内是近现代塑像，画是补充。
T05 的大雄殿本身就有**七佛 + 14 胁侍 + 2 天王 + 彩画 + 壁画**，是一套完整的辽代视觉系统；任何一张奉国寺的照片/彩画/壁画贴进去，都会把「原创演绎」变成「复制」。所以 T05 的策略是：

- **建筑**：按实测数字 + 公开形制，程序生成；不贴寺方照片。
- **造像**：原创七佛/胁侍/天王；馆藏四件只作工艺参考。
- **彩画/壁画**：原创纹样系统；只参考公开描述的题材/颜色/构图。
- **声音**：全部合成；不录寺方/游客。
- **光**：按 F01 入口漫射天光；不拿现场照片的亮度当标准。

这样既保住了「像奉国寺」，又不侵占任何人的照片/测绘/造像权利。
