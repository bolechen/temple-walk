# T05 现场采集清单

核对日期：2026-11-17。本文是「如果要去义县奉国寺，带什么、问什么、拍什么、记什么」。
**没有现场许可就不做**；进入景区与获准拍照不等于获得商业图片/测绘授权。

---

## 0. 先去之前

### 0.1 许可与边界

- [ ] 向**义县奉国寺文物保管所／景区管理处／义县文化旅游主管部门**说明来意：游戏场景研究、非商业发布前的资料采集；问清是否允许拍照、测量、录音。
- [ ] 说明用途：网页游戏《山门之外》的 T05 关卡；是否收费未定；素材是否进游戏、是否商用，要如实说。
- [ ] 问清：哪些殿可进、哪些区域不开放、大雄殿内是否允许停留/拍摄、月台/钟亭/碑亭是否可去、2025 年屋面修缮是否封闭、法会/施工时间。
- [ ] 寺院/景区与文保单位是不同管理方；分别问。
- [ ] **不进入**未开放区域、施工围挡、文物保护红线；不拍岗哨、不拍工作人员/游客正面。
- [ ] **不使用无人机**；**不架三脚架**堵路；**殿内不用闪光灯**；不拍摄正在礼佛的人正面。
- [ ] 遵守景区开放时间（夏季约 8:00–17:00，16:30 停止入馆；冬季约 8:30–16:30，16:00 停止；以当日公告为准）。
- [ ] 若需要专业测绘（全站仪/RTK/激光扫描/摄影测量），必须另行取得文物与规划部门许可；本文默认**不做专业测绘**。
- [ ] 不触摸佛像、佛坛、壁画、彩画、碑刻、门窗；不跨越护栏；不登佛坛/台基边缘；不烧香/点烛（殿内禁火）。
- [ ] 不在殿内大声说话、不走动拍摄、不长时间占用通道；遇到法会/礼佛，退到一旁。

### 0.2 装备

- 相机 + 24–70 mm / 70–200 mm；广角 16–35 mm；偏振镜。
- 手机（记录 GPS、时间、指南针、水平仪）。
- 激光测距仪（室内 40 m 够用）；卷尺 5 m；粉笔/标记贴（不损伤表面）。
- 录音机 + 防风毛套 + 立体声话筒；耳机。
- 色卡（X-Rite 或灰卡）；白平衡卡。
- 笔记本/表格；笔。
- 水、伞、防滑鞋；冬天防滑、防寒；夏天防蚊。
- **不携带**：无人机、大型灯架、反光板（殿内）、扩音器、香烛。

## 1. 空间与建筑测量

### 1.1 总体

- [ ] 寺院南缘/东街入口 GPS、海拔（手机 GPS 即可，标误差）。
- [ ] 外山门—内山门—牌坊—无量殿—月台—大雄殿的**水平距离**（激光/测距仪 + 步测）。
- [ ] 每段高差（院子—月台—台基—殿内）。
- [ ] 月台踏道：级数、级高、踏面、总宽、垂带/栏板。
- [ ] 主要路线的宽度（最窄处）。

### 1.2 大雄殿（重点，至少 90 分钟）

- [ ] 平面：面阔九间的逐间柱中距、进深五间的逐间柱中距；台基宽/深/高；月台宽/深/高。
- [ ] 立面：檐口高、屋脊高、台基高、门高/宽、窗高/宽、墙厚。
- [ ] 屋顶：单檐庑殿的举高、出檐、瓦作（青灰瓦的规格/颜色）、脊饰。
- [ ] 柱：檐柱 28 根的柱位/柱径/柱础；内柱 20 根的柱位/柱径/柱础；侧脚、生起。
- [ ] 斗拱：12 种的逐种位置、材广/厚、出跳、昂面、耍头；先拍外檐柱头/补间/转角三朵。
- [ ] 梁架：八缝的逐缝配置（四椽栿/六椽栿/乳栿/丁栿/剳牵/驼峰/槫/椽）；彻上明造。
- [ ] 门窗：三门四窗的净宽/高、门槛、门钉、门簪、格心、抱鼓石。
- [ ] 匾额：三块竖匾的文字、尺寸、挂法、龙边、落款（只记录，不描）。
- [ ] 墙面：灰砖/白灰/土朱/赭红；墙脚返潮、雨痕、剥落。
- [ ] 地面：砖/石、磨亮、修补。
- [ ] 2025 年修缮：脚手架/围挡/揭取/新补构件；拍照记录，但不进游戏。

### 1.3 佛坛与造像（重点，至少 60 分钟）

- [ ] 佛坛：长、深、高；前缘到门槛的距离；两侧通道宽度。
- [ ] 七佛：逐尊的中心位置、须弥座/莲座尺寸、像高（到肉髻）、头向、手印、袈裟、胸衣纹样。
- [ ] 14 胁侍：每尊的位置（哪尊佛的左/右）、身高、冠式、手势、姿态、衣纹。
- [ ] 2 天王：位置、身高、持物、甲胄。
- [ ] 倒坐观音：位置、面相、尺寸（若可接近）。
- [ ] 背光：形状、尺寸、颜色、与梁架的关系。
- [ ] 1948 年修补：释迦右手、屋顶/彩塑的修补痕迹（只记录，不触摸）。

### 1.4 彩画/壁画（重点，至少 60 分钟）

- [ ] 彩画：梁/栿/斗拱上的分布；飞天（42 躯）的位置；网目纹/宝相花/凤纹卷草；颜色；残损。
- [ ] 壁画：东西墙十佛、北墙八菩萨、南尽间十一面观音、南槛墙十八罗汉（若仍可见）；逐幅尺寸/年代/病害。
- [ ] 记录方式：远/中/近三档；不触摸、不拓、不使用闪光；以现有光为准，不补光。

## 2. 照片清单

### 2.1 六站（每站至少 3 张：16:9、4:3、9:16）

1. **院落远望**：九间立面 + 台基 + 屋脊；不要裁掉屋脊。
2. **台基**：踏道 + 台基侧面 + 檐柱/斗拱；屋脊可出画。
3. **殿门中央**：门框 + 中央三尊 + 佛坛 + 梁架；记录曝光。
4. **侧向观看**：七佛侧面 + 胁侍 + 侧壁壁画 + 柱列。
5. **仰视梁架**：八缝梁架 + 斗拱 + 彩画；尽量垂直向上。
6. **回到中央**：中央四至五尊 + 佛坛 + 背光；记录「看不全七尊」。

### 2.2 细节

- [ ] 大雄殿：正面/左前/右前/侧面/背面（若可绕）；屋顶/檐下/斗拱特写。
- [ ] 门：门洞、门钉、门簪、门槛、抱鼓石。
- [ ] 匾：三块竖匾（只记录）。
- [ ] 台基/月台：压阑石、踏道、垂带、钟亭/碑亭。
- [ ] 七佛：每尊正面/侧面/手印特写；至少中央毗婆尸、东端迦叶、西端释迦各一组。
- [ ] 胁侍：每组 2–3 尊；冠式/手势/衣纹。
- [ ] 天王：两尊正面/侧面/持物。
- [ ] 彩画：飞天/网目纹/宝相花各 3–5 处。
- [ ] 壁画：十佛/八菩萨/十一面观音各 1–2 幅。
- [ ] 碑刻：金/元/明/清碑的位置与碑文（只记录，不拓）。
- [ ] 月台：钟亭（六角）/碑亭（四角）。
- [ ] 无量殿/天王殿：外观、匾、门窗。
- [ ] 院子：地面、排水、树、墙。

### 2.3 光线与天气

- [ ] 同一天至少拍「上午/正午/下午」三组，记录时间、天气、太阳方向。
- [ ] 晴天/阴天/雪后（若遇到）各拍门洞光比。
- [ ] 记录殿内外的曝光差（EV），用于 F01 光模型。
- [ ] 不要为了「好看」而用闪光/补光改变现场；记录现场光。

### 2.4 元数据

每张照片记录：文件名、时间、地点、朝向、镜头/焦距、光圈/快门/ISO、白平衡、天气、许可、备注。
回来按建筑/主题建文件夹，保留原图，不覆盖。

## 3. 声音

见 `SOUND.md` 第 2 节。补充：

- [ ] 每条 60–90 秒，同一天、同设备。
- [ ] 记录声压（手机 App 即可，标误差）或至少「安静/一般/吵」。
- [ ] 不录可辨识的人声；若无法避免，回来说明并删除。
- [ ] 不敲钟/鼓/木鱼/磬；只录环境。
- [ ] 殿内录 3 个点：门槛外、中轴、内槽下；记录混响（拍手/气球需许可，否则只录环境）。
- [ ] 院外录 2 个点：南侧街面、无量殿前院子。
- [ ] 雪后（若遇到）录脚步/院外声。
- [ ] 风/鸟：等风，录 2–3 分钟；不辨种。

## 4. 植被与地表

- [ ] 院内主要树种、位置、冠幅、健康状况；T05 的院子树不多，不要套 T00 的竹林。

- [ ] 排水：位置、断面、坡向、水迹。
- [ ] 围墙/挡墙：材料、高度、收分。
- [ ] 雪后：屋顶/台基/院子的雪线、融雪水痕。

## 5. 城市与声音环境

- [ ] 寺院南侧 50–100 米内的街面/车流/商铺，拍 4 个方向。
- [ ] 从院内看县城：院子/月台各拍一张朝南。
- [ ] 从院外看寺：东街/南侧拍大雄殿屋顶与院墙。
- [ ] 天气与能见度（晴/阴/雪/霾）。
- [ ] 县城的高度/体量：不要做成大都市，也不要做成深山。

## 6. 数据管理

- [ ] 原图/原音不动；工作副本另存。
- [ ] 每个文件算 SHA-256；目录结构：
  ```
  t05-field-YYYY-MM-DD/
    photo/<building>/...
    audio/<zone>/...
    notes/
    register.csv
  ```
- [ ] `register.csv` 列：文件、类型、时间、地点、作者、许可、用途、SHA-256、备注。
- [ ] 不把现场照片直接放进仓库；先筛，再按授权决定。
- [ ] 长录像放仓库外，记地址与 SHA-256。
- [ ] 与寺院/景区的许可文件、联系人、日期，单独存档。

---

## 7. 礼仪与安全

- 不挡香客礼佛；不拍人脸；不进入标有「游客止步」的区域。
- 殿内不喧哗、不饮食、不倚靠佛像/佛坛/柱子；不触摸壁画/彩画。
- 不跨越护栏、不登佛坛、不爬台基边缘/屋顶。
- 雨后石阶滑；冬天防滑、防寒；夏天防暑、防蚊。
- 若被问起，如实说明是游戏研究；不冒充记者/学者/官方。
- 若管理方拒绝，尊重并停止；不偷拍、不绕开。
- 殿内禁火：不点香、不点烛、不烧纸。

## 8. 回来之后

1. 当天备份、算 hash、写备注。
2. 把「能支持的事实」逐条写进 `SOURCES.md`；把「照片里看到的」与「文字资料说的」分开。
3. 更新 `SITE.md` 的尺寸/高程（若有实测）。
4. 更新 `ARCHITECTURE.md` 的形制（若有新发现）。
5. 更新 `GALLERY.md`/`asset-register.csv` 的授权状态。
6. 若发现本包的推断有错，直接改，并在 `README.md` 记一条「2026-xx-xx 现场修正」。
7. 若拍了 2025 年修缮的现状，单独存档，标注「非游戏内状态」。
