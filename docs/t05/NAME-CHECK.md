# T05 寺名「奉明寺」重名与商标检索

检索日期：2026-11-25。范围：只读检索，不改代码。本页只摆事实和风险等级，**不下「可以用」的结论，由所有者定**。

## 0. 先说检索的局限（读之前请先看这一节）

- 检索用的是 WebSearch（美国区，通用搜索），不是各国商标库。**中国商标网（sbj.cnipa.gov.cn）、国家企业信用信息公示系统、日本 J-PlatPat、韩国 KIPRIS、WIPO Global Brand Database、USPTO、Steam 站内搜索，一个都没有直接查到**；这些库要交互式查询或验证码，本次没有做。
- 下表「读了多少」一栏：**全部是「搜索结果摘要」，没有逐条打开原页面通读**。摘要由搜索服务生成，可能有概括或笔误，引用时请回到原链接核对。
- 「没搜到」不等于「不存在」：小寺、台湾和海外华人寺、未上线的商标申请、小游戏都可能不在这个搜索覆盖里。
- 项目名词澄清：任务说明里英文名写作 Silent Clarity Temple，但仓库里已定的英文名是 **Fengming Temple**（`docs/t05/DECISIONS.md` §2，2026-11-20）；Silent Clarity Temple 是 `PRD.md` §11 第 6 项被作废的旧推荐。下面两个英文名都查了。

## 2. 发现，逐条

### 2.1 「奉明寺」原字：没有检到现存寺院

- 搜「奉明寺」，搜索服务回答「没有关于奉明寺的直接信息」，只给了字形近的别的寺（高明寺、海明寺、大明寺、崇明寺、普明寺等）。读了多少：摘要。链接例：[Gaoming Temple](https://en.wikipedia.com/wiki/Gaoming_Temple)、[Daming Temple](https://Www.wikipedia.org/wiki/Daming_Temple)。
- 扩展检索「奉明寺 寺庙 OR 佛寺 OR 游戏」，唯一含此名的结果是**本项目自己的公开 PR**（[#176 docs(t05): 奉国寺调研包](https://github.com/bolechen/temple-walk/pull/176)）。读了多少：摘要。含义：这个名字已经在公开仓库里出现，但那是我们自己的。
- 日韩读法：「奉明寺／ほうみょうじ」「봉명사」没有检到对应的现存寺院（摘要）。韩文查到的是北朝鲜开城的凤鸣山（鳳鳴山）相关旧寺，是「凤鸣」不是「奉明」（见 2.3）。
- **未做**：台湾佛寺名录、日本的寺名库、各省宗教局登记、地方志。

### 2.2 「奉明」作品牌、商标：没有检到，但商标库没有查

- 搜「奉明寺 商标」「奉明 商标 国家知识产权局 …」均**没有检到注册信息**（摘要）；搜索服务也明说自己没有查到商标库。读了多少：摘要。
- 搜「奉明 品牌／公司／茶／禅」，结果是茶叶品牌（幽蘭青、茗林源、新鳳鳴 New Fonming 等），**名字与「奉明」都不同**，只说明「禅 + 茶」类品牌拥挤，不是冲突证据。链接例：[Behance 幽蘭青](https://www.behance.net/gallery/122801529/YOULANQING)、[新鳳鳴](https://creativexpo.tw/brands/633)。读了多少：摘要。
- **怎么查（未做，需要人或有账号的工具）**：
  1. 中国商标网「商标近似查询」：输入「奉明寺」「奉明」「凤鸣寺」，类别看第 9（软件、游戏）、第 41（娱乐、游戏）、第 43（餐饮、住宿）、第 45（宗教服务），再加第 16、25、30、35 类做排查；
  2. 企查查／天眼查查「奉明寺」「奉明」的公司和商标；
  3. WIPO Global Brand Database、USPTO TESS 的后继 Trademark Search、EUIPO eSearch、J-PlatPat、KIPRIS，各输入 Fengming、「奉明」；
  4. Steam、itch.io、TapTap、App Store、Google Play、Bilibili 的站内搜索；
  5. 国家宗教事务局的「宗教活动场所」登记（有无叫奉明寺的场所）。

### 2.3 「凤鸣寺 / Fengming」：同音同拼，现存寺院不止一处

- 摘要检到（来源均为搜索摘要，**各寺的细节未核原页**）：
  - 浙江桐乡凤鸣禅寺，称始建于后周广顺二年，现寺 1998 年重建：[桐乡新闻网 古刹凤鸣寺](http://txhistory.zjol.com.cn/system/2008/01/24/010319526.shtml)、[百度百科 凤鸣禅寺](https://baike.baidu.com/item/%E5%87%A4%E9%B8%A3%E7%A6%85%E5%AF%BA/10763613)；
  - 云南宜良凤鸣寺：[携程攻略](https://you.ctrip.com/sight/yiliang2177/145358076.html)；
  - 陕西宝鸡凤鸣禅寺：[游妙方](https://aiyoutravel.com/location/detail/0f92e0823157fb48ceff48dcc2af224e)；
  - 江西武宁凤鸣山弥陀寺（现名弥陀寺，凤鸣山是山名）：[大菩文化](https://www.pusa123.com/pusa/wenhua/mingsigucha/122678.shtml)；
  - 韩国／北朝鲜：开城凤鸣山的旧寺（光通普济禅寺、运岩寺），摘要称在北朝鲜境内：[한국민족문화대백과](https://encykorea.aks.ac.kr/Article/E0005314)。
- 以英文搜 "Fengming Temple" 和 "Feng Ming Temple"，**没有检到以此命名的英文条目**（只给近名：Fengguo、Fengshan、Fengxian、Fengtian 等）。这说明英文世界里这个名字还空着，但**不能推出中文世界里没有**：上面几处凤鸣寺的拼音就是 Fengming（摘要，未核其官方英文名）。
- 另有火车站 [Fengming railway station](https://en.wikipedia.org/wiki/Fengming_railway_station) 和绍兴的地名 [凤鸣村](https://us.trip.com/travel-guide/shaoxing/fengming-mountain-89434/)，只说明「Fengming」是常见地名拼音。
- 风险点：玩家或商店搜 "Fengming Temple" 会看到真的凤鸣寺。**游戏里的寺是「奉明寺」，字不同，所以中文界面没有冲突；只有英文拼音这一处撞车**。拼音撞音是 `DECISIONS.md` 已经写下的顾虑，现在有了实例。

### 2.4 「奉明寺」与原型奉国寺的关系（自家的混淆风险）

- 原型：辽宁义县奉国寺，历史别名咸熙寺（辽）、七佛寺、大奉国寺（金）：[Fengguo Temple（维基百科英文）](https://wikiwand.com/en/Fengguo_Temple)、[Architectura Sinica 奉國寺](https://architecturasinica.org/place/000027)。读了多少：摘要；元大德七年《义州重修大奉国寺碑》一说是搜索服务的转述，**未读碑文原文**。
- 没有发现奉国寺有叫「奉明寺」的别名；`CULTURE.md` §1.1 已有本项目自己的核对，本次不重复。
- 「奉明」「奉国」只差一字，英文 Fengming 与 Fengguo 也近。`I18N.md` 第 27 行已有「说明牌要区分原型与游戏里的寺」的规定，本检索没有新的发现，只是印证这一条应保留。

### 2.5 「Silent Clarity Temple」：没有检到同名

- 检索结果里没有以此命名的寺院、品牌或游戏（摘要）；近似的只有游戏地名 [Temple of Silence（Genshin Impact 粉丝维基）](https://genshin-impact.fandom.com/wiki/Temple_of_Silence)、[Temple of the Silent Storm（Guild Wars 2）](https://wiki.guildwars2.com/wiki/Temple_of_the_Silent_Storm)，以及一个禅修网站模板 [Silent Peak](https://www.wix.com/sgtemplates/the-silent-peak-old)。读了多少：摘要。
- 它是意译，不是「奉明」的音译，**与中文寺名没有对应关系**；若改用，匾额与英文名会脱节。现已不用，只记录。

## 3. 真实同名寺院 与 游戏虚构 的关系

按本项目原则（`CLAUDE.md` 开头：原创演绎、寺名虚构）：

1. **「奉明寺」没有检到真实的同名寺院**，所以现在不存在「游戏借用了一座真寺的名字」的问题；但因为检索没有覆盖寺院登记库，这是「没检到」，不是「确认没有」。
2. **「凤鸣寺 / Fengming」有真实同音寺院，至少 3–4 处**。游戏里没有写「凤鸣」二字，但英文名会指到它们。需要所有者定：保留 Fengming Temple，还是改成带声调或意译的英文名，或英文界面处加一行「虚构，与现存凤鸣寺无关」的说明。（这是选项，不是建议。）
3. 游戏已有的做法：寺名虚构、说明牌写「取意辽宁义县奉国寺」、不描现存匾字。检索没有改变这些做法的依据，也没有证明它们够用；是否要在鸣谢页或说明里加一句「寺名为虚构，如与现存寺院同名纯属巧合」，由所有者定。
4. 宗教场所名称的法律问题（中国对「寺」「院」名称的登记和使用另有宗教事务方面的规定）**本次没有查，也不是律师意见**；若要上 Steam 或在国内发行，建议请有商标和宗教事务经验的律师过一遍。

## 4. 下一步（需要人做的，按成本从低到高）

1. 在中国商标网和企查查输入「奉明寺」「奉明」「凤鸣寺」，截图存证。
2. 在 Steam、TapTap、App Store 搜 Fengming、Feng Ming、「奉明寺」。
3. 决定英文名是否保留 Fengming Temple（2.3）。
4. 要正式使用「奉明寺」作为游戏或系列品牌时，申请商标前先做律师级近似检索（第 9、41、45 类至少）。
