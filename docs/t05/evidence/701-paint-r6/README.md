## 眼：斜沟 / 细毛是不是上色之后才有的

`eyes-clay-vs-paint.jpg`：同机位同光，上排灰模、下排上色，三尊各 10 米与 4 米。灰模上睑线干净，眼裂的形清楚，没有斜沟。上色后，外眼角处多出几道细线（拘留孙 4 米、拘那含牟尼 10 米最明显），睑线的形还在、没糊；这几道线灰模上没有。**它们是上色这一步带来的**，来源有三个候选，我没有拆开验证：面部贴花画的眼线与眉线、折纹明暗（`folds`）、顶点 AO。要拆的话，我可以逐个关掉各出一张。
