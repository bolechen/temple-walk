# 七尊第五轮：胸衣、白毫（#370）

2026-11-21，主创看第四轮后给的三条方向。模型同第三轮（r3），只改 `tools/t05-hall/paint/`，帧耗不变。

1. 拘留孙、毗婆尸、拘那含牟尼胸前的三道灰绿直带去掉（像贴上去的胶条）；迦叶沿圆领的弯带留着。
2. 胸衣和袈裟拉开：三尊胸前的方块涂低饱和的褐灰 `#584F47`（粗糙 0.82），明度比袈裟 `#6A3428` 高一点，饱和度低很多（ART.md §3.1）。先试的 `#7B7065` 在殿里近乎发白，压暗了一档。方块的边界从各尊的正投影格子图读出（`tools/t05-hall.cjs` 的 ortho），写在锚点 `chestMin/Max` 里。
3. 白毫从米白亮点 `#D6D0C2` 压成暗金 `#8A7550` 的小点。
