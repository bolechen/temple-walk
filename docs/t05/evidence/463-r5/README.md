# #463 毗婆尸 r5：比例编辑修嘴和下巴垫，新的四个量数，烘焙三处（2026-11-21）

回 3D 评审第二轮。r4 的嘴没过（平视和仰看都撅、下巴堆着），评审作废了「上唇到鼻底—下巴连线」的量法，改用比例编辑和四个按原型定阈值的量数。

## 做法

所有修改都在 148 万面的原件上做（`tools/t05-statue/vipasyin/repair.json`），然后减面、烘法线。新加的三步，参数由 `tools/t05-statue/face-ops.py` 从这一尊自己的特征点算出，配方在 `tools/t05-statue/face/recipe.json`（本目录也存了一份 `face-recipe.json`）；另外六尊照同一份配方由它们自己的点给参数，不逐尊手调。

- 嘴：`scale`，以嘴缝中点为中心，横 ×1.08、高 ×0.8、深 ×0.8，再整体后移 0.015 倍脸宽。高斯权重的半径按嘴宽算：横、深 1.3w，竖 0.6w。鼻底以上不动，免得鼻子跟着变宽、变扁。
  - 评审给的横向是 1.2–1.3。我没照做：这一尊的嘴宽/脸宽本来就有 0.31（原型 0.29–0.31），放宽到 1.25 倍会超出原型 +15%。嘴看起来小，是因为画的唇比雕的嘴窄；现在唇的贴花宽度改由量到的嘴角定（`lipHalf`）。
- 下巴垫：`scale` 只改深度 ×0.68，以颏唇沟的深度为中心，半径 0.8w；嘴缝以上不动。
- 颏唇沟：填平其深度的 35%（`push`，半径 0.5w）。只把下巴往后收，沟本身仍然深，所以要填。
- 人中 k 0.5、眉心 k 0.3、头前倾 10°、嘴角上收：保留 r4 的做法。

## 四个量数（`tools/t05-statue/face-ratios.py`）

原型和网格用同一种量法。原型的取点位置见 `concept-points.json`。网格的取点见 `ratios-vipasyin-r*.json` 里的 `points`；头前倾的那份先把剖面转回 10° 再找特征点。

| 量 | 原型 | 阈值 | r3 | r4 | r5 |
|---|---|---|---|---|---|
| 嘴宽 / 脸宽（嘴缝处） | 毗婆尸 0.291，释迦 0.311 | 在原型的 ±15% 以内：毗婆尸 0.247–0.335，释迦 0.264–0.358 | 0.320 | 0.311 | 0.335 |
| 唇厚 / 嘴宽（上唇最前点到下唇最前点的高差） | 0.210 | ≤ 0.242 | 0.270 | 0.291 | 0.217 |
| 唇前伸 / 嘴宽（上唇最前点比鼻底点往前多少） | −0.043 | ≤ −0.043 | +0.031 | +0.005 | −0.058 |
| 颏唇沟深 / 嘴宽（沟底到「下唇最前点—下巴最前点」连线的距离） | 0.106 | ≤ 0.127 | 0.177 | 0.199 | 0.110 |

- 四个数 r5 都在阈值内。嘴宽卡在毗婆尸原型的上限。
- 毗婆尸的原型图没有侧面，侧面三项（唇厚、唇前伸、颏唇沟深）**借用**释迦的侧面图（同一家人、同一比例画），不是毗婆尸自己的依据；等所有者补出毗婆尸的侧面再换。
- 原型的嘴只有 48 px 宽，1 px 约等于 0.02 w，所以原型的侧面三项各带约 ±0.02 的误差。
- 原型的唇厚也在正面量了一次（看得见唇红的上下缘）：毗婆尸 0.287、释迦 0.281。正面和侧面量的是两样东西：正面是唇红的高，侧面是两片唇最前点的高差。网格上只能量侧面那一种，所以阈值用侧面的。

## 烘焙三处

- **鼻孔下的暗圈**：射线距离从 6 cm 收到 2.2 cm，笼子从 3 cm 收到 1 cm。暗圈没了，见 `vipasyin-r5-nose.png`（左仰看、右平视）。
- **螺发上的三角亮块**：头（模型高 0.735 以上，约 1.5 万面）单独展 UV、单独烘一张 2048²，身另一张。烘后螺发是平滑的颗粒（`vipasyin-r5-bake-before-after.png`，上未烘、下烘了）。
- **眼线和雕的睑沟错开，外角翘尾**：在网格上找睑缝（上睑悬垂处，正面看表面往后退一步），拟合出每只眼睑缝中点的高度和往外升的斜率（左 +0.30、右 +0.24），眼线画在这条缝上，随缝倾斜（锚点 `lidL`、`lidR`，`paint.js`）。眼线两端收到几乎为零，不再翘出去。眉仍跟原来的眼锚点。
