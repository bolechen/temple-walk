## 构建：第 81 版

在第 69 版上加了三样，用来封开口（参数见 `H-varada-params.json`，日志见 `H-varada-log.json`）：

1. **前臂内衬**：前臂内侧 5 mm 一层反向的面（`arm.lining`）。
2. **拐角内衬**：腕后内侧拐角的一个框里，所有面都加一层内衬，朝向能从缺口看进去的那些机位（`cleanup.lining_box`、`lining_face`，在 `varada-tidy.py` 里做）。
3. **补块**：缺口最后剩下的四处，用四个小的闭合块填上，单面朝外（`cleanup.fill_blobs`）。

另外，前臂底面的扇形封口改成双面，两层在中点处相距 1 mm。
