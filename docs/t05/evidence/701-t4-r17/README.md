## 总监这一轮点的七件，改了什么
1. **头发没涂全**：毗婆尸、迦叶、尸弃、拘留孙……的螺发下沿一圈和耳后。发际平面的两点按图下移（hairFront −0.07 m、hairBack −0.30 m），耳后一块用另一个条件（耳后、耳垂上沿 0.25 m 以上）补进螺发，螺发避开的耳椭球缩小（`earHL/earHR/earH_`、`napeP/napeFloorP`，配方里 `螺发` 区加了一条 or）。`stage.js` 加了 `paint:{ hair: "#ff00ff" }` 的平涂看图。
2. **颈和领口**：领口上沿的一条（衣领）原来没进内衣区，成了粉红带；内衣的掩码按 `pixelPoint` 读出的领口高度加了种子并上调了框，`close` 0.10；迦叶右翻领的青色用 `stops` 挡住；拘留孙、毗舍浮、拘那含颈根那圈**赭黄线是衣缘描金的圈**（#701 新掩码带来的，不是配方），金边的框上沿下移到领口以下。
3. **手**：尸弃贴胸的手、拘那含举手等的手掩码加了边缘增益（`gain` 2.4，`blur` 0.008），指背的红边收了。
4. **尸弃下半张脸发花**：查了，不是皮肤层：同机位灰模里颏下就是一圈细碎的起伏（M40b 的下巴几何）；上色没有别的层混进去（`folds` 关、`masks` 关、灰模四张对比）。没动几何。
5. **眼缝**：是 AO 加深的：AO 关与开的对比里缝线明显变细；不再整个关掉，把 AO 强度降到 0.4（`aoi`，页面地址与 spec 的 `aoi`、`t05-gpu.sh` 的 `AOI`）。
6. **aisle55**：机位改到殿中半步外、抬高：[X+3.0, 5.6, −7.4] 看 [X, 10.0, −18.1]（另一个试位 [X+3.4, 4.6, −8.8]），邻座的莲座退出前景，邻座是整尊的像（软件图 `df9`）。
