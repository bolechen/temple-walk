# #701：举起的手，皮肤止于袖口的布边（软件自检，2026-11-25）

总监复看 #743（头 `5dbc6963`）：领口的绿、划痕过；手没过：肤色到袈裟红的分界落在手上（拘留孙掌根外侧与虎口下一条直斜线、拇指侧一小块红；毗舍浮腕部一道宽渐变、腕下半截发粉；拘那含手背靠腕偏红褐、食指根一道红细线）。要的是：皮肤一直到袖口的布边为止都是肤色，分界就是袖口那道几何的边，硬的、跟着布走。

## 做法

不再用手摆的胶囊去定分界。前臂本来是裸的，一直伸到袖口，袖子的边是网格自己的折痕。用 `mask.py` 从网格自己的法线图里长出来：从手背、掌心、前臂上的种子，沿法线连续的地方长，到折痕（袖口、袖子的褶边）就停，再轻轻模糊 5 mm（所以边是硬的）。步骤：

1. 用新网格重画三尊的前视法线与深度图，范围放宽到 x ±2.5、y 2.7–7.7 m（举起的手在 x −1.6 一带，原来的 ±1.5 装不下）：`specs/t05-arm-normals-b.json`。
2. 重新生成前视掩码（`paint/masks/<尊>-front-c.png`，`masks/<尊>-front-c.json`）：领口的内衣、描金、拘留孙的袒露的胸照旧，**新加一条并入皮肤通道的「举起的手与前臂」**（`mask.py` 新加 `union`：同一通道里并上一个区域）。配方里肤色区本来就读前视掩码的这一通道，**配方没有改**；原来的手上的胶囊保留（管手指和手心这些细处），它们都落在皮肤里，不再单独决定分界。
3. 我也试了加一张右侧视的掩码，它把前臂旁边袖子的褶面也染成了肤色，去掉了，只用前视的。

## 看到的

`raised-arms-before-after.jpg`（证据集 `t05/701-paint-r10/png/`，git 里是缩小的一张）：每尊四格：改前（T4 run `t05-20261125-200622` 的交界图）、改后同机位（软件）、改后举手近景、改后肤色分区平涂绿。三尊的手与前臂现在是一个肤色一直到袖口，分界是袖口、袖边的几何边，硬，没有渐变，手上没有分界线。

没做到的：拘那含前臂外缘还有一条很细的肤色落在袖子的褶边上，拘留孙前臂外缘有一小块同样的；都在袖边的一条褶上。另外这次没有重新量唇、内衣色相（掩码只动了前视图的范围，领口那一路照旧）。

## 没做

没有动几何、法线、配方，没有开 T4；`png/` 里的图是软件渲染（冬昼、灯 45、环境光 0.6、曝光 3.2；近景无灯、曝光 4.5）。
