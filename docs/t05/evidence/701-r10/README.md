# #701：上半脸里的线有多深（总监说眉间到鼻根的沟、下睑下一道横纹、外眼角放射纹，像几何里就有）

`collage.jpg`：三尊（拘留孙、毗舍浮、拘那含牟尼）倾斜后的全分辨率脸，正面的「浮雕」图：每点的前表面深度减去它自己用 σ = 15 mm 的高斯模糊后的深度，亮是脊、暗是沟（`tools/t05-statue/relief.py`，射线 5 mm 一格，灰度 = 128 + 12 × 深度差毫米）。

## 看图

- 图里最亮最黑的是睑线、眼窝边、眉弓、鼻翼——结构，不是线。
- **眉头沿鼻梁两侧到鼻翼上方各有一条暗的下行带**（三尊都有，拘留孙、毗舍浮更清楚）：那是眉弓的脊和鼻梁之间的谷，几何里确实有，不只是法线上的细毛。
- **下睑下一条很淡的暗弧**（拘留孙、毗舍浮、拘那含牟尼都有，很浅）。
- 外眼角：眉弓与睑线在外角处收拢，那里有一小团暗，放射纹（细）在这个模糊半径下读不出，说明它是更细的东西。

## 数（`relief.py`，σ 15 mm 与 σ 50 mm，各四块；model mm = 文件单位 × 1000，舞台毫米 ÷ 8.45）

- σ 50 mm 的最深沟（舞台 mm）：拘留孙 眉头到鼻根 −50.8、眉间 −12.4、下睑下 −50.8、外眼角 −37.3；毗舍浮 −37.8 / −12.7 / −37.8 / −34.9；拘那含牟尼 −33.4 / +3.1 / −33.4 / −23.8。
- σ 15 mm 下（模型 mm）：拘留孙 −6.44 / −0.12 / −6.60 / −6.92；毗舍浮 −3.64 / −0.42 / −5.89 / −5.66；拘那含牟尼 −2.52 / −0.10 / −3.05 / −3.45。
- **这些数不能当「线的深度」用**：四个盒子都框进了睑线与眼窝的边（−50 mm 级的是它们，眉头到鼻根与下睑下两块最深值相同，就是同一个眼窝边），盒子分不开线和结构。「眉间两道沟」只有「眉间」那块（中线两侧 0–5 cm）量到的 −0.1 到 −0.4 model mm（拘那含牟尼 +0.4，没有沟）；沟在中线外 2–14 cm，被眼窝边的数淹没了。要量线本身，得先把睑线和眼窝边遮掉。我没有做这一步。
