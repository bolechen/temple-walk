# #701 第二轮：调下巴（只试了拘留孙）、写改脸的闸、查锚点缺 `eyeL`

软件渲染石膏色，只看形；光色要 T4。以下「看图」是我的判读，不是美术总监的判。

## ① 下唇下的圆垫：试了五次，没有一次让仰看里的圆垫变样 —— 没过，也没铺到另两尊

`tuning.jpg`（上行仰看 10 m、下行侧面；拘留孙；按列是 f2、g1、g2、g3、g4、p35）。每个变体改了什么（数都是「自拟」，没有造像依据，只是把现有配方的旋钮往同一方向拧）：

| 变体 | 改了 | 看图 |
|---|---|---|
| g1 | 下巴 `scale` 深度 0.68→0.5，半径 1.0→1.1，中心 0.45→0.6 w；`fill` k 0.5→0.8；`lipsFwd` 0.033→0.015 | 与 f2 几乎一样 |
| g2 | 下巴深度 0.3，中心 0.35 w，半径 1.2；`fill` k 1.0 | 与 g1 几乎一样 |
| g3 | g2 + 嘴深度 ×0.8，`lipsFwd` 0 | 嘴更薄，圆垫还在 |
| g4 | g3 + 下脸横向 ×0.85、`underJaw` 1.0、`jaw.d` 0.03 | **更差**：耳垂与颈起了折，侧面出现横带 |
| p35 | g3 + 一个 `push`：圆垫中心向后 3.5 cm（半径 0.30 m） | 侧面下巴稍收；仰看圆垫仍在 |

我的判断：仰看里下唇下那一块圆垫，是 Tripo 头本身下半脸（下唇 + 颏 + 颌）连成的一团，现有的嘴、下巴 `scale`、`fill`、`lipsFwd` 管的是它的局部，管不到整团。再往下做要换手段（比如一个按锚点的整块后移加平滑，或重出），那是 3D 评审和美术总监的决定，我没有往下试，也没有在另两尊上花时间。**不要把「f2」当成过了验收第 1 条**：它只是方向对。

## ② 改脸的闸：`tools/t05-statue/closed/face-gate.py`（单测 `tests/unit/face-gate.test.mjs`）

和 `gate.py` 的区别写在 `closed/README.md`。拘留孙 r3 → f2：12 项全过（脸区以下最大位移 0.23 mm ≤ 1 mm；面数不变；开口边、非流形边、碎块与改前相同；背面射线六个机位都是 0）。只在拘留孙上跑了，另两尊没跑。

## ③ r3 的 210 条开口边（照实记）

原件（`02-krakucchanda.base_model.glb`）开口边 0、碎块 0；r3 有 210 条开口边、105 个 ≤10 面碎块（面数少 210：1,463,014 → 1,462,804）；f2 与 r3 完全相同。**不是这次造成**，来自 r3 的修形步骤（`repair.json` 的 `squeeze`、`zband` 等对点的搬动与导出；我只比较了结果，没有逐步查是哪一步）。这违反「先闭合、过 gate.py 再上色」。本 PR 不修，闸只保证不增加。只量了拘留孙；另五尊没量。

## ④ 锚点缺 `eyeL`：不是缺点，是 `face-build.py` 的搜索窗没盖住

三尊的 `*-t05.json` 里都有 `eyeL`、`eyeR`。`KeyError` 出在 `face-ratios.py` 返回的 `eyes` 为空：它在「把头前倾转回去」的坐标里，以我们给的猜测点为中心（−0.12 到 +0.08 m）找眼窝的台阶；`face-build.py` 给的是已前倾的猜测点，拘留孙的颈支点较低、前倾把眼往下带了 0.15 m，窗口没盖住真实的眼（7.01 m，猜测 6.87 m）。毗婆尸的恰好盖住。办法（已做）：猜测没找到眼时，用前倾前的眼点再找一遍（`face-build.py`，毗婆尸的路径不变）。结果：三尊的锚点都出来了：`tools/t05-hall/paint/<尊>-f2.json`，睑 y 拘留孙 7.016/7.021、毗舍浮 7.19/7.183、拘那含牟尼 6.979/6.974（睑与眼点相差不到 1 cm，合理）。**这些锚点是 f2（未过验收的形）的，不要拿去重上色。**
