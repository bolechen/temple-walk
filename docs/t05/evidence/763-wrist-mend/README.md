## 怎么拍的

- 软件渲染（SwiftShader），不是 T4；页面 `?level=t05&hall=open&shot=1&q=high&season=winter&time=day`，1280×720。**殿里的灯是 #763 分支自己的（没有 #762 的补光）**，所以整体很暗；拼图为了看清，改前改后一样提亮了 1.8 倍，原图没有提亮。颜色不能拿这组图判，只看形。
- 眼的位置按像自己的坐标（米，座底为 0，面朝 +z）：西廊 `(−4.05, 0.2, 2.6)`，坛前 `(−1.95, 0.2, 3.1)`，都看向腕 `(−1.85, 3.58, 1.38)`。`w` 是西廊、`f` 是坛前；`0` 视角 40°，`1` 视角 22°，`1z` 视角 9°（推近，访客的眼不会这么近，留影推近能拍到）。
- `-old`：数据集 `ship-701/sakyamuni.glb`（sha256 `589ac283…ddd4`）；`-new`：`ship-763/sakyamuni.glb`（`c7b39460…c859`）。其余六尊没有动。
