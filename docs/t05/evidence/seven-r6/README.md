# 七尊第六轮：分区从网格自身取边（#370）

2026-11-21。主创看第五轮后指出：胸衣是一块直边直角的矩形，像贴了一块板；衣缘的方头、肩上的直线分界也是同一类问题——用包围盒画分区，边就一定是直的。这一轮换了分区办法。模型同第三轮（r3），帧耗不变。

## 办法：从正投影的法线图上长出掩码

1. `tools/t05-hall.cjs` 画像的正投影（正面、背面或右侧面），一张是法线（不带格子，`"grid": false`），一张是深度（`"depth": true`：像自己坐标系里朝眼睛方向的深度，灰度 (深度 + 3.5) / 7）。
2. `tools/t05-hall/mask.py` 从几个种子点出发，在法线图上逐像素生长，相邻像素的法线差超过 `tol` 就停。网格在领口的棱、袈裟边压在内衣上的那道褶、束带上都会断，所以区域的边就落在这些地方。两块之间没有干净的断口时（毗婆尸的胸衣顶到脖子），用两边的种子在法线变化的强度上对长（`watershed_ift`），在最强的那条线上相遇。然后闭合 3 cm（盖过束带上的细线）、填洞，边缘高斯模糊约 1.2 cm，过渡 2–4 cm。贴边看不到的面（像的侧面）把区域往空背景里外扩几厘米再模糊，免得被模糊淡掉。
3. 掩码 PNG 的 R 是袒露的肤（释迦），G 是衣缘描金（R 区外沿 6 cm 的一道，限在前襟），B 是胸衣，A 是这一面看到的深度。
4. `tools/t05-hall/paint.js` 的新叶子 `map`：把掩码从它那一面投到像上，只给朝那一面、并且就是那张图看到的那层表面（比深度靠后 6 cm 以上的不给，掠过的面放宽），所以前臂的掩码不会落到后面的衣褶上。

## 用在哪

| 像 | 区 | 掩码 | 以前 |
|---|---|---|---|
| 拘留孙、毗婆尸、拘那含牟尼 | 胸衣 | `paint/masks/<尊>-front.png` 的 B | 盒子 |
| 释迦 | 袒露的胸、肩、右臂（正面） | `sakyamuni-front.png` 的 R | 半空间 + 椭球 + 胶囊 |
| 释迦 | 衣缘描金 | `sakyamuni-front.png` 的 G | 两个平面夹出的一片 |
| 释迦 | 袒露的背（背面） | `sakyamuni-back.png` 的 R | 六段折线（六个盒子各配一个半空间） |
| 释迦 | 右侧腋下（正背面都被手臂挡住的那一片） | `sakyamuni-right.png` 的 R | 椭球 |

每张掩码怎么生成写在 `tools/t05-hall/masks/<尊>-<面>.json`（种子、限框、阈值、闭合、模糊），`python3 tools/t05-hall/mask.py <json>` 可复现。
