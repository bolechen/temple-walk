2. **迦叶**：蓝 V 的上沿接到颈上，没有橙色的缝；两个领角的橙块没有了（上沿加了种子，颈上加了止点）。
3. **毗舍浮**：蓝带左上的粉（衣缘描金的黄边）撤了——毗舍浮的金边通道整个撤掉；右侧被切进来的方红补上了（种子跨过）。
4. **毗婆尸**：领口上沿那一抹橙补成蓝，蓝块上沿接到颈。
5. **释迦**：斜披袈裟上那条蓝（原来是一个椭圆的内衣区）整个不要了（`innerC/innerR` 等锚点删掉），袒露的皮肤和袈裟的边就是袈裟的折；肩上的一小块黄也撤了。
