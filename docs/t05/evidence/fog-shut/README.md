## 门洞与墙的亮度比

量法：眼高 1.6 m，用 `__look` 立在院子中轴上，看当心门。把三樘门的门洞和两尽间的墙面按相机精确投影到屏上，各取 7×7 个点，用 `__probe` 读色，算平均亮度。脚本是一次性的，不在仓库里。

| 情况 | z = +44（新 A 站） | z = +55 |
|---|---|---|
| #425 第三轮（殿内遮蔽 15%、补光 10，雾照旧） | 0.93 | — |
| 本 PR（雾盒、殿内遮蔽 6%、补光 0） | **0.58** | **0.48** |
| 殿内整个换成纯黑体块（只为量下限，没有提交） | 0.32 | — |

纯黑体块那一行是下限：门外四十多米的空气照样把门洞抬亮。所以 A 站在 J01 的雾里，比值到不了 1/4。
