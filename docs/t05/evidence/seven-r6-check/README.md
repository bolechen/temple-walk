# 第六轮的两项补测：掩码的帧耗、低档 LOD（#370）

2026-11-21，主创在交 Fable 美术把关前要的两项。

## T4 帧耗：掩码开和关

run `t05-20261121-055200`，Tesla T4（ANGLE/Vulkan），站点 `d86cf10`（干净），`gpu-report-masks.json`。七尊上色，殿内三个视角；高档 1920×1080 开 GTAO，低档 960×540 不开 AO。「关」是同一份代码 `paint({ masks: false })`：掩码的叶子拿不到锚点、直接返回，其余分区照旧。开、关交替各量两遍（同一个 Job，暖机和漂移两边一样），每次 120 帧取平均（`window.hall.cost`）。

| 档 | 视角 | 关（第 1 / 2 遍） | 开（第 1 / 2 遍） |
|---|---|---|---|
| 高 | door3 殿门内 | 8.12* / 5.32 | 5.41 / 5.47 |
| 高 | cam06 中轴 | 5.04 / 5.12 | 5.07 / 5.22 |
| 高 | front10 佛前 10 m | 5.19 / 5.38 | 5.41 / 5.46 |
| 低 | door3 | 1.22 / 1.54 | 1.85 / 2.08 |
| 低 | cam06 | 1.44 / 1.65 | 1.32 / 1.56 |
| 低 | front10 | 1.35 / 1.05 | 1.09 / 1.24 |

\* 这一组第一个量的，卡还在暖机，不计。

均值：高档 5.21 → 5.34 ms（+0.13 ms），低档 1.38 → 1.52 ms（+0.15 ms，同一格两遍之间的抖动有 0.3 ms，这个差在噪声里）。PRD 第 7 条的线是高档 ≤ 12 ms、低档 ≤ 6 ms。

## LOD：2 万面、6 千面两档

`lod20000-sheet.png`、`lod6000-sheet.png`（collage.jpg 上下两半）：每张第一行是三尊胸部的殿内暖光近照（拘留孙、毗婆尸、拘那含牟尼），第二行是释迦的正面、右侧、背面和暖光半身，右上是七尊排开。掩码、锚点都不改，只换模型文件。

- 2 万面：掩码和 6 万面一样贴在原位，胸衣的侧边、下沿、释迦袒右的分界都没错位。
- 6 千面：没有错位，但边界跟着网格变粗。毗婆尸胸衣的上沿在脖子下面成一段折线，释迦右肩前有一个小红点。这一档是最远的一档，殿门 24 m 外才用，在那个距离上看不出来。
