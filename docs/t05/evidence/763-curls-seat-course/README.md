## 改了什么

| 项 | 改前 | 改后 |
|---|---|---|
| 螺发颜料 | `#23394F`（Lab 23.2 / 16.1 / 265°） | `#283D4D`（24.7 / 12.8 / 255°） |
| 莲座颜料 | 下层 `#483F35`、上层 `#483D32`（Lab 27 / 8–9） | 下层 `#604B36`（33.5 / 16.9 / 70°）、上层 `#614933`（33.0 / 18.5 / 68°），带一点旧漆的深浅；中尊的座另乘 1.6 |
| 座下 | 每尊一块 5.39 × 4.12 × 0.4 米的石台，没有 `ao`；像在佛坛中线前 0.3 米 | 佛坛上通长的一层石台（比坛沿每边收 5 厘米，高 0.4 米）；像退回佛坛中线 |

座下的原因是量出来的：莲座底的直径 4.4–5.0 米，佛坛深 4.8 米（连坛沿 5.1），像又靠前 0.3 米，七尊的莲座前沿都探出佛坛正面 0.1–0.4 米；石台比莲座浅，整块落在座的影子里，又没有 `ao`，灯照不到的地方是纯黑；那截「黑柱」是相邻两块石台之间 0.14–0.41 米宽、4 米深的槽。
