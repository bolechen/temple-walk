## 我自己看的（不替美术总监判）

- **A、B 东西**：墙头上现在是一排低屋面夹着松、柏和落叶树，屋面坡在树间看得见，读得出「树后是人家」；上一版的一排排圆锥和暗色实心的东西没有了。
- **C、F 朝南**：不再是一道实心树墙，是屋面坡、柱状柏、扁层的松混在一起，天从层间透出来；但这一带的高度还是一个量级、疏密也相近，我认为还比较「平」，请美术看。
- **松**：我第一次画的松，树干到半截就停，从 A、B 看四五个扁盘飘在空里像飞碟；这一版让树干一直通到顶，层压在干上。近看（到达点）读成松，远看读成「几层平顶的树」。
- **到达点**：这一处我没有主动动，但树种换了（锥形的杉没有了，换成松、柏、落叶树），「街对面的人家」的屋的位置没变；请美术确认还是读成那个意思（上面图里「到达点西」）。
- 白盒，不判材质。
