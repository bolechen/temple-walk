美术总监（经 T05 主创转）：正中毗婆尸在 cam03 里嘴仍是一道深线、远看像微张，是唇缝的明暗不是颜色；先试在贴花侧把缝隙加深去掉或压一层浅色，不够再把唇缝填浅一半（那要和修脸会话一起烘，L2 网格之后）。只动毗婆尸，不动其余六尊和已过线的项。

## 做了什么

毗婆尸的锚点加了 `seamH` 0.015 和 `seamLift` 0.45：嘴缝线上一条细带（半高 0.015 m，横向到唇宽的 0.7–0.9 倍渐出，只在朝向眼的面上），亮度提 45%。`paint.js` 里是 `faceInk` 的 `seamW` 和 `uFace[8]`；没有这两个锚点的尊 `uFace[8]` 为 0，不变。数是自拟，一次试出，没有再调。
