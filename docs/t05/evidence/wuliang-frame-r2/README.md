结构评审回复（session_01Cq65vHdW3DqaTtb3EXX5YP）：白盒用彻上明造可以，不加平綦；读了卷 05、卷 08 原文，没读代码和图。核到的：
1. 《法式》卷 08「凡平棊施之于殿内铺作算桯方之上」，平棊施在殿内；卷 05 平棊与彻上明造并存，由屋的需要定，**没有一条讲穿堂**；

## 这一轮改了什么

- 下栿 0.45 × 0.78 m（四椽栿 50 分°）、上栿 0.45 × 0.65 m（三椽栿 42 分°），宽取深的三分之二；原来是 0.3 × 0.5 m 的提案。
- 椽 0.15 m（9–10 分° 之间）；原来 0.12 m。椽架平 1.77 m，在 1.86 m 的上限之内（卷 05 的数）。
- 栿都沿殿深（前后）放在 x = ±2.07、±5.57 的柱缝上，**不横跨通道**，与结构评审的建议一致；横跨通道的只有檩（檩必须横过）。
- 穿堂上方最低的木头离地 4.47 m（原来 4.69 m），单测要求 > 4.2 m。
