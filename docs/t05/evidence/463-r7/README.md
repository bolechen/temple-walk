## 改了什么

- **前倾 10°**：沿用 r6 的 10° 版。
- **唇的体积**：保留饱满（衰减 k 0.6），不刻沟；下唇略厚于上唇。
- **嘴周的框、人中垫、贴花的光晕**：
  - 上唇两侧那道 1–2 cm 深的沟（框的来源）由 `face-ops.py` 的新步骤 `frame` 在嘴缝上 0.05w、0.2w、0.35w 三个高度各找最深处，往前推 0.8 倍深。近景里框大半没了，嘴角外侧和人中两边还留一道浅竖线。
  - 有两处量到的深度是 4.7–7.4 cm，比网格上量的沟深得多，可能碰到了颊沟或鼻翼，3D 评审请看这一处的形。
  - 人中垫衰减到 0.2；贴花不再有光晕，边缘约 2 mm。
- **嘴宽**：按原型比例 0.29–0.31 做（美术总监已撤回「鼻翼的 1.2 倍」），贴花半宽取脸宽的 0.15。
- **唇色**：赭红 `#6A4239`。在 0931a54 上用 10 m 仰看、漫射光量过：屏上色相 12.7°，亮度为脸的 0.69，饱和度比脸颊高 0.17，都在目标里（色相 10–14°，亮度 0.6–0.7，饱和度高 0.15–0.2）。这一轮贴花形状改了，颜色没改，没重量。
- **贴花盖住上唇**：r7 第一版只盖了下唇，上唇雕出的部分是肤色，读成一圈框。现在从下唇最前点以下 1.2 cm 到嘴缝以上 3.5 cm。再往上到鼻底算人中，不上色。
  - 舞台比我的量法高 1.5 cm，是从近景里读出来的，已经补上。
  - 贴花是椭圆，两端比雕出的唇尖略圆、略出，还不算「紧贴」。
- **鼻下的棱、下巴、颏唇沟、下半脸**：
  - 下巴并入两颊（横向 ×0.9，深 ×0.68，下移 0.45w）；
  - 下颌线两侧上提；
  - 颏唇沟填 0.5，留浅；
  - 颧骨以下横向收到 ×0.95。
- **嘴角**：不低于下唇中点。
- **乙的眼睛**：上睑线下画窄窄一条眼白、一点深色瞳孔，只画不改形；第二道睑褶淡掉。
- **侧面的眉、睑线**：面朝前的程度（n.z）在 0.35–0.65 之间渐隐。
