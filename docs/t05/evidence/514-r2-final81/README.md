## 可重跑（第 2 条）

同一输入跑两次，**输出不是逐字节一致的**：

- 两次的点数、面数、面的次序完全相同，点的坐标最多差 0.4 µm；和第 81 版的文件比，最多差 0.7 µm。
- 不一致从两步开始：
  - 腕口收进前臂那一步：用 Blender 的 `mathutils` BVH 找最近点，是单精度；
  - 前臂内衬那一步：用的是 Blender 算出的顶点法线。
- 把 OpenBLAS / OpenMP 限成单线程，结果没有变。
- 没去修，是因为所有者接受的就是第 81 版这一份。改成双精度会让形移动约 1 µm，第 81 版的字节就对不上了。

## 补块和内衬对几项量的影响（照实写）

第 69 版加补块之前，这三项都过：开口边 0、腕口边全在前臂表面下 7.9–11.1 mm、缝带碎片 0。第 81 版：

| 量 | 第 81 版 | 原因 |
|---|---|---|
| 臂旁开口边 | 18 个点，离未动的面 39–48 mm | 内衬和扇形封口自己的边 |
| 腕口边离前臂表面 | 最浅的高出表面 5.5 mm，有 10 个点不到 5 mm 深 | 扇形封口的边落进了这项量的范围 |
| 缝带里不足 50 面的碎片 | 59 | 拐角内衬把原件的小碎片也复制了一份，加上扇形封口的碎边 |

这三样都在腕后那个角里，正是 #578 要解决的。
