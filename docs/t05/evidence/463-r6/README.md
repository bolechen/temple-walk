## 改了什么

- **嘴周一圈棱、鼻底到上唇的卷边**（3D 评审第 1 条）：嘴的深度位移用单独的半径 2.3w（形状的半径仍是横 1.3w、竖 0.6w），从鼻底到上唇最前点逐渐加满，人中一路往后收到鼻底。仰看时那圈棱比 r5 浅了，卷边还看得出来。
- **唇色比雕的唇窄**（第 2 条）：唇的贴花盖满雕出的唇，上缘到上唇最前点以上 2.5 cm，下缘到下唇最前点以下 1.5 cm，宽到量出的嘴角，边缘约 2 mm 软过渡。颜色仍用美术总监判过的 #6B5144，没再调深调暖。10° 那版贴得紧；15° 那版下缘还多出一点。
- **下巴垫像个球**（第 3 条）：下巴横向 ×0.9，深度不再多压（仍是 ×0.68）；下颌线两侧各上提 0.01 倍脸宽。
- **嘴宽**：美术总监要约鼻翼的 1.2 倍，鼻翼宽约 0.30 m。网格横向 ×1.03，量得嘴宽 10° 版 0.375 m（1.25 倍）、15° 版 0.36 m（1.2 倍）。嘴宽/脸宽两版都是 0.364，略超释迦原型 +15% 的上限 0.358，毗婆尸原型上限 0.335 也超了。这里照美术总监的倍数做，超出原型的部分写明，由两位判。
  - 第一次横向放 1.12，量得 0.38，太宽，就收了回来。
- **螺发的三角亮块**：r5 时我说「亮块没了」，**不对**。r5 发出的平视和仰看都是烘后的文件，亮块还在。原因不在法线，在我第一轮加的衣褶磨损：它用屏幕空间导数算曲率，小螺髻上逐个三角形发亮。现在衣褶的明暗只用在袈裟和莲座上，r6 的图里亮块没了。
- **配色、眼线、鼻孔、头单独一张图**：沿用 r5。

## 漫射光对照

r5 和 r6 都出了漫射光的仰看（只有半球光，日光、门的光、地面补光、灯都关掉）。r5 在漫射光下仍读成撅嘴，所以问题在形，不在殿内的光（T05 主创的判断）。r6 在漫射光下嘴比 r5 平，但仰看时还是像一小块凸出来的，下巴也还鼓。照实写，要两位看图判。
