## 做法：`repair.py` 的新操作 `lowerback`

下半脸整块向后（+y）推 `d`，权重是三个平滑阶梯的乘积，**没有横向缩放**（g4 的耳垂与颈折线来自横向缩放）：

- 高度：从嘴缝下 0.0046 个文件单位处起（上唇与嘴缝不动），到嘴缝下 0.0416 处全量，再往下 0.025 渐到 0（拘留孙：z 0.772 → 0.735 → 0.710；约在颈的头线 z0−fade 之上）；
- 横向：中线 0.19 m 以内全量，到 0.42 m 渐到 0（耳在 0.45 m 以外）；
- 前后：只动颈轴线（`-neck.c[1]/s`）之前的点，过渡 0.012；
- 之后对被移动的点用邻点均值松弛（权重同上场，`lam` 0.5，`iter` 次），不让场的边缘留下棱。

数都是「自拟」，没有造像依据：后移量与松弛次数是试出来的，只按「圆垫不再读成深口、嘴缝与下唇还在、耳垂与颈没有折」判。
