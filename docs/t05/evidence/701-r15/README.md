# #701：出货姿势的头（拘留孙），总监对 dc28ce4 的判语之后

灰模，软件渲染，没烘法线。`collage.jpg`：上排 站直、嘴的高度、900 mm 正视：r3c / 出货 10° / 出货 14°（头倾回）；下排 10 米、高 1.2 m 略仰：r3c / 出货 10° / 出货 14°。

## 做了什么（`tools/t05-statue/face-ship.py`，一条命令出 `repair-S10.json`、`repair-S14.json`）

r3c 的原操作 → 头前倾 10° 或 14° → **没有 f2 的脸操作**（嘴缩放、下巴缩放、`fill`、`flatten`、`lipsFwd`、`facex`、`depthk` 全不要），所以唇、眉、鼻、眼都是 r3c 倾斜后的 → L4 的颏（`chinshape`，k_groove 0.85、arc_keep 0.5、颏尖后 9.5 mm、横向钟形 0.40 m；新参数 `chin_shift` 0.015 m：颏处的补凸中心比颏尖低 1.5 cm，从下看颏的上沿弧放缓）→ 鼻唇沟与木偶纹用 `flatblocks` 淡到 0.4（**只在唇之外**：唇的盒子是 |x| < 0.145 m、口裂上下各 4.5 cm，块从盒子外起、软边 2 cm）→ `mouthlift` 24 mm。

## 看图（我的判读）

- 10 米略仰：r3c 的撅与苦相很重（上唇突、下唇圆鼓、颏像第二片唇）；出货 10° 与 14° 的嘴读成一条平缓的线，唇仍在，颏是一个圆面、没有再像第二片下唇；14° 比 10° 更松。**倾斜就解决了大部分「从下看」的苦相**，几何的改动可以少。
- 站直平视：**下唇和 r3c 不一样**——r3c 的下唇是一块完整的圆垫，底下有一道深的影；出货版的下唇变成一个略斜的月牙，底下的影淡了。原因是 `chinshape` 把下唇底到沟底的陡落缓下来（总监认的侧面：沟深优先，arc_keep 不提），正面就读成下唇薄。「唇一点不抹」做到了上唇和口裂（它们是 r3c 的）；下唇的圆垫在正面比 r3c 弱，是沟变浅的代价。
- 出货版口裂两端略不对称（视图左端略高）：`mouthlift` 本身左右对称，是 r3c 的唇原来就有一点不对称。
