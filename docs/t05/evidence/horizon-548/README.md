# #548 墙头以上放什么：三个方案的示意图

美术总监，2026-11-21。给 #548「T05 墙头以上只有天」选方案用。**这是示意图，不是成图，也不是游戏里的画面**：在三张真实的白盒截图上，用脚本把墙外的东西按关卡自己的米数摆好，再按那张截图的镜头投到屏上。所以每样东西在屏上的大小和被墙挡住多少是真的，画法（树的形、屋顶的样子）是示意。

## 这张图说明的事（都是几何，不靠画法）

- 院墙高 3.2 米，离 A 站 42 米，墙头在眼睛上方 2.2°。**站在院子里，仰角 2.2° 以下的东西全被墙挡住**：远处的屋顶、山影都看不见，看得见的只有紧贴墙外的高东西（树、头一排屋脊）。
- 上了月台，眼高 4.6 米，高过墙头，地平线露出来：这时才看得到一片屋顶和远处的塔。
- 远塔离月台约 940 米，方位 241°（西南偏西），塔顶仰角 2.2°，1080 线上约 48 像素高。从院子里只露出塔尖 0.2°–0.5°。
- 墙外贴近的松柏高 8.5–13 米时，在院子里占墙头以上 9°–15°。
