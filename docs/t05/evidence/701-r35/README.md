# 701-r35 · 毗婆尸：「嘴角以内取改前、嘴角以外取 VPD」的拼法（总监对 701-r33）

灰模，一盏棚灯，只看形。`collage.jpg` 四列：改前（B4H10）/ VPD（701-r33）/ **VPF**（拼法一）/ **VPG**（拼法二，更强）；上排 10 米，下排侧廊斜看。

## 做法
总监的拼法：嘴角以内（两嘴角之间、鼻底到颏沟）整块取改前，一点不动；嘴角以外的脸颊（嘴角外 1 cm 起）取 VPD 的：鼻翼斜下来的沟在脸颊上的一段抹浅、嘴角窝减半；块子的软边落在脸颊平处；不做 mouthlift；不要 uplip、不抹人中。
- 先查了为什么 VPD 把唇弄坏：`face.json` 的嘴角在 x = ±0.25 m，而我上两轮的「鼻唇沟」块子（x 0.115→0.135 m）和「嘴角窝」块子（x 0.155→0.175 m）都落在**两嘴角之间**（鼻底下、唇上），不是脸颊上的沟——它们抹的是唇框和唇红的外圈，这才是 VPD 在 10 米上唇线化开的真正原因（总监说的 uplip 与人中是加重因素）。拘那含的 K1/K1L 也用了这两个块子（同样在嘴角之间），**拘那含的脸总监已经认了，我没动**，但这一点要让你们知道。
- VPF：块子挪到嘴角外：鼻唇沟 `--nl=0.3 --nl-x0=0.27 --nl-x1=0.29 --nl-z1=0 --nl-r=0.025 --nl-soft=0.04`，嘴角窝 `--corners=0.5 --corners-x=0.28 --corners-r=0.02 --corners-soft=0.03`；VPG：`--nl=0.2 --nl-x0=0.24 --nl-x1=0.29 --nl-r=0.03 --nl-soft=0.05`、`--corners=0.4`。

## 看到的
- 10 米：VPF、VPG 的嘴和人中与改前分不出（嘴角以内没动，达到了）。**脸颊上多了一道细竖痕**（图上左颊，从鼻翼斜下），VPG 更明显、还有一块抹糊的斑：块子的软边在脸颊上留了痕。
- 侧廊斜看：VPF 的沟比改前略浅，**仍是咧的**，不像 VPD 那样松；VPG 更浅但脸颊的痕更重。
- 结论（总监的判法）：「若拼出来侧廊又咧回去，就直接用改前」。**我的判断是用改前**：VPD 的松来自嘴角之间的块子，而那恰是弄坏正面的部分，两者分不开；嘴角外的块子只能得到很轻的松并带来脸颊痕。
