## 根因（做出来的）

- 不加任何操作，只让 `repair.py` 导入再导出拘留孙原件：旧的焊点容差 1e-6 把相距几微米、不在同一条缝上的点焊在一起，塌掉 210 个面（1,463,014 → 1,462,804），开口边 0 → 210，非流形 0 → 210。与配方无关；与「删退化面前没先合并共点」那条推断也不一样（没有零面积面，`validate()` 前后不变）。

## 更正

05f0344 里的 repair.py 把「1e-8」的注释接在 `remove_doubles` 那一行后面，同一行里的 `print`、`bm.to_mesh(me)`、`bm.free()` 被吃进注释，**那一版根本没焊点**。「r3c 闭合」只是因为没焊：纯位移的 squeeze/zband 在没焊的网格上各缝一致地动。一做按连通域的脸操作（`attenuate`、`push` 的洪泛区），缝就裂（拘留孙 L2 开口 486、毗舍浮 398、拘那含牟尼 696；`face-gate` 抓到，二分在 attenuate 与第一个 push）。现已修对，那一版的哈希与桶里文件作废，已用新文件覆盖，登记行替换。

## lowerback 接进 face-build，三尊 L2 烘好

- `face-build.py <尊> L2 --tilt=10 --recipe=tools/t05-statue/face/recipe-L2.json --anchors-from=tools/t05-hall/paint/<尊>-t05.json --colour=<尊>-L2 --measure=<f2 的 glb>`：配方里的 `lowerback` 块按各尊自己的嘴缝与颈轴线铺开（`recipe-L2.json` 在 `recipe.json` 之外只多这一块：后移 1.8 cm、横向 0.19 m 全量到 0.42 m 渐出、从嘴缝下 0.0046 起到 0.0416 全量、再 0.025 渐出、松弛 12 次）；减面 6 万 / 2 万 / 6 千；Blender 烘法线（2048²，同毗婆尸的口径 `--cage=0.0012 --ray=0.0025`，头单独一张）。
- `--measure`：`lowerback` 动了嘴缝以下的肉，`face-ratios.py` 找嘴角的凹痕（嘴缝上下 4 cm）读到的是另一张嘴，所以唇与眼睑的量在没有 `lowerback` 的同尊（f2）上做。**f2 是旧焊点（未焊）版本做的**，嘴缝以上与 L2 相同，我没重做它。
- `face-gate.py`（r3c 为前，L2 为后）：三尊 12/12 过，朝向严格；脸区以下位移 拘留孙 0.23 mm、毗舍浮 0.29 mm、拘那含牟尼 0.65 mm；开口边、非流形、碎块都与 r3c 相同。
- 锚点：`tools/t05-hall/paint/<尊>-L2.json`（前倾后、`lidL/lidR` 用 `eyeL` 回退、`lipH/lipHalf/mouth` 取自 f2 的量）。**`jawMin`、`chinMin` 随嘴的下移已跟着动，但下巴后移 1.8 cm 本身没有重算进锚点**；`lipH` 0.66–0.71 是旧量法在三尊上不可信的那个数（见 701-r2），上色会话的唇区按它自己的 `lipAt` 重点。
