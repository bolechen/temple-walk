## 内衣色相（#463 的线：色相 125–145°、彩度 ≤0.25）

按总监说的加了 cam06（和 cam03、cam04）进软件配置（`specs/t05-paint-701z.json`）。在屏上量（无灯，`measures-cam-env06.md`、`measures-cam-env16.md`）：

| 尊 | cam06 色相°，环境光 0.6（现在用的） | 彩度 | cam06 色相°，环境光 1.6（#463 旧口径） | 彩度 |
|---|---|---|---|---|
| 拘留孙 | **147.1** | 0.244 | 133.8 | 0.200 |
| 毗舍浮 | **147.6** | 0.239 | 135.2 | 0.203 |
| 拘那含牟尼 | 144.8 | 0.242 | 130.9 | 0.197 |

**环境光 0.6 下拘留孙、毗舍浮的色相越线（147°，线 145°），拘那含牟尼在线内（144.8°）；彩度都在 0.25 内（0.24）。** 环境光 1.6（旧口径）下三尊都在线内（131–135°，彩度 0.20）。所以色相上移是为了「脸不比灰模平」把环境光降到 0.6 带来的（没动内衣的颜色）；未换形的迦叶（147.9°）、尸弃（148.3°）、毗婆尸（150.5°）、释迦牟尼（148.9°）同样越线，因为同一个台面设置。cam03 同样（144.5–150.8°，彩度 0.25）。我没有改内衣的颜色去补，要补就要在台面设置与内衣色之间定一个，请你或总监定。另一条受环境光影响的线：光背身占脸的比例（#463 的「约一半」）环境光 1.6 时 0.37–0.6，0.6 时 0.52–0.86，同理。
