# #684 下半：面板里重建一间房子，改前 / 改后 / 改回

`collage.jpg`：T05 冬日白天，`?level=t05&shot=1&q=low`，软件渲染（SwiftShader），镜头用 `__look` 对着第 0 号房子（近排，x -50.69, z -39.24）。a 是原样；b 是面板的 `rebuild("0", { w: 12, ridge: 6.4, wall: 2, tone: 2, roof: "hip" })` 之后；c 是用 a 的数改回去之后。

- a 与 c 在画面左 700 列里只差 36 个像素（最大差 157，都在右上角的 stats 帧率小图那 40×43 的框里，不是场景）；a 与 b 差 55 842 个像素。就是说：改一间看得见，改回去画面回到原样，别的房子一件没动。
- 软件渲染本身有噪声（main 对 main 也不逐像素一致），所以这里比的是同一页面里连续三帧、`?shot=1` 冻结了时间；不能替代 T4 上的逐像素。
