# T05 无量殿穿堂顶，第三轮：栿、檩与椽、望板拉开明暗（#511，2026-11-21）

美术总监对 #511 的意见（美术通过，不挡）：栿、檩和椽、望板之间现在只差五六个 L*，请拉到 8 以上，总体不要更亮。

## 做法

栿与蜀柱、檩、椽各用一份从生成器的木色克隆出来的材质，木色分别乘 1.9、1.45、0.3（`wuliang-frame.js` 的 `TONE`；檩的底色原来就比栿亮，所以乘得少）。只动这座殿架子自己的材质，没动共用的 `materials.js`。

## 量法（判法 14：在哪里、怎么量）

软件渲染高档 1280×720，秋·昼，`?off=layers`，第一轮的同一个机位（眼在穿堂里 z = +72，朝北上看，`hall-top`）。L* 取 sRGB 转线性后按 CIE L* 算；每处取 12×12 像素的均值，点位固定：左栿 (330, 260)、右栿 (960, 260)、檩 (640, 445)、椽 (637, 330)、望板 (610, 330) 与 (700, 380)。

| | 改前（#511 美术通过的那一版） | 改后 |
|---|---|---|
| 栿（左、右） | 14.7、15.0 | **20.0、20.8** |
| 檩 | 16.3 | **19.6** |
| 椽 | 13.5 | **11.5** |
| 望板（两处） | 11.2、11.1 | 11.2、11.1（共用的板底，没动） |
| 栿、檩与椽、望板之间的差（最小） | 约 3.5–5（栿 14.7 比望板 11.2） | **8.1**（檩 19.6 比椽 11.5）；栿比望板 ≥ 8.8 |
| 整张图的平均 L* | 27.04 | 28.49（+1.45） |

**「总体不要更亮」没有做到，差 +1.45 L***（整张图含两侧白墙；只看中间一条木头是 12.8 → 14.1）。原因：木头往暗处压到约 11 L* 就压不下去了（椽乘 0.05 与乘 0.3 一样是 11.1–11.5，板底共用的材质本来就在这个底上，环境光与反射撑着），所以拉开差只能靠把栿和檩抬亮，抬亮就让整张图亮一点。要把总体压回去，只能把无量殿的板底（共用的 `rafters` 材质）整体调暗，那会连带暗到殿檐外面的板底，是改外观，没有做；要做的话请说一声，我在 T05 自己的一边换一份材质。
