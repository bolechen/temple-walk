# T05 无量殿穿堂顶：黑三角改成露明的梁架（#492 的追加，2026-11-21）

T05 主创的意见：无量殿穿堂里抬头是一块平黑（屋面板底），和 T00 山门原先的毛病一样；#475 的平綦只给 timber 的 pass 加，不会给这座五间单檐歇山殿加。

## 为什么是黑的

`__pick` 在穿堂里抬头三点，打到的都是 `rafters` 材质的屋面板底一片：`buildHall` 只画瓦与板底，殿内没有梁架（大雄殿的梁架是 `hall.js` 自己画的，这座殿由生成器出，没有）。

## 做法（`app/levels/t05/wuliang-frame.js`，新文件）

**彻上明造**，白盒：在四条内柱缝上各一榀架，每榀两层栿（下栿前柱缝到后柱缝，上栿在离檐檩两步的两根檩之间）加蜀柱到各檩；檩沿殿长、每一折一道；椽每半米一根，随各折的坡度挂在板底下。屋面的数从建好的殿里读（`roofAt`、`roof.purlin`、`EZ`、`EX`），屋面改了架子跟着走。**位置与断面是提案，不是出处**（`docs/t05/SOURCES.md` §13.2）；辽构歇山殿的穿堂顶是明造还是平綦，已问结构评审，等回复；回复若是平綦，这一份可以换成平綦，不影响别处。
