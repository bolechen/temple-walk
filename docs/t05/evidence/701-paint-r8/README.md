## 1. 拘那含牟尼的手还带红

原因：这一尊的手的肤色胶囊是旧姿势的：举起的手朝着观者伸来（指尖 z 约 1.9，手腕在袖口 z 约 0.92），旧的一条横胶囊（y 5.03、半径 0.37）盖不住手掌与拇指，又伸过袖口，在腕下切出一道浅粉的平边。做法：平涂绿色看漏，用 `pixelPoint` 读回手背、掌心、拇指根与指尖、袖口的位置（`handRa/b`、`handL2`、`handLc`、`handR3` 的新值，`tools/t05-hall/paint/kanakamuni-L2.json`），肤色铺满整只手，止于袖口。`fix1-hand-kanakamuni.jpg`：改前（T4 的交界图）、改后（同机位）、改后的手部近景：手是一个肤色，腕下的粉带没有了；袖口处仍有一小块肤色略越过袖边（近景左下）。

## 2. 皮肤上的划痕

白细划线出现在手上没被算作皮肤的那部分（那里用的是袈裟的一层，我判断是折纹边的磨损，没有逐项关掉验证），手补全后同机位近景里它们不见了：`fix2-scratches-kanakamuni.jpg`，同机位近景，改前手背与手指上有白细划线，改后没有。**没有另做关法线或关磨损的改动**（皮肤分区本来不吃折纹磨损）。毗舍浮、拘留孙的皮肤（脸、颈、两手）我看了同机位近景，没有看到划线；但两尊举起的手仍有没盖到的地方（拘留孙举手的外缘与腕下，毗舍浮举手腕部有一块圆形的淡斑落在袖口上），**这次没有改**，总监也没有点到。

## 3. 领口的绿洇到颈上

原因：领口的绿（内衣）来自一张掩码图，是照旧姿势的前视法线图画的；新网格的颈与颏位置变了，掩码的边就从领口上沿漫到颈根。做法：用新网格重画前视法线与深度图（`specs/t05-chest-normals-b.json`），照原来的种子与参数重新生成掩码（`masks/<尊>-front-b.json` → `paint/masks/<尊>-front-b.png`，内衣与描金的盒子上沿压在各尊肤色盒的下界：毗舍浮 6.276、拘那含牟尼 6.04、拘留孙 6.077 m），三尊的锚点改指新掩码。`fix3-neck-green.jpg`：毗舍浮、拘那含牟尼的颈根，改前有一条发绿的软带，改后颜色边界跟着领口的边走。毗舍浮的颈根左侧还有一小块橙褐的点，这次没有处理。
