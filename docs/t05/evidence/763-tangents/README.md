# 像身上四个画成「非数」的小三角（#763，2026-11-26）

## 现象

T05 主创在 T4 上从毗舍浮正前 10 米（尺子的 `mid10-4`）看，画面四分之三发黑；关掉辉光就好，软件渲染从来看不到。他把场景画进半浮点缓冲读回来，整屏只有一个像素是非数：屏幕 (1520, 519)，距离 11.43 米（运行 `20261126-113052`）。辉光把这一个像素糊成了一大片。

上一轮证据（`763-review-two/`）里写的「`mid10-4` 各区都是 L* 10.8、C* 2.2，有东西挡在眼前」就是它，**不是挡**。

## 源头

不在画法的着色器里，在像文件的切线上。发布的七个文件里有四个游离的小三角，三个点的切线是导出器的兜底值 (1, 0, 0)，法线正好是 (−1, 0, 0)（其中一个差字节的一格），两者共线：

| 尊 | 部位 | 像自身坐标（米） |
|---|---|---|
| 毗婆尸（中尊） | 头侧面 | −0.61, 6.68, −0.18 |
| 毗舍浮 | 右臂外侧，两个 | −0.90, 5.49, 1.39 |
| 拘那含牟尼 | 耳后 | −0.84, 6.28, −0.57 |

three 的顶点着色器用「法线叉乘切线再归一化」得副切线。叉积是零，归一化零向量在显卡上是非数，整个三角盖到的像素都是非数。

对上的办法：按主创那个机位（眼在毗舍浮发际下 0.6 米、像前 10 米，视角 52°）把这几个三角投到屏上，毗婆尸头侧那个落在 (1520–1521, 519–521)、距离 11.43–11.44 米，和读到的像素一格不差。主创当时按位置猜是拘那含牟尼，其实从毗舍浮正前看，右边是中尊。另外三个朝西，从西廊或背后才看得到。

## 修法

不改 GLB，不改数据集。像到货时 `app/levels/t05/figures/tangents.js` 把每个「切线和法线共线、或切线零长」的点的切线改成垂直于法线，手性不变，别的点一个字节不动（发布的文件里一共 12 个点）。这几个三角的贴图坐标本来就是退化的，法线贴图在它们上面没有意义，所以画面上别处不会变。以后发布的像如果带着同样的毛病，也一并修掉。

`tests/unit/t05-figure-mend.test.mjs` 数发布文件里的这 12 个点，守「改过之后一个不剩，别的点不动」。
