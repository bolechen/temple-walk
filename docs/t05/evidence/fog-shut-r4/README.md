## 这五盏补光代表什么（美术判法 7：殿内每一处亮都要说得出来源）

- **代表的光**：殿内的漫反射天光。门窗进来的天光落在地面、墙和梁上，在殿里来回反弹。
- **位置**：所以放在殿内高处，散开。
- **颜色**：偏一点暖（`#fff4e8`），因为反弹经过木构和白墙。
- **为什么随「在殿内的程度」升起**：它代表的是眼睛进殿以后的适应，也就是曝光。殿里并没有真的多出一份光。所以眼在院子里时它是 0，门洞照旧是暗的。
- **以后**：正式的殿内光（门光、佛前灯、光照探针、自动曝光）是第二阶段的事。
