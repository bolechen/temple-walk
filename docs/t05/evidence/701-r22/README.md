# 701-r22 · 毗舍浮 a/b 与拘那含三处（姿势 B4H10，总监认），gate 16/16

灰模（workbench，一盏棚灯，只看形）。`collage.jpg` 上排毗舍浮：①r3c 站直、眼与嘴同高平视（对照）/ ②V3：只做 a（颏）/ ③V4：a + b（唇后收 15%）正前 10 m 略仰 / ④V4 侧廊斜看（7 m·55°·眼高 1.6 m）。下排拘那含：⑤K1 不做 mouthlift 正前 / ⑥K1 侧廊 / ⑦K1L 做 mouthlift 正前 / ⑧K1L 侧廊。

## 毗舍浮
- **噘是雕塑里的**（①平视也有：下唇鼓、上唇 M 形顶）。倾 14° 合计只是让它更显；所以 b 做了，按总监的话。
- a（颏）：`--fill=1 --bell=1.25`，新操作 `chinfill`（`repair.py`）：竖沟两侧各有一鼓包，`flatblocks` 压细节压不平（k 0.15、0.0、800 遍都试了，两鼓包仍在，V1/V2 弃）；`chinfill` 逐高度比较中线与两侧鼓包顶的深度差，把中线按差补平（钟形半宽 0.035 m），钟形再加宽 1.25 倍。正前 10 m 里中线没了、成一个整圆面；下缘仍有一道横的暗带（原 r3c 下鼓包的边），没抹。
- b（唇）：`--lips=0.85`：唇区（胶囊 r 4.5 cm）的起伏对周围面保留 85%，只动深度，口裂/轮廓/嘴角位置不变。侧廊斜看里唇不再那么顶出，但变化小。
- 我没把唇「前后厚度收 15%」做成绝对量，而是起伏比例（**自拟**）；沿深度整体后退 15% 与它不同，要的话再做。

## 拘那含（K1 = 三处；K1L = 三处 + mouthlift 24 mm）
- 嘴角窝：`--corners=0.5`（窝的起伏保留一半，唇外）；木偶纹：`--mar=0.1`（保留 10%，400 遍）；颏下横软棱：`--ridge=0.15`（-0.31 m 处）。
- 侧廊斜看，窝与往下的小钩没了，下巴成一个圆面；正前颊边还有很淡的一道木偶纹残影。
- 颏下横棱在正前还剩一道淡横线。试过更强一版（ridge 0.05、更宽、位置 -0.265）会在颏下抹出一块有台阶的平板，**弃**（未入库）。
- mouthlift 做/不做：口裂两端差别很小（K1 平、K1L 两端略上），没替他决定。
