## 要的形（T05 主创转达总监）

下唇 → 一道软沟，深度约 r3c 的 1/3 到 1/2 → 颏重新鼓出来成一个圆的凸面 → 再转向下颌；颏最前点不超过下唇最前点，退在它后面一点。

## 做法：`repair.py` 的新操作 `chinshape`（取代 `lowerback`；上半脸仍用 `hold` 取倾斜基线）

正中线（|x| < 3 cm）的剖面从下唇最前点到下颌，用两样东西重建：它自己两端（下唇最前点与颏尖下 0.07 m 的下颌点）连的直线，加上快照（r3c 倾斜后）相对它自己那条线的偏离——沟的深度取 `k_groove`（0.55）、颏的鼓取 `k_chin`（1.5）。新旧剖面之差（只沿前后）横向在中线 0.19 m 内全量、到 0.42 m 渐出，只动颈轴线之前；差本身先在高度上平滑（9 格）、两端 smoothstep 渐入渐出（各 25%），再对被动的点松弛 20 次、遇翻面就减半位移。下唇最前点以上不动（`above_z0_max_move` 在日志里）。数全是「自拟」，没有造像依据。
