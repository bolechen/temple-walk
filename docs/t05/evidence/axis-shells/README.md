看图时要知道的：
- 三座都是 `buildHall` 出的宋式词汇（白墙、深色木、灰瓦、歇山顶、铺作），不是辽式，也不是清式；真形制没有资料，位置与尺寸全是提案，见 `docs/t05/SOURCES.md` §13、§13.1。
- 侧面图里两侧的墙是甬道墙和高台墙，不是外壳的墙。
- 无量殿正面与背面的白墙在柱后；殿内沿中间一间的两缝柱有两道隔墙，穿堂是一条走廊，两侧房间进不去。
- 内山门的便门只在北面（台面一侧）看得到（`inner-back.png`）。
