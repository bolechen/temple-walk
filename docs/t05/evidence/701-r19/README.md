## 做了什么
`tools/t05-statue/face-ship.py krakucchanda B4H10 --tilt=10 --lean=4 --chin-shift=0.015 --no-furrows --no-lift`（新选项 `--lean`）：莲座以上整体绕坐骨后缘前倾 4°，再把头相对身体倾 10°，脸上合计仍 14°（`chinshape` 的 bow 取合计）。按总监对拘留孙的裁定，淡沟与 mouthlift 都不做。
- 轴：舞台高 3.0 m、深 −1.6 m（座后缘，**自拟**，量自 r3c 各高度的前后范围：座在 3.0 m 附近后缘约 −1.9）；转角在莲座顶 2.8 m 以下为 0、4.0 m 以上全量（**自拟**），所以膝与手跟着转了一点，莲座不动。
- 前倾后的颈枢与口裂高度按身倾后的位置重算；上脸「保持线」的基准是倾后的样子。
