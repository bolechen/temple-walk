# #701：出货姿势（头前倾 14°）三尊，整尊与 10 米

灰模，软件渲染，没烘法线。`collage.jpg` 三列拘留孙 / 毗舍浮 / 拘那含牟尼，三行：10 米、高 1.2 m 略仰（头部）/ 斜 50° 看整尊（14 m，眼高 1.6 m，`tools/t05-statue/whole-views.py`）/ 正侧 90° 看整尊。**斜 50° 与正侧是我取的角度，不是实拍第 15 张那个角度**（我不知道它是哪个），请对照。

## 做法

`tools/t05-statue/face-ship.py <尊> S14 --tilt=14 --chin-shift=0.015`（毗舍浮加 `--cleft`：颏正中那条竖沟用 `flatblocks` 细节取 0.3）：r3c 原操作 → 前倾 14° → 没有 f2 的脸操作 → L4 的颏（`chinBehind` 每尊在 `face.json`：9.5 / 8 / 6.5 mm）→ 鼻唇沟与木偶纹淡到 0.4（唇外）→ `mouthlift` 24 mm（三尊都用同一个量，**拘那含牟尼我没单独调**）。

## 总监要确认的三条（图上）

- **颈后不折：** 整尊侧面与斜 50° 里，三尊颈后到肩的线是顺的，没有折；袈裟领口在头前倾后没有被顶起。
- **头不耷拉：** 侧面里头只是略低，下巴离胸还有一个手掌多的空；耳与肩的关系没坏（耳还在肩线之上，耳垂离肩有空）。
- 侧面不成立的迹象我没看到；但 14° 的整尊头比 r3c 站直时低、脸朝下约 14°，**从斜 50° 看脸被袈裟领口抬得略近**，这个要总监看。

## 10 米略仰（头部）我的判读

- 拘留孙：嘴平缓，唇在，颏是圆面、不再像第二片下唇。
- 毗舍浮：**最差的一尊**：嘴读成「噘」（下唇圆鼓而上唇「M」形），颏上有一条竖沟的残影和一个「下唇下的第二个鼓面」；`--cleft` 的 0.3 只抹了一部分。
- 拘那含牟尼：口裂平，两端与中点齐平，鼻唇沟淡；但颏下有横的软棱，木偶纹的痕迹还在。

## 没做

没量数；毗舍浮的颏沟与鼓面要再处理（竖沟 k 取 0.15、或再加宽钟形）；没烘；`701-r18/` 是拘留孙 14° 上「不做」的对比。
