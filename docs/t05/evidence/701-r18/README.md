# #701：拘留孙 14°，淡沟与 mouthlift 各「不做」的 10 米图

灰模；`collage.jpg` 上排 10 米略仰：S14（淡沟 + mouthlift）/ F14（不淡沟、有 mouthlift）/ L14（淡沟、不 mouthlift）；下排 r3c 站直斜 50° 与正侧（对照）。

## 看图

三张的差别很小。F14 的鼻翼到嘴角那两道沟稍明显一点；L14 的口裂两端比 S14 略低一点点，仍是平的。**14° 之后「不做」也平**：按总监的话「倾斜后不做也平就不做」，淡沟与 mouthlift 都可以不做。我没替他决定：两笔都留着也不坏，不做更省改动。下排 r3c：站直时头顶到下巴的侧面轮廓里颏是球形、超出下唇，这是那一笔 `chinshape` 要治的。
