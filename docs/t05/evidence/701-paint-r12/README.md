# #701：迦叶、释迦牟尼用新做法上色（软件，冬昼 无灯口径 + 灯 45 口径的数字，2026-11-25）

网格：`kasyapa-B4H10b.glb`（sha256 2f730134…faf19d）、`sakyamuni-V14b.glb`（df2bc9ef…a1a229），均为桶里 ship-701 的直接导出。配方不动，只换两尊的锚点（`paint/kasyapa-B.json`、`paint/sakyamuni-B.json`）和前视掩码（`masks/*-front-c.json`）。

## 做法
- 脸上不画线（`noInk`），唇铺色羽化无描边（`lipSoft` 0.45，`lipMul` 迦叶 0.92、释迦 1.08）。
- 手、领口、袒露的胸与右臂：用新网格自己的法线/深度图长出来的掩码（`mask.py`）；迦叶的内衣与金边、释迦的皮肤区（含举手的前臂）。
- 释迦：旧的背面、右侧掩码是按嫁接前的头颈做的，会在下颌盖出一块袍色，已撤；颈的胶囊与肤色分界按新颈位重设（颈前/颈后锚点降到 y 6.1）。
- 耳垂：迦叶的耳垂椭球放大；释迦的按图点位补上。
