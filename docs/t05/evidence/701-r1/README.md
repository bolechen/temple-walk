## 闭合体与改动范围

- `closed/topology.py`：原件开口边 0、碎片 0；**r3 已有 210 条开口边、105 个 ≤10 面碎块**（原件没有，是 r3 的修形步骤造成的，既有问题，不是这次的）；f2 与 r3 完全相同（面 1,462,804，开口边 210，碎块 105，朝向一致）。脸的改动没有增减拓扑。（仅拘留孙；另两尊未跑 topology。）
- `closed/gate.py` 只适用于改手的释迦（读 `varada.json` 与 `varada-check3`），**不能直接用在改脸上**；要不要为改脸写一个等价的闸（区外位移 ≤1 mm、面数、闭合、背面射线）待 T05 主创定。
- 拘留孙 f2 与 r3 逐点比：顶点数相同，动的 112,419 个，**stage 高度 5.49–8.35 m、最大位移 40 cm**。最大位移来自头前倾 10°（绕颈转整个头），不是嘴；嘴区的位移没单独量。
- 烘出的 `…-f2b.60000.glb` 有了 UV（原 60k 档无 UV）。#683 的掩码是按锚点画的不是按 UV 的，所以不受影响；但头前倾和嘴的位移使锚点要跟着变：`face-build.py --anchors-from` 需要锚点里有 `eyeL`，拘留孙 / 毗舍浮 / 拘那含牟尼的 `*-t05.json` 没有（只有毗婆尸有 `-eyes`），这一步报 `KeyError: 'eyeL'`，所以**锚点没有重出**，要先补眼点。
