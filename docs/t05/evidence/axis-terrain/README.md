# T05 中轴前奏的地形：向外看一圈与可走图（#435）

2026-11-21，分支 `claude/t05-axis-terrain`。软件渲染（SwiftShader），低档，960×540，夏·昼，`?level=t05&shot=1&q=low&cam=x,z,yaw,pitch`，第一人称，眼高 1.6 m。25 张，页面没有报错。

- `collage.jpg`：五个站（到达点、外山门位、内山门位、牌坊位、院子北口）各朝北、东、南、西和朝右侧墙顶仰 31°。每格左上写着站名与方向。
- `walk-diff.png`：本提交对 main 的 `t05.bin` 的可走图。灰是两边都到，蓝是多出来的，红是少了的，北在上。蓝的是：二层高台（约 740 m²）、甬道从 12 m 放宽到 16 m（两侧各 2 m）、内山门位台基两侧的台面；红的是：碑亭位的体块与它周围一个身宽、灯案体块与它周围一个身宽、三道踏步两侧垂带的外缘，以及月台中央原有的一点。
- 单张原图在证据库里，不进 git。

出图脚本不进仓库（一次性的）：对 `dist/` 的页面逐站设 `?cam=`；要重出，用 `node tools/shots.js --level=t05 outer inner paifang passage mouth` 看五个命名机位。
