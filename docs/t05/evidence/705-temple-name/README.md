# #705 寺名与印随关卡：留影卡片

用途：美术初审看「留影卡片上的寺名和印」；证明 T00 卡片改前改后不变。

## 怎么拍的
- 两个 Vite 开发服务器各开一份：`main`（origin/main，改前）与本分支（8e22ece，改后）。
- 同一地址：`?q=low&lang=<zh|en>&cam=0.3,2.2,0,0.05&season=summer&time=day&shot=1&enter`（T05 另加 `&level=t05`），Chromium 软件渲染 1280×720，`__photo(true)` 后 `__capture()`，1700×1165 的卡片。
- 比较方法：解成像素，逐字节比。

## 结果
| 对比 | 结果 |
|---|---|
| T00 中文：main ↔ 本分支 | **逐像素一致**（0 个字节不同，JPEG 字节也相同） |
| T00 英文：main ↔ 本分支 | **逐像素一致**（第二次各拍一张，0 个像素不同）。第一次拍时本分支那张在场景里有 128 个像素不同（x 400–415, y 368–375，16×8 的一小块），而 main 两次拍相同、本分支两次拍彼此就不同，不在卡片文字和印的位置，是场景自身的偶发抖动，不是这次改动带来的 |
| T05：卡片文字 | 中文「奉明寺 · 夏 · 昼」，印「奉明」；英文「Fengming Temple · Summer · Day」，印「奉明」；没有云径 / Yunjing |
