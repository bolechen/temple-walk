# #701：尸弃（M40b）、毗婆尸（B4H10b）用新做法上色（软件，2026-11-25）

网格：`sikhin-M40b.glb`（sha256 94c28215…2d91b1f）、`vipasyin-B4H10b.glb`（a4048531…e2728428），桶 ship-701/baked 的直出版，哈希与桶里的 SHA256 文件一致。配方不动；锚点 `paint/sikhin-B.json`、`paint/vipasyin-B.json`，前视掩码 `masks/sikhin-front-c`、`masks/vipasyin-front-c`（由新网格的法线、深度图长出）。

## 做法
- 脸上不画线（`noInk`），唇铺色羽化无描边（`lipSoft` 0.45，`lipMul` 不动，两尊的唇数已在线内）；额心白毫保留，没有被染成斑。
- 旧锚点里按旧姿势写的手胶囊、袖、袒露的胸全部删掉，手与前臂由前视掩码（皮肤通道，从新网格自己的折痕长出，到袖口为止）：
  - 尸弃：右手抬到下颌、左手向外摊开（手心向上），两只手、前臂到袖口；
  - 毗婆尸：右手结印抬起（拇指食指成环）、左手搭膝；
  - 内衣的区域：尸弃领口一条（框在 y 5.55–6.1，免得盖满整个胸），毗婆尸是网格自带的一块方的内衣（几何本身就是矩形）。
- 耳垂：椭球放大到 0.26×0.34×0.42，位置按耳的锚点往下取，两尊耳垂不再是袍色。
