# #493 殿内补光第二版：四盏（帧耗）

第一版（`../altar-493/`）用八盏：四盏门光聚光、一盏顶光、三盏反弹。T4 高档在门槛（cam03）比 main 多 1.45 ms，超过主创给的 1 ms。

原因：three 是前向渲染，每盏灯都写进每个受光材质的着色器；在院子里强度虽是 0，着色器照算。门口一带高档还要为铺地的倒影把院子再画一遍，这份开销又多一倍。

改成四盏：两盏宽的门光聚光、一盏顶光、一盏反弹，比 main 原来的五盏还少一盏。几盏灯都**不投影**；都在殿里，强度随「在殿内的程度」升起，殿外为 0，但仍在着色器里。
