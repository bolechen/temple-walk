## 这一轮改了什么

1. **殿墙单独成一个网格**。原先殿墙和院墙合在一个网格里，按室外画。
2. **墙的内皮一直到墙角都算殿内**。墙是只有角点的长盒子。山墙内皮的前端伸进了前墙的厚度里，那里的角点落在殿内盒子以外，被当成室外，亮度就顺着整面墙抹开了。上一轮东山墙是后墙的五倍，补光关掉也一样。现在按法线判：墙厚以内、朝殿里的面算殿内；朝外的面、顺着墙的面不算。
3. **山墙的壁画底收到前墙内皮为止**，不再伸进前墙。

单测：`t05-plan.test.mjs` 最后一条（墙角的内皮、外皮、壁画底的范围）。

## 补光代表什么

见第四轮的 README（`../fog-shut-r4/README.md`）。这一轮没有改补光：五盏灯代表殿内的漫反射天光，随「在殿内的程度」升起，代表的是眼睛的适应。
