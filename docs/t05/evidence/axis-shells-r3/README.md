# T05 甬路、土面、树干占位与墙帽（#446，PR #464 第三轮）

2026-11-21。美术总监对 #457 的意见（[评论](https://github.com/bolechen/temple-walk/pull/457#issuecomment-7059232025)）与主创加进 #446 的两条（[评论](https://github.com/bolechen/temple-walk/issues/446#issuecomment-7059237035)）：

- 甬道与高台不再墙到墙满铺石板：只铺中轴一条 6 m 宽的路（x = ±3），两侧是土面（甬道上与 0 高程齐，高台上比台面高 0.01 m）。
- 路两边立树干占位：圆柱半径 0.4 m、高 11 m，x = ±5.5；甬道上自 z = +132 每 9 m 一对到 +195（16 根），高台上 z = +81、+89、+109、+114（8 根，避开牌坊位前后各 8 m）。
- 墙顶加墙帽的体块（不加垛、不分段）。
