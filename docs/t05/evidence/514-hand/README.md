两张都由 `tools/t05-statue/views.py` 用 Blender（`bpy` 5.3.0，无界面）渲出。

## 发现：释迦的右手和膝是长在一起的

在 148 万面的原件上，从正前方朝手背打射线（打了六处），穿过手背之后的下一个面就是佛像的背面了。也就是说：

- 手和膝之间没有分开的面；
- 手掌那一面根本不存在；
- 手底下也没有膝的表面。

所以「在现有网格上把手转过来」行不通：转过来的那一面是空的，膝上会留一个洞。这也说明了 #514 提到的「转过来那一面没雕掌纹」：那一面不是没雕，是根本没有。

## 提议：移植尸弃的左手，镜像到右边

尸弃的左手生成时就是掌心朝外、手垂在膝外，而且是悬空的。

按 #514「做法和本方案相反先提出来」的要求，先报给主创和两位评审，同意了再做。做法：

1. 在 Blender 里切出尸弃的左手和前臂下段，按 x 镜像。按两尊手的长度比例缩放，摆到释迦右膝上方，摆成掌心朝前、指尖朝下。
2. 删掉释迦原来的右手，补膝面：补洞，再在局部体素重建，平滑接进周围。
3. 在腕处接上：两段腕口桥接，局部体素重建，再做矫正平滑。
4. 导出 glb；整件减面、烘法线，照旧用 `tools/t05-statue.mjs` 和 `bake.py`。

除右手和右前臂以外，别处位移都要 < 1 mm（#514 验收第 3 条），用顶点逐个比来验。

## 第一轮（2026-11-21）：移植做出来了，还没过

3D 评审同意移植（#514 评论）、T05 主创给了四个条件之后做的。脚本是 `tools/blender/varada.py`，参数在 `tools/t05-statue/sakyamuni/varada.json`（本目录 `r1-varada-params.json`），量用 `tools/blender/varada-check.py`。全程用无界面 Blender（`bpy` 5.3.0），没花点数。

### 怎么做的

1. **切手**（尸弃 `sikhin-r3.glb`，SHA-256 `a1224ee7…f057`）。
   - Tripo 的网格是 167 个没焊接的壳，手由其中几个组成：掌、拇指、两段手指，各有 85–100% 落在手的框里。腕所在的那个壳往上一直连进袖子。
   - 规则：五成以上落在框里的壳收进来，再按腕口的平面和框切掉多余部分。
   - 袖口不带过来：切口在袖口下面的光腕上。
   - 切下来的部分按 0.002 m 焊接。
2. **镜像、摆位**。
   - 按 x 镜像，左手变成右手；镜像后重算面的朝向（3D 评审第 4 条风险）。
   - 摆到释迦的腕上：腕在前臂搭在大腿上的末端（−1.72, 3.92, 1.38），指尖朝（−1.77, 3.02, 1.99），掌心朝前。
   - 缩放 0.83；绕手的长轴转 5°，免得和尸弃那只手完全一样（3D 评审的建议）。
3. **膝面**（3D 评审第 3 条风险）。
   - 原手所在的范围：框（−2.25, 2.5, 1.25）到（−1.25, 3.98, 2.4），原件在框里的点有 19,093 个。
   - 框内的面换成释迦自己左膝镜像过来的面，衣褶是他自己的。
   - 框边 8 cm 的过渡带里，原有的点贴到同一个镜像面上，再平滑 40 遍。
4. **接腕**：手的腕口沉进前臂末端 6 cm，直接并在一起，没有做布尔运算或桥接环（原因见下面第 5 项）。
