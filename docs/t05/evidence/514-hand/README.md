# #514 释迦右手改与愿印：先查的两件事（2026-11-21）

`before-and-donor.jpg`：

- 上排：释迦样件 `sakyamuni-r1.60000.glb` 现在的样子。依次是正面、右侧面，以及右手的正面、侧面和低处正面。右手是触地式：手背朝外，指尖搭在莲座上。
- 下排：尸弃 `sikhin-r3.60000.glb`。依次是正面、左侧面，以及左手的近景。尸弃的左手伸出膝外，掌心朝外，手是悬空的。

两张都由 `tools/t05-statue/views.py` 用 Blender（`bpy` 5.3.0，无界面）渲出。

## 发现：释迦的右手和膝是长在一起的

在 148 万面的原件上，从正前方朝手背打射线（打了六处），穿过手背之后的下一个面就是佛像的背面了。也就是说：

- 手和膝之间没有分开的面；
- 手掌那一面根本不存在；
- 手底下也没有膝的表面。

所以「在现有网格上把手转过来」行不通：转过来的那一面是空的，膝上会留一个洞。这也说明了 #514 提到的「转过来那一面没雕掌纹」：那一面不是没雕，是根本没有。

## 提议：移植尸弃的左手，镜像到右边

尸弃的左手生成时就是掌心朝外、手垂在膝外，而且是悬空的。

按 #514「做法和本方案相反先提出来」的要求，先报给主创和两位评审，同意了再做。做法：

1. 在 Blender 里切出尸弃的左手和前臂下段，按 x 镜像。按两尊手的长度比例缩放，摆到释迦右膝上方，摆成掌心朝前、指尖朝下。
2. 删掉释迦原来的右手，补膝面：补洞，再在局部体素重建，平滑接进周围。
3. 在腕处接上：两段腕口桥接，局部体素重建，再做矫正平滑。
4. 导出 glb；整件减面、烘法线，照旧用 `tools/t05-statue.mjs` 和 `bake.py`。

除右手和右前臂以外，别处位移都要 < 1 mm（#514 验收第 3 条），用顶点逐个比来验。
