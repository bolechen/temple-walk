## 数

- **屋**：南面第一排屋分三类，小棚（4.2–6 × 4–5.5 m，脊 3.8–4.7）、中屋（6.5–9.5 × 5.5–8，脊 4.8–5.8）、长屋（10.5–15 × 6–8.5，脊 5.5–6.3），大约 28% / 44% / 28%；脊顺墙或垂直于墙六四开；屋与屋的空当 2–13 m 不等（原来 7–12 m）。头一排仍离墙外皮 3–6 m。
- **树**：南面的树成丛，一丛 2–4 棵、丛内相隔 3.2–5.2 m，前后两排落在同一丛的范围里；丛与丛之间 15–25 m，只有屋面；去掉了靠墙的「屋间树」（它们落在要留的空当里）。单测逐丛量：每丛 2–4 棵、丛内相隔 3.1–6.5 m、丛间 14.9–25.1 m，整个南面至少 8 丛；相邻高差 ≥ 20%、同种不连着超过三棵仍然成立。

## 看到的（我自己看的，不替美术总监判）

- C、F 朝南：地平线上不再是一串均匀的树和一样大的屋，成了几簇松柏落叶树夹着中间只露屋面的空当，屋有大有小，脊的方向不一；没有一道连续的树墙。
- 月台西南、东南：同上；西南那边 241° 的缺口（给塔）仍然是空的。
- A 南、到达点南：几乎没变（大殿和门挡着；到达点的屋和树没动）。
- 还有的毛病：屋顶的形都是同一种两坡顶，只有大小和朝向在变；屋的颜色和高低（脊）变化仍是白盒的程度；屋面的瓦色一样。这些是我看到但没有改的。
