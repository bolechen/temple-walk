# #463 毗婆尸收尾：睑缘只在低模上压（2026-11-21）

两位评审收拢在 r8 的 A、闭目之后，T05 主创排的收尾。不另算一轮。

## 做法

3D 评审给的做法是：「在减面后的低模上压，前后限制在脸平滑面外 3 cm 以内；法线仍取没被压的原件烘，睑沟和睑缘的雕刻留在法线图里，平视的睑线也不会断。」

1. **原件**：照 A 的配方重建（`vipasyin-r8C.glb`），但在原件上不压睑缘。r8 里 `lidClamp`（原件上压外端）和 `lids`（3 mm 平滑）都从配方里去掉了，因为它们改了原件的睑缘形，画在原件睑裂上的睑线就断了。
   - 唇前伸、颏唇沟和 A 一样：−0.047、0.079。
2. **低模**：三档低模（6 万、2 万、6 千面）各用 `tools/t05-statue/lowclamp.py` 压睑缘。
   - 参照面：每只眼，从眼下的颊（睑裂下 6 cm）到眼上的眉（睑裂上 8 cm）连一个面，两端各取同一横向位置上最前的表面点。
   - 限：眼区（离眼中线横向 19 cm 以内）的表面不超出这个面 3 cm；眼区以外往太阳穴再 12 cm，不超出 5 mm。
   - 没用网格平滑当参照面：拉普拉斯平滑会把头缩小，量出来处处「凸出」；陶宾和 Humphrey 平滑又会被一个离群点带偏，而且留下和上睑一样宽的棱。三种都试过。
3. **法线**：从没压过的原件 `vipasyin-r8C.glb` 烘到压过的 6 万面上：`bake.py`，2048，xatlas，头单独一张。

## 量（`lowclamp-r8C-<面数>.json`）

| 低模 | 眼区内最大超出，压前 → 压后（左 / 右） | 眼区外最大超出，压前 → 压后（左 / 右） | 动了的点（左 / 右） |
|---|---|---|---|
| 6 万 | 13.1 / 13.8 cm → 3.0 / 3.0 cm | 9.3 / 9.5 mm → 5.0 / 5.0 mm | 37 / 43 |
| 2 万 | 13.6 / 14.5 cm → 3.0 / 3.0 cm | 10.8 / 9.4 mm → 5.0 / 5.0 mm | 12 / 11 |
| 6 千 | 13.9 / 14.0 cm → 3.0 / 3.0 cm | 0 → 0 | 4 / 5 |

- **侧面轮廓**：在 6 万面上，睑裂附近每个高度取全脸最前的点（横向 0–0.6 m）。
  - r7：y 7.26–7.30 处是上睑，最前到 z 0.465–0.499，比鼻梁（0.433）还靠前 3–7 cm。侧面看到的「鳍」就是它。
  - r8C：同样高度上最前的点都在正中（鼻梁），眼区最前 0.408–0.420，没有任何东西伸出侧面轮廓。
- **验收**：「眼区轮廓外不再有离脸平滑面超过 5 mm 的薄片」。按上面的参照面量，眼区外最大 5.0 mm，在限内。

## 还没做到的

- **平视的睑线是一道细带，不是单独一道细线。** 美术总监要的是「沿睑缘的棱画一道连续的细线，到外眼角前淡掉」。连续做到了；细带里那道浅线是睑缘在法线图里的高光，要再收窄，就得改画法（`lidT`）或睑线的位置。
- **侧面眼区之内，睑的形在法线图里还读得出一条深线**，这是有意保留的雕刻，不伸出轮廓。
