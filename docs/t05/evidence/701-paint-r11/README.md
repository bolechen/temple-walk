# #701：举手的两处溢出收掉，毗舍浮的肤色延到袖口是不是裸前臂（软件自检，2026-11-25）

## 1. 两处溢出

- **拘留孙前臂外缘一小块肤色落在袖子上**：来自手掌的大胶囊（半径 0.34，伸到前臂外缘的袖褶上）。前视掩码已经覆盖手与前臂，所以把拘留孙举手的那些胶囊都撤了，只留一条管手指的（y 5.35 以上，`handRa/b` 半径 0.26）。前臂外缘现在是干净的，手指也有色。
- **拘那含前臂外缘一条细的**：同样来自手掌胶囊起点伸到袖褶上（x −1.48，半径 0.25）；起点往里收到 x −1.36、半径 0.21。条没有了；试过缩到 0.16，腕处会出一道缺口，所以取 0.21。

## 2. 毗舍浮（拘留孙、拘那含同样看了）：肤色延到袖口，延出去的一段是不是裸前臂

`png/skin-edge-on-grey-model.png`：同机位（冬昼灯 60、曝光 5.5）的灰模，上排灰模、下排在同一张上画皮肤区的边（红线，取自平涂绿色的图）。看到的：

- 三尊的红线都落在灰模上看得见的折痕上：前臂外侧沿着袖子的内缘折痕往下，里侧沿着前臂与身体之间的缝，下端落在袖褶汇合处（袖口）；红线不穿过袖子的褶、也不落在布面上。
- 毗舍浮：前臂是一根光滑的圆管，从手腕一直到下面袖褶汇合处，约一个手掌长还多；管上没有布的褶，布的褶在它左边和下端；所以这一段是裸前臂，改前是红的才是错的（旧的手胶囊止在腕处）。拘留孙、拘那含同理，前臂也是光滑的管，到袖褶汇合处为止。
- 限度：我分不清「紧贴在臂上的一层袖布」和裸臂，两者在这个网格上都是一根光滑的管；判断的依据是布在别处的样子（有褶、有边）和这一段没有褶没有边，以及它在腕下一路连到手背。
