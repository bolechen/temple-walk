- **平台边**：补三张站在平台外侧、看得到平台边、踏步和矮墙的图：`outer-edge`（外山门，0.5 m 的平台，右边是前院的矮墙）、`inner-edge`（内山门，1.0 m，右边是甬道墙）、`hall-edge`（无量殿北面，踏步下到院子）。

- **便门近景**：`wicket-45`、`wicket-side`，和 `inner-back`（内山门北面）。
