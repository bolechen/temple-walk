## 做了什么
颏面鼓面上有几个小丘（正前三个：左、中上、右），灰模上读成「花」。只在颏面抹平：`face-ship.py sikhin M40v … --chin-smooth=0.4 --chin-smooth-iter=150 --chin-smooth-dz=-0.24 --chin-smooth-ax=0.15 --chin-smooth-ay=0.08 --chin-smooth-soft=0.10`（`flatblocks` 的椭圆块，中心在唇下 0.24 m，其余照 M40：mouthlift 40 mm、窝 0.5、木偶纹 0.1、颏下线 0.1、chinfill、unfold）。
- 试过的：起伏保留 0.2–0.25 且软边 0.03–0.06（M40c2/c0、M40t）：颏面成一块有硬边的平板（圆盘），弃；保留 0.2、软边 0.10（M40u）：圆盘没了，但颏的最前点退得更多（点位移最大 38.6 mm）；取 **保留 0.4、软边 0.10（M40v）**：点位移最大 28.0 mm（p99 23.4 mm），颏面的丘抹成一块平顺的鼓面。
- 嘴、嘴角、颏轮廓：与 M40 比，唇带（唇下 6 cm 以上）的点位移最大 0.22 mm（实测），嘴角不动；颏中线上最前点只退 2.9 mm（实测），颏面里抹掉的丘最深处位移 23 mm（点位移最大 28 mm 在颏面下半）。**若总监觉得抹得不够或太多，改保留量（0.4 → 0.2 更平、0.6 更轻）再来一版。**
