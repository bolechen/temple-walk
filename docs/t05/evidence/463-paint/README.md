## 量法

屏上色是该区像素的平均 sRGB（stage.js `zoneIds`：四邻都是同一区的像素）；颊是 faceFrom10 里一块 17×17 px 的平均，取点在眼外 1.15 倍眼半距、眼到嘴一半高处，左右各一再平均（`probe`，`paint-measure.py`）。饱和是 HSV 的 (max−min)/max，色相是度，亮度是 Rec. 709 的亮度。取法是**自拟**。

## 要说清的

- 两端两尊（迦叶、释迦）站在白盒殿灯光较弱处，莲座要乘 `lotusGain` 1.5、背光板乘 1.3 才到同一档。**这是对现在白盒光的补偿**，殿内光（第二阶段）改了要重量。
- `座上` 是新加的一区（`lotusUp`：座顶以下 0.95 m 起），这样「上层」才是一个可量的面。
- 看得见的改动登记在 `docs/t05/SOURCES.md`；单测 `tests/unit/t05-paint-recipe.test.mjs`。
