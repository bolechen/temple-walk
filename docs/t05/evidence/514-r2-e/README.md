## 补褶的做法和结果

1. **挂裙片**（`arm.skirt`）：从前臂开口边的每个点往下挂一列袍到大腿，顶上焊住，底下沉进大腿面 4 mm。
   - 结果：外侧腕下那一段**底下是空的**。腕悬在膝前，往下 0.5 m 内没有面，裙片没地方落，挂不上。
   - 拿掉补块以后，近景背面从 0 涨到 9–73。
2. **横跨底面的一片**（`arm.bridge`）：在前臂底面的内外两边之间，每隔 1.5 cm 挂一条下垂的横片，两头收进前臂 5 mm。
   - 结果：73 个站点里只有 30 个两边都找得到开口边，其余的没挂上。
