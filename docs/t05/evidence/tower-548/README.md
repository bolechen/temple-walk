## 数

- 真塔离月台 952.1 m、方位 241.66°，高 42.5 m，月台眼高 4.6 m：塔顶在眼睛上方 2.28°，塔脚在地平线下 0.28°，塔座对角约 1°；1280×720、纵向视角 52° 里整座塔约 36 像素高（实测看得见的部分约 25 像素，塔脚融进雾里）。我没有放大它。
- 为了画得出来：画在从月台到真塔的连线上离月台 700 m 处，同比缩小 0.735（镜头远平面 800 m，场景的雾在 952 m 抹掉一切）。从月台看，方位和视角高度与真塔一模一样（单测 0.005° 以内）；从到达点、A 站看，视角高度差 0.12° 之内，方位错 4–5°。
- 画法上的一个发现：这座塔在天穹之外（天穹半径 600 m，不写深度），不特别处理会被天穹盖掉（T4 上第一次什么都看不到，原因查清后用 `renderOrder = 1`）。
- 薄雾：塔脚占雾色 0.85，塔顶 0.42，雾色取场景当下的；夏昼，塔顶比它后面的天暗 ΔL* 约 12（0.55 时是 8），塔脚 3。这两个占比美术总监已通过（评论 7072039663），不动。她留的线是夏昼正对塔、塔顶比天暗 8–14 L*、塔脚不超过 4；e2e 场景 `tower-mist` 把它画出来量，我的数法读到塔顶 13.5、塔脚 5.3（塔脚比 4 大 1.3，所以场景里的界限是 8–15 和 ≤ 6，数法的差别还是该改雾的数，待她判）。
- 1504 个三角形，一个绘制调用，不进烘焙地面：walk-diff 为 0（`t05.bin` 与 main 逐字节相同，命名地点 24 个都到得了）。
- **帧耗**（同一个 Job，轮流两次，`__cost`）：A 站 7.08、7.23 → 7.16、7.71 ms；cam07 8.77、8.74 → 8.41、8.27。塔不在这两个机位的画面里（三角形数相同：197,898、396,086），读数的差在噪声里。塔本身在画面里时只多一次绘制、1500 个三角形。
