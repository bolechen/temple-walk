# #701 第二轮：七尊的唇往毗婆尸那边靠（2026-11-25）

美术总监第二轮（经 T05 主创转，PR #718 上）：第一轮把唇画到了唇上，但深色的口换了位置，仍像口；cam03 里五尊有四尊嘴上是一个深点读成张口，连毗婆尸也是。要求：唇色只比肤色暗 6–8 L*、彩度高 3–5，只落唇面，不落上唇底面和唇缝；cam03 里没有一尊的嘴是全脸最暗的一点。

只动 `tools/t05-hall/`；网格仍是 `mesh-sha256.txt` 里当前的 r3（`lipAt` 是按它点的）。

## 做了什么

- 唇色 #573A2E → **#6A503A**：在肤色 #75634F 的 Lab 里暗 7 L*、彩度高 4、色相偏红 8°（原来暗 16 L*）。
- 唇色只落在朝向眼的唇面上：法线 z 在 0.3–0.6 渐入，y 在 −0.3–0 渐入（`paint.js` 的 `faceInk`），不落上唇的底面和唇缝的壁。
- 「嘴一带的缝隙加深减半或去掉」：贴花不再落到缝的壁上，唇色又浅了；缝的暗是网格的明暗，配方里没有别的在画它。
- 七尊同一个配方，没有逐尊的补偿。

## 量数

软件渲染，殿内光（冬、不开佛前灯），`paint-measure.py` 新增唇的 L*、彩度和 cam03 的「嘴是不是全脸最暗」。`before-after.md` 是七尊的前后（前 = 第一轮 #573A2E，后 = 这一轮）。**参照不同要写明**：`before-after.md` 里的 L*、彩度是唇比颊的一块 17×17 px（颊亮点，差会偏大）；`measures.md` 里的是唇比头部肤色的平均（差偏小）。两个都不是总监估的口径，只是两个定义清楚的取法。

| | 拘留孙 | 毗舍浮 | 拘那含牟尼 | 毗婆尸 |
|---|---|---|---|---|
| 唇比头暗 L*（线 6–8，头部平均） | 4.4 | 4.0 | 6.8 | 8.4 |
| 唇比颊暗 L*（颊亮点） | 7.3 | 7.3 | 10.1 | 12.6 |
| 唇比头浓 C（线 3–5） | 3.4 | 3.6 | 2.8 | 2.7 |

七尊都在 `measures.md`：唇比头暗 0.7–8.4 L*（迦叶 4.9、拘留孙 4.4、尸弃 0.7、毗婆尸 8.4、毗舍浮 4.0、拘那含牟尼 6.8、释迦 4.0），彩度高 2.7–4.3。在 6–8 L* 里的只有拘那含牟尼，毗婆尸略过，其余偏浅；彩度 4 尊在 3–5。散开的原因同上一轮：白盒光和每尊唇的朝向，没有为它加补偿。

**cam03（1920 px）里嘴是不是全脸最暗的点**（取嘴心周围 29×37 px 的盒，3×3 平均亮度）：毗婆尸 **是**（36.8，盒内最暗就是嘴）；拘留孙、尸弃、毗舍浮、拘那含牟尼 **不是**（最暗在眼的线上或嘴下 6 px 的下唇影里，嘴处 41.8–50.5，盒内最暗 37.4–39.5）；迦叶、释迦在 cam03 里出画。毗婆尸那一点是唇缝的暗，是网格的明暗，唇色已经只比肤色暗 8.4 L*，再浅就违反 6–8；留给总监判。

## 取代了什么线

这一轮的线**取代** #683 里依 #480 第七轮的两项：「唇亮度是脸的 0.58–0.64」和「全脸最深的是唇」。后者现在反过来：cam03 里没有一尊的嘴是全脸最暗的一点。这一轮的量数不再对那两项报「过/不过」。**「色相 12–16°」「饱和比颊高 0.10–0.15」两条这次没有重述，待主创确认是否仍有效**：这一轮的数是色相 24.4–25.2°（上一轮 11.8–14.2°），饱和比颊高 0.114–0.147（仍在 0.10–0.15 内）。
