# 七尊：初审和终审退回的四条（#763，2026-11-26 第二轮）

`18b2024` 没过独立初审（评论 7188199708）和美术总监的终审（评论 7188284034），必改四条相同：螺发读成藏青的帽子、下巴下有一条肤色带压在袍领上、释迦右臂的色块和黑片、中尊的莲座发灰。这一轮只改画法（分区和颜料），**没有动任何 GLB 和遮罩**。

## 怎么拍的

T4（t4-small，1920×1080 高档，冬·昼，第一人称，`?hall=open`），运行 `20261126-103558`，Hugging Face Job `6b080b9fb6a90bbe997fd3d6`。站点是**不合并的草稿树**：#762 的 `25b22b8` 合上本分支，再加这次提交的改动，所以 `report.json` 的 `site.commit` 记作 `25b22b8…+dirty`，`site.sha256` `1044ffc7…21f1`。量法是 #762 的尺子 `tools/t05-zones.cjs`（不取 `picks`）。`zones.json` 是全部读数。

这是调画法时量的，**不是验收的那一轮**：两个 PR 合拍由 T05 主创在两边的新头上拍，以那一轮为准。
