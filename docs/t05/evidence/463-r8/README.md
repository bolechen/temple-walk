## 形改了什么（3D 评审）

- **唇前拉**（`lipsFwd`）：
  - 只在鼻底以下，上唇最前点处移满；
  - 放在所有平滑之后做。
  - 嘴的整体不再往后压：`back` 从 +0.015 改成 −0.01，深度 ×1.0。
- **下颌以下**：深度 ×0.9，向头的竖轴收（`underJaw`）。下巴垫不再压。
- **上唇两侧的沟**：只填浅于 3 cm 的、外侧的部分，填一半（`frame`）。深的那两处是鼻翼沟，不填。
- **下巴下沿的横折**：沿折线一条约 0.1w 宽的窄带衰减到 0.3（`chinFold`）。
  - 折线在九处剖面上找最急的转折，用二次曲线连起来；
  - 种子 25 个，间距等于半径。
- **眼睑的鳍**（`lidclamp`，新写）：
  - 鳍是上睑外端的一道棱，比旁边的太阳穴和下面的颊凸出 12–15 cm。
  - 只在眼的外半段，把表面压回从颊（缝下 6 cm）到眉（缝上 8 cm）连出的面，外留 3 mm。
  - 从眼中线起 6 cm 内渐入，眼中间的雕刻不动。
  - 量得外端（离中线 0.36–0.40 m）往回收了 5–9 cm。

## 画改了什么（美术总监）

- **唇色**：`#6A4239` → `#5D3F37`，往赭褐偏。
- **睑线**：
  - 宽度收到原来的三分之一（`lidT` 0.03 → 0.01）；
  - 到外眼角之前淡掉。
- **乙**：
  - 瞳孔画成一条带，约占眼裂宽的四成，上下顶到睑缘；
  - 眼白压暗到暖灰（`#7E7366`）；
  - 内眼角不画白。
