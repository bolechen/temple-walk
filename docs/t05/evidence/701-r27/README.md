# 701-r27 · 三尊烘法线：脸区不带法线，身体/耳颈手/发/莲座带法线；交界三处近景

总监认「形和减面」（701-r25/r26）后的烘焙。`collage.jpg`：Cycles（CPU，一盏太阳，一色灰泥，法线图生效）三行拘留孙 B4H10 / 毗舍浮 V3 / 拘那含 K1L；三列：发际（正前）/ 耳根（侧 60°，长焦）/ 颈（斜 30°）。

## 做法
- 高模：定案全分辨率（`<尊>-<版>.glb`）；低模：分区减面（`…z.glb`，79,262 / 79,374 / 74,882 面）。`bake.py`（xatlas 展 UV，头与身两张 2048 图，头图以颈 z0 − 0.002 为界），笼距 0.0012、射线 0.0025（与 r3c 上验过的一样）。
- 脸区不带法线：`zoned.mjs` 把脸档的点写在 `<out>.face.json`；`bake.py --face=` 把这些三角形在法线图里的像素（外扩约 1 px）改成中性色（0.5, 0.5, 1），脸由几何自带的平滑法线打光（脸区全密度，等同高模）。头图里拘留孙 30,950 个脸三角被抹平，毗舍浮头图 30,864 + 身图 214（颏下缘落在头身分界以下）、拘那含头图 26,567。（`bake.py` 打印 `face_triangles_flattened`。）
- 耳廓内部、螺发、袈裟、莲座、手、颈仍带法线。

## 看到的
- 发际、耳根、颈三处，三尊都没有一圈明暗接缝或台阶（耳根处耳轮廓线上有极细的暗线，是耳与颅的真实交界）。
- 螺发上有几处小尖刺/小斑（头顶偏右、耳上方），是烘焙在薄的卷尖上投射的杂点，三尊都有，**没处理**；若上色后在 10 m 看得见，再逐点修。
- 光是一盏太阳的灰泥，不等于上色会话的灯；他们取新文件后再看。
