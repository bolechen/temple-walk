# 后续 PR（#705 的两条美术意见）：T05 卡片的诗句与二维码

用途：看 T05 的留影卡片只印它自己的诗句、不印二维码和网址，并证明 T00 的卡片不变。

## 怎么拍的
- 两个 Vite 开发服务器：origin/main（a8fef0a，改前）与本分支（改后）。同一地址：`?q=low&lang=<zh|en>&cam=0.3,2.2,0,0.05&season=<s>&time=<h>&shot=1&enter`（T05 加 `&level=t05`），Chromium 软件渲染 1280×720，`__photo(true)` 后 `__capture()`，逐像素比较。

## 结果
- `collage.jpg`：左起 T05 冬·昼中文（印 J01 自己的「寒霜清晨，钟声独远」，无二维码、无网址）、T05 冬·昼英文、T05 夏·昼中文（它没有这个时刻的诗句，不印）、T00 冬·昼中文（二维码、网址仍在）。
- T00 改前改后，三个时刻（夏昼、冬昼、秋暮）× 中英，**卡片脚部（诗句、寺名、网址、二维码、印）逐像素一致**（0 个像素不同）。
- T00 夏昼的整张卡片逐像素一致。冬昼、秋暮的画面部分在软件渲染下每次拍都不同（飘雪、灯火），同一个 main 自己拍两次也有 348k / 2.5k 个像素不同，所以只能用脚部做判断，画面部分不能逐像素比。
- 证据库（`MANIFEST.json`）里只有这张拼图，没有单张原图。
