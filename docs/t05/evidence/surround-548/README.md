## 看到的（我自己看的，不替美术总监判）

- 到达点（东、南、西）：墙头以上有近处的松和落叶树，南面和东面有低屋的屋顶；这是三处里最像「寺在城里」的，因为屋就在近处。
- A、B（东、西）：墙头上一带松柏和落叶树，高低不齐，层间见天；**屋脊几乎看不到**，被树挡在后面（屋脊 ≤ 5 m，墙头在眼上 2.6°，墙外 15 m 以外的屋脊只高出墙头一点）。所以 A、B 读成「树林」，读不成「县城」。要读成县城，要么第二步的一片屋顶，要么头一排屋挪到离墙更近；我没动，等美术总监定。
- C、F 朝南：**读成一道深色的常绿树墙**，接近美术总监说的「不是一道实心的树篱」的边。原因：cam07 的约束把南面这几排压在 7.4 m 以下，从月台（眼高 4.3）看，墙头以上 0.5°–3° 只对着 4.9–8.2 m 那一带，要到 40% 只能用柱状的柏，圆锥的松顶太尖填不上。这一处是约束之间的张力：要么放宽 cam07 的檐线（让南面树高一点），要么接受 C、F 朝南是一道矮常绿带。请美术总监看这两张。
- 落叶树是白盒的枝，形简单；松是五六层圆锥。都是白盒，不判材质。

## 判法（`skills/art-gate/SKILL.md`）

我用了：12（树冠要透：比例 40–80%，不是实心树篱）、10（「看得见」写成画面条件：檐线用射线逐点量，不写绝对高度）、11（一排一样的东西要打散：每排间距不等、各排错位；南面一排柏我没打散到位，见上）、8（挪机位带进画外毛病：cam01、cam07 的檐线）。cam03 和 cam07 的画面由美术总监判。
