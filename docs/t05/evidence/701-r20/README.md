# 701-r20 · 拘留孙三档分区减面（B 方案，总监/主创裁定上限每尊 77,000 面）

灰模，Blender workbench，只看形，光要 T4。`collage.jpg` 上排：满面 r3c（1,463,014 面）；下排：`r3cz3`（本版）。四列：10 m 全身 / 举手与托钵手与袈裟边（斜 20°，4.5 m）/ 莲座与膝（斜 40°，5 m）/ 脸与颈前耳根（斜 30°，3.2 m 仰）。

配置 `tools/t05-statue/krakucchanda/zones.json`；命令 `node tools/t05-statue/zoned.mjs <r3c.glb> <out.glb> --scale=8.443 --tiers=<zones.json>`。
`topology.py`：边界边 0、非流形边 0、1 块、有向一致、水密（体积 0.12024，原 0.120549，差 0.25%）。上一版的 6 处两面小片已在 `zoned.mjs` 里按「只靠两面共边相连的十面以下碎片」删掉（按拓扑找，不按位置焊接）。

## 看到的
- 举手五指分开、托钵手、耳、颈前读得出；脸盒与颈、耳根的接缝在第四列没见环或台阶。
- 袈裟衣纹与莲瓣在近景里仍有明显刻面（其余档 36k，按总监「可留刻面」未动）；10 m 全身图上是软的刻面感。这是工作台的平涂光，没有法线图也没有 T4 的光，**不等于入殿后的样子**，要烘焙后用上色会话的光再看。
- 脸区不带法线图的事要烘焙时定；这一步只出几何。

## 没做
- 另两尊的盒子（要按各自口裂高度与耳位重定）；接缝环在上色光下的复查；姿势（身 4° + 头 10°）还没定，**这一版是 r3c 站直的脸，不是出厂姿势**，姿势定后要在那个姿势上再减一遍。
