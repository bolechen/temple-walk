## 读数

- RT60（在各自生成的脉冲上，衰减 60 dB 用时 / T20 外推）：院子 2.85 / 4.18 秒，木构殿 1.57 / 1.69 秒，**T05 大殿 5.09 / 5.04 秒**（SOUND.md §1.1：4–6 秒，提案、未实测）。
- 峰值 −26.1 dBFS（mp3 的 +14 dB 之前）；院子均值 −43 dBFS，殿内 −56 dBFS（进殿后底与风降 16 dB，脚步进长混响）。
- 静音段（0.25 秒窗低于 −70 dBFS、连续 1.5 秒以上）：无。T05 的 Z1 有一层很轻的底，殿内是它的远影，所以没有「全静」；留白在脚步之间与混响尾里。
- T00 十分钟走访（summer-day）：38 个乐句，**乐句日志逐项相同**；峰值 −15.39 对 −15.3 dBFS，三秒以上静音段的起止差在零点几秒内——混响脉冲由 `Math.random` 生成，每次渲染本来就有这点差，不是代码变了。T00 的 `zoneOf`、混响参数与 `AIR` 另由 `tests/unit/t05-sound.test.mjs` 逐点钉住。
- 十分钟的 T00 音频文件（10 MB 以上）超过证据库单文件 1 MB 的限，未上传；它的报告（文本）在上面。
