# T05 牌坊两侧的树：撤掉屋脊后的「两只耳朵」（#482，第五轮，2026-11-21）

T05 主创对 #492 的意见（美术通过后、合并前）：牌坊北面紧挨中轴两侧的两棵树，树冠从 cam07 看顶在牌坊屋脊后面，从无量殿前回望像两只耳朵。改法：牌坊南北各 17 m 以内、离中轴不到 8 m 的地方不立树，单测锁住。判法：cam07 和无量殿前朝南回望这两张图上，牌坊三座楼的屋脊以上只有天。

## 做了什么

- `axis.js`：`ARCHWAY_CLEAR = { z: 17, x: 8 }`、`nearArchway`；树干**或树冠**离中轴不到 8 m 的、在牌坊南北 17 m 内的，不立（只按树干在 8 m 以外还不够：第一版按树干，z = +127 上下一对仍在 cam07 里露在牌坊屋脊旁）。牌坊与内山门之间那一对撤了，高台上原 z = +97 至 +107 的几棵撤了或北移，西三东三的位置重排（z = +81.6、+86.4、+95.2 与 +79.6、+90.3、+94.8），仍不等分、不成对。共 17 棵 → 14 棵。
- 单测 `t05-axis.test.mjs`：①17 m / 8 m 的规则；②在牌坊每一处屋脊之上 4 m 内取点（先向下打射线得屋脊的高，再每 0.4 m、每 0.5 m 高取），从 cam07 的眼与无量殿前的眼连到该点并延到大殿侧与山门侧，没有一条被树干或树冠挡（先只测到牌坊的平面时没抓到屋脊后的树冠，延长后抓到两棵，已北移；把这两棵放回原处则红）。

## 查了什么

`t05-*` 与 `paifang` 单测 43 项全过（含 `t05-cam07` 三条画面条件不变）；`edges`（T05）0 处超限；`nearplane`（T05）13 过、2 跳过、0 失败；walk-diff 对当前 main：命名地点 17 处全到；与上一轮相比只有二层高台「画的」少了的面积由 16.6 降到 12.7 m²（少了几棵树干占地）、旧数据走不到的由 3.65 降到 2.81 m²，其余（内山门 −76.0、山门间 +24.0/−16.9、牌坊 +33.5/−2.5）不变。
