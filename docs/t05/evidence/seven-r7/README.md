## 应该改的三条

- **5 袈裟**：以屏上为准调。cam03 冬不开灯，在袈裟表面取点（`hall.pick` 正面取点、`occlusion` 判可见、读屏上像素）：`#6A3428` 一系屏上色相 10.3°、饱和 0.56；改 `#6E4C3E` 后 **13.5°、0.46**，在 10–14°、0.40–0.50 里。每尊的锚点 `tint` 给袈裟各乘一点（±3–5%），像先后重妆过。朝上的面落灰（`recipe.dust`，往壁画底 `#8A7A66` 混 0.35，按法线朝上的程度）。衣褶深处压暗、棱上磨薄这两样没做。
- **6 衣缘暗金**：七尊都有，沿掩码的边连续一道（G 通道），`#9A7A3E`。释迦锁骨那道黑线查过：素泥图上同一处也有，是网格颈根的一道褶，不是漆，没动。
- **7 零星漏色**：按新掩码重画后，释迦腹前右端露肤已没有；手指尖那几处没有逐一核。
