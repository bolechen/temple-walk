# #701 下唇下的圆垫：先试上色（2026-11-25）

只动 `tools/t05-hall/`（锚点、一行 `paint.js`、T4 的配置）；`app/`、网格、Blender、Tripo 没碰。用的网格是**当前的 r3（60k，未修开口边）**，哈希见 `mesh-sha256.txt`；`lipAt` 是按这批网格点的，**网格换版本（修脸会话改 `repair.py` 导出之后哈希会变）要重点一次**。

## 发现

拘留孙、毗舍浮、拘那含牟尼三尊的 `mouth` 锚点落在下唇下的圆垫上，比雕出的唇低 0.16–0.20 m，唇贴花又比别的尊高一倍（`lipH` 0.098–0.1，别的尊 0.044–0.056），所以圆垫上画了一个深红的椭圆，读成张开的口；真正的唇在它上面，是肤色。毗婆尸、尸弃、迦叶的锚点在唇上，所以没这个毛病。

## 做法

在 faceFrom10 的图上点三尊的唇角和上下唇中缝，用 `pixelPoint` 取在像的坐标里的位置（自拟，r3 形），新加 `lipAt`（贴花中心）、`lipHalf`、`lipH` 0.045；`mouth` 不动（别处还在用它）；圆垫本来就在肤色区里，没有另画。`paint.js` 的 `faceUniforms` 读 `lipAt`，没有 `lipAt` 的尊同前。**没做**：「下唇比上唇浅半档」、不压暗下唇与圆垫之间的凹（贴花不再落到那里，所以那道凹没有被画深）。

## 照实写

- 数是在软件渲染里量的；T4 只出图，没有量数（`t05-hall-gpu.cjs` 的 `shots` 不带分区图）。
- 读不读成张口、圆垫读不读成「闭着的厚唇和圆颏」，是美术总监按图判；我只看到 T4 的图上深色的口没有了，唇画在唇上，没有判美术。
- 佛前 4 米的图里，拘那含牟尼和毗舍浮举起的手的前臂上有一条浅色的肤色带压在袖上（`front4-kanakamuni`、`front4-visvabhu`）：不是这一轮的改动，是原来肤色区的前臂胶囊，**没修**，报给主创。
