## 量法

- `measure-fill.py`：用页面自己的镜头（`frames.json`，在页面里读的 `__frame()`）把世界坐标里的点和面投到图上，取 13×13（1280×720 下）的 L* 均值，面取包围框里的线性亮度均值。
- 图先缩到 1280×720 再量。
- `tune.cjs` 是在软件渲染里试强度和朝向用的；它要一个临时钩子 `window.__fills`，那个钩子从不提交。
- 软件渲染和 T4 的数相差在 0.1 L* 以内。
