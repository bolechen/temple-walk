# #701 第五轮：L2 的折叠三角形（3D 评审 2026-11-25T12:51）

`collage.jpg`：每尊两行（旧 L2 / 新），三列正面、侧面、访客眼高仰看；软件渲染只看形。

## 1. 折叠三角形：不是 lowerback 造的，是 `facex`；原件没有

指标（评审的）：同一份点序下，三角形几何法线与改前的夹角 > 90°（点积 < 0）。用 `REPAIR_DUMP`（`repair.py` 新增：每个操作之前存一份点）逐操作数拘留孙 L2 对原件：

- squeeze 之后 2 个（r3c 本来就有，莲座那一带，与评审说的莲座底 y=0.024 的 2 个面同一处）；
- **`facex`（下脸 ×0.95 横向变窄）之后 127（+120）**，之后每个操作都不再增加，**`lowerback` 0**。
- 原因：`facex` 用「`co[:,1] < front`」硬阶跃：平面一侧的点变窄、另一侧不变，跨过平面那 4 mm 厚的一层，从脸颊到脸颊，曲面翻过去了——与评审量到的位置（z 4 mm 一层、横跨脸宽）一致。
- 修：`repair.py` 的 `facex` 横向宽度与前平面都改成 smoothstep（`fx` 0.02、`ffade` 0.012，文件单位，默认值）。**毗婆尸 r8A 的配方也走这个操作，它的 12 个操作版本同样受影响**（我没重出它）。
- 拘留孙修后 0 个。毗舍浮 2、拘那含牟尼 3（量到原件 0）：在 `lowerback` 里，下颌边缘渐出处几个毫米的三角形（x≈0.29，高 6.3 m，边 1–1 cm）被推松后翻了。`lowerback` 现在遇到翻面就把那里的位移减半、并在六圈邻点内渐回全量，直到没有；第一次只减一圈，在毗舍浮、拘那含牟尼下巴边留下了小凹点，改成六圈后看图没有了。

## 4. L2 体积为什么比 r3c 大

评审量到 L2 比 r3c 大 0.000133 / 0.000150（单位³，闭合最大块），我这边是 +0.000135（拘留孙）。逐操作（`REPAIR_DUMP`，按有符号体积，换成立方厘米是 立方单位 × 8.4531³ m³ × 10⁶）：

- **倾斜 +110,241 cm³**：绕颈转头，渐变段（`fade` 内，头与颈之间）被剪切拉伸，体积不守恒，是这一项让 L2 比 r3c 大；
- `lowerback` −4,429、`depthk` −13,892、`facex` −12,037、`attenuate` −1,690、`scale` +3,154（均为体积变化，单位 cm³，量级 0.1 m³ 以内）。
- 只倾斜基线：拘留孙 0.120732，r3c 0.120549，L2 0.120684：**L2 比只倾斜小 0.000048（−29,000 cm³），比 r3c 大 0.000135**。评审的单位是「立方单位」，写成了 cm³，差 10⁶ 倍以上；真的往外长的是倾斜，不是 lowerback。

## 6. 眼角的放射细纹（美术总监看到拘留孙、毗舍浮 L2 比 r3c 重）

**定位到烘焙，不是倾斜，也不是 lowerback。**

- `lowerback` 在嘴缝线以上位移为 0：`repair.py` 现在把「嘴缝线以上最大位移」写进日志，`face-gate` 读它（`lowerback: largest move above the slit line`，限 0.01 mm），三尊 0.0 mm，闸 14/14 全过。三尊 L2 重跑了一遍，哈希与上一轮完全相同（可复现）。
- 倾斜是整头刚性转 10°，不会生出线。
- `eyes-krakucchanda.jpg`：拘留孙全分辨率（148 万面）的眼部，三格：r3c、只倾斜、L2，同一灯同一机位。**眼睑边缘那圈锯齿状的细毛（和眼角的细纹）在 r3c 的全分辨率几何里就有**，只倾斜和 L2 里同样有，三格几乎一样。
- r3c 的 6 万面档没有烘法线，几何被减面磨平，所以 r3c 的图上没有这些；L2 的 6 万面档带 2048² 的法线贴图，把原件的这圈细毛烘进去，所以读起来重。来源是 Tripo 原件自己的细节，烘焙把它带回来了。
- 我没有在三维引擎里直接比 L2 烘好的头与 r3c，只比了全分辨率几何；「烘进去了」是据此的推断，没有量法线贴图本身（头的 UV 岛分散，我没把眼区对到贴图上）。
- 另：脸上除 `lowerback` 外的其他操作（眉心 `attenuate` 的平滑半径 0.6 m 在内，嘴 `scale` 的深度半径 2.3 倍嘴宽）相对只倾斜基线在眼、鼻区也有位移（我量到眉心那一个在眼区最大约 22 mm；量的盒子取在未倾斜的眼高，略高于眼睑，没有重量）。这些是 f2 配方的东西，不是这一轮加的。

**可做（等你和美术定，没做）**：在全分辨率上先把眼睑边缘的细毛压平再烘（`attenuate`，眼角半径约 2 cm，k 约 0.4），或只在眼区把法线贴图的强度调低。要注意：上色的睑线按这条边画，压平后要核对。
