# T05「画的能站、旧数据走不到」的那些格子（#446，PR #464）

2026-11-21，头提交 `e0eccf6`（已含 #457 的 `2a02690`）。`walk-diff` 报告里「画的地面能站、写好的平面走不到」合计 38.1 m²（main 上是 5.2 m²，#435 的基准上是 3.1 m²）。逐格查过，分两类，都是**旧平面比画出来的地面窄**，没有一格是该关而没关的：

| 位置 | m² | 原因 |
|---|---|---|
| 内山门、外山门穿堂两侧，|x| < 2.7 | 15.2（内 7.5、外 7.7） | 写好的平面里次间的墙从面上板门的内缘起算，把整个进深都按那个宽度挡了（`gates.js` `sides()` 的 `planked`：宽度减去 0.25 + 0.2 + 身宽）；画的地面在门屋里是整个中间一间，一直到次间的板墙。站上去看过：`views/inner-gate-flank-E.png`（朝东，板墙在眼前，脚下是石板）、`views/inner-gate-flank-S.png`（朝南，左边是板门的内缘，门缝在面上）。`edges:grid` 在这些格子上 0 处超限，所以身体进不了任何东西 |
| 台阶两颊与树干，其余各处 | 22.9 | 写好的平面用「比物件大一个身宽」的方块（0.38 m），格子地面用他自己的轮廓在物件高度处量，差 3–25 cm 的一圈，沿物件的脚下。按位置逐块看过：大殿前踏步两颊（z = 14–20，#435 的基准里已有，3.1 m²）；外山门、内山门、无量殿的踏步颊（z = 202–212、124、58）；树干（x = ±5.5，每根约 0.15 m²，甬道与高台共 24 根）。没有别的块超过 0.25 m² |

`views/walk-diff-vs-main.png` 是本分支对 main 的可走图。数是 `tools/walk-diff.mjs` 对 main 与本分支各自烘焙的 `t05.bin` 所得，再按位置分类（`oldReached` 为假、画的为开）。没有用 `__walkviz`，用的是站上去的第一人称图。

结论写进 PR：旧平面漏掉的地，不关。写好的平面在第六步删除，旧数据窄不挡。
