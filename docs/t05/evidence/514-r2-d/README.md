# #514 释迦与愿印 第二轮 (d)：局部重新网格化试了一版，没成（2026-11-21）

T05 主创定了第 2 条路：腕到膝这一带局部体素重建，再投回原表面。只给一版，止损线是：背面不到 0，或形明显变软，就停下报数，不再自己开新修法。**这一版没过，已经停下。**构建仍是第 81 版（`../514-r2-c/`），这条路的代码和参数留在仓库里，作为记录。

## 做法

`tools/blender/varada-remesh.py`，参数在 `varada.json` 的 `remesh_trial`。在第 81 版的几何上跑，跑之前去掉了它的内衬、扇形封口和补块。步骤：

1. **取范围**：框 x −2.12..−1.36、y 3.45..3.72、z 1.15..1.75，再往外放 1.5 cm 作为体素的范围。框里的面每半个体素采一个点，手的面也算，这样封口能接到手上。
2. **做实体**：离点 3 mm 以内的体素算实体（体素 1.5 mm）。再先胀后缩 12 mm（闭运算），宽 24 mm 以内的缝就填上了。
3. **出面**：用 marching cubes 出一个闭合的面，再用 Blender 的体素重建按 1.5 mm 重排成四边形，最后三角化。
4. **只留外层**：只留朝外一侧对着框外空气的面。框外的空气取「框前面那一面大半开向的那块空气」，占前面 53%。
5. **投回原表面**：每个点贴到原表面最近点。下面没有原表面的点（填上的缝）往里退 3 mm。
6. **换面**：去掉框里原来的面（手除外），换成新面里盖在这些面上的部分，新面的边贴到洞的边上。

## 为什么没成（我的判断）

- **体内的空气没和框外分开**：
  - 宽过 24 mm 的口子，加上前臂这根管子，让身体里面的空气连到了框外的空气。
  - 于是实体内外两层都被当成「朝外」留了下来，新面里 25.8 万个点下面没有原表面，面数也翻了上去。
- **6 万面减面把这一带拆坏了**：
  - 全分辨率的新面本身没有非流形边，可 205 万面减到 6 万面以后，腕后成了一片带细纹的黑口。
  - 背面视线比第 81 版多得多，近景从 0 涨到 401。
- **投回原表面和贴边**都会把整齐的四边形拉扁，细长三角形就是这样来的。

要让这条路走通，至少还得做三件事：
- 用可靠的里外判定（不靠空气连通）；
- 重建区和其余部分分开减面，或者重建区不减；
- 接缝用沿洞边的拉链式三角化。

照止损线，这些我都没有再做。
