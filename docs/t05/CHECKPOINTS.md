# T05 观察页设计

核对日期：2026-11-17。本文从**关卡设计**角度列 T05 的观察点，并把「真实访客在奉国寺做什么」与「这座殿真正独特的东西」分开。
不是所有能看的都要做成页；第一版只做三页，其余是静观。

---

## 0. 先定三条原则

1. **观察不是收集。** 不做「集齐三页才算通关」，不做进度条、不做「恭喜获得」。每一页只是纸上多一道墨；走完可以一页都没有。
2. **不做求财、求姻缘、算命、许愿。** 七佛不是七个许愿位；不做「七种人格/七种能力/七个愿望」。不做「数佛」换签。
3. **不碰文物。** 不触摸佛像/佛坛/壁画/彩画/碑刻；不上佛坛；不敲钟；不拓碑；不烧香；不闪光。所有观察都是「看、听、站、走、记」。
4. **宗教分寸（顾问评审 2026-11-20，`ADVISOR-REVIEW.md` 第 7 条）。** 自由静观为主，礼敬（合掌）可选；用自然的栏界控制与佛坛的距离；不攀坐、不碰触造像，礼佛不换奖励，不做造像的惊吓效果。上线前请熟悉汉传寺院礼仪的人看一次实机走动（`PRD.md` §9 第 9 条）。

---

## 1. 两种观察

| 类型 | 做什么 | 例子 | 适合 T05 吗 |
|---|---|---|---|
| 观察型 | 站住、看、比较，然后在纸上记一笔 | 看台基、看手印、看梁架 | **主**：与「记录者的观察页」一致，安静 |
| 行为型 | 做一件与地点相称的事 | 走完六站、在中央站住 | **辅**：少量，不夸张 |
| 仪式型 | 上香、拜佛、诵经、供灯 | — | **不做**：T05 不是法会，也不碰宗教仪式 |

T05 的定位是「先验证看与走」，所以**观察型为主，行为型只保留「走到/站住」**。

## 2. 六站与三页

### 2.1 六站

| 站 | 位置（x,z） | 看什么 | 对应页 |
|---|---|---|---|
| C01 院落远望 | (0,+55) | 九间、单檐庑殿、青灰瓦、3 米台基、月台 | P1 整体 |
| C02 台基 | (0,+17) | 踏道、台基高度、檐柱/斗拱、门洞的暗 | P1 整体 |
| C03 殿门中央 | (0,+0.6) | 门框、中央三尊、佛坛、背光、梁架 | P2 人物 |
| C04 侧向观看 | (+19,−8) | 七佛侧面/手印、14 胁侍、2 天王、侧壁壁画 | P2 人物 |
| C05 仰视梁架 | (0,−12) | 彻上明造、八缝梁架、斗拱、彩画 | P3 梁架 |
| C06 回到中央 | (0,−2) | 中央四至五尊、佛坛、背光 | 收束 |

### 2.2 三页

| 页 | 名称 | 完成条件 | 纸上留下什么 |
|---|---|---|---|
| P1 | 整体 | 在 C01 站住看立面 ≥3 秒；在 C02 抬头看屋檐/屋脊（pitch ≥25°）≥2 秒 | 一道横墨 + 「九间，单檐庑殿，青灰瓦。台基比人高。」 |
| P2 | 人物 | 在 C03 看中央佛 ≥3 秒；在 C04 看过 ≥3 尊不同的佛 + ≥2 尊胁侍（视线命中/角度判定） | 七个小点 + 「东边第一尊是迦叶，西边最后是释迦。中间是毗婆尸。」 |
| P3 | 梁架 | 在 C05 抬头（pitch ≥40°）≥3 秒，并沿梁架方向走 ≥3 米 | 一道斜墨 + 「没有天花。梁架全露在外面。彩画在梁上。」 |

- 三页可以按任意顺序完成；不做「还差几页」的提示。
  - **所有者 2026-11-26 指定两句例外**（#770）：殿门关着时，走到门前说一句「门还关着。」（每次走近一次）；C01 满足而 C02 未满足时，底部说一句「走到檐下，抬头看看。」（只一次，不计数、不说还差什么）。除这两句外仍不提示。
- 完成一页：一声极轻的纸/笔声（合成），不弹「成就」。
- 三页都完成：C06 的收束句变长；一页都没有：C06 说「今天只是走了一趟」。
- 不做评分、不做排名、不做「全收集」奖励。

### 2.3 为什么是这三页

- **整体**：T05 的第一印象是「大」，但「大」不是一张脸；它是九间、台基、屋顶的总和。让玩家先把「大」记下来。
- **人物**：七佛不是一排复制品；手印、袈裟、胸衣、头向都不同。让玩家在侧面发现「他们不一样」。
- **梁架**：彻上明造是 T05 与 T00/T01 最不一样的地方；抬头是这一关的高潮。
- 三页对应资料库 T05 的「整体、人物、梁架三张观察页」。

## 3. 五处静观（可选，不落页）

| 编号 | 位置 | 触发 | 一句话 | 备注 |
|---|---|---|---|---|
| Q1 | C02 踏道 | 低头看石级 ≥2 秒 | 「这一级的石色浅些，边角也齐整。」 | 修补/补石；不指定哪一级 |
| Q2 | C03 门槛 | 看门槛/门钉 ≥2 秒 | 「门槛中间被磨亮了。」 | 脚步的痕迹 |
| Q3 | C04 侧向 | 先后看两尊佛的手 ≥2 秒 | 「东边第一尊的手放在膝上，中间那尊的手抬到胸前。」 | 禅定印 vs 说法印；不解释教义 |
| Q4 | C04 侧向 | 看一对胁侍 ≥2 秒 | 「两尊胁侍，一尊抬头，一尊低头。」 | 姿态差异；不命名 |
| Q5 | C05 梁架 | 看一根梁上的彩画 ≥2 秒 | 「梁上有一个飞天，衣带还看得清。」 | 飞天/网目纹；不描具体粉本 |

- 静观不落页、不计数；只是纸条上的一句。
- 可以重复触发，但不重复计数；不做「五处全看」成就。
- 雪后变体：Q1 的句子改成「雪化了，石级边缘是湿的。」；Q2 改成「门槛上有一点雪水。」

## 4. 触发与反馈（技术）

### 4.1 触发

| 类型 | 做法 | 复用 |
|---|---|---|
| 站住看 | 位置圆 + 视线夹角 + 持续 2–3 秒 | `walker` 位置、相机朝向；`__probe` |
| 抬头 | pitch 阈值 + 持续 2–3 秒 | 相机 pitch |
| 比较两尊 | 射线命中不同的佛像/胁侍 + 时间窗 | `__pick` / raycast |
| 沿梁架走 | 在内槽下沿 z 方向移动 ≥3 米 | `walker` 位置 |
| 读碑/匾 | 近距 + 朝向 + `pickFloor` 命中 | T00 的交互/卡牌（第一版不做） |

抄碑（#728）抄的是元大德七年碑。所有者 2026-11-25 发来金明昌三年《大奉国寺续装两洞贤圣题名记》的近照（双龙碑首、篆额「大奉国寺」、四周回纹边框、龟趺，碑文可读）：照片版权未知，只作内部参考，不进仓库；若改抄这通碑，先核录文（原文出处、校本）再定，不凭照片认字（`SOURCES.md` §17）。

### 4.2 纸与反馈

- 观察页的纸、笔触、墨痕复用 `paper.js` / `ui.css` 的纸本风格；**不要**用 T00 的朱印（红印是 T00 的语法）。
- 每页落笔：一声极轻的笔触/纸声（合成），不弹「成就」。
- 三页可以是一张折页（左中右），也可以是三张竖纸条；最终看界面评审。
- 收束句按已完成的页数变化；不做评分。

### 4.3 季节与时辰

- 三页与五处静观全年可做，不依赖天气。
- 雪后只改句子，不改触发。
- 不做「必须某个时辰才能进」的门槛。

### 4.4 性能与内容量

- 三页：一张折页 + 3 段短句；不需要复杂动画。
- 五处静观：5 句短句；不需要额外模型。
- 不做 NPC、对话树、任务标记。
- 不做「七佛收集」；七佛是空间内容，不是收集品。

### 4.5 隐私与无障碍

- 不询问年龄/生日/性别；不存任何个人数据。
- 不做计时、不做连点、不做必须跳/跑的动作；六站可以慢慢走。
- 所有文字四语；纸上的字用可读字号；颜色之外还有形状/位置区分。
- 可以跳过任何一页；收束不惩罚。
- 不做「必须看全七尊」；看不全才是 T05 的真实。

## 5. 不做清单（及原因）

- **七佛 = 七种人格/七种能力/七个愿望**：旅游文案，不是佛教像设；不做。
- **求财/求姻缘/求健康**：不做；不承诺现世结果。
- **数佛/数罗汉换签**：T05 没有罗汉堂；不做。
- **触摸佛像/佛坛/壁画/彩画/碑刻**：文物保护；不做。
- **上佛坛/绕到佛坛背后**：第一版不做；不做「取宝」。
- **敲钟/敲鼓/烧香/点烛**：殿内禁火；不做。
- **拓碑/拓摩崖**：专业行为；不做。
- **闪光灯/快门声**：殿内禁止；不做。
- **战斗/射击/追逐**：T05 不是动作游戏；不做。
- **收集七佛/七件法器/七个印章**：不做收集；观察页不是收集。
- **「七佛同堂 = 七个祝福」**：不做。
- **2025 年修缮的脚手架/围挡**：游戏标明「非今日实况」；不做。
