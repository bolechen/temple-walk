- **量的法子**：眼在踏道上 1.6 m，用 `__look` 朝前方踏面看；踏道（头 z = 15.4、高 3.0，脚 z = 21.18、高 0；17 级，run 5.78）取下段、中段、上段三处，每处**往上看、往下看**各一张（踢面朝前、踏面朝上，只从一面量不算）；每张画 `crest` = 1、0.25、0（有时 0.5、0.15），取每行中位亮度的差（`crest` 减 0）的最大值，和有差的那些行的亮度。

  - 往下看：加 **12–15 L***，带 L* 85–91（`crest` 0 时 74–85，踏面本来就被晒亮）。
  - 所以连成了。（远一点的 cam02 整道踏道上看不出来：亮 2 L* 以上的像素只有 0.2%，最长连续 37 / 630；近看才连。）

## 6. 教训

### 6.1 开口壳拼成的扫描件，要先修成闭合体，才轮得到体素重建或 Blender（#514，2026-11-22）

- 释迦像是 Tripo 出的，由许多开口的壳拼成：前臂原来压在袍上，没有底面。
- 第二轮把整条右臂往前移了 0.3 m，前臂底面就沿两侧、沿悬在膝前的腕下全部敞开了。
- 之后试过的修法都只封住了查过的那几处，没查过的地方照样漏：
  - 内衬、补块、扇形封口（第 81 版）；
  - 局部体素重建（`docs/t05/evidence/514-r2-d/`）；
  - 补褶，先挂裙片、再改成横跨底面的一片（`514-r2-e/`）。
- 体素重建失败的直接原因：身体里面的空气经开口连到了外面。实体内外两层都被当成朝外留下，减到 6 万面后腕后又被拆坏。
- 以后对这类件，先把要动的部分修成闭合体，再移位、重建或补形。闭合指每条边恰好两个面，内外可判。
- 判「封好没有」，用所有能站的位置的视线去打背面，不能只看几张验收机位：西侧廊那处就是这样查漏、后来才冒出来的。
- 而且要先量**原件**在同样视线下有多少背面。在西侧廊最近能站的点（供台西端外，离手约 3.2 m）往上看，原件本身就有 147 / 1681 条视线打到袍底的背面；在这个点要求 0，等于要求改原件。
