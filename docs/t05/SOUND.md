# T05 声音设计调研

核对日期：2026-11-17。T00/T01 的音频全部是 Web Audio 合成，没有录音；T05 默认沿用这条路线。
本文先写「现场有什么声」，再写「哪些能合成、哪些必须录、哪些不用」。

---

## 1. 三层声场

| 层 | 位置 | 主导声 | 次要声 | 不该有的 |
|---|---|---|---|---|
| Z1 院外/院子 | 无量殿与月台之间、寺院南侧 | 县城低声、远处车流、风过院树、麻雀/喜鹊 | 脚步、衣料、远处说话（不可辨） | 深山的风声、竹林、瀑布、旅游广播 |
| Z2 门洞/台基 | 踏道、月台、门槛 | 风被门洞压低、砖/石脚步、衣料、门轴 | 殿内混响从门里溢出、香炉轻响 | 突然的静音、电子音效、夸张的“吱呀” |
| Z3 殿内 | 佛坛前、侧廊、梁架下 | **非常长的混响**、脚步之间的间隔、呼吸、衣料 | 极远的鸟/风、木构轻微收缩、香灰落下 | 持续配乐、诵经采样、游客谈话、闪光灯声 |

### 1.1 声压与距离（提案，需现场测）

- 院外：约 45–55 dB(A)（县城，非主干道）；进殿后降到 30–35；佛坛前更静。
- 殿内混响：RT60 约 **4–6 秒**（48×25×16 米的硬地面/木梁架/厚墙）；比 T00 的庭院/木构更长。
- 门洞是「滤波器」：外院的高频被墙/门压低，低频还在；进殿后，外院声变成一层很远的底。
- 殿内不是绝对静音：有风、鸟、木构、自己的呼吸；但**没有持续声源**。

### 1.2 时间

- 上午：鸟多、人少、光低；院外车流少；殿内最静。
- 中午：院外声上升；殿内仍静。
- 下午：风起、树声；光斜；殿内更暗。
- 傍晚：院外下班车流；殿内几乎没有光；第一版不做夜游。
- 雪后：所有声音变闷；脚步变低；院外车流更远。

## 2. 现场录音清单（若做）

> 前提：取得寺院/景区/文保单位许可；不录可辨识的游客谈话；不使用无人机；不在殿内使用闪光灯/快门声。

每个点 60–90 秒，同一天、同一设备、写明天气/时段/朝向/事件：

1. 寺院南侧/东街，朝山门。
2. 无量殿前院子，朝大雄殿。
3. 月台踏道下，朝门洞。
4. 门槛外，朝殿内。
5. 殿内中轴，朝佛坛。
6. 殿内东侧，朝西/朝北。
7. 殿内内槽下，朝梁架（只录环境，不录人）。
8. 月台东侧钟亭外（不敲钟）。
9. 月台西侧碑亭外。
10. 单独录：砖/石脚步、门槛、门轴、衣料、呼吸、香灰、风过门洞、麻雀/喜鹊（不辨种）。

**每条记录**：文件名、时间、地点、朝向、设备、天气、许可、SHA-256。
**不做**：敲钟、敲鼓、诵经、游客访谈、无人机、殿内闪光。

## 3. 合成方案（默认路线）

T00 的 `audio.js` 有三条总线（音乐、山声、音效）、两套混响（庭院、木构殿内）、`instruments.js` 的琴/箫/泛音/钟/鼓。T05 新增：

| 声 | 合成做法 | 复用 |
|---|---|---|
| 院外县城 | 粉红噪声 + 低通 150–300 Hz + 缓慢 LFO；远处车流用随机带通扫频 | 新 |
| 风过院树 | 噪声 + 带通随时间移动 + 稀疏叶簇颗粒 | T00 `trees` 声可改 |
| 鸟 | 复用 `bird()`，只放在院外/门洞，白天 | 复用 |
| 砖/石脚步 | 复用 `steps.js`；新增「干砖」「干石」「门槛」「雪后闷响」四种 | 复用 + 新 |
| 门轴 | 摩擦噪声 + 低频谐振；稀疏、短 | 新 |
| 殿内长混响 | 4–6 秒 IR（生成，不录）；比 T00 的庭院/木构更长 | 新 |
| 衣料/呼吸 | 极轻的噪声包络；只在静止/观察时出现 | 新 |
| 木构收缩 | 极稀疏的木质「嗒」；不要做成恐怖屋 | 新 |
| 香灰落下 | 极轻的沙沙；只在香炉附近 | 新 |
| 钟/鼓 | 复用 T00 `bell()` / 鼓；T05 第一版**不敲**，只在远处偶发 | 复用（克制） |

**原则**：

- 院外是「底」，不是「事件」；不要每隔几秒来一辆车。
- 门洞是「滤」，不是「静音」；进门后外院声还在，只是远了。
- 殿内是「空」，不是「满」；留白最多；脚步之间的间隔是内容。
- 木构/香灰是「点」，不是「循环」；稀疏到几乎听不见。

### 3.1 与 T00/T01 的差异

| T00 | T01 | T05 |
|---|---|---|
| 竹林风、竹击、龙井滴水、檐下滴水 | 城市低频、车流、地铁、放生池水、塔铃 | 县城低声、门洞滤波、大殿长混响 |
| 墙内只有钟磬 | 墙内仍有极远城市底噪 | 殿内几乎无外声；只有风/鸟/木构 |
| 山顶回望是群山 | 塔下回望是城市屋顶 | 回到中央，听到的是自己的脚步 |

## 4. 配乐

> 资料库 T05 没有要求配乐；T01 的经验是「首轮可无配乐」，先采环境声。T05 建议**默认无配乐**，把空间留给脚步与混响。

### 4.1 可选方案（若所有者要）

- **调式**：仍可用 G 羽；主题更短（3–5 音），更「空」，像殿内的回声。
- **乐器**：琴、箫；不加鼓/钟/电子低频。
- **出现位置**：只在「进门」和「回到中央」两处，各一小段；不循环。
- **与脚步的关系**：音乐在脚步之下；不盖过混响。
- **结尾**：停在 D 或 G 的泛音，不回家；与「看不全七尊」的收束一致。

### 4.2 不要做

- 不要用诵经/佛号采样，除非取得授权；T05 的殿内是安静的，不是法会。
- 不要用「庄严低音鼓/史诗弦乐」；T05 不是预告片。
- 不要让音乐盖过脚步/混响/院外声；T00 的经验是音乐在场景之下。
- 不要用钟声当循环背景；钟是事件，不是环境。

## 5. 与 T00 音频代码的对应

| T00 | T05 用法 |
|---|---|
| `audio.js` 三条总线 | 直接可用；院外声放「山声」，脚步/门轴放「音效」，音乐可选 |
| 两套混响 | 庭院混响用于院外/门洞；新增「大殿长混响」4–6 秒 |

| `tools/music.mjs` | 可离线渲染 T05 的十分钟走访（若做音乐） |
| `__listen` / `__music` | 测试钩子沿用 |

## 6. 验收

- [ ] 院外能听见县城低声；进门后变闷；殿内只剩很远的底。
- [ ] 殿内混响明显比院外长；脚步之间有间隔。
- [ ] 三层声场切换不爆音、不突然静音。
- [ ] 音乐（若有）不盖过脚步、混响、院外声。
- [ ] 殿内有留白，不是一直有声音。
- [ ] 没有可辨识的游客谈话/诵经/佛号（除非取得授权）。
- [ ] 没有木构「恐怖屋」式的随机吱呀；木构声稀疏到几乎听不见。
- [ ] 雪后变体的脚步变闷、院外声更远。

**注意**：自动测试只能证明「不削波、按规则切换、频率对」，不能证明「好听」。T05 的音频最终要真人试听，最好在耳机与手机外放各听一次。

## 7. 一句话给声音

**T05 的主角是「脚步之间的空」。** 院外是低的，门洞是闷的，殿内是长的；不要用音乐填满它。七佛不说话，空间说话。

## 7. 先行版的实现（2026-11-25）

第一阶段只做了 Z1、Z3 两层与混响切换，没有旋律：`app/levels/t05/level.js` 的 `zones.layers.hall` 给大殿壳的内壁范围，`score.js` 的 `layerOf` 按他站的位置判 `yard`/`hall`（T05 的殿是月台上的壳，不是院下的房间，`inside` 永远为假）；`audio.js` 里 `room()` 在 `hall` 层改送大殿自己的长混响（`HALL_VERB`，脉冲 7 秒，实测衰减 60 dB 用 5.1 秒，落在 §1.1 的 4–6 秒内，仍是提案、未现场测），风与门内的空气滤波（`AIR`）沿用 T00；Z1 另有一层很轻的底（`BED`，150–300 Hz 取 220 Hz，时钟上的慢正弦起伏，没有随机、没有车流扫频与鸟，进殿后随空气层降 16 dB）。数字的来源级别与哪些是自拟，见 `docs/t00/SOURCES.md` 末尾那一行；证据与读数在 `docs/t05/evidence/sound-layers/`（`node tools/t05-sound.mjs` 渲出）。Z2（门洞）这一版不单做；脚步的干砖/干石/门槛三种、门轴、木构收缩、香灰、县城车流与鸟都还没做。
