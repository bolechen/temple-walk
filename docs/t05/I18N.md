# T05 语言与命名

核对日期：2026-11-17。T00/T01 的规则照旧：**中文是记录文本**，日/英/韩由中文查表；新增文字四种语言齐全，字体重新裁切。
本文只写 T05 新增的术语、命名与翻译陷阱。

## 1. 语言范围

- 汉语（简）：记录文本；所有界面、对白、说明先写中文。
- 日语、英语、韩语：由 `app/locales/{ja,en,ko}.js` 按中文查表；T05 的关卡文字放 `app/levels/t05/locales/`。
- 测试与工具固定 `zh-CN`；`lang` 场景与 `mobile-audit --lang=ja|en|ko` 看另外三种。
- 每个分析事件带 `lang`（`withLang`）。

## 2. 命名政策

### 2.1 寺名

- **已定（2026-11-20）：T05 的寺名是「奉明寺」，英文 Fengming Temple**（所有者：「就用奉明寺」；理由见 `DECISIONS.md` 同日条）。T00 用虚构寺名「云径禅寺」（英文 Yunjing Temple）；T01 暂名「栖岚寺」。
- **各语言的写法放在哪里（#738）：** `app/levels/t05/locales/ja.js`、`en.js`、`ko.js` 里的 `"奉明寺"` 一条（ja 奉明寺、en Fengming Temple、ko 봉명사），由 `Level.name` 经 `Level.tr`（`levelSay`）读出，留影卡、存图名、分享标题与标签页都取它。不放进 `app/locales/`（生产包整份带它，而生产包不带「奉明」）；也不写在 `level.js` 里：`pnpm run check` 把 `level.js` 里的字符对着中文字体查，只有关卡自己的 `locales` 表才对着该语言自己的字体查。
- 2026-11-17 本包原以「寂明寺」为主、「奉明寺」为备选；寂明的英文与南京鸡鸣寺（Jiming Temple）同音，这条顾虑随改名不再成立。
- **未进行重名或商标检索。** 上线前需检索「奉明寺」「Fengming Temple」是否与现有寺院/品牌冲突；「Fengming」与「凤鸣寺」拼音相同。
- 若虚构：
  - 匾额、印章、标题都用「奉明寺」；不出现「奉国寺」四字作为本寺名。
  - 年表、殿名可以取意，但不能写「奉国寺始建于……」，要写「本关取意辽宁义县奉国寺」。
  - 说明牌可以出现「奉国寺」作为原型，但必须与「奉明寺」区分；两名只差一字，说明牌上的写法要让人一眼看出哪个是原型、哪个是游戏里的寺（例如「本关取意辽宁义县奉国寺」）。
- 若用真名：
  - 需要寺院/景区/文保单位许可；匾额书法不能描乾隆/刘钟麟原迹；年表与殿名要逐条核。
  - 游戏内要注明「场景为原创演绎，非实测复原」。

**翻译陷阱**：

- **过去七佛 ≠ Seven Past Buddhas**。英文用 **Seven Buddhas of the Past**；「Past Buddhas」听起来像「过去的七位已故佛」，且容易被误读为「七佛药师」。
- **七佛 ≠ 七佛药师**。过去七佛是毗婆尸等七位；七佛药师是药师七佛，另一套系统。不要混用名号/图像。
- **迦叶佛 ≠ 大迦叶**。迦叶佛是过去佛之一（Kāśyapa Buddha）；大迦叶是释迦的弟子（Mahākāśyapa）。英文要写全。
- **辽 ≠ 辽宁 ≠ 辽河**。Liao dynasty / Liaoning province / Liao River 三件事；不要写「Liao dynasty (Liaoning)」当同义词。
- **义县 ≠ Yixian County**。英文用 Yi County；Yixian 是拼音，不加 County 会重复。
- **奉国寺 ≠ Fengguo Si**。英文用 Fengguo Temple；首次出现可注「Fengguo Si」。
- **大雄殿 ≠ 大雄宝殿**。奉国寺的殿名是「大雄殿」；英文都是 Mahavira Hall，但中文不能写成「宝殿」。
- **胁侍 ≠ disciple/attendant**。英文用 attendant bodhisattva；不要写成「two disciples」。
- **彩画 ≠ 壁画 ≠ fresco**。彩画在梁架/斗拱上；壁画在墙上；fresco 是湿壁画，不是中国建筑彩画。
- **减柱造 ≠ fewer columns**。英文用 column-reduction construction；首次出现给注释。
- **彻上明造 ≠ open ceiling**。英文用 exposed-beam ceiling；强调「没有天花，梁架全露」。
- **庑殿顶 ≠ hip-and-gable**。hip roof 是庑殿；hip-and-gable 是歇山。T05 是庑殿。
- **七铺作 ≠ seven-step bracket**。英文用 seven-ply bracket set；puzuo 是铺作，不是「step」。
- **奉明寺 ≠ 奉国寺**。两名只差一字；英文 Fengming 与 Fengguo 也近。游戏里的寺一律写奉明寺，奉国寺只在「取意」的说明里出现。
- **无量殿／天王殿是同一座**。不要在同一段里当成两栋建筑。
- **咸熙寺→奉国寺是同一座寺**。不要当成两座寺。

## 6. 不翻译的东西

- 匾额文字（奉明寺、大雄殿、法轮天地、慈润河山等）。
- 碑文、诗、楹联原文。
- 博物馆来源行、作者名、版权行。
- 寺名/地名的罗马字（可在括号里给读音）。
- 七佛的名号：中文用「毗婆尸」等；日/英/韩可在括号里给梵名/拉丁名，但不改写中文名号。
