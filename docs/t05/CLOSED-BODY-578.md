### 最小改动方案（只是建议，没有动手；先请主创和 3D 评审定）

背面既然都在加的几何上，办法是**不再加「里层」，把前臂切口自己封成一层**：
1. 在 `varada.py` 搬臂之后，把前臂切口的边环（臂的新底面与袍之间的开口）按边环**只补一层面**（Blender `bmesh.ops.holes_fill` / `triangulate_fill`，或 `grid_fill`，朝外），不再加内衬、双面扇形和四块补块；
2. 补出来的面压平后与前臂表面相切，补的边环两侧不动（区外位移 <1 mm，量法沿用 `varada-check3.py` 的 `elsewhere`）；
3. 每改一步跑 `topology.py`（一块、朝向一致、无 ≤10 面碎屑，开口边 ≤ f1 的 204）和 `backfaces.py`/`raycompare.py`（f1 的 0 为线）；
4. 面数目标 ≤ 原件的 110%（第 81 版是 102.2%，去掉内衬和扇形只会减）。
风险（照实说）：边环很长（框内 94 m 是内衬和扇形的边，不是原切口的长度），原切口的真实边环要先找；腕后角本来「三个面凑不拢」，补面可能出尖，要在白盒殿同机位图上看。
