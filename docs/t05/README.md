## 先给结论

1. **T05 的骨架不是「七尊大佛」，而是「殿比眼睛宽」。** 大雄殿面阔九间、通面阔约 47.8–48.2 米，七佛横列在中央七间、跨度约 38 米；人在殿内用 44–50° 的镜头，一次只能看三到五尊。所谓「七佛同堂」，不是一张画面，而是走、停、转身之后在头脑里拼起来的秩序。这正好接住资料库给 T05 的题眼：「从一尊像，看到整座殿的秩序。」
2. **七佛不是按经典次第排的，差别就是内容。** 殿内自东向西为：迦叶、拘留孙、尸弃、毗婆尸（居中）、毗舍浮、拘那含牟尼、释迦牟尼。三尊「庄严劫」佛在中央，四尊「贤劫」佛分列两侧；手印各不同，释迦在最西端、头略向西、右手与愿印。不要把七尊做成七份复制品，也不要把它们解释成「七种人格／七种能力」。
3. **大雄殿是辽代原构，其余多是清代与当代。** 1020 年始建，单檐五脊庑殿顶，青灰瓦；台基高约 3 米，月台约 37×15 米；减柱造，内柱 20 根、檐柱 28 根；七铺作双抄双下昂，材广 28 厘米、厚 20 厘米；彻上明造，梁架彩画约 2444 平方米；壁画约 534 平方米。山门、牌坊、无量殿、钟亭、碑亭都是清代或更晚。
4. **1020 年可靠，「为萧太后建家庙」是推证。** 元大德七年（1303）碑明写「开泰九年处士焦希赟创其基」；「辽圣宗为母萧绰所建」是学界与媒体长期采用的解释，但辽代直接文献没有这一句。写年表时两说并存，不把推证写成敕建明文。
5. **公开空间数据只够做骨架。** OSM 只有 4 栋建筑（寺院范围、大雄殿、无量殿、一栋不明建筑）；SRTM 30 米格网在 66–75 米之间，几乎读不出台基。白盒可以用「实测尺寸 + 标注清楚的复原」，但不能假装有测绘。
6. **美术方向是「赭红、暗金、矿物绿、深梁架」，光是「入口漫射天光」。** 殿外亮、殿内暗，南门与四窗是唯一的光源；佛像的脸靠门光与地面反弹读出来，越往北越暗。不是金色大厅，不是琉璃瓦，不是满堂亮。
7. **馆藏只用四件辽代造像，且都不是奉国寺旧藏。** 克利夫兰的观音、文殊、驮象，纽约大都会的毗卢遮那，全部 CC0／公有领域；它们只说明「辽代同一时期的造像工艺」，不冒充寺藏。七佛、胁侍、天王、彩画、壁画全部原创，不用寺方照片。

## 怎么读本包的标记

- **【原文】**：本包写作时实际打开了页面并读了正文。
- **【PDF】**：下载 PDF 并用文本层抽取（故宫博物院院刊 2012 年论文）。
- **【摘要】**：只读到搜索引擎摘要或别人转述，没有打开原文。引用前要再核。
- **【API】**：结构化数据（OSM Overpass、Nominatim、SRTM），按字段读。
- **【照片】**：只读现场照片的描述或搜索结果，不把它当测绘。
- **【推算】**：由 OSM 轮廓、SRTM 高程或公开数字算出来的，可能有数米或数度误差。
- **【设计提案】**：我们自己的取舍，不是奉国寺的事实。可以改，改了不算篡改历史。
- **【未核】**：资料互相矛盾或没有一手来源，开发时不得当作定论。

## 三条纪律

1. **不把参考照片当实机证据。** 六机位截图、行走录像、帧耗必须来自 T05 自己的页面与白盒。
2. **不把推证写成史实。** 「为萧太后建家庙」「七佛象征辽七帝」「七佛手印是一个连续动作」都要标「通说／一说／推断」，不写成辽代明文。
3. **不把奉国寺的照片、彩画、壁画、三维扫描直接搬进游戏。** 它们适合做研究与配色参考；要进游戏，先按 `ASSETS.md` 的许可规则逐张核。七佛与胁侍是原创雕塑，不是复制品。

## 本轮最重要的七个「不要」

1. 不要把 T00 的宋式重檐大殿直接刷成赭红当 T05；T05 是辽代单檐庑殿、九间、青灰瓦。
2. 不要把七佛做成七份同样的坐佛；手印、袈裟、胸衣纹样、头向、高度都不同。
3. 不要把「过去七佛」解释成「七种人格／七种能力／七个愿望」；那是民间附会，不是佛教像设。
4. 不要把迦叶佛写成释迦的弟子大迦叶；两者不是一位。
5. 不要用「七佛药师」的图像或名号替代「过去七佛」；这是两套系统。
6. 不要把殿内做成平顶或藻井；大雄殿是彻上明造，梁架全部外露。
7. 不要用寺方照片、彩画壁画照片、梁思成测绘图或任何未授权三维扫描；馆藏只用 CC0／公有领域的四件辽代造像。
