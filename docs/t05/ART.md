# T05 美术方向与六个机位

核对日期：2026-11-17。本文不是最终美术定稿，是把「奉国寺这块地长什么样」翻译成可执行的光、色、构图与验收口径。
通用原则以 [`../ART-SPEC.md`](../ART-SPEC.md) 为准；本包按资料库给 T05 的四个词——**赭红、暗金、矿物绿、深梁架**——展开，并对照 F01「入口漫射天光」。

---

## 1. 一句话方向

**「七佛同堂，殿门一线天光」**：院子里是北方初冬的亮，台基把殿抬高三米，门洞是一条窄的暗；走进殿内，眼睛要两三秒才适应，七尊佛的脸从暗里一尊一尊出来；抬头，梁架和彩画在更暗的高处；回到中央，看不全七尊，但知道了它们的秩序。

与 T00/T01 的差别：

| 维度 | T00 云径禅寺 | T01 宝通寺 | T05 奉国寺 |
|---|---|---|---|
| 主色 | 白墙、深木、灰瓦、竹绿 | 黄墙、琥珀瓦、赭红塔 | **赭红、暗金、矿物绿、深梁架**、青灰瓦 |
| 光 | 阴天雨后的柔光 | B01 秋雾 / 冬晴 | **F01 入口漫射天光**；殿内暗、门光亮 |
| 远景 | 五峰、云海、竹林 | 城市屋顶线、塔 | 县城低屋、院墙、青灰瓦 |
| 近景 | 竹、柳杉、石阶 | 黄墙、石狮、菜薹田 | 3 米台基、踏道、板门、门钉 |
| 情绪 | 出世、静 | 入世中的静 | 被尺度压住，再被秩序安放 |
| 季节 | 夏昼（J01） | 冬晴／秋末雨后 | **初冬晴冷**（J01）；雪后（J02） |

## 2. F01「入口漫射天光」

### 2.1 资料库原页与读取限制

资料库把 T05 的入口光命名为 **F01「入口漫射天光」**。本轮原页返回 **HTTP 401**，未能读到它的数值/参考图；本包按名称、T01 已记录的 B01/B02 光线纪律，以及奉国寺大雄殿的实际采光条件（南面三门四窗、厚墙、彻上明造）转译。以下带「【设计提案】」的数值是我们的取舍，不是资料库的原始数值。

### 2.2 转译后的光模型【设计提案】

| 项 | 做法 |
|---|---|
| 主光 | 南面门洞与四窗的**天空漫射**；没有直射阳光落在佛像上 |
| 补光 | 地面/台基的反弹光，色温中性偏暖；越靠北越弱 |
| 光比 | 殿外 : 殿内 ≈ 8:1–16:1（约 3–4 EV）；门口最亮，佛坛最暗 |
| 佛像面部 | 约殿外天空的 1/8–1/16；靠门光 + 地面反弹读出；不是舞台追光 |
| 梁架 | 比佛像更暗半档到一档；彩画在暗处仍可辨色，不死黑 |
| 色温 | 室外冷白（约 6500–7500K 的阴天/雪天感）；室内反弹偏暖（约 4500–5000K） |
| 雾/霾 | 院外可有薄霾；殿内无雾、无雪、无花瓣 |
| 局部光 | 可加一盏极弱的 altar lamp（约 1800–2200K），只为可读性；标为设计补光 |
| 全局滤镜 | 不做橙色滤镜；暖色只来自材料/反弹/灯火 |

### 2.3 为什么是「入口」而不是「殿内布光」

- 大雄殿的墙是厚墙，正面只有三门四窗；殿内没有大面积侧光。
- 七佛 8–9 米高，脸在 8 米以上；门光从下往上照，脸的下部亮、上部暗，正好是「低头看人」的感觉。
- 如果做成满堂亮，七佛会变成一排展品；如果做成死黑，梁架和壁画就看不见。F01 的难点是**在暗里保住可读性**。

**纪律**：

- 暖色必须来自可信的光或材料，不做全局橙色滤镜。
- 低饱和不等于灰片；门洞、佛像面部、梁架彩画、壁画都要看得清。
- 赭红不是一整片均匀的红：墙脚返潮、门钉磨亮、柱脚磕碰、雨痕要有位置。
- 青灰瓦不是一块灰：瓦垄、瓦当、雨痕、雪线要有层次。
- 暗金不是金色大厅：只在匾、背光、佛像贴金、供器上；大部分木构是深褐/灰褐。
- 矿物绿不是装饰色：只在彩画/壁画的纹样里，面积小于赭红/深梁架。

### 3.0 建模说明（不进验收问句，游记 S44 转引）

- 鸱尾弯如新月：交 3D 评审、结构评审定形（《营造法式》卷十三只给高八尺，形状是转引未核）；`cam01` 的必看里提一句。
- 须弥座束腰有力士、神兽驮负莲台：成图阶段的细节，白盒不判。
- 进门光线骤暗：只作「外亮内暗」的旁证，见 `docs/ART-LESSONS.md`。

### 3.1 七佛的彩塑（顾问评审 2026-11-20）

原创分区配色，不复原逐尊辽代原色（原色待查，`ADVISOR-REVIEW.md` 第 5 条）：

- **肤色温哑**：不做亮金脸、不做粉白；贴金只在少数部位点用（「暗金」一行的下限）。
- **袈裟赭红**：用上表「赭红」「赭红深」，不做整片大红。
- **内衣低饱和**：矿物绿、褐灰一类，压在袈裟下面不抢。
- **胸衣素面**：首轮不画团花、不画龙纹。
- **光背**：独立建模、首轮统一形制；暗金为主，不做亮金。

色值只是显示色参考，正式值写进 `recipe`，在殿内光照下看图定（`STATUE-PIPELINE.md` §六）。

## 4. 基准季时

### 4.1 白盒阶段

- 中性日光；不做季节、不做调色；先看清九间、台基、门洞、七佛、梁架的比例。
- 用 `?q=high` 或固定质量档，避免 governor 改变画面。

### 4.2 第一版美术对照：T05-J01「初冬晴冷，殿门一线天光」

- 季节/天气：初冬，晴，冷，空气清冽；没有雪，或只有背阴处的一点残雪。
- 时间：上午 9:00–10:30，太阳低，南光照到台基/门槛，不进殿内深处。
- 天光：冷白；阴影偏蓝；院墙/青灰瓦的暗部有细节。
- 地面：干石/干砖；踏道有磨亮的中线；墙脚有返潮。
- 植物：院树落叶，枝干清楚；没有 T00 的竹/柳杉。
- 人：很少；脚步声清楚。
- 为什么选它：低角度南光正好穿过门洞，形成「一线天光」；冷空气让远处屋脊清楚；与 T00 的夏昼、T01 的秋雾都不同。

### 4.3 变体：T05-J02「雪后初晴」

- 青灰瓦上薄雪；台基/月台的白边；殿内更暗，门光更亮；院子的脚步更闷。
- 雪只落在露天；殿内、檐下、月台顶（有顶的部分）没有雪。
- 不做 T00 的深山雪景；T05 的雪是县城里的雪，屋顶/墙头/石阶三层。

### 4.4 不推荐

- 夏昼：与 T00 重复；北方夏天热、湿、光硬，容易把大殿拍成旅游照。
- 秋雾：与 T01 的 B01 重复；T05 需要更冷、更清的光。
- 夜景：奉国寺的夜间照明不是史料；不要做「灯光秀」。

## 5. 六个机位

坐标是局部坐标：原点在大雄殿前檐柱中线与中轴的交点，+x 东、+z 南、y 上；殿内地面 y=0，院落地坪 y=-3.0；`ground_m` 用 SRTM 约 70 米作参考，`eye_m` 是眼高。
详细 JSON 见 `camera-manifest.json`。

### CAM-01 院落远望（A 站）

- 位置：`x=0, z=+44`，院落地坪 `y=-3.0`，眼高 **1.6 m**；`ground_m≈67.0`。（原为 `z=+55`；**主创 11-21 据 Fable 意见改**：55 米处九间只占画面宽六成、上面四成是空天，不是目标图 `refs/t05-cameras-2026-11-21/cam01-courtyard.png` 的距离。现在按九间立面连出檐横向铺满 16:9 画面约八成、屋脊完整来取。）
- 朝向：**yaw 0°（正北），pitch +6°**；fov **50°**（游戏里固定机位用 52°）。
- 竖幅：另设一个更近的机位 `a-tall`，`x=0, z=+30`，pitch +10°，取中间几间从台基脚到屋脊（`ART-SPEC.md`「相机」：竖幅另设机位，不裁横幅）。
- 画面：下三分之一是院子/踏道，中景是 3 米台基、九间立面、三门四窗、三块竖匾，远景是单檐庑殿顶与青灰瓦；月台东西的钟亭/碑亭在边缘。
- 必须看到：九间、单檐五脊庑殿、青灰瓦、3 米台基、月台、三门四窗、钟亭/碑亭的剪影。
- 不能出现：重檐、琉璃瓦、七间、T00/T01 的殿式、塔/城市天际线抢主体。
- 笔记：这是「先感到大，但看不清里面」的一站；屋脊不要被树/旗杆切断。

### CAM-02 台基（B 站）

- 位置：`x=0, z=+27`，院落地坪 `y=-3.0`，眼高 **1.6 m**；`ground_m≈67.0`。（原写 `z=+17`，但那里落在踏道上；白盒一度把 B 站放到月台上 z = +14.4，站高 +3，台基就到了脚下，「被台基压住」这一站没了。**主创 11-21 据 Fable 意见改**：先放回踏道脚下 z = +22.5、仰 18°，实拍下半截全是踏步，檐柱和门洞被月台矮墙挡掉；再退到 z = +27、仰 14°。）
- 朝向：**yaw 0°，pitch +14°**；fov **50°**。
- 画面：近景是踏道的石级/垂带，中景是 3 米台基的侧面、月台边缘、檐柱与斗拱，远景是门洞的暗；屋脊出画。
- 必须看到：3 米台基的高度、踏道、月台边缘、檐柱/斗拱、门洞的暗。
- 不能出现：整座屋顶、悬空的台基、1 米以下的台明、把台基做成 T00 的薄台。
- 笔记：这一站要让人「被台基压住」；镜头不要抬高到看见屋脊。

### CAM-03 殿门中央（C 站）

- 位置：`x=0, z=+0.6`，月台/殿内地面 `y=0`，眼高 **1.6 m**；`ground_m≈70.0`。
- 朝向：**yaw 0°，pitch +8°**；fov **50°**。
- 画面：门框在左右边缘，中央三尊佛 + 胁侍 + 佛坛 + 背光 + 梁架；光从背后（南）来，佛像面部半亮半暗。
- 必须看到：门框、中央三尊、佛坛、背光、梁架、光梯度。
- 不能出现：一张看全七尊、平顶/藻井、七尊相同、舞台追光。
- 笔记：这是「第一尊脸出现」的一站；门框要压住画面，不要退到门外太远。

### CAM-04 侧向观看（D 站）

- 位置：`x=+19.0, z=-8.0`，殿内地面 `y=0`，眼高 **1.6 m**；`ground_m≈70.0`。
- 朝向：**yaw 305°（西北），pitch +5°**；fov **50°**。
- 画面：七佛的侧面/半侧面、手印、袈裟、胸衣；14 胁侍的前后节奏；侧壁壁画；柱列；佛坛的深度。
- 必须看到：七佛侧面/手印差异、14 胁侍、2 天王（至少一尊）、侧壁壁画、柱列。
- 不能出现：佛像背面、把胁侍做成弟子、把壁画做成彩画、把七尊做成一样的侧影。
- 笔记：这一站是「发现他们不一样」；镜头不要正对佛坛，要斜着看。

### CAM-05 仰视梁架（E 站）

- 位置：`x=0, z=-9.0`（原 −12.0；美术总监 2026-11-21 在 #549 定南移 3 米，像头只在画面最下 18%），殿内地面 `y=0`，眼高 **1.6 m**；`ground_m≈70.0`。
- 朝向：**yaw 0°，pitch +80°**（原 +58°、+66°；2026-11-26 美术总监选 b2′，只看梁架）；fov **55°**（页面定机位实际是 52°）。
- 画面：彻上明造、八缝梁架、四椽栿/六椽栿、驼峰、槫、椽、七铺作斗拱、彩画飞天/网目纹/宝相花。
- 必须看到：彻上明造、八缝梁架、四椽栿/六椽栿、驼峰、斗拱、彩画。
- 不能出现：平顶/藻井、清式彩画、裁掉梁头、把梁架做成一片黑。
- 笔记：这一站是「从人的尺度抬头到屋的尺度」；pitch 要够高，但不要把佛像头部切掉太多。

### CAM-06 回到中央（F 站）

- 位置：`x=0, z=-2.0`，殿内地面 `y=0`，眼高 **1.6 m**；`ground_m≈70.0`。
- 朝向：**yaw 0°，pitch +9°**；fov **65°**。
- 画面：中轴、中央四至五尊、佛坛、背光、两侧尽间各一尊的局部；门在身后，光从背后来。
- 必须看到：中轴、中央四至五尊、佛坛、背光、两侧尽间局部。
- 不能出现：声称一张看全七尊、裁掉中央佛头、把七尊做成复制品、把两端硬塞进画面。
- 笔记：这一站是「看不全，但知道了」；如果验收需要全景，用三张拼接/横移，不用一个超广角硬塞。

### 5.1 机位纪律

- 六个机位都要能站人、能走上去；不能悬空/穿墙/穿佛坛。
- 每个机位拍 16:9、4:3、9:16 三种画幅（T00 的 `shots.js` 支持）。
- 每个机位至少拍「基准季时 + 一个备选季时」。
- 机位定稿后写进 `camera-manifest.json`，由 `tools/cameras.mjs` 生成清单。
- 六个机位之外，证据可以加「三张拼接的全景」；但游戏内相机不做拼接。

## 6. 验收口径（看图时问什么）

### 6.1 每张图

- [ ] 主体（殿/门/佛/梁架）是否在三分线或中心，是否被切？
- [ ] 近景/中景/远景是否至少有三层？
- [ ] 阴影里是否看得清梁柱、门洞、佛像面部、通路？
- [ ] 赭红是否有雨痕/返潮/磨亮，而不是一片平涂？
- [ ] 青灰瓦是否有瓦垄/瓦当/雨痕，而不是一块灰？
- [ ] 湿面与干面是否有可解释的区别？
- [ ] 佛像的手印/袈裟/胸衣/头向是否有差异？耳垂是否近肩（游记，转引，S44；并入 #463 神情清单）？
- [ ] 胁侍的冠、持物、手势是否各不相同（仍不起名，§6.3；游记，转引，S44）？
- [ ] 梁架彩画是否在暗处仍可辨色，而不是一团黑？辨得出朱、白、墨，青绿是点缀（游记，转引，S44）？
- [ ] 是否有不属于辽代/奉国寺的器物（日式石灯笼、藏式经幡、清式藻井）？
- [ ] 门洞的光是否「一线」，而不是一片？

### 6.2 整组

- [ ] 六张是否像同一座殿、同一季节、同一天？
- [ ] 是否一眼看出「七佛同堂」而不是「一尊大佛」？
- [ ] 是否感到「殿比眼睛宽」——第六张看不全七尊是否成立？
- [ ] 赭红、暗金、矿物绿、深梁架是否形成可记忆的色组？
- [ ] 与 T00/T01 的六张并排，是否明显是另一座寺？
- [ ] 1948 年的炮弹/右手修补是否只作安静的痕迹，没有变成特效？

## 9. 一句话给美术

**先把「暗」做对，再把「金」放进去。** T05 的庄严不是靠亮，是靠门洞那一线光、七尊从暗里出来的顺序、以及抬头时梁架的黑。赭红、暗金、矿物绿、深梁架是四个音，不是四个滤镜。
