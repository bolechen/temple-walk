# 美术经验（按关卡）

写于 2026-11-21。所有者当天说：「T00 的 art 标准，要沉淀下来经验，同步给 T05 用。」

这一页记每一次「美术暂不通过」学到了什么，一次一行，带 PR 号。判法本身（数、机位、命令）在 [`skills/art-gate/SKILL.md`](../skills/art-gate/SKILL.md)，下面用「判法 N」指它第三节的第 N 条。末节写 T05 怎么用这些判法。

怎么加：这一页只由美术总监写。别的审图把条目发给美术总监（哪个 PR、哪一轮、为什么没过、以后怎么判）。一条经验如果能写成数或机位，同时在 `SKILL.md` 里加或改一条判法；写不成的只留在这里。

## T05 怎么用

T05 的验收口径在 [`t05/ART.md`](t05/ART.md) §6。下表把每条判法对到 §6 的问句上，写明照搬、要改还是不适用。T05 和 T00 有两处根本不同：一是辽构（九间单檐庑殿，斗栱高约柱高的一半，出檐 3.75 米，殿与院子连成一个空间，没有另建的殿内房间）；二是基准季时是初冬晴冷（T05-J01：硬的低角度阳光，门里一线天光），T00 是雨后阴天的软光。

| 判法 | 对到 `t05/ART.md` | 怎么用 | T05 的数或改动 |
|---|---|---|---|
| 1 主体比座先被看到 | §6.1「主体是否…被切」「阴影里是否看得清…佛像面部」；§6.2「一眼看出七佛同堂」 | 照搬（出自 T05） | `cam03` 冬、不开佛前灯：座 = 脸的 0.6–0.7，背板约一半。七尊一起量，不只量释迦 |
| 2 分区落在棱上 | §6.1「手印/袈裟/胸衣/头向是否有差异」；§3.1 | 照搬（出自 T05） | 七尊各对自己的原型图 |
| 3 颜色以屏上为准 | §3 标题「显示色参考，不是材质基色」；§6.2「赭红、暗金、矿物绿、深梁架是否形成可记忆的色组」 | 照搬，数要重量 | 现在的数（袈裟色相 10–14°、内衣 125–145°）是在白盒借的 T00 冬光下量的。T05-J01 的光定下来以后，在 `cam03` 上重量一遍，配方再预偏一次。建筑的赭红、深梁架也这样判：院子里量一次，殿内量一次 |
| 4 阴影里看得清 | §6.1「阴影里是否看得清梁柱、门洞、佛像面部、通路」「梁架彩画是否在暗处仍可辨色，而不是一团黑」 | 照搬，成图的线要高 | 白盒的下限：E 站 L50 ≥ 10，L95 − L05 ≥ 15。目标图 `cam05` 是 L50 21.2、差 37.5、彩度 13.2。成图的线（提案）：E 站 L50 ≥ 16，差 ≥ 28，彩度 ≥ 10，等第一组 T4 成图出来再定 |

| 12 树冠要透 | §6.1「近景/中景/远景是否至少有三层」 | 做法照搬，**数不照搬** | T05 是古柏和松，冠本来就深、密，银杏和柳杉的亮度比不适用。改成：冠的剪影上有见天的缺口，干和大枝读得出，一排树高矮疏密不一样。数等第一个树的 PR 来了再定，新旧并排的做法不变 |

读法：

- 院子（`cam01`）比 T00 的 J01 亮得多（L50 50.6 对 31.8），亮部偏冷（`light_b` −11.2）。殿内四张的 L50 是 16–26，亮部偏暖（`light_b` 15–18）。**外冷内暖、外亮内暗**是这一关的明度结构，成图要守住。
- 殿内四张的彩度（8.8–13.2）不比院子低。暗不等于灰。
- `cam07` 的门框占了画面的两边，所以 L05 很低、彩度低，这张的数只在同一个画框里比。
- 成图的带子（提案，等第一组 T4 成图出来由美术总监定）：每个机位 L50 在目标图的 ±6 以内，L95 在 −8/+4 以内，彩度不低于目标图的四分之三。白盒不判这些数。

### §6 里 T00 没有可借的判法

这几句是 T05 自己的，到成图阶段要立判法：

- 「湿面与干面是否有可解释的区别」：T00 是雨后，到处是湿的。T05 初冬晴冷，是干的，只有背阴处有残雪。要立的是「残雪只在背阴处，朝阳的面是干的」。
- 「是否有不属于辽代/奉国寺的器物」：T00 的对应是 `JINGSHAN.md`「有意没有做的」。T05 照 §6.3 逐条看。
- 「是否感到殿比眼睛宽，第六张看不全七尊是否成立」：`cam06` 上两端的像被画框切掉，是对的，不要为了看全把机位往后拉。
- 「1948 年的炮弹/右手修补是否只作安静的痕迹」：做到那一步时，先定它在哪一个机位上看得见、占画面多大。
